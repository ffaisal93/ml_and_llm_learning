## Question

Build a small similarity search engine over a list of text documents using a bag-of-words representation, written from scratch without scikit-learn or any other vectorizer library. Given a query string, rank the documents by cosine similarity to it and return the best matches.

### What to implement

1. tokenize(text) -&gt; list[str]: split text into tokens.
2. build_vocab(docs) -&gt; dict[str, int]: map each distinct token in a list of documents to an index.
3. vectorize(text, vocab) -&gt; dict[int, int]: the sparse bag-of-words vector of a text, mapping vocabulary index to count.
4. cosine(u, v) -&gt; float: cosine similarity of two sparse vectors.
5. search(query, corpus, k) -&gt; list[tuple[int, float]]: the top k documents of corpus for query, as (document_index, score) pairs.

### Rules

1. Tokenization: convert to lowercase, then a token is a maximal run of the characters a-z and 0-9. Every other character separates tokens. There is no stop-word removal and no stemming.
2. build_vocab assigns indices 0, 1, 2, ... in order of first appearance, reading the documents in order and each document left to right.
3. vectorize uses raw counts (no TF-IDF weighting). A token that is not in the vocabulary is ignored.
4. cosine returns dot(u, v) / (|u| * |v|), or 0.0 when either vector is empty (zero norm).
5. search builds the vocabulary from corpus only, vectorizes the query and every document with it, and scores each document with cosine. Query tokens outside the vocabulary are ignored, so they do not change the query's norm.
6. Scores are rounded to 9 decimal places. The results are sorted by rounded score, highest first; documents with equal rounded score are ordered by lower index first. Documents with score 0.0 are included when fewer than k documents score above zero.
7. Return min(k, len(corpus)) pairs, with the rounded score as the second element; k = 0 returns an empty list.

### Examples

1. tokenize("Hello, World! Hello-2024") returns ["hello", "world", "hello", "2024"]: case is folded and punctuation separates tokens.
2. build_vocab(["b a", "a c"]) returns {"b": 0, "a": 1, "c": 2}, and vectorize("a a c z", vocab) returns {1: 2, 2: 1} because z is not in the vocabulary.
3. search("cat", ["cat sat", "dog", "cat cat dog"], 2) returns [(2, 0.894427191), (0, 0.707106781)]. Document 2 scores 2/sqrt(5), document 0 scores 1/sqrt(2), and document 1 shares no token with the query so it scores 0.0 and falls outside the top 2.
4. search("a", ["a b", "b", "a b"], 3) returns [(0, 0.707106781), (2, 0.707106781), (1, 0.0)]: documents 0 and 2 tie, so the lower index comes first.

### Constraints

Up to 1000 documents of at most 200 tokens each, and 0 &lt;= k &lt;= 1000.
Do not build dense vectors over the whole vocabulary; sparse dictionaries keep a query fast.

## Worked solution

### Build the specified raw-count geometry

Use one corpus vocabulary in first-appearance order, never a query-fitted vocabulary or TF-IDF. Sparse dictionaries store only present terms. A cosine dot product visits the smaller dictionary and its norms include only in-vocabulary tokens. Round **before sorting**, then sort by negative rounded score and document index. Zero-score documents remain eligible.

```python
import math
import re
from collections import Counter


def tokenize(text):
    return re.findall(r'[a-z0-9]+',text.lower())


def build_vocab(docs):
    vocab={}
    for doc in docs:
        for token in tokenize(doc):
            if token not in vocab:
                vocab[token]=len(vocab)
    return vocab


def vectorize(text,vocab):
    return dict(Counter(vocab[t] for t in tokenize(text) if t in vocab))


def cosine(u,v):
    normu=math.sqrt(sum(x*x for x in u.values()))
    normv=math.sqrt(sum(x*x for x in v.values()))
    if not normu or not normv:return 0.0
    if len(u)>len(v):u,v=v,u
    return sum(value*v.get(key,0) for key,value in u.items())/(normu*normv)


def search(query,corpus,k):
    if k<0:raise ValueError('k must be nonnegative')
    if k==0:return []
    vocab=build_vocab(corpus); q=vectorize(query,vocab)
    scores=[(i,round(cosine(q,vectorize(doc,vocab)),9)) for i,doc in enumerate(corpus)]
    return sorted(scores,key=lambda pair:(-pair[1],pair[0]))[:k]

assert tokenize('Hello, World! Hello-2024')==['hello','world','hello','2024']
assert build_vocab(['b a','a c'])=={'b':0,'a':1,'c':2}
assert vectorize('a a c z',{'b':0,'a':1,'c':2})=={1:2,2:1}
assert search('cat',['cat sat','dog','cat cat dog'],2)==[(2,.894427191),(0,.707106781)]
assert search('a',['a b','b','a b'],3)==[(0,.707106781),(2,.707106781),(1,0.)]
assert search('unknown',['a','b'],5)==[(0,0.),(1,0.)]
assert search('',[],1)==[] and search('a',['a'],0)==[]
assert search('cat OOV',['cat sat'],1)==search('cat',['cat sat'],1)
print('W129: tokenization, sparse counts, exact ranking/ties/OOV checks passed')
```

### Why it works and what it costs

A bag-of-words coordinate counts the token at that shared vocabulary index, so the dot product sums matching-term count products. Dividing by both Euclidean lengths removes pure length scaling: “cat cat” and “cat” have cosine 1. Empty/OOV vectors score zero by contract. The supplied “cat” example yields document 2 at .894427191 then document 0 at .707106781, exactly as checked. Punctuation separates, so “a-b” is two tokens and non-ASCII letters are separators after lowercasing under the specified rule.

With M corpus tokens and N documents, vocabulary/vector construction is O(M), score computation visits sparse terms, and final sorting is O(N log N). No dense vocabulary-sized vectors are constructed. Repeated production queries should cache the corpus vocabulary/vectors/norms; this exercise intentionally builds them per call.
