## Question

A 60-minute live Jupyter/notebook session. Load a small per-row JSON dataset: hours_spent_reading_a/b/c (float), current_post_category ("A"/"B"/"C"), and click (binary). Predict whether the user clicks the currently-shown post.

Deliverables
1. Load JSON into pandas and inspect the schema.
2. Quick EDA: distributions, target balance, correlations.
3. Preprocess: one-hot encode the category, train/test split.
4. Train and compare &gt;=2 models (dummy baseline -&gt; logistic regression -&gt; random forest / XGBoost).
5. Justify model choice and pick + defend a metric.

Data is intentionally clean; the round grades modeling judgment. A 2026 variant ships dirty data (missing values, ~20% positive imbalance) and expects imputation + imbalance handling and F1 / PR-AUC over raw accuracy.

## Worked solution

### A leakage-safe notebook workflow

No JSON file is attached. Use `df=pd.read_json(path)` for a JSON array or `pd.read_json(path,lines=True)` for JSONL after confirming the file contract. The runnable function below starts from that DataFrame; its tests generate an explicitly synthetic dataset and make no claim about interview-data scores. Inspect types, numeric quantiles, missingness, category counts, target prevalence and feature/label correlations. Check that reading time is measured before the shown post and that duplicates/users cannot leak across splits; if IDs/time are available, split by user or time instead of random rows.

The model must use both reading history and the currently shown category. One-hot encoding preserves categorical meaning; encoding A/B/C as 0/1/2 invents an ordering. A useful extension is interactions between each category indicator and its matching reading hours, which logistic regression otherwise cannot model automatically. Compare dummy, logistic and random forest under the same splits and transforms. Imputation and scaling are fit inside each training pipeline, never on the whole dataset.

```python
import numpy as np
import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.model_selection import train_test_split
from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import average_precision_score, f1_score, log_loss

FEATURES = ['hours_spent_reading_a', 'hours_spent_reading_b', 'hours_spent_reading_c']

def compare_ctr(df):
    """Return held-out metrics; choose model and threshold ONLY on validation."""
    df = df.copy()
    if not df['click'].isin([0, 1]).all():
        raise ValueError('invalid/missing binary label: quarantine before fitting')
    print(df.dtypes.to_string())
    print(df[FEATURES].describe().to_string())
    print('missing:', df.isna().sum().to_dict(), 'positive rate:', df.click.mean())
    print(df[FEATURES + ['click']].corr().to_string())
    X, y = df[FEATURES + ['current_post_category']], df.click.astype(int)
    Xdev, Xtest, ydev, ytest = train_test_split(X, y, test_size=.2, stratify=y, random_state=42)
    Xtrain, Xval, ytrain, yval = train_test_split(Xdev, ydev, test_size=.25, stratify=ydev, random_state=43)
    models = {'dummy': DummyClassifier(strategy='prior'),
              'logistic': LogisticRegression(max_iter=1000, class_weight='balanced', solver='liblinear'),
              'forest': RandomForestClassifier(n_estimators=100, min_samples_leaf=5, class_weight='balanced', random_state=42)}
    fitted, validation = {}, {}
    for name, estimator in models.items():
        prep = ColumnTransformer([
            ('numeric', Pipeline([('impute', SimpleImputer(strategy='median')), ('scale', StandardScaler())]), FEATURES),
            ('category', Pipeline([('impute', SimpleImputer(strategy='most_frequent')),
                                   ('encode', OneHotEncoder(handle_unknown='ignore'))]), ['current_post_category'])])
        pipe = Pipeline([('preprocess', prep), ('model', estimator)]).fit(Xtrain, ytrain)
        pv = pipe.predict_proba(Xval)[:, 1]
        thresholds = np.linspace(.05, .95, 91)
        threshold = max(thresholds, key=lambda t: f1_score(yval, pv >= t, zero_division=0))
        validation[name] = {'ap': average_precision_score(yval, pv), 'threshold': float(threshold)}
        fitted[name] = pipe
    chosen = max(validation, key=lambda k: validation[k]['ap'])
    p = fitted[chosen].predict_proba(Xtest)[:, 1]
    return {'validation': validation, 'chosen': chosen,
            'test': {'ap': average_precision_score(ytest,p), 'f1': f1_score(ytest,p >= validation[chosen]['threshold']),
                     'log_loss': log_loss(ytest,p)}}
```

For the dirty/20%-positive variant, average precision (a summary of the precision–recall curve) measures rare-positive ranking; dummy AP is near prevalence. Choose model by validation AP, choose an F1 threshold on validation, then evaluate the frozen choice once on test. The code reports test AP, F1 and log loss; class weights can hurt probability calibration, so calibrate on a separate validation fold if accurate CTR probabilities are the product requirement. For a clean balanced variant, log loss is often a better main metric for probability prediction, with calibration and ROC-AUC as secondary checks. Do not select the model or threshold on test accuracy and then call the resulting F1 unbiased.

Small datasets may need cross-validation and uncertainty intervals rather than a brittle 60/20/20 split. If positives are too rare to stratify, report that limitation and collect more labels. The function rejects missing/nonbinary labels rather than imputing the target. Numeric missing values and unknown held-out categories are handled by the preprocessing pipeline. Tests check the complete pipeline and valid metric ranges, not a fabricated fixed winning model.
