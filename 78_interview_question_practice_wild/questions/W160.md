## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Some simulators and embedded systems only offer a uniform random number generator that returns floats in [0, 1). Many models still need noise from a standard normal distribution, with mean 0 and standard deviation 1. Build a sampler that turns uniform draws into one standard normal sample, without any library sampler.

What to implement
uniform() -&gt; float: provided. It returns a float drawn uniformly from [0, 1). It can return exactly 0.0.
sample_gaussian() -&gt; float: return one sample from the standard normal distribution, built only from calls to uniform().
Rules
1.
Use the Box-Muller transform and return its cosine output.
2.
Each call to sample_gaussian() calls uniform() exactly twice. The first value is u1 and the second is u2.
3.
u1 sets the radius and u2 sets the angle.
4.
Use 1 - u1 wherever the transform takes the logarithm of u1. Since 1 - u1 lies in (0, 1], a draw of 0.0 never causes a math domain error.
5.
Do not use numpy.random, random.gauss, random.normalvariate or any other ready-made normal sampler. Only math and uniform() are allowed.
6.
Return a plain Python float. Do not cache the unused sine output between calls.
Examples

Each example fixes the two values that uniform() returns, in order.

Example 1: draws 0.5, 0.0. Output: 1.1774100225154747.

Explanation: 1 - u1 = 0.5 gives radius sqrt(2 ln 2) ≈ 1.17741, and the angle is 0, so the cosine is 1.

Example 2: draws 0.5, 0.5. Output: -1.1774100225154747.

Explanation: the radius is the same as in Example 1, and the angle is half a turn, so the cosine is -1.

Example 3: draws 0.0, 0.3. Output: 0.0.

Explanation: 1 - u1 = 1 and ln 1 = 0, so the radius is 0. The draw of 0.0 is safe because of rule 4.

Example 4: draws 0.75, 0.0. Output: 1.6651092223153954.

Explanation: 1 - u1 = 0.25 gives radius sqrt(2 ln 4) ≈ 1.66511, and the cosine of angle 0 is 1. Taking the logarithm of u1 itself would give 0.75853 instead.

Constraints
Results are compared with a tolerance of 1e-9.
Over many calls with a real uniform(), the samples must have mean close to 0, variance close to 1, and about 68.3% of them inside (-1, 1).
One call must run in O(1) time and space.</pre>

## Worked solution

1. Generate Gaussian noise using only uniform random numbers. The Box–Muller transformation converts two independent uniforms into two independent standard Gaussian draws.
2. Draw U1 in (0,1) and U2 in [0,1), avoiding log(0).
3. Set R=sqrt(-2*log(U1)) and theta=2*pi*U2; return R*cos(theta) and R*sin(theta).
4. For mean mu and standard deviation sigma, transform each z to mu+sigma*z. Test sample moments and distribution shape rather than exact draws.

### Small example / sanity check

With U1=exp(-0.5) and U2=0, the pair is (1,0).

### Common trap

Using the same uniform twice or treating good sample moments alone as proof of independence.
