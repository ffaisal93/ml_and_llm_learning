## Question

Some simulators and embedded systems only offer a uniform random number generator that returns floats in [0, 1). Many models still need noise from a standard normal distribution, with mean 0 and standard deviation 1. Build a sampler that turns uniform draws into one standard normal sample, without any library sampler.

### What to implement

uniform() -&gt; float: provided. It returns a float drawn uniformly from [0, 1). It can return exactly 0.0.
sample_gaussian() -&gt; float: return one sample from the standard normal distribution, built only from calls to uniform().

### Rules

1. Use the Box-Muller transform and return its cosine output.
2. Each call to sample_gaussian() calls uniform() exactly twice. The first value is u1 and the second is u2.
3. u1 sets the radius and u2 sets the angle.
4. Use 1 - u1 wherever the transform takes the logarithm of u1. Since 1 - u1 lies in (0, 1], a draw of 0.0 never causes a math domain error.
5. Do not use numpy.random, random.gauss, random.normalvariate or any other ready-made normal sampler. Only math and uniform() are allowed.
6. Return a plain Python float. Do not cache the unused sine output between calls.

### Examples

Each example fixes the two values that uniform() returns, in order.

Example 1: draws 0.5, 0.0. Output: 1.1774100225154747.

```text
Explanation: 1 - u1 = 0.5 gives radius sqrt(2 ln 2) ≈ 1.17741, and the angle is 0, so the cosine is 1.
```

Example 2: draws 0.5, 0.5. Output: -1.1774100225154747.

Explanation: the radius is the same as in Example 1, and the angle is half a turn, so the cosine is -1.

Example 3: draws 0.0, 0.3. Output: 0.0.

```text
Explanation: 1 - u1 = 1 and ln 1 = 0, so the radius is 0. The draw of 0.0 is safe because of rule 4.
```

Example 4: draws 0.75, 0.0. Output: 1.6651092223153954.

```text
Explanation: 1 - u1 = 0.25 gives radius sqrt(2 ln 4) ≈ 1.66511, and the cosine of angle 0 is 1. Taking the logarithm of u1 itself would give 0.75853 instead.
```

### Constraints

Results are compared with a tolerance of 1e-9.
Over many calls with a real uniform(), the samples must have mean close to 0, variance close to 1, and about 68.3% of them inside (-1, 1).
One call must run in O(1) time and space.

## Worked solution

### Implementation

The order of the two calls and the `1-u1` transformation are part of the contract. Returning both Box–Muller outputs or caching the sine sample would violate it.

```python
import math


# uniform() is supplied by the caller/environment.
def sample_gaussian():
    u1 = uniform()
    u2 = uniform()
    radius = math.sqrt(-2.0 * math.log1p(-u1))
    angle = 2.0 * math.pi * u2
    return float(radius * math.cos(angle))
```

`log1p(-u1)` evaluates exactly the requested mathematical expression log(1-u1), with better numerical accuracy when u1 is tiny. Since 0≤u1<1, 1-u1 is positive, including when u1=0. Each call makes exactly two uniform draws and returns one float in O(1) time and space. There is no rejection sampling, caching or normal-library call. Depending on the cosine sign, zero may display as `-0.0`; it equals 0.0 and satisfies the tolerance.

### Why the distribution is normal

Let V=1-U1. For ideal independent continuous uniforms V is uniform on (0,1], and Θ=2πU2 is independent and uniform on a full circle. For r≥0,

$$P(R\le r)=P(V\ge e^{-r^2/2})=1-e^{-r^2/2},\quad f_R(r)=r e^{-r^2/2}.$$

The polar joint density is r exp(-r²/2)/(2π). Changing coordinates to X=R cosΘ,Y=R sinΘ divides by the Jacobian r, giving exp(-(x²+y²)/2)/(2π). This factors into two standard-normal densities; the cosine output alone is therefore standard normal. Finite-precision uniforms give a discrete approximation with a bounded tail, as any digital sampler does.

### Worked cases and behavior checks

With draws (0.5,0), radius is √(2 ln2) and output 1.1774100225154747. With (0.5,0.5), cosine is -1 and output is the negative of that value. With (0,0.3), radius is zero. With (0.75,0), radius is √(2 ln4)=1.6651092223153954; using log(u1) would produce the wrong answer.

A fake uniform iterator verifies all four outputs to absolute tolerance 1e-9 and exactly two calls each. The linked test also uses a seeded ordinary uniform generator for 200,000 samples and checks broad, predeclared tolerances on mean, variance and the fraction in (-1,1). Those moment checks catch gross distribution errors but are not the mathematical proof above. Test a value immediately below 1 for finite output; exactly 1 is outside the supplied uniform contract.
