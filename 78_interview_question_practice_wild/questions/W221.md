## Question

Given n 1D training points [(x_i, y_i)] for i = 1..n, consider the following piecewise-constant model:

```text
y_hat_i = b1,  if x_i <= t
y_hat_i = b2,  if x_i >  t
```

where t is the threshold (split point), and b1, b2 are constants for the left and right segments.

Your task is to find parameters (b1, b2, t) that minimize the mean squared error (MSE) on the training set:

```python
MSE = (1/n) * sum_i (y_i - y_hat_i)^2
```

### Requirements

Design an algorithm to output an optimal t, b1, and b2 (if multiple optimal solutions exist, output any).
State the time complexity (optimize if possible).
Input format (stdin)
Line 1: integer n
Next n lines: two numbers x_i y_i
Output format (stdout)
Print one line: t b1 b2 (space-separated; floating-point outputs are allowed).

### Constraints

1 &lt;= n &lt;= 2e5
x_i are real numbers or integers (may be unsorted; duplicates allowed)
y_i are real numbers or integers
t can be any real number (note that any t between two consecutive distinct x values yields the same partition)
Sample Tests
Test 1

### Input

```text
5
1 1
2 2
3 2
4 4
5 5
```

Output (one valid example):

```text
3.5 1.6666666667 4.5
```

(left segment {x&lt;=3.5} = {1,2,3} with mean 1.6667, right segment {x&gt;3.5} = {4,5} with mean 4.5, giving the minimum MSE.)

## Worked solution

### Solution outline

After sorting the predictor, every valid split has a left mean and a right mean; prefix sums make evaluation cheap.

1. Sort (x,y) pairs and consider boundaries only between distinct x values if the model uses a threshold on x.
2. Use prefix sums of y and y² to calculate each side's SSE as sum(y²)-sum(y)²/count.
3. Choose the smallest total SSE under a stated tie rule; return a threshold and two fitted means, handling empty or unsplittable data explicitly.

### Understand why the approach works

#### Prefer projections and stable solves to memorized inverses

Least squares finds the projection of the response onto the feature space:

$$
\hat\beta=\arg\min_\beta\|X\beta-y\|_2^2,
\qquad X^\top X\hat\beta=X^\top y.
$$

The normal equations explain the mathematics, but explicitly forming $(X^\top X)^{-1}$ is usually a poor numerical implementation. Squaring the condition number can amplify instability. QR or SVD-based least-squares routines expose rank and near-dependence more reliably.

For two datasets with the same feature definitions, sufficient statistics add:

$$
S=X_1^\top X_1+X_2^\top X_2,\qquad
 t=X_1^\top y_1+X_2^\top y_2.
$$

Solving the pooled problem is not equivalent to averaging the two coefficient vectors. Rows carry different directional information, not only different sample counts.

State centering, intercept and regularization conventions. With ridge, the penalized directions satisfy $(X^\top X+\lambda I)\beta=X^\top y$, but an unpenalized intercept needs separate treatment. Distinguish coefficient identification from predictive usefulness: correlated columns can make individual coefficients unstable while their combined predictions remain fairly stable. Validate forecasts on independent data; impressive training fit, including interpolation of noise, is not evidence of a real predictive relation.

### Work a small example

For y=[1,1,9,9] at increasing x, the middle split yields zero SSE with means 1 and 9.

### Edge cases and common mistakes

Splitting equal x values into different prediction regions when a single threshold cannot reproduce that assignment.
