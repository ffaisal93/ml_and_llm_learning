## Question

Given n 1D training points [(x_i, y_i)] for i = 1..n, consider the following piecewise-constant model:

```text
y_hat_i = b1,  if x_i <= t
y_hat_i = b2,  if x_i >  t
```

where t is the threshold (split point), and b1, b2 are constants for the left and right segments.

Your task is to find parameters (b1, b2, t) that minimize the mean squared error (MSE) on the training set:

```python
MSE = (1/n) * sum_i (y_i - y_hat_i)^2
```

### Requirements

Design an algorithm to output an optimal t, b1, and b2 (if multiple optimal solutions exist, output any).
State the time complexity (optimize if possible).
Input format (stdin)
Line 1: integer n
Next n lines: two numbers x_i y_i
Output format (stdout)
Print one line: t b1 b2 (space-separated; floating-point outputs are allowed).

### Constraints

1 &lt;= n &lt;= 2e5
x_i are real numbers or integers (may be unsorted; duplicates allowed)
y_i are real numbers or integers
t can be any real number (note that any t between two consecutive distinct x values yields the same partition)
Sample Tests
Test 1

### Input

```text
5
1 1
2 2
3 2
4 4
5 5
```

Output (one valid example):

```text
3.5 1.6666666667 4.5
```

(left segment {x&lt;=3.5} = {1,2,3} with mean 1.6667, right segment {x&gt;3.5} = {4,5} with mean 4.5, giving the minimum MSE.)

## Worked solution

### Only distinct x boundaries can split the data

Sort points by x. For a fixed nonempty group, differentiating squared error shows its optimum constant is its mean. If the group's sum is S, size m and squared-sum Q, its SSE is $Q-S^2/m$. Thus minimizing total SSE is equivalent to maximizing $S_L^2/n_L+S_R^2/n_R$; the total squared-sum is constant. Scan prefix sums after whole equal-x groups. Splitting equal x values would violate `x <= t`.

The all-left partition is legal because the statement does not require nonempty segments. It handles n=1 and all x equal; choose arbitrary b2, here the same mean. Return t equal to the last left x rather than a midpoint, avoiding overflow and preserving the partition. Sorting takes $O(n\log n)$, scanning $O(n)$ and storage $O(n)$.

```python
import sys


def fit_two_segments(points):
    if not points:
        raise ValueError("at least one point required")
    points = sorted(points)
    n = len(points)
    total = sum(y for _, y in points)
    # The all-left partition is legal, including n=1/all x equal.
    best_score, best = total * total / n, (points[-1][0], total / n, total / n)
    left = 0.0
    for i, (x, y) in enumerate(points[:-1], 1):
        left += y
        if x == points[i][0]:
            continue
        right = total - left
        score = left * left / i + right * right / (n - i)
        if score > best_score:
            best_score = score
            # x itself avoids midpoint overflow and gives the same partition.
            best = (x, left / i, right / (n - i))
    return best  # t, b1, b2


def piecewise_main():
    data = sys.stdin.buffer
    n = int(data.readline())
    print(
        *fit_two_segments(
            [tuple(map(float, data.readline().split())) for _ in range(n)]
        )
    )
```

Use `piecewise_main()` as the stdin entry point. On the sample, the winning split is after x=3, with t=3, b1=5/3 and b2=4.5; t=3.5 is equivalent. The SSE is 7/6 and MSE is 7/30. Duplicate-x, all-equal, singleton and random exhaustive-split tests are included. Floating-point cancellation can matter for enormous y offsets; center y first or use compensated/high-precision accumulation if that precision requirement is added.
