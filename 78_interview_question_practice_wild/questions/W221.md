## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Given n 1D training points [(x_i, y_i)] for i = 1..n, consider the following piecewise-constant model:

y_hat_i = b1,  if x_i &lt;= t
y_hat_i = b2,  if x_i &gt;  t

where t is the threshold (split point), and b1, b2 are constants for the left and right segments.

Your task is to find parameters (b1, b2, t) that minimize the mean squared error (MSE) on the training set:

MSE = (1/n) * sum_i (y_i - y_hat_i)^2
Requirements
Design an algorithm to output an optimal t, b1, and b2 (if multiple optimal solutions exist, output any).
State the time complexity (optimize if possible).
Input format (stdin)
Line 1: integer n
Next n lines: two numbers x_i y_i
Output format (stdout)
Print one line: t b1 b2 (space-separated; floating-point outputs are allowed).
Constraints
1 &lt;= n &lt;= 2e5
x_i are real numbers or integers (may be unsorted; duplicates allowed)
y_i are real numbers or integers
t can be any real number (note that any t between two consecutive distinct x values yields the same partition)
Sample Tests
Test 1

Input:

5
1 1
2 2
3 2
4 4
5 5

Output (one valid example):

3.5 1.6666666667 4.5

(left segment {x&lt;=3.5} = {1,2,3} with mean 1.6667, right segment {x&gt;3.5} = {4,5} with mean 4.5, giving the minimum MSE.)</pre>

## Worked solution

1. Fit a one-dimensional two-segment constant regressor. After sorting the predictor, every valid split has a left mean and a right mean; prefix sums make evaluation cheap.
2. Sort (x,y) pairs and consider boundaries only between distinct x values if the model uses a threshold on x.
3. Use prefix sums of y and y² to calculate each side's SSE as sum(y²)-sum(y)²/count.
4. Choose the smallest total SSE under a stated tie rule; return a threshold and two fitted means, handling empty or unsplittable data explicitly.

### Small example / sanity check

For y=[1,1,9,9] at increasing x, the middle split yields zero SSE with means 1 and 9.

### Common trap

Splitting equal x values into different prediction regions when a single threshold cannot reproduce that assignment.
