## Question

Implement a simple Dense Layer using Numpy, where you need to implement the forward pass and backward pass, and derive the Sigmoid function.

### Requirements

Write a Python function dense_layer_forward that takes input data matrix X, weight matrix W, and bias vector b, and returns the output matrix Y.
Write a Python function dense_layer_backward that takes the output gradient dY, input data matrix X, weight matrix W, and bias vector b, and returns the input gradient dX, weight gradient dW, and bias gradient db.
Use Sigmoid as the activation function, and provide separate functions sigmoid and sigmoid_derivative.

Provide a complete implementation and several test cases including scenarios for both forward and backward passes. Assume input data are Numpy arrays with compatible dimensions.

Sample Test Case:

X: np.array([[0.5, 0.2]])
W: np.array([[0.3, 0.8], [0.5, 0.2]])
b: np.array([0.1, 0.4])
Output: Appropriate matrix result

Example

### Input

```python
X = np.array([[0.5, 0.2]])
W = np.array([[0.3, 0.8], [0.5, 0.2]])
b = np.array([0.1, 0.4])
```

## Worked solution

### Solution outline

Each parameter receives the sum of contributions from every example that used it.

1. For Y=XW+b with X:(N,D), W:(D,C), let upstream G:(N,C).
2. Compute dX=G@Wᵀ, dW=Xᵀ@G and db=sum(G,axis=0).
3. Do not average again unless the scalar objective's reduction requires it; G may already include the mean factor.

### Understand why the approach works

#### Derive a local rule, then apply the chain rule

Treat a layer as a function with a declared input and output shape. Write the scalar loss and its reduction first: a sum, mean over rows and mean over all elements produce different gradient scales. For an affine layer $Y=XW+b$ with upstream gradient $G=\partial L/\partial Y$,

$$
\frac{\partial L}{\partial X}=GW^\top,\qquad
\frac{\partial L}{\partial W}=X^\top G,\qquad
\frac{\partial L}{\partial b}=\sum_i G_{i,:}.
$$

The bias sum is over all leading positions where the same bias was reused. Do not average again if $G$ already contains the mean-loss factor. For example, with one row $x=[2,3]$ and scalar upstream derivative $4$, the weight derivative is $[8,12]$.

Cache the forward values needed by the derivative; compute all gradients before updating parameters. Updating $W$ midway would make the earlier-layer derivative use a different function from the one evaluated forward.

Check a scalar objective using central differences:

$$
\frac{\partial L}{\partial\theta_j}\approx
\frac{L(\theta+h e_j)-L(\theta-h e_j)}{2h}.
$$

Use float64 and several sensible $h$ values. An arbitrarily tiny $h$ loses the difference to rounding, while a large one measures curvature rather than a local derivative. Avoid ReLU's kink at zero during this check, and test inputs, weights and biases separately.

### Apply this question’s exact contract

If the dense layer includes sigmoid, cache a=sigmoid(XW+b), compute dZ=dY*a*(1-a), then dX=dZ Wᵀ, dW=Xᵀ dZ and db=sum_rows(dZ). Use a stable branchwise sigmoid for large positive/negative logits. If the layer is affine-only, do not introduce this activation derivative; the prompt’s activation contract decides.

### Work a small example

For one example x=[2,3] and scalar upstream 4, the weight gradient is [8,12].

### Edge cases and common mistakes

Summing the bias gradient over features instead of examples or silently transposing the weight convention.
