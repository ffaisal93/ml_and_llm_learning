## Question

Implement a simple Dense Layer using Numpy, where you need to implement the forward pass and backward pass, and derive the Sigmoid function.

### Requirements

Write a Python function dense_layer_forward that takes input data matrix X, weight matrix W, and bias vector b, and returns the output matrix Y.
Write a Python function dense_layer_backward that takes the output gradient dY, input data matrix X, weight matrix W, and bias vector b, and returns the input gradient dX, weight gradient dW, and bias gradient db.
Use Sigmoid as the activation function, and provide separate functions sigmoid and sigmoid_derivative.

Provide a complete implementation and several test cases including scenarios for both forward and backward passes. Assume input data are Numpy arrays with compatible dimensions.

Sample Test Case:

X: np.array([[0.5, 0.2]])
W: np.array([[0.3, 0.8], [0.5, 0.2]])
b: np.array([0.1, 0.4])
Output: Appropriate matrix result

Example

### Input

```python
X = np.array([[0.5, 0.2]])
W = np.array([[0.3, 0.8], [0.5, 0.2]])
b = np.array([0.1, 0.4])
```

## Worked solution

### Differentiate through the sigmoid, not only the affine map

Let $Z=XW+b$ with X:(N,D), W:(D,C), b:(C,), and $Y=\sigma(Z)$. Since $\sigma(z)=1/(1+e^{-z})$, differentiation gives $\sigma'(z)=e^{-z}/(1+e^{-z})^2=\sigma(z)(1-\sigma(z))$. For upstream dY, set $dZ=dY\odot Y\odot(1-Y)$, then $dX=dZW^T$, $dW=X^TdZ$, $db=\sum_i dZ_i$. No extra average is needed because the upstream derivative defines the scalar reduction.

```python
import numpy as np


def sigmoid(z):
    z = np.asarray(z, dtype=np.float64)
    out = np.empty_like(z)
    positive = z >= 0
    out[positive] = 1 / (1 + np.exp(-z[positive]))
    ez = np.exp(z[~positive])
    out[~positive] = ez / (1 + ez)
    return out


def sigmoid_derivative(z):
    s = sigmoid(z)
    return s * (1 - s)


def dense_layer_forward(X, W, b):
    return sigmoid(X @ W + b)


def dense_layer_backward(dY, X, W, b):
    dZ = dY * sigmoid_derivative(X @ W + b)
    return dZ @ W.T, X.T @ dZ, dZ.sum(axis=0)


X = np.array([[0.5, 0.2]])
W = np.array([[0.3, 0.8], [0.5, 0.2]])
b = np.array([0.1, 0.4])
Y = dense_layer_forward(X, W, b)
assert np.allclose(Y, [[0.5866175789, 0.698465216]])
assert np.allclose(sigmoid([-1000, 0, 1000]), [0, 0.5, 1])
rng = np.random.default_rng(2)
X = rng.normal(size=(3, 2))
W = rng.normal(size=(2, 4))
b = rng.normal(size=4)
G = rng.normal(size=(3, 4))
grads = dense_layer_backward(G, X, W, b)
eps = 1e-6
worst = 0.0
for value, grad in zip([X, W, b], grads):
    for index in np.ndindex(value.shape):
        old = value[index]
        value[index] = old + eps
        plus = (dense_layer_forward(X, W, b) * G).sum()
        value[index] = old - eps
        minus = (dense_layer_forward(X, W, b) * G).sum()
        value[index] = old
        error = abs((plus - minus) / (2 * eps) - grad[index])
        worst = max(worst, error)
        assert error < 1e-7
zero = dense_layer_backward(np.zeros_like(G), X, W, b)
assert all(np.all(g == 0) for g in zero)
print(f"W147: forward {Y}; all X/W/b finite differences passed, max error {worst:.2g}")
```

### Worked result and verification

The supplied example has logits `[.35,.84]` and output `[[.586617579,.698465216]]`. A branchwise sigmoid avoids exponential overflow at ±1000. `sigmoid_derivative` accepts logits, not already-sigmoided probabilities; mixing these conventions gives a plausible but wrong gradient.

The tests cover the exact example, saturated/zero logits, all-zero upstream gradient, multi-example bias reduction and independent central differences of X, W and b for scalar objective `sum(forward*G)`. Use float64 and epsilon 1e-6, compare before any parameter update, and keep batch and output-feature axes distinct. Both passes cost O(NDC) and gradients have the corresponding input/parameter shapes.

### Optional PyTorch study counterpart

Keep the required NumPy implementation and derivation above as the primary answer. This optional tensor version uses X:(N,D), W:(D,C), b:(C,), exactly the same orientation and sigmoid activation. sigmoid_derivative_torch accepts **logits**. The manual backward multiplies dY by sigmoid′ before computing dX/dW/db, sums the bias gradient over rows and adds no averaging beyond the supplied upstream gradient. torch.sigmoid handles the ±1000 stability cases.

```python
import math
import torch


def sigmoid_torch(z):
    """W147: stable sigmoid; derivative takes logits, not probabilities."""
    return torch.sigmoid(z)


def sigmoid_derivative_torch(z):
    s = sigmoid_torch(z)
    return s * (1 - s)


def dense_layer_forward_torch(X, W, b):
    """W147: X:(N,D), W:(D,C), b:(C,); return sigmoid(X@W+b)."""
    return sigmoid_torch(X @ W + b)


def dense_layer_backward_torch(dY, X, W, b):
    dZ = dY * sigmoid_derivative_torch(X @ W + b)
    return (dZ @ W.T, X.T @ dZ, dZ.sum(dim=0))
```

A small training/gradient check:

```python
x = torch.tensor([[0.5, 0.2]], dtype=torch.float64, requires_grad=True)
w = torch.tensor([[0.3, 0.8], [0.5, 0.2]], dtype=torch.float64, requires_grad=True)
b = torch.tensor([0.1, 0.4], dtype=torch.float64, requires_grad=True)
y = dense_layer_forward_torch(x, w, b)
dy = torch.ones_like(y)
dx, dw, db = dense_layer_backward_torch(dy, x, w, b)
y.backward(dy)
assert torch.allclose(dx, x.grad)
assert torch.allclose(dw, w.grad) and torch.allclose(db, b.grad)
```
