## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Layer Normalization normalizes each sample independently across its feature dimension, so it does not depend on batch statistics and behaves the same in training and inference. It is the standard normalization layer in Transformers. In this problem you implement its forward and backward passes by hand with NumPy, as you would when writing a small neural-network library without autograd.

What to implement
layernorm_forward(x, gamma, beta, eps=1e-5) -&gt; (out, cache)
layernorm_backward(dout, cache) -&gt; (dx, dgamma, dbeta)
x: float array of shape (N, D), N samples with D features each
gamma: scale, shape (D,)
beta: shift, shape (D,)
eps: small positive constant, default 1e-5
dout: upstream gradient with respect to out, shape (N, D)
cache: any object you choose that holds what the backward pass needs; the caller only passes it back unchanged
Rules
1.
For each row x[i], compute the mean mu and the biased variance var = mean((x[i] - mu)^2) (divide by D, not D - 1).
2.
Normalize: xhat = (x[i] - mu) / sqrt(var + eps). eps is added to the variance inside the square root.
3.
Output: out = xhat * gamma + beta, shape (N, D).
4.
layernorm_backward returns dx with shape (N, D), dgamma with shape (D,) and dbeta with shape (D,), the exact gradients of a loss L whose gradient with respect to out is dout.
5.
Use only NumPy operations and no automatic differentiation. Do not loop over N or D in Python; use vectorized array operations.
6.
The result must stay accurate when all values share a large constant offset (for example x + 1e8), so compute the variance from deviations x - mu, not from mean(x^2) - mu^2.
Examples

Forward, one sample with gamma = [1, 1, 1, 1], beta = [0, 0, 0, 0]:

x   = [[1, 2, 3, 4]]
out ~ [[-1.3416, -0.4472, 0.4472, 1.3416]]

The mean is 2.5 and the biased variance is 1.25, so each deviation is divided by sqrt(1.25 + 1e-5).

Forward, two samples with gamma = [1, 2, 1, 2], beta = [0, 0, 1, 1]:

x   = [[1, 2, 3, 4],
[2, 2, 2, 2]]
out ~ [[-1.3416, -0.8944, 1.4472, 3.6833],
[ 0.0,     0.0,    1.0,    1.0   ]]

The second row is constant, so its normalized values are 0 and only beta remains.

Backward, for the first forward example with dout = [[1, 1, 1, 1]]:

dx     ~ [[0, 0, 0, 0]]
dgamma ~ [-1.3416, -0.4472, 0.4472, 1.3416]
dbeta  =  [1, 1, 1, 1]

A constant upstream gradient on a normalized row cannot change dx, because normalization removes any shift of the row.

Constraints
1 &lt;= N &lt;= 4096, 1 &lt;= D &lt;= 4096
Inputs are float64 arrays; your gradients must agree with a central finite-difference check to about 1e-5.</pre>

## Worked solution

1. Implement LayerNorm forward and backward. Each row is centered and rescaled independently across its features; the backward pass must include the effects of both statistics.
2. Compute mean, centered values, population variance and inv_std=1/sqrt(var+eps). Set xhat=centered*inv_std and out=gamma*xhat+beta.
3. For g=dout*gamma, use dx=inv_std*(g-mean(g)-xhat*mean(g*xhat)), with means over features.
4. Sum dout*xhat and dout over the batch for dgamma and dbeta. Verify with central finite differences in float64.
5. Optimize a tokenizer without changing its semantics. An efficient encoder must preserve the specified tokenization, including tie rules and boundaries.
6. First implement and test a simple reference over small strings and special tokens.
7. For fixed-vocabulary longest matching, consider a trie; for ranked BPE merges, use a representation that updates neighboring merge candidates efficiently.
8. Benchmark normalization, Unicode handling and merge operations separately, comparing exact token ids against the reference.

### Small example / sanity check

A constant row has xhat=0, so its forward output equals beta; epsilon keeps the inverse standard deviation finite.

### Common trap

Using mean(x²)-mean(x)² for large-offset data, or forgetting that epsilon is inside the square root.
