## Question

Layer Normalization normalizes each sample independently across its feature dimension, so it does not depend on batch statistics and behaves the same in training and inference. It is the standard normalization layer in Transformers. In this problem you implement its forward and backward passes by hand with NumPy, as you would when writing a small neural-network library without autograd.

### What to implement

layernorm_forward(x, gamma, beta, eps=1e-5) -&gt; (out, cache)
layernorm_backward(dout, cache) -&gt; (dx, dgamma, dbeta)
x: float array of shape (N, D), N samples with D features each
gamma: scale, shape (D,)
beta: shift, shape (D,)
eps: small positive constant, default 1e-5
dout: upstream gradient with respect to out, shape (N, D)
cache: any object you choose that holds what the backward pass needs; the caller only passes it back unchanged

### Rules

1. For each row x[i], compute the mean mu and the biased variance var = mean((x[i] - mu)^2) (divide by D, not D - 1).
2. Normalize: xhat = (x[i] - mu) / sqrt(var + eps). eps is added to the variance inside the square root.
3. Output: out = xhat * gamma + beta, shape (N, D).
4. layernorm_backward returns dx with shape (N, D), dgamma with shape (D,) and dbeta with shape (D,), the exact gradients of a loss L whose gradient with respect to out is dout.
5. Use only NumPy operations and no automatic differentiation. Do not loop over N or D in Python; use vectorized array operations.
6. The result must stay accurate when all values share a large constant offset (for example x + 1e8), so compute the variance from deviations x - mu, not from mean(x^2) - mu^2.

### Examples

Forward, one sample with gamma = [1, 1, 1, 1], beta = [0, 0, 0, 0]:

```python
x   = [[1, 2, 3, 4]]
```

out ~ [[-1.3416, -0.4472, 0.4472, 1.3416]]

The mean is 2.5 and the biased variance is 1.25, so each deviation is divided by sqrt(1.25 + 1e-5).

Forward, two samples with gamma = [1, 2, 1, 2], beta = [0, 0, 1, 1]:

```python
x   = [[1, 2, 3, 4],
[2, 2, 2, 2]]
```

out ~ [[-1.3416, -0.8944, 1.4472, 3.6833],
[ 0.0,     0.0,    1.0,    1.0   ]]

The second row is constant, so its normalized values are 0 and only beta remains.

Backward, for the first forward example with dout = [[1, 1, 1, 1]]:

dx     ~ [[0, 0, 0, 0]]
dgamma ~ [-1.3416, -0.4472, 0.4472, 1.3416]

```python
dbeta  =  [1, 1, 1, 1]
```

A constant upstream gradient on a normalized row cannot change dx, because normalization removes any shift of the row.

### Constraints

1 &lt;= N &lt;= 4096, 1 &lt;= D &lt;= 4096
Inputs are float64 arrays; your gradients must agree with a central finite-difference check to about 1e-5.

## Worked solution

### Solution outline

#### Implement LayerNorm forward and backward.

Each row is centered and rescaled independently across its features; the backward pass must include the effects of both statistics.

1. Compute mean, centered values, population variance and inv_std=$1/\sqrt{v+\epsilon}$. Set xhat=centered*inv_std and out=gamma*xhat+beta.
2. For g=dout*gamma, use dx=inv_std*(g-mean(g)-xhat*mean(g*xhat)), with means over features.
3. Sum dout*xhat and dout over the batch for dgamma and dbeta. Verify with central finite differences in float64.

#### Compute variance accurately when values have a large common offset.

Avoid subtracting nearly equal large moments when the variance itself is small.

1. For in-memory arrays, subtract the mean first and average squared deviations.
2. For streaming data, use Welford's update for count, mean and centered sum of squares.
3. Choose population or sample variance deliberately and validate with a constant-offset transformation test.

### Understand why the approach works

#### Derive the normalization and its gradient

For row $x_i\in\mathbb R^D$, compute population statistics across **features**, independently of the other rows:

$$
\mu_i=\frac1D\sum_jx_{ij},\quad
v_i=\frac1D\sum_j(x_{ij}-\mu_i)^2,\quad
s_i=(v_i+\epsilon)^{-1/2},\quad
\hat x_{ij}=(x_{ij}-\mu_i)s_i.
$$

Then $y_{ij}=\gamma_j\hat x_{ij}+\beta_j$. The epsilon goes inside the square root. Compute variance from centered deviations, not $E[x^2]-E[x]^2$: the latter subtracts two huge nearly equal numbers when inputs share a large offset.

Let $G_{ij}=\partial L/\partial y_{ij}$ and $U_{ij}=G_{ij}\gamma_j$. The chain rule has three paths: a direct input path, the row mean path and the row variance path. Combining them gives

$$
\frac{\partial L}{\partial x_{ij}}=
 s_i\left(U_{ij}-\overline U_i-
 \hat x_{ij}\,\overline{U_i\hat x_i}\right),
$$

where each overline averages across the $D$ features of that row. The parameter gradients sum over rows:

$$
\frac{\partial L}{\partial\gamma_j}=\sum_iG_{ij}\hat x_{ij},\qquad
\frac{\partial L}{\partial\beta_j}=\sum_iG_{ij}.
$$

For $[1,2,3,4]$, the mean is $2.5$ and variance $1.25$. With unit scale and zero bias, the result is approximately $[-1.3416,-0.4472,0.4472,1.3416]$. A constant row normalizes to zero, so its output equals the bias. Its input derivative is not universally zero: it depends on the upstream pattern and epsilon.

The forward cache stores normalized inputs, inverse standard deviations and scale. Do not mutate these before backward. Validate $x$, $\gamma$ and $\beta$ derivatives independently with float64 central differences; checking only output shape cannot catch omitted statistic paths. Both passes cost $O(ND)$.

### Readable reference implementation

Read the explanation first, then trace one small input through these functions. This is the same implementation used by the local checks; its stated simplifications still apply.

```python
import math
from collections import deque
from dataclasses import dataclass
import numpy as np


def layernorm_forward(x, gamma, beta, eps=1e-5):
    x = np.asarray(x, dtype=np.float64)
    gamma, beta = np.asarray(gamma), np.asarray(beta)
    if x.ndim != 2 or gamma.shape != x.shape[1:] or beta.shape != gamma.shape or eps <= 0:
        raise ValueError("invalid shapes or epsilon")
    centered = x - x.mean(axis=-1, keepdims=True)
    inv = 1 / np.sqrt((centered * centered).mean(axis=-1, keepdims=True) + eps)
    normalized = centered * inv
    return normalized * gamma + beta, (normalized, inv, gamma)


def layernorm_backward(dout, cache):
    normalized, inv, gamma = cache
    dout = np.asarray(dout)
    g = dout * gamma
    dx = inv * (g - g.mean(axis=-1, keepdims=True)
                - normalized * (g * normalized).mean(axis=-1, keepdims=True))
    return dx, (dout * normalized).sum(axis=0), dout.sum(axis=0)
```

### Work a small example

A constant row has xhat=0, so its forward output equals beta; epsilon keeps the inverse standard deviation finite.

### Edge cases and common mistakes

Using mean(x²)-mean(x)² for large-offset data, or forgetting that epsilon is inside the square root.
