## Question

For imbalance data, if you apply down sampling to the training data, should you also down sample the test data?

## Worked solution

### Keep the test population representative

Usually **no**: if you downsample negatives for training, do not downsample the test set simply to match training. The test set should represent deployment prevalence and the population on which you want to make a claim. Split before downsampling, and apply the sampling only to the training partition. Preserve a representative validation set for threshold selection and probability calibration as well.

Suppose production has 1% positives. A model has recall 80% and false-positive rate 5%. Among 10,000 representative cases, expect 80 true positives and 495 false positives, so precision is $80/(80+495)\approx13.9\%$. In an artificially balanced 10,000-case test, the same rates give 4,000 true positives and 250 false positives, so precision appears to be 94.1%. Nothing about the classifier improved; the evaluation population changed.

### Probability calibration also changes

Let $s_1$ and $s_0$ be class-conditional sampling rates and let $q(x)$ be the posterior in sampled training data. If sampling depends only on the class, population odds satisfy

$$\frac{p(x)}{1-p(x)}=\frac{s_0}{s_1}\frac{q(x)}{1-q(x)}.$$

For example, keeping every positive but only one tenth of negatives makes sampled positive odds ten times the population odds. Correct the prior shift or recalibrate on representative data before interpreting scores as deployment probabilities. The formula is not enough when sampling also depends on features within a class.

Downsampling a huge evaluation population can be reasonable for cost, but use a deliberate stratified design, retain sampling probabilities and report weighted population metrics and uncertainty. A separately labeled balanced diagnostic set can help inspect rare errors; it must not masquerade as the production test set. ROC-AUC is less directly dependent on prevalence than precision, but can still change if within-class sampling changes the feature distribution. Choose PR metrics, recall at a fixed false-positive budget and business cost on the intended population.
