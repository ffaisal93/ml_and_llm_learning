## Question

Build a binary text classifier on top of a language model that you can only query through one helper function. You may not use model weights, hidden states, gradients or fine-tuning. The classifier turns the model's next-token probabilities for the two label tokens into a normalized score, a predicted label and a loss.

### What to implement

The helper next_token_probs is passed in as an argument. It maps a token prefix to a dictionary from each possible next token to its probability, P(next_token | tokens):

```python
def next_token_probs(tokens: list[str]) -> dict[str, float]: ...
```

The provided helper tokenize(s: str) -&gt; list[str] splits a string on whitespace.
1. classify_and_score(text, threshold, next_token_probs, l_pos=" yes", l_neg=" no") -&gt; dict
text: the input text x.
threshold: the decision threshold in [0, 1].
next_token_probs: the helper above.
l_pos, l_neg: the two label tokens (each a single token).
2. bce_loss(result, y) -&gt; float
result: the dict returned by classify_and_score.
y: the ground truth, 1 for the positive label and 0 for the negative one.

### Rules

1. Build the prompt string exactly as "Text:
" + text + "

Label:" and tokenize it with tokenize.
2. Call next_token_probs exactly once on those tokens. One call returns the probability of every next token, so it covers both labels. A label missing from the returned dictionary has probability 0.
3. Let p_pos and p_neg be the raw probabilities of l_pos and l_neg, and Z = p_pos + p_neg. Return a dict with exactly these keys:
"p_pos": p_pos / Z
"p_neg": p_neg / Z
"prediction": l_pos if p_pos / Z &gt;= threshold, otherwise l_neg (a tie goes to the positive label).
4. If Z == 0 (neither label token is in the dictionary), return p_pos = p_neg = 0.5, and apply the same threshold rule to 0.5.
5. bce_loss returns -(y * log(p_pos) + (1 - y) * log(p_neg)) using the normalized values in result. Clamp each probability to at least 1e-12 before taking the log so the loss stays finite.

### Examples

1. The stub returns {" yes": 0.6, " no": 0.2, " maybe": 0.2} and threshold = 0.7. Then Z = 0.8, the result is {"p_pos": 0.75, "p_neg": 0.25, "prediction": " yes"}, because 0.75 &gt;= 0.7. With y = 1 the loss is -log(0.75) = 0.2877.
2. The stub returns {" yes": 0.1, " no": 0.3} and threshold = 0.5. Then Z = 0.4, the result is {"p_pos": 0.25, "p_neg": 0.75, "prediction": " no"}, because 0.25 &lt; 0.5. With y = 1 the loss is -log(0.25) = 1.3863.
3. The stub returns {" other": 1.0}. Then Z = 0, so both normalized probabilities fall back to 0.5. With threshold = 0.5 the result is {"p_pos": 0.5, "p_neg": 0.5, "prediction": " yes"}, because 0.5 &gt;= 0.5 and a tie goes to the positive label.

### Constraints

0 &lt;= threshold &lt;= 1; every probability is in [0, 1].
Use only the helper; no other model access.

## Worked solution

### Condition on the two permitted labels

The score is $P(l_{pos}\mid l_{pos}\text{ or }l_{neg},\text{prompt})$, so unrelated token mass cancels. Preserve the literal leading spaces in the label dictionary keys; they are not prompt tokens produced by the whitespace tokenizer. The all-zero case is the specified fallback, not an inference about model confidence.

```python
import math


def tokenize(s):
    return s.split()


def classify_and_score(text, threshold, next_token_probs, l_pos=" yes", l_neg=" no"):
    if not 0 <= threshold <= 1:
        raise ValueError("threshold must be in [0, 1]")
    if l_pos == l_neg:
        raise ValueError("labels must differ")
    tokens = tokenize("Text:\n" + text + "\n\nLabel:")
    probabilities = next_token_probs(tokens)  # Exactly one model query.
    pos = probabilities.get(l_pos, 0.0)
    neg = probabilities.get(l_neg, 0.0)
    total = pos + neg
    pos, neg = (pos / total, neg / total) if total else (0.5, 0.5)
    return {
        "p_pos": pos,
        "p_neg": neg,
        "prediction": l_pos if pos >= threshold else l_neg,
    }


def bce_loss(result, y):
    if y not in (0, 1):
        raise ValueError("binary target required")
    return -(
        y * math.log(max(result["p_pos"], 1e-12))
        + (1 - y) * math.log(max(result["p_neg"], 1e-12))
    )


def check():
    calls = []

    def stub(tokens):
        calls.append(tokens)
        return {" yes": 0.6, " no": 0.2, " maybe": 0.2}

    r = classify_and_score("a good film", 0.7, stub)
    assert calls == [["Text:", "a", "good", "film", "Label:"]]
    assert set(r) == {"p_pos", "p_neg", "prediction"}
    assert math.isclose(r["p_pos"], 0.75) and r["prediction"] == " yes"
    assert math.isclose(bce_loss(r, 1), -math.log(0.75))
    r = classify_and_score("x", 0.5, lambda _: {" yes": 0.1, " no": 0.3})
    assert r["prediction"] == " no" and math.isclose(bce_loss(r, 1), -math.log(0.25))
    r = classify_and_score("x", 0.5, lambda _: {"other": 1.0})
    assert r == {"p_pos": 0.5, "p_neg": 0.5, "prediction": " yes"}
    assert classify_and_score("x", 0.6, lambda _: {})["prediction"] == " no"
    assert classify_and_score("x", 0, lambda _: {" no": 1.0})["prediction"] == " yes"
    assert math.isfinite(bce_loss({"p_pos": 0, "p_neg": 1}, 1))
    print("W107: all behavior checks passed")


if __name__ == "__main__":
    check()
```

For the three question stubs the positive probabilities are .75, .25, and .5; the positive-target losses are .287682, 1.386294 and .693147. The explicit check also verifies the exact prompt tokens, the single helper call, the three-key contract, missing labels, clamped loss and the threshold endpoints. At threshold zero even a zero positive score selects the positive label, exactly as the specified >= rule requires. Neither weights nor hidden states are accessed.

Run `python3 ../review_w107_implementation.py` from this directory. Runtime is one helper call plus linear prompt tokenization; auxiliary classifier storage is constant apart from the prompt and helper output.
