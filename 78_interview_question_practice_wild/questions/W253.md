## Question

You are given an N-ary tree where each node is a separate server. Each node can only talk to its parent and its children. Communication is asynchronous; messages may arrive late, out of order, be duplicated, or be lost. Write the per-node logic so the tree can count its total number of nodes, with only the root printing the final total.

Interface (you cannot change send_async; treat it as a black box):

```text
class Message:
def __init__(self, kind, request_id, payload): ...
class Node:
def __init__(self, node_id, parent_id, children): ...
def send_async(self, to_node_id, message): ...  # provided
def call(self, from_node_id, message): ...       # you implement
```

The interview has three parts: (1) basic counting assuming perfect delivery, (2) handling duplicate messages, (3) handling lost messages (packet loss). Leaf nodes reply 1; internal nodes send request_count to all children, wait for all replies, then reply 1 + sum(child_counts) to their parent; the root prints the total.

## Worked solution

### Protocol and runnable per-node logic

The topology is a fixed rooted tree for one request; node IDs and request IDs are unique and only neighbors communicate. A request_id identifies one logical traversal. Every node stores replies by child ID rather than incrementing a count for every arriving message. Once all children have replied, its total is one plus their sums. Only the root prints, once per request. Leaves have no outstanding children and immediately return one.

The complete implementation follows; `send_async` remains the provided black-box transport. The host runtime calls `retry_pending()` from a timer. It does not replace the transport or assume synchronous delivery.

```python
"""Per-node count logic. The transport supplies send_async and calls retry_pending."""
from dataclasses import dataclass

@dataclass(frozen=True)
class Message:
    kind: str
    request_id: str
    payload: object = None

class Node:
    def __init__(self, node_id, parent_id, children):
        self.node_id, self.parent_id = node_id, parent_id
        self.children = tuple(children)
        self.requests = {}
        self.printed = set()

    def send_async(self, to_node_id, message):
        raise NotImplementedError('provided transport')

    def call(self, from_node_id, message):
        rid = message.request_id
        if message.kind == 'request_count':
            if from_node_id != self.parent_id:
                raise ValueError('count request must come from parent/root trigger')
            if rid not in self.requests:
                self.requests[rid] = {'replies': {}, 'total': None}
            state = self.requests[rid]
            if state['total'] is not None:
                self._return(rid)
            else:
                for child in self.children:
                    if child not in state['replies']:
                        self.send_async(child, Message('request_count', rid))
                self._finish(rid)
        elif message.kind == 'count':
            if from_node_id not in self.children or rid not in self.requests:
                return
            value = message.payload
            if not isinstance(value, int) or isinstance(value, bool) or value < 1:
                raise ValueError('subtree count must be a positive integer')
            state = self.requests[rid]
            prior = state['replies'].get(from_node_id)
            if prior is not None and prior != value:
                raise ValueError('inconsistent duplicate count')
            state['replies'][from_node_id] = value
            self._finish(rid)

    def _finish(self, rid):
        state = self.requests[rid]
        if state['total'] is None and len(state['replies']) == len(self.children):
            state['total'] = 1 + sum(state['replies'].values())
            self._return(rid)

    def _return(self, rid):
        total = self.requests[rid]['total']
        if self.parent_id is None:
            if rid not in self.printed:
                self.printed.add(rid)
                print(total)
        else:
            self.send_async(self.parent_id, Message('count', rid, total))

    def retry_pending(self):
        # Call from a timer, with backoff/jitter supplied by the runtime.
        for rid, state in list(self.requests.items()):
            if state['total'] is None:
                for child in self.children:
                    if child not in state['replies']:
                        self.send_async(child, Message('request_count', rid))
```

### Why duplicates and packet loss are safe

Without failures this uses N-1 downward requests and N-1 upward replies, so 2(N-1) messages and O(number of children) aggregation state per node per request. Message delay determines latency; no synchronous round duration is assumed. A duplicate pending request resends only unanswered child requests. A duplicate completed request returns the cached total. A duplicate child response replaces the same dictionary entry and cannot increase the sum. If a response was lost, the parent's retry causes the child to resend its cached response. The root's printed set suppresses repeated output.

Example: root R has leaf A and child B with two leaves. A returns 1; B returns 3; R prints 1+1+3=5. Deliver B's response three times or lose its first response: the output remains 5. Out-of-order responses from a different request do not enter this request's state.

Retry with exponential backoff and jitter, bounded by an operation deadline if the caller wants a timeout status. A timeout may report INCOMPLETE, never an exact partial total. Completion requires eventual delivery on each edge and eventually responsive nodes. Permanent subtree loss makes an exact count impossible under the interface. To survive process restart, persist request/reply/printed state or use a durable result sink keyed by request_id; a print itself is not transactionally exactly once across a crash. Demo state is in memory and assumes no restarts/topology changes. Production garbage collection needs a request-retention/acknowledgment protocol; evicting completed state while arbitrary old messages remain can reprint or recompute. Tests explicitly inject loss, duplication and reordering on a five-node tree and verify one root output.
