## Question

Applied Scientist / MLE rounds drill the full Transformer stack: self-attention math, encoder vs decoder masking, multi-head intuition, optimizer choice, and modern variants (Flash Attention, RoPE, KV cache).

## Worked solution

### Trace one Transformer computation

For $X:(B,T,D)$, project $Q=XW_Q$, $K=XW_K$, $V=XW_V$ and reshape to $(B,H,T,d_h)$ where $D=Hd_h$. Each head computes $P=\operatorname{softmax}(QK^T/\sqrt{d_h}+M)$ over the last, **key**, axis and $O=PV$. Concatenate head outputs and apply $W_O$ to return $(B,T,D)$. Separate Q/K projections learn asymmetric matching; V carries content, and heads see the full sequence in different learned feature spaces rather than disjoint token groups.

If independent zero-mean unit-variance Q/K coordinates are assumed, a dot product has variance $d_h$; dividing by $\sqrt{d_h}$ keeps variance near one, reducing premature softmax saturation. This scale argument differs from subtracting the maximum for numerical stability. For a query with exactly one allowed key, its output equals that key's value regardless of its score.

### Encoder, decoder and training target

An encoder allows bidirectional attention among nonpadding inputs. A decoder masks future keys with $-\infty$ before softmax; padding also needs masking, and an all-masked row needs an explicit policy to avoid NaNs. Encoder-decoder cross-attention uses decoder queries and encoder keys/values with shape $(B,H,T_{dec},T_{enc})$. For next-token training align inputs `[a,b,c]` with targets `[b,c,d]`; do not shift twice when a model API already shifts internally. Bidirectional masked-token training has a different target and does not use this causal shift.

A pre-norm block is $u=x+\mathrm{Attn}(\mathrm{LN}(x))$, $y=u+\mathrm{FFN}(\mathrm{LN}(u))$; a post-norm block normalizes after each addition. FFN typically expands features, applies a nonlinearity/gate and projects back, independently at every position. Residuals provide direct gradient paths; depth still needs suitable scale management. LayerNorm learns per-feature gamma/beta using each token's own statistics, with no BatchNorm running averages.

### Positions, exact attention and cache

Without position encoding, unrestricted self-attention is permutation **equivariant**, not invariant: permuting inputs permutes outputs. Pooling can make a downstream result invariant; a causal mask supplies some order structure but does not replace explicit positional design. RoPE rotates query/key coordinate pairs by position-dependent angles; $(R_mq)^T(R_nk)=q^TR_{n-m}k$ exposes relative displacement. Cached keys are typically already rotated; new decoding tokens must use the correct continued position, not position zero.

Flash-style tiled attention computes the same softmax attention with online running maxima/normalizers while avoiding full $T\times T$ probability storage in high-bandwidth memory; it changes IO, not causal semantics. Work remains quadratic in sequence length for dense attention. KV caching stores old layer keys/values and computes only the new token's projections/MLP at decode time, at memory $2BLTH_{KV}d_hs$. Grouped-query attention reduces $H_{KV}$; it is not the same thing as reducing query heads.

### Optimization and checks

AdamW maintains bias-corrected first/second gradient moments and applies decoupled weight decay; warmup limits large early updates, global gradient clipping limits unusually large steps, and mixed precision needs overflow monitoring/unscaling before clipping. They address different issues and cannot repair a mask or target alignment bug.

For $B=2,T=3,H=4,d_h=8$, attention scores are `(2,4,3,3)` and concatenated contexts `(2,3,32)`. Verify causality by altering a future token and checking earlier logits, cache parity against full-prefix inference, padding invariance and finite loss/gradients on a tiny overfit task. Explain compute versus memory trade-offs with measured context and batch sizes rather than asserting one optimizer or kernel solves all bottlenecks.
