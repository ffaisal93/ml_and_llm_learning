## Worked solution

### The five actual questions and schemas are missing

A list of SQL topics is not enough to derive five unknown result sets. The following is an explicit **practice fixture**, using four tables compatible with the neighboring exercises: `blocks(workspace_id,block_id,parent_id,block_type)`, `events(event_id,block_id,user_id,event_type,platform)`, `users(id,subscription_id,country,created_at)` and `subscription(id,user_id,plan_type)`. Assume global block IDs, unique user/subscription IDs and current subscription via users.subscription_id. No unseen screen answers are claimed.

Practice five concrete tasks in order: (1) parent block type with most direct children; (2) country with most events; (3) event type with most events; (4) percentage of blocks never edited; (5) top event type → current-plan event distribution → winning plan. The first uses SELF+LEFT JOIN, the second a many-to-one JOIN, the third GROUP BY/MAX, the fourth NOT EXISTS, and the fifth layered CTEs plus DENSE_RANK. Their complete executable queries are below, each with the output already named by its SELECT.

#### Practice task 1

```sql
WITH totals AS (
 SELECT p.block_type,COUNT(c.block_id) AS total_children
 FROM blocks p LEFT JOIN blocks c
   ON c.workspace_id=p.workspace_id AND c.parent_id=p.block_id
 GROUP BY p.block_type
)
SELECT block_type,total_children FROM totals
WHERE total_children=(SELECT MAX(total_children) FROM totals);
```
#### Practice task 2

```sql
WITH totals AS (
 SELECT u.country,COUNT(*) AS event_count
 FROM events e JOIN users u ON u.id=e.user_id GROUP BY u.country
)
SELECT country,event_count FROM totals
WHERE event_count=(SELECT MAX(event_count) FROM totals);
```
#### Practice task 3

```sql
WITH totals AS (
 SELECT event_type,COUNT(*) AS event_count FROM events GROUP BY event_type
)
SELECT event_type,event_count FROM totals
WHERE event_count=(SELECT MAX(event_count) FROM totals);
```
#### Practice task 4

```sql
SELECT 100.0*SUM(CASE WHEN NOT EXISTS (
 SELECT 1 FROM events e WHERE e.block_id=b.block_id AND e.event_type='edit_text'
) THEN 1 ELSE 0 END)/NULLIF(COUNT(*),0) AS never_edited_percentage
FROM blocks b;
```
#### Practice task 5

```sql
WITH event_totals AS (
 SELECT event_type,COUNT(*) AS event_count FROM events GROUP BY event_type
), top_types AS (
 SELECT event_type FROM event_totals WHERE event_count=(SELECT MAX(event_count) FROM event_totals)
), distribution AS (
 SELECT e.event_type,COALESCE(s.plan_type,'UNKNOWN') AS plan_type,COUNT(*) AS event_count
 FROM events e JOIN top_types t ON (t.event_type=e.event_type OR (t.event_type IS NULL AND e.event_type IS NULL))
 LEFT JOIN users u ON u.id=e.user_id
 LEFT JOIN subscription s ON s.id=u.subscription_id AND s.user_id=u.id
 GROUP BY e.event_type,COALESCE(s.plan_type,'UNKNOWN')
), ranked AS (
 SELECT *,DENSE_RANK() OVER(PARTITION BY event_type ORDER BY event_count DESC) AS rnk FROM distribution
)
SELECT event_type,plan_type,event_count FROM ranked WHERE rnk=1;
```

For boolean logic, a filter such as `platform='web' AND (event_type='view' OR event_type='edit_text')` requires parentheses; otherwise OR can bypass the platform filter. SQL NULL predicates are unknown, COUNT(*) counts rows, COUNT(column) ignores NULL, and moving a right-table filter from ON to WHERE can turn a LEFT JOIN effectively into INNER. Verify join grain before aggregation: joining all subscription histories multiplies events, while the current pointer chooses at most one. The batch's SQLite fixtures execute these five chosen tasks with ties, missing dimensions, repeated facts and multiple subscriptions; original questions remain unavailable. In the real screen, write the requested output grain first, label each intermediate CTE and keep a tiny counterexample for every dedup/null assumption.
