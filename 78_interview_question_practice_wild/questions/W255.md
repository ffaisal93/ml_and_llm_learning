## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Data Engineer / Cell Integrity &amp; Quality case: five randomly assigned battery groups each undergo three pass/fail tests; identify which group has the best overall quality and justify the statistical method.

Requirements
There are five groups of batteries.
Batteries are randomly assigned to the five groups.
Each battery goes through three different inspections or tests.
Each test result is pass or fail.
The data has already been stored.
Determine which battery group has the best overall quality.
Notes
Treat this as an experiment-design and statistical-comparison case, not a pure SQL exercise.
Clarify sample sizes, whether the three tests have equal importance, whether failures are independent, and whether a battery-level pass requires all three tests to pass.
Reasonable approaches include group-level pass-rate estimates with confidence intervals, multiple-comparison-aware hypothesis testing, and a composite quality score if the tests have different severity.
If each battery has three binary outcomes, define the unit of analysis before ranking: per-test pass rate, all-tests-pass battery rate, or weighted defect severity score can produce different winners.</pre>

## Worked solution

1. Choose the battery as the analysis unit and define quality before inspecting winners: all-three-tests pass, per-test rates or a predeclared severity-weighted score are different objectives.
2. Compute each group’s sample size, missingness and outcome distribution. Estimate battery-level pass rates with uncertainty; retain the correlation among three outcomes from the same battery.
3. Compare randomized groups under a suitable binomial/logistic or permutation approach, accounting for five-group multiple comparisons and any predeclared covariates. Report effect sizes and uncertainty, not only the largest sample percentage.
4. If sample sizes or actual outcomes are absent, no numerical winning group is identifiable. State what data would establish a practically meaningful advantage and how missing outcomes are handled.

### Small example / sanity check

A group with 9/10 all-pass batteries has a higher point estimate but much wider uncertainty than a group with 880/1000; ranking by percentage alone hides that difference.

### Common trap

Multiplying the three marginal pass rates as if the tests on a battery were independent.
