## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Write the backward pass of a two-layer MLP whose weight matrices are split by rows across several shards that communicate only through all_gather.

Setting

The forward pass, which is given, computes

h_pre = A @ x
h     = relu(h_pre)
y     = B @ h

A (n_hid × n_in) and B (n_out × n_hid) are row-sharded: shard i holds a contiguous block of rows, blocks appear in shard order, and blocks may have different sizes (including zero rows). The input x is identical on every shard. Each shard receives a comm object with comm.num_shards, comm.my_shard_index and comm.all_gather(value). Every shard must call all_gather the same number of times, in the same order. Each call returns the list [value_0, ..., value_{num_shards-1}] of the values that the shards passed. Matrices are lists of row lists and vectors are lists of floats.

Provided code (do not modify):

from typing import Any, Dict, List, Sequence, Tuple

Vector = List[float]
Matrix = List[List[float]]

# === Provided context code (DO NOT MODIFY) ===================================

def relu(x: Sequence[float]) -&gt; Vector:
return [0.0 if v &lt;= 0 else float(v) for v in x]

def matvec(W: Matrix, v: Sequence[float]) -&gt; Vector:
return [sum(a * b for a, b in zip(row, v)) for row in W]

def sharded_matmul(sharded_W: Matrix, v: Sequence[float], comm: Any) -&gt; Vector:
&quot;&quot;&quot;Forward: (W @ v) where W is row-sharded. Rows concatenate in shard order.&quot;&quot;&quot;
local_out = matvec(sharded_W, v)
gathered = comm.all_gather(local_out)
return [value for part in gathered for value in part]

def sharded_mlp(sharded_A: Matrix, sharded_B: Matrix, x: Sequence[float],
comm: Any) -&gt; Tuple[Dict[str, Vector], Vector]:
h_pre = sharded_matmul(sharded_A, x, comm)
h = relu(h_pre)
y = sharded_matmul(sharded_B, h, comm)
return dict(x=list(x), h_pre=h_pre, h=h), y

# === END OF PROVIDED CODE ====================================================
Requirements
1.
relu_grad(x, y_grad) -&gt; list[float]: return dL/dx for relu, given the pre-activation x and y_grad = dL/d relu(x). The gradient at x[i] &lt;= 0 is 0.0, matching relu.
2.
sharded_matmul_grad(sharded_W, v, out_grad, comm) -&gt; (W_grad, v_grad): the backward pass of sharded_matmul. out_grad is dL/d(W @ v) for the whole output and is identical on every shard. Return two values. W_grad is the gradient for this shard&#x27;s rows only, with the same shape as sharded_W. v_grad is the full dL/dv, of length len(v) and identical on every shard. Do not assume that rows divide evenly between shards.
3.
sharded_mlp_grad(sharded_A, sharded_B, activations, y_grad, comm) -&gt; dict: given the activations dict returned by sharded_mlp and y_grad = dL/dy, return {&quot;sharded_A&quot;: dL/dA for this shard&#x27;s rows, &quot;sharded_B&quot;: dL/dB for this shard&#x27;s rows}.
4.
Use only comm.all_gather for communication, and support any number of shards and any dimensions.
Input

Each shard calls the functions with its own sharded_A, sharded_B and comm, and the shared x, activations and y_grad.

Output

Per shard, a dict whose two matrices equal (to floating-point tolerance) this shard&#x27;s rows of dL/dA and dL/dB, the gradients of the loss with respect to the full, unsharded A and B.

Examples

Example 1: two shards, an uneven split.

A = [[1, 0], [0, -1], [1, -1]], B = [[1, 2, 3], [0, 1, 0]], x = [2, 1], y_grad = [1, 1], two shards: shard 0 holds A rows 0–1 and B row 0, shard 1 holds A row 2 and B row 1. The forward pass gives h_pre = [2, -1, 1], h = [2.0, 0.0, 1.0], y = [5.0, 0.0].

shard 0: {&quot;sharded_A&quot;: [[2.0, 1.0], [0.0, 0.0]], &quot;sharded_B&quot;: [[2.0, 0.0, 1.0]]}
shard 1: {&quot;sharded_A&quot;: [[6.0, 3.0]],             &quot;sharded_B&quot;: [[2.0, 0.0, 1.0]]}

Explanation: dL/dh = Bᵀ y_grad = [1, 3, 3]. The relu zeroes entry 1, because h_pre[1] = -1. Each row of dL/dA is that entry times x, and each row of dL/dB is y_grad[r] times h. Each shard returns only its own rows.

Example 2: three shards, one of them empty, and a pre-activation exactly at 0.

A = [[1, 0], [1, -2], [1, -1]], B = [[1, 2, 3], [0, 1, 0]], x = [2, 1], y_grad = [1, 1]. A is split [2, 0, 1] rows and B is split [1, 0, 1] rows, so shard 1 holds no rows of either. The forward pass gives h_pre = [2, 0, 1], h = [2.0, 0.0, 1.0], y = [5.0, 0.0].

shard 0: {&quot;sharded_A&quot;: [[2.0, 1.0], [0.0, 0.0]], &quot;sharded_B&quot;: [[2.0, 0.0, 1.0]]}
shard 1: {&quot;sharded_A&quot;: [],                       &quot;sharded_B&quot;: []}
shard 2: {&quot;sharded_A&quot;: [[6.0, 3.0]],             &quot;sharded_B&quot;: [[2.0, 0.0, 1.0]]}

Explanation: dL/dh = [1, 3, 3] again, but h_pre[1] is exactly 0, so its gradient is 0 (requirement 1). A mask with &lt; 0 would wrongly give [6.0, 3.0] for row 1. The empty shard still joins every all_gather and returns empty matrices.

Constraints
1 &lt;= num_shards &lt;= 8; 1 &lt;= n_in, n_hid, n_out &lt;= 64.</pre>

## Worked solution

1. Derive the backward communication of a row-sharded linear layer. The gradient communication follows which forward tensors were replicated or assembled, not the name of a collective alone.
2. Fix a convention: X:(N,d_in), W:(d_in,d_out), Y=XW. If output columns of W are split, each worker produces a slice of Y.
3. For replicated X, each worker computes its local dW=Xᵀ*dY_slice and partial dX=dY_slice*W_sliceᵀ.
4. Sum partial dX across workers. If forward concatenated slices with all-gather, backward distributes the corresponding gradient slices with the correct sum semantics for the surrounding graph.

### Small example / sanity check

For W=[W0 W1], dX=dY0*W0ᵀ+dY1*W1ᵀ. Neither worker's contribution alone is the complete input gradient.

### Common trap

Using “row-sharded” without stating weight orientation; different libraries use the term differently.
