## Question

Write the backward pass of a two-layer MLP whose weight matrices are split by rows across several shards that communicate only through all_gather.

Setting

The forward pass, which is given, computes

```python
h_pre = A @ x
h     = relu(h_pre)
y     = B @ h
```

A (n_hid × n_in) and B (n_out × n_hid) are row-sharded: shard i holds a contiguous block of rows, blocks appear in shard order, and blocks may have different sizes (including zero rows). The input x is identical on every shard. Each shard receives a comm object with comm.num_shards, comm.my_shard_index and comm.all_gather(value). Every shard must call all_gather the same number of times, in the same order. Each call returns the list [value_0, ..., value_{num_shards-1}] of the values that the shards passed. Matrices are lists of row lists and vectors are lists of floats.

### Requirements

1. relu_grad(x, y_grad) -&gt; list[float]: return dL/dx for relu, given the pre-activation x and y_grad = dL/d relu(x). The gradient at x[i] &lt;= 0 is 0.0, matching relu.
2. sharded_matmul_grad(sharded_W, v, out_grad, comm) -&gt; (W_grad, v_grad): the backward pass of sharded_matmul. out_grad is dL/d(W @ v) for the whole output and is identical on every shard. Return two values. W_grad is the gradient for this shard's rows only, with the same shape as sharded_W. v_grad is the full dL/dv, of length len(v) and identical on every shard. Do not assume that rows divide evenly between shards.
3. sharded_mlp_grad(sharded_A, sharded_B, activations, y_grad, comm) -&gt; dict: given the activations dict returned by sharded_mlp and y_grad = dL/dy, return {"sharded_A": dL/dA for this shard's rows, "sharded_B": dL/dB for this shard's rows}.
4. Use only comm.all_gather for communication, and support any number of shards and any dimensions.
Input

Each shard calls the functions with its own sharded_A, sharded_B and comm, and the shared x, activations and y_grad.

### Output

Per shard, a dict whose two matrices equal (to floating-point tolerance) this shard's rows of dL/dA and dL/dB, the gradients of the loss with respect to the full, unsharded A and B.

### Examples

Example 1: two shards, an uneven split.

```text
A = [[1, 0], [0, -1], [1, -1]], B = [[1, 2, 3], [0, 1, 0]], x = [2, 1], y_grad = [1, 1], two shards: shard 0 holds A rows 0–1 and B row 0, shard 1 holds A row 2 and B row 1. The forward pass gives h_pre = [2, -1, 1], h = [2.0, 0.0, 1.0], y = [5.0, 0.0].
```

### Constraints

1 &lt;= num_shards &lt;= 8; 1 &lt;= n_in, n_hid, n_out &lt;= 64.

## Worked solution

### Differentiate the stated row-oriented matrix-vector operation

Here weights are output×input and $y=Wv$. For a shard owning output rows `[start:stop]`, take that slice of the **global** out_grad. Local $dW_{ij}=g_i v_j$, and its contribution to input gradient is $u_j=\sum_{i\text{ local}}g_iW_{ij}$. All-gather partial u vectors and sum them, rather than concatenate or average. Determine offsets by gathering actual row counts, so uneven/empty shards work.

For the MLP, differentiate B first to get full dh, multiply by `h_pre>0`, then differentiate A. Exactly four all_gather calls occur per rank: B row counts, B partial input gradients, A row counts, A partial input gradients. Empty ranks participate in all four calls.

```python
# Computation uses only Python lists and the provided all_gather interface.
def relu_grad(x,y_grad):
    return [float(g) if value>0 else 0. for value,g in zip(x,y_grad)]

def sharded_matmul_grad(sharded_W,v,out_grad,comm):
    counts=comm.all_gather(len(sharded_W))
    start=sum(counts[:comm.my_shard_index]);stop=start+len(sharded_W)
    local_g=out_grad[start:stop]
    W_grad=[[g*value for value in v] for g in local_g]
    partial=[sum(g*row[j] for g,row in zip(local_g,sharded_W)) for j in range(len(v))]
    gathered=comm.all_gather(partial)
    v_grad=[sum(part[j] for part in gathered) for j in range(len(v))]
    return W_grad,v_grad

def sharded_mlp_grad(sharded_A,sharded_B,activations,y_grad,comm):
    B_grad,h_grad=sharded_matmul_grad(sharded_B,activations['h'],y_grad,comm)
    pre_grad=relu_grad(activations['h_pre'],h_grad)
    A_grad,_=sharded_matmul_grad(sharded_A,activations['x'],pre_grad,comm)
    return {'sharded_A':A_grad,'sharded_B':B_grad}

if __name__=='__main__':
```

### Verify and explain the boundary cases

Both supplied examples produce local A gradients `[2,1]`, zero, `[6,3]` in original row order, and both B rows `[2,0,1]`. The three-shard example returns empty matrices from shard1 and zero derivative at exactly-zero ReLU, matching the forward convention. The fixture also checks one shard and identical collective counts. Computation is plain lists; NumPy/autograd is not used to obtain any gradient.

The included standalone test imports the independent barrier fixture from `review_w035_implementation.py`; in the exercise use its provided comm unchanged. `out_grad` is one replicated mathematical upstream vector, so sum each rank's **local-row** contribution once; do not multiply it by the number of replicas. With row counts already cached from forward, that first gather per layer could be avoided, but this backward-only interface does not supply them. Per-rank arithmetic is O(local_rows·input_width), with all-gather storing p partial input vectors; all-reduce would be a more direct collective if it were allowed.
