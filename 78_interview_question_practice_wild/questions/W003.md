## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Implement multi-head scaled dot-product attention from scratch, using only array operations (NumPy or tensor math). Library attention modules such as nn.MultiheadAttention or F.scaled_dot_product_attention are not allowed. The function splits the model dimension into several heads, lets each head attend over the sequence independently, and joins the heads back together.

What to implement

multi_head_attention(Q, K, V, num_heads, mask=None)

Q, K, V: arrays (or nested lists) of shape (batch, seq, d_model). The three share one shape.
num_heads: a positive integer that divides d_model. Each head works on d_k = d_model / num_heads consecutive features.
mask: optional boolean array that can be broadcast to (batch, num_heads, seq, seq). True means the query position may attend to that key position; False means it must not.
Returns a float array of shape (batch, seq, d_model).
Rules
1.
There are no learned projection matrices. Head j uses features j * d_k to (j + 1) * d_k - 1 of Q, K and V directly.
2.
For each head, the scores are Q_h @ K_h^T / sqrt(d_k), with shape (seq, seq) per batch item.
3.
Scores at masked positions (mask is False) are excluded from the softmax, so they get weight exactly 0. Every query row keeps at least one allowed position.
4.
The softmax runs over the key axis and must be numerically stable: huge scores must not overflow.
5.
Each head&#x27;s output is the attention weights times V_h. The heads are concatenated in head order back to d_model features.
Examples
1.
Q = K = zeros((1, 2, 2)), V = [[[1, 2], [3, 4]]], num_heads = 1, no mask. All scores are 0, so every weight is 0.5 and both rows of the output are [2, 3].
2.
Same inputs with the causal mask [[True, False], [True, True]]. Position 0 sees only itself and position 1 sees both, so the output is [[1, 2], [2, 3]].
Constraints
1 &lt;= batch, seq &lt;= 64, 1 &lt;= d_model &lt;= 512.
num_heads divides d_model.</pre>

## Worked solution

1. Trace every shape in multi-head self-attention. Heads are parallel attention computations over smaller feature spaces; they do not each attend to a disjoint piece of the sequence.
2. Project X:(B,T,d) into Q,K,V:(B,T,H*d_h). Reshape and transpose to (B,H,T,d_h).
3. Multiply Q by K transposed on its last two axes to obtain (B,H,T,T). Softmax over the final key axis.
4. Multiply by V to obtain (B,H,T,d_h), transpose to (B,T,H,d_h), concatenate to (B,T,H*d_h), and apply Wo to return to (B,T,d).
5. Implement stable scaled dot-product attention. Compute a normalized weighted average of values, with one probability distribution per query.
6. Project X into Q,K,V, then form QKᵀ/sqrt(d_k).
7. Replace forbidden scores with negative infinity. Subtract each row's maximum, exponentiate, and divide by the row sum.
8. Return probabilities @ V. Check mask shape and reject rows with no valid keys. See the executable attention implementation in the coding lab.

### Small example / sanity check

For B=2, T=3, H=4, d_h=8, each score tensor has shape (2,4,3,3); concatenating produces (2,3,32).

### Common trap

Reshaping without the transpose, which silently mixes token and head dimensions while preserving the total element count.
