## Question

Implement multi-head scaled dot-product attention from scratch, using only array operations (NumPy or tensor math). Library attention modules such as nn.MultiheadAttention or F.scaled_dot_product_attention are not allowed. The function splits the model dimension into several heads, lets each head attend over the sequence independently, and joins the heads back together.

### What to implement

multi_head_attention(Q, K, V, num_heads, mask=None)

Q, K, V: arrays (or nested lists) of shape (batch, seq, d_model). The three share one shape.

```text
num_heads: a positive integer that divides d_model. Each head works on d_k = d_model / num_heads consecutive features.
mask: optional boolean array that can be broadcast to (batch, num_heads, seq, seq). True means the query position may attend to that key position; False means it must not.
```

Returns a float array of shape (batch, seq, d_model).

### Rules

1. There are no learned projection matrices. Head j uses features j * d_k to (j + 1) * d_k - 1 of Q, K and V directly.
2. For each head, the scores are Q_h @ K_h^T / sqrt(d_k), with shape (seq, seq) per batch item.
3. Scores at masked positions (mask is False) are excluded from the softmax, so they get weight exactly 0. Every query row keeps at least one allowed position.
4. The softmax runs over the key axis and must be numerically stable: huge scores must not overflow.
5. Each head's output is the attention weights times V_h. The heads are concatenated in head order back to d_model features.

### Examples

1. Q = K = zeros((1, 2, 2)), V = [[[1, 2], [3, 4]]], num_heads = 1, no mask. All scores are 0, so every weight is 0.5 and both rows of the output are [2, 3].
2. Same inputs with the causal mask [[True, False], [True, True]]. Position 0 sees only itself and position 1 sees both, so the output is [[1, 2], [2, 3]].

### Constraints

1 &lt;= batch, seq &lt;= 64, 1 &lt;= d_model &lt;= 512.
num_heads divides d_model.

## Worked solution

### Solution outline

#### Trace every shape in multi-head self-attention.

Heads are parallel attention computations over smaller feature spaces; they do not each attend to a disjoint piece of the sequence.

1. Project X:(B,T,d) into Q,K,V:(B,T,H*d_h). Reshape and transpose to (B,H,T,d_h).
2. Multiply Q by K transposed on its last two axes to obtain (B,H,T,T). Softmax over the final key axis.
3. Multiply by V to obtain (B,H,T,d_h), transpose to (B,T,H,d_h), concatenate to (B,T,H*d_h), and apply Wo to return to (B,T,d).

#### Implement stable scaled dot-product attention.

Compute a normalized weighted average of values, with one probability distribution per query.

1. Project X into Q,K,V, then form $QK^\top/\sqrt{d_k}$.
2. Replace forbidden scores with negative infinity. Subtract each row's maximum, exponentiate, and divide by the row sum.
3. Return probabilities @ V. Check mask shape and reject rows with no valid keys. See the executable attention implementation in the coding lab.

### Understand why the approach works

#### Derivation and a complete small example

For one token matrix $X\in\mathbb R^{n\times d_{\rm model}}$, learn projections

$$
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V,
$$

with $W_Q,W_K\in\mathbb R^{d_{\rm model}\times d_k}$ and $W_V\in\mathbb R^{d_{\rm model}\times d_v}$. The output has shape $n\times d_v$. Row $i$ asks which keys help query $i$; therefore softmax normalizes **across columns**, not across queries.

Let $X=W_Q=W_K=I_2$ and $V=\begin{bmatrix}1&2\\3&4\end{bmatrix}$. The score matrix is $I_2/\sqrt2$. The first row's probabilities are

$$
p_{11}=\frac{e^{1/\sqrt2}}{e^{1/\sqrt2}+1}\approx0.669762,
\qquad p_{12}\approx0.330238.
$$

Its output is $0.669762[1,2]+0.330238[3,4]\approx[1.660477,2.660477]$. This explicitly shows that the output is a weighted value mixture, not the selected key or a vocabulary probability.

For a boolean allowed-mask, set forbidden scores to $-\infty$ **before** softmax. Subtract each valid row maximum before exponentiation; this prevents overflow without changing the distribution. An all-forbidden row needs a declared policy because subtracting $-\infty$ from $-\infty$ creates NaN. This exercise guarantees at least one allowed key, and the reference rejects a violated contract.

**Cost.** Pairwise attention uses $O(n^2(d_k+d_v))$ arithmetic and $O(n^2)$ score storage in this straightforward implementation, in addition to the linear projections. **Checks.** Identity-only masking returns $V$ exactly; changing a forbidden future input must not change an earlier causal output.

### Readable reference implementation

Read the explanation first, then trace one small input through these functions. This is the same implementation used by the local checks; its stated simplifications still apply.

```python
import math
from collections import deque
from dataclasses import dataclass
import numpy as np


def attention_qkv(q, k, v, mask=None):
    """Single-head attention. True mask entries mean allowed. Empty rows rejected."""
    q, k, v = [np.asarray(a, dtype=np.float64) for a in (q, k, v)]
    if any(a.ndim != 2 for a in (q, k, v)):
        raise ValueError("q,k,v must be matrices")
    if q.shape[1] != k.shape[1] or k.shape[0] != v.shape[0]:
        raise ValueError("incompatible attention shapes")
    if q.shape[1] == 0 or k.shape[0] == 0:
        raise ValueError("empty head dimension or key sequence")
    if not all(np.isfinite(a).all() for a in (q, k, v)):
        raise ValueError("inputs must be finite")
    scores = q @ k.T / math.sqrt(q.shape[1])
    if mask is not None:
        mask = np.asarray(mask, dtype=bool)
        if mask.shape != scores.shape or not mask.any(axis=-1).all():
            raise ValueError("invalid mask or all-masked row")
        scores = np.where(mask, scores, -np.inf)
    z = scores - scores.max(axis=-1, keepdims=True)
    weights = np.exp(z)
    weights /= weights.sum(axis=-1, keepdims=True)
    return weights @ v


def attention(x, wq, wk, wv, mask=None):
    x = np.asarray(x, dtype=np.float64)
    return attention_qkv(x @ wq, x @ wk, x @ wv, mask)
```

### Work a small example

For B=2, T=3, H=4, d_h=8, each score tensor has shape (2,4,3,3); concatenating produces (2,3,32).
