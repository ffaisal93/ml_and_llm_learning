## Question

Implement multi-head scaled dot-product attention from scratch, using only array operations (NumPy or tensor math). Library attention modules such as nn.MultiheadAttention or F.scaled_dot_product_attention are not allowed. The function splits the model dimension into several heads, lets each head attend over the sequence independently, and joins the heads back together.

### What to implement

multi_head_attention(Q, K, V, num_heads, mask=None)

Q, K, V: arrays (or nested lists) of shape (batch, seq, d_model). The three share one shape.

```text
num_heads: a positive integer that divides d_model. Each head works on d_k = d_model / num_heads consecutive features.
mask: optional boolean array that can be broadcast to (batch, num_heads, seq, seq). True means the query position may attend to that key position; False means it must not.
```

Returns a float array of shape (batch, seq, d_model).

### Rules

1. There are no learned projection matrices. Head j uses features j * d_k to (j + 1) * d_k - 1 of Q, K and V directly.
2. For each head, the scores are $Q_h K_h^{\top}/\sqrt{d_k}$, with shape (seq, seq) per batch item.
3. Scores at masked positions (mask is False) are excluded from the softmax, so they get weight exactly 0. Every query row keeps at least one allowed position.
4. The softmax runs over the key axis and must be numerically stable: huge scores must not overflow.
5. Each head's output is the attention weights times V_h. The heads are concatenated in head order back to d_model features.

### Examples

1. Q = K = zeros((1, 2, 2)), V = [[[1, 2], [3, 4]]], num_heads = 1, no mask. All scores are 0, so every weight is 0.5 and both rows of the output are [2, 3].
2. Same inputs with the causal mask [[True, False], [True, True]]. Position 0 sees only itself and position 1 sees both, so the output is [[1, 2], [2, 3]].

### Constraints

1 &lt;= batch, seq &lt;= 64, 1 &lt;= d_model &lt;= 512.
num_heads divides d_model.

## Worked solution

### Split existing features into heads, with no learned projections

The question supplies Q/K/V already and explicitly forbids learned projection matrices. Reshape `(B,T,D)` to `(B,T,H,d)` then transpose to `(B,H,T,d)`. Compute scaled score matrices `(B,H,T,T)`, apply the broadcast **allowed** mask before a key-axis softmax, multiply by V, then transpose/concatenate back. No output projection is introduced.

```python
import numpy as np


def multi_head_attention(Q, K, V, num_heads, mask=None):
    Q, K, V = [np.asarray(a, dtype=np.float64) for a in (Q, K, V)]
    if Q.ndim != 3 or Q.shape != K.shape or Q.shape != V.shape:
        raise ValueError("matching B,T,D inputs required")
    B, T, D = Q.shape
    if num_heads < 1 or D % num_heads:
        raise ValueError("heads must divide model width")
    d = D // num_heads
    q, k, v = [a.reshape(B, T, num_heads, d).transpose(0, 2, 1, 3) for a in (Q, K, V)]
    scores = q @ k.swapaxes(-1, -2) / np.sqrt(d)
    if mask is not None:
        allowed = np.broadcast_to(np.asarray(mask, dtype=bool), scores.shape)
        if not allowed.any(axis=-1).all():
            raise ValueError("all-masked query")
        scores = np.where(allowed, scores, -np.inf)
    probabilities = np.exp(scores - scores.max(axis=-1, keepdims=True))
    probabilities /= probabilities.sum(axis=-1, keepdims=True)
    return (probabilities @ v).transpose(0, 2, 1, 3).reshape(B, T, D)


q = np.zeros((1, 2, 2))
v = np.array([[[1, 2], [3, 4]]])
assert np.allclose(multi_head_attention(q, q, v, 1), [[[2, 3], [2, 3]]])
assert np.allclose(
    multi_head_attention(q, q, v, 1, [[1, 0], [1, 1]]), [[[1, 2], [2, 3]]]
)
rng = np.random.default_rng(3)
q, k, v = [rng.normal(size=(2, 3, 8)) for _ in range(3)]
# Per-head oracle independently slices consecutive feature ranges.
y = multi_head_attention(q, k, v, 4)
for b in range(2):
    for h in range(4):
        sl = slice(h * 2, (h + 1) * 2)
        scores = q[b, :, sl] @ k[b, :, sl].T / np.sqrt(2)
        p = np.exp(scores - scores.max(1, keepdims=True))
        p /= p.sum(1, keepdims=True)
        assert np.allclose(y[b, :, sl], p @ v[b, :, sl])
mask = np.tril(np.ones((3, 3), dtype=bool))
a = multi_head_attention(q, k, v, 4, mask)
k[:, 2] += 100
v[:, 2] += 100
assert np.allclose(a[:, :2], multi_head_attention(q, k, v, 4, mask)[:, :2])
assert np.isfinite(multi_head_attention(q * 1000, k * 1000, v, 4)).all()
print(
    "W003: examples, independent head oracle, broadcast causal mask and stability passed"
)
```

### Why the axis order matters

A reshape alone cannot swap tokens and heads; the two transposes preserve each token's consecutive features. Zero Q/K makes uniform weights, yielding `[2,3]` at both positions in the first example; the causal mask returns `[1,2]` then `[2,3]`. Stable max subtraction prevents exponent overflow for representable scores. The checks include an independent per-head sliced oracle, a broadcast causal mask, future K/V perturbation and large logits.

Time is O(BT²D), score memory O(BHT²), excluding supplied arrays. All-masked query rows raise because they have no normalized distribution. This array reference makes no library attention calls and does not modify Q/K/V.

### Optional PyTorch study counterpart

This optional counterpart uses only tensor operations, with no nn.MultiheadAttention or scaled-dot-product-attention helper. It splits the supplied Q/K/V features directly: (B,T,D) → (B,H,T,D/H), then concatenates in the original head order. There are no learned input/output projections. The True=allowed mask broadcasts to (B,H,T,T), softmax normalizes the final key dimension, and gradients flow through the reshapes, transposes and matrix products.

```python
import math
import torch


def multi_head_attention_torch(Q, K, V, num_heads, mask=None):
    """W003: consecutive supplied features, no learned/output projections."""
    if Q.ndim != 3 or Q.shape != K.shape or Q.shape != V.shape:
        raise ValueError("matching (B,T,D) tensors required")
    B, T, D = Q.shape
    if min(B, T, D) < 1 or type(num_heads) is not int or num_heads < 1 or D % num_heads:
        raise ValueError("positive heads must divide D")
    d = D // num_heads
    q, k, v = [a.reshape(B, T, num_heads, d).transpose(1, 2) for a in (Q, K, V)]
    scores = q @ k.transpose(-1, -2) / math.sqrt(d)
    if mask is not None:
        allowed = torch.as_tensor(mask, dtype=torch.bool, device=Q.device)
        try:
            allowed = torch.broadcast_to(allowed, scores.shape)
        except RuntimeError as exc:
            raise ValueError("mask cannot broadcast to (B,H,T,T)") from exc
        if not bool(allowed.any(dim=-1).all()):
            raise ValueError("all-masked query")
        scores = scores.masked_fill(~allowed, -torch.inf)
    shifted = scores - scores.amax(dim=-1, keepdim=True)
    probabilities = shifted.exp()
    probabilities = probabilities / probabilities.sum(dim=-1, keepdim=True)
    return (probabilities @ v).transpose(1, 2).reshape(B, T, D)
```

```python

k = torch.zeros_like(q, requires_grad=True)

    out, torch.tensor([[[1.0, 2.0], [2.0, 3.0]]], dtype=torch.float64)

```
