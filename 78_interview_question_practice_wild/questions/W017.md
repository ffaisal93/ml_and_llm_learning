## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Description

Three methods dominate the fine-tuning of language models toward human or automatic feedback: PPO, DPO and GRPO. They differ in what data they consume, which extra models they keep in memory, and whether they sample from the policy during training. Compare them precisely enough that someone could implement each loss and pick the right method for a project.

The three methods are:

PPO: Proximal Policy Optimization, as used in RLHF with a learned reward model.
DPO: Direct Preference Optimization, the form with a frozen reference policy.
GRPO: Group Relative Policy Optimization, the critic-free method introduced with DeepSeekMath.
What to answer
1.
Losses. Write the exact training loss each method minimizes, and define every symbol. For PPO include the clipped surrogate, the value-function loss, the entropy bonus and the KL penalty to the reference policy.
2.
DPO derivation. Show how the DPO loss follows from the KL-regularized reward-maximization objective, and explain why no explicit reward model is needed.
3.
Requirements. For each method, list what it needs: a reward model or reward function, a value model, a reference model, preference pairs, or several samples per prompt. Say whether it trains online (sampling from the current policy) or offline.
4.
Intuition, advantages and disadvantages. One short intuition per method, then its main strengths and weaknesses.
5.
When to use which. Recommend a method for each case below and justify it.
(a) A dataset of human preference pairs and a small compute budget.
(b) Math or code tasks whose answers a program can check.
(c) A learned reward model with a need for online exploration, or a multi-step control task such as robotics.
Expected depth
Notation is free, but each loss must be correct up to sign and constant factors, and must say whether it is minimized or maximized.
Use one worked number for DPO and one for GRPO to show the loss or the advantage on a small case.
A compact comparison table at the end is expected.</pre>

## Worked solution

1. Compare PPO, DPO and GRPO using their training requirements. Choose by available feedback, exploration needs and memory budget rather than treating the methods as interchangeable names.
2. PPO uses current-policy rollouts, advantages and a clipped probability-ratio objective; common RLHF setups add a reward model, critic and reference-policy regularization.
3. DPO trains on preferred/rejected pairs with a frozen reference and a logistic loss on differences of sequence log-probability ratios; no explicit reward model is required in that objective.
4. GRPO compares several sampled answers for a prompt using group-relative rewards, avoiding a learned value critic in its usual form. Reward and variant details still matter.
5. Write and interpret the DPO loss. DPO increases the preferred response's relative probability advantage over the rejected response, measured against a reference policy.
6. Let a=log pi_theta(y_w|x)-log pi_ref(y_w|x) and b=log pi_theta(y_l|x)-log pi_ref(y_l|x).
7. Minimize L=-log sigmoid(beta*(a-b)); use a stable log-sigmoid or softplus implementation.
8. Sum token log probabilities over each response, excluding prompt and padding targets under a consistent convention. Keep the reference frozen.
9. Explain a clipped PPO update in plain language. PPO rewards actions with positive estimated advantage while limiting the incentive for a large probability-ratio change within an update.
10. Form r=pi_new(action|state)/pi_old(action|state) from the rollout policy, with rollout quantities treated as fixed.
11. Maximize mean(min(r*A,clip(r,1-epsilon,1+epsilon)*A)). A common minimized total loss adds value error and KL regularization and subtracts an entropy bonus.
12. Estimate advantages from returns and a value baseline, then monitor policy KL, reward, value error and clipping fraction.
13. Calculate group-relative advantages and diagnose zero-variance rewards. GRPO-style normalization asks which sampled answers did better than their siblings for the same prompt.
14. Sample G responses, score each, and compute A_i=(r_i-mean(r))/(std(r)+epsilon) under the chosen convention.
15. Use these fixed advantages in the policy-ratio update, with any reference penalty and token reduction explicitly specified.
16. If every reward is equal, centered advantages are zero. Investigate sampling diversity, task difficulty and reward informativeness rather than dividing by zero.

### Small example / sanity check

Use preference pairs with modest compute for a DPO baseline; programmatically checked math/code rewards are a natural setting for group-relative online training.

### Common trap

Saying DPO requires online rollouts at every step, or that critic-free training removes the need for a reliable reward signal.
