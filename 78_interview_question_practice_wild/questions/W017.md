## Question

### Description

Three methods dominate the fine-tuning of language models toward human or automatic feedback: PPO, DPO and GRPO. They differ in what data they consume, which extra models they keep in memory, and whether they sample from the policy during training. Compare them precisely enough that someone could implement each loss and pick the right method for a project.

The three methods are:

PPO: Proximal Policy Optimization, as used in RLHF with a learned reward model.
DPO: Direct Preference Optimization, the form with a frozen reference policy.
GRPO: Group Relative Policy Optimization, the critic-free method introduced with DeepSeekMath.
What to answer
1. Losses. Write the exact training loss each method minimizes, and define every symbol. For PPO include the clipped surrogate, the value-function loss, the entropy bonus and the KL penalty to the reference policy.
2. DPO derivation. Show how the DPO loss follows from the KL-regularized reward-maximization objective, and explain why no explicit reward model is needed.
3. Requirements. For each method, list what it needs: a reward model or reward function, a value model, a reference model, preference pairs, or several samples per prompt. Say whether it trains online (sampling from the current policy) or offline.
4. Intuition, advantages and disadvantages. One short intuition per method, then its main strengths and weaknesses.
5. When to use which. Recommend a method for each case below and justify it.
(a) A dataset of human preference pairs and a small compute budget.
(b) Math or code tasks whose answers a program can check.
(c) A learned reward model with a need for online exploration, or a multi-step control task such as robotics.
Expected depth
Notation is free, but each loss must be correct up to sign and constant factors, and must say whether it is minimized or maximized.
Use one worked number for DPO and one for GRPO to show the loss or the advantage on a small case.
A compact comparison table at the end is expected.

## Worked solution

### Solution outline

#### Compare PPO, DPO and GRPO using their training requirements.

Choose by available feedback, exploration needs and memory budget rather than treating the methods as interchangeable names.

1. PPO uses current-policy rollouts, advantages and a clipped probability-ratio objective; common RLHF setups add a reward model, critic and reference-policy regularization.
2. DPO trains on preferred/rejected pairs with a frozen reference and a logistic loss on differences of sequence log-probability ratios; no explicit reward model is required in that objective.
3. GRPO compares several sampled answers for a prompt using group-relative rewards, avoiding a learned value critic in its usual form. Reward and variant details still matter.

#### Write and interpret the DPO loss.

DPO increases the preferred response's relative probability advantage over the rejected response, measured against a reference policy.

1. Let a=log pi_theta(y_w|x)-log pi_ref(y_w|x) and b=log pi_theta(y_l|x)-log pi_ref(y_l|x).
2. Minimize L=-log sigmoid(beta*(a-b)); use a stable log-sigmoid or softplus implementation.
3. Sum token log probabilities over each response, excluding prompt and padding targets under a consistent convention. Keep the reference frozen.

#### Explain a clipped PPO update in plain language.

PPO rewards actions with positive estimated advantage while limiting the incentive for a large probability-ratio change within an update.

1. Form r=pi_new(action|state)/pi_old(action|state) from the rollout policy, with rollout quantities treated as fixed.
2. Maximize mean(min(r*A,clip(r,1-epsilon,1+epsilon)*A)). A common minimized total loss adds value error and KL regularization and subtracts an entropy bonus.
3. Estimate advantages from returns and a value baseline, then monitor policy KL, reward, value error and clipping fraction.

#### Calculate group-relative advantages and diagnose zero-variance rewards.

GRPO-style normalization asks which sampled answers did better than their siblings for the same prompt.

1. Sample G responses, score each, and compute A_i=(r_i-mean(r))/(std(r)+epsilon) under the chosen convention.
2. Use these fixed advantages in the policy-ratio update, with any reference penalty and token reduction explicitly specified.
3. If every reward is equal, centered advantages are zero. Investigate sampling diversity, task difficulty and reward informativeness rather than dividing by zero.

### Understand why the approach works

#### Compare the actual data and losses

Start with what feedback is available. SFT uses demonstrations; DPO uses preferred/rejected pairs; common PPO/GRPO settings generate rollouts and score them. “Uses reinforcement learning” is not enough to specify an implementation.

For PPO let $r_t=\pi_\theta(a_t\mid s_t)/\pi_{\rm old}(a_t\mid s_t)$ and let $\hat A_t$ be a rollout-derived advantage treated as fixed during the policy update. A common minimized objective is

$$
L_{\rm policy}=-\mathbb E_t\min\!\left(r_t\hat A_t,
\operatorname{clip}(r_t,1-\epsilon,1+\epsilon)\hat A_t\right),
$$
$$
L=L_{\rm policy}+c_v\mathbb E_t(V_\theta(s_t)-\hat R_t)^2
-c_H\mathbb E_t H(\pi_\theta(\cdot\mid s_t))
+\beta\mathbb E_t D_{\rm KL}(\pi_\theta\Vert\pi_{\rm ref}).
$$

Specific implementations differ in return/advantage estimation, token reduction and where the KL penalty enters. The old rollout policy in the importance ratio is **not** necessarily the frozen reference used to preserve behavior. Clipping is a surrogate; it does not impose a hard global KL bound.

DPO's reference-relative winner/loser margin yields a logistic loss, avoiding an explicitly trained reward model in that objective. Under a KL-regularized reward problem, the optimal policy satisfies $\pi^*(y\mid x)\propto\pi_{\rm ref}(y\mid x)e^{r(x,y)/\beta}$. Solving for reward gives $r=\beta\log(\pi^*/\pi_{\rm ref})+\beta\log Z(x)$; the shared prompt-dependent constant cancels in a reward difference, producing the DPO margin under a Bradley–Terry preference model.

GRPO replaces a learned value baseline with relative rewards within a sampled prompt group, in its common form:

$$
\hat A_i=\frac{R_i-\bar R}{s_R+\varepsilon}.
$$

For rewards $[0,0,1,1]$ and population standard deviation, advantages are approximately $[-1,-1,1,1]$. If all rewards are equal, the centered reward contribution is zero; any separate regularization can still produce an update. Define the exact normalization and objective variant rather than treating all named variants as identical.

| Situation | Reasonable baseline | Main cost or failure to check |
|---|---|---|
| Fixed preference pairs, constrained compute | DPO | Pair quality, length effects, reference mismatch |
| Programmatically verifiable sampled answers | Group-relative policy optimization | Reward reliability, sampling cost, low-variance groups |
| Online control with a useful learned value baseline | PPO-style actor–critic | Critic fit, rollout cost, update stability |

A lower optimization loss is not independent evidence of better task behavior. Reserve evaluation data and inspect reward exploitation and regressions.

### Work a small example

Use preference pairs with modest compute for a DPO baseline; programmatically checked math/code rewards are a natural setting for group-relative online training.

### Edge cases and common mistakes

Saying DPO requires online rollouts at every step, or that critic-free training removes the need for a reliable reward signal.

### Check your reasoning on related cases

**Write and interpret the DPO loss.** If beta*(a-b)=0, the loss is log(2)=0.693. If the margin is 1, the loss is about 0.313.

What can go wrong despite decreasing loss? Preference-label errors, length artifacts, distribution shift and excessive movement from desired behavior.

**Explain a clipped PPO update in plain language.** For A=2, epsilon=0.2 and r=1.5, the positive surrogate is capped at 1.2*2=2.4 rather than 3.

Does clipping enforce a strict KL constraint? No; it is a surrogate, so empirical KL monitoring still matters.

**Calculate group-relative advantages and diagnose zero-variance rewards.** Rewards [0,0,1,1] have mean 0.5 and population standard deviation 0.5, giving advantages [-1,-1,1,1] before epsilon.

What if reward variance is mostly noise? Relative normalization can amplify unreliable comparisons; improve the reward and inspect sensitivity.
