## Question

Implement the K-Means algorithm from scratch.

Implement a K-Means clustering algorithm from scratch. The algorithm should take the following parameters: a list of 2D data points data_points, an integer k indicating the number of clusters, and max_iterations, the maximum number of iterations. The output should be a list of integers, where each integer represents the cluster label of the corresponding data point in data_points.

Example input:

[[1.0, 2.0], [1.5, 1.8], [5.0, 8.0], [8.0, 8.0], [1.0, 0.6], [9.0, 11.0]]

### Output

```python
[0, 0, 1, 1, 0, 1]
```

Data scale:

data_points contains up to 1000 2D points.
k ranges from 1 to 10.
max_iterations defaults to 300.

## Worked solution

### Alternate assignment and recomputation

K-means minimizes the within-cluster squared Euclidean distance. Given centers, assign each point to the nearest center. Given assignments, each nonempty center becomes the mean of its assigned points. Repeat until assignments stabilize or the iteration cap is reached. Labels are arbitrary cluster IDs, not ordered semantic classes.

The prompt does not specify initialization or empty-cluster behavior. The following deterministic solution uses farthest-first initialization, starting at the first point, and keeps an empty center unchanged. It returns a final nearest-center assignment after the last update. A contract that explicitly requests the last *pre-update* assignment would need a different final line.

```python
def kmeans(data_points, k, max_iterations=300):
    points = [tuple(map(float, point)) for point in data_points]
    if not points or not 1 <= k <= len(points) or max_iterations < 1:
        raise ValueError('Invalid data, k or iteration count')
    if any(len(point) != 2 for point in points):
        raise ValueError('Expected 2D points')
    def distance2(a, b):
        return sum((x - y) ** 2 for x, y in zip(a, b))
    chosen = [0]
    while len(chosen) < k:
        remaining = [i for i in range(len(points)) if i not in chosen]
        index = max(remaining,
            key=lambda i: min(distance2(points[i], points[j]) for j in chosen))
        chosen.append(index)
    centers = [points[i] for i in chosen]
    def assign():
        return [min(range(k), key=lambda j: distance2(point, centers[j]))
                for point in points]
    previous = None
    for _ in range(max_iterations):
        labels = assign()
        if labels == previous:
            break
        previous = labels
        for cluster in range(k):
            members = [point for point, label in zip(points, labels) if label == cluster]
            if members:
                centers[cluster] = tuple(sum(p[d] for p in members) / len(members)
                                         for d in range(2))
    return assign()
```

The supplied points split into the near-origin group `[0,1,4]` and the larger-coordinate group `[2,3,5]`, giving the illustrated labels under this initialization. Equal-distance ties select the smaller cluster index. Duplicate points can leave clusters empty, so do not divide by zero. K-means may converge to a local optimum; multiple seeded restarts and the lowest objective improve robustness but are beyond this minimal contract. Time is $O(I n k)$ for 2D points, plus initialization; space is $O(n+k)$.

Scaling matters: a coordinate measured in thousands can dominate one measured in units. Standardize when appropriate, fit that scaling on training data, and inspect whether roughly spherical Euclidean clusters make sense before using K-means.
