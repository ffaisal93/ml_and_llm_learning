## Question

Evaluate a one-day Value at Risk model and propose a defensible validation plan. State every convention you use; monetary losses are positive numbers in this problem.

### Assumptions

The position has current notional USD 1,000,000.
One-day simple return is R, with a continuous distribution and known cumulative distribution function F.
Ignore funding, borrow fees, margin calls, market impact, and position rebalancing unless a follow-up explicitly adds them.
Use 99% confidence. Define VaR_0.99(L) as the 0.99 quantile of loss L.
Questions
1. For a long position, write the loss random variable and its 99% VaR in terms of a return quantile. Do the same for an equal-notional short position. State exactly when the two VaRs are equal and explain why neither direction is generally larger without distributional assumptions.
2. If the validated long VaR is USD 100,000, what can and cannot be inferred about the short VaR? Contrast a distribution symmetric about zero with a skewed distribution, giving a number for each.
3. Design a Monte Carlo convergence rule for estimating the 99% VaR. Specify an accuracy target, confidence level, repeated-run or bootstrap procedure, and a stopping rule; for a normal return model, estimate the path count that meets your target, and do not give an unsupported universal path count.
4. Design backtesting for daily VaR forecasts. Cover exceedance frequency, independence or clustering, traffic-light interpretation (zone boundaries and what each zone triggers, for 250 daily observations at 99%), rolling windows, and the limitations of backtesting a tail quantile.
5. Describe stress testing, sensitivity analysis, benchmark or challenger models, data-quality checks, change control, and ongoing monitoring. Separate model assumptions from operational risks such as liquidity and margin.
Follow-up: real short-position frictions

Explain how borrow costs, recalls, margin requirements, liquidity, and unbounded price upside can be represented in a broader loss model. Do not claim that these frictions change the mathematical VaR of the simplified return-only model unless they are explicitly included in L.

## Worked solution

### Fix loss signs before comparing tails

With V=1,000,000 USD and return R, long loss is $L_\ell=-VR$ and short loss is $L_s=VR$. For continuous return quantiles q,

$$VaR_{.99}(L_\ell)=-Vq_{.01}(R),\qquad VaR_{.99}(L_s)=Vq_{.99}(R).$$

For unique relevant quantiles, they are equal exactly when $q_{.99}=-q_{.01}$; symmetry about zero suffices but is not necessary. Symmetry about a nonzero mean does not give equality. The simplified short has no automatic larger 99% VaR merely because its worst loss is unbounded. Continuity alone can permit a flat CDF at a quantile level: then the exact long identity uses $-V\sup\{x:F(x)\le.01\}$, while the short uses $V\inf\{x:F(x)\ge.99\}$. The familiar formula and examples here use unique quantiles.

Long VaR 100,000 identifies q.01=-.10 and says nothing numerical about q.99 beyond quantile ordering. If R is zero-centered symmetric, short VaR is also 100,000. A continuous uniform return on [-.105, .395] has q.01=-.10 but q.99=.39, giving short 390,000. Uniform [-.102, .098] also has q.01=-.10 but q.99=.096, giving short 96,000. Both larger and smaller short VaR are possible. VaR can even be negative when the specified loss quantile is a gain; do not silently floor at zero.

### A reproducible Monte Carlo precision rule

In this one-factor problem with known F, use the analytic quantile as a benchmark; simulation validates the estimator/implementation, not the truth of the return law. Target a 95% interval with half-width at most 1,000 USD around the 99% loss quantile. For iid losses with density f_L(q)>0, asymptotic quantile standard error is $\sqrt{.99(.01)/N}/f_L(q)$. A normal zero-mean model calibrated to long VaR 100,000 has sigma ≈ .042986, loss sd ≈ 42,986 and density at q ≈ $6.20\times10^{-7}$ per dollar. A **single planned** 95% look therefore needs about 99,000 paths for the target; this estimate changes with tail density and ignores parameter/model uncertainty.

Use independent seeded runs or an iid bootstrap to check estimated bias/interval stability; for dependent simulations use an appropriate block method. The runnable protocol below instead uses distribution-free binomial order-statistic intervals under iid continuity and planned doubling looks with alpha-spending. Stage j uses error .05/2^j, so the union bound preserves at least 95% simultaneous coverage over the stopping looks. Stop when the entire interval lies within estimate ± 1,000 USD, or return nonconverged at 400K. Never repeatedly peek at ordinary 95% intervals and claim unchanged sequential coverage.

```python
import numpy as np
from scipy.stats import binom


def quantile_mc(
    draw, half_width=1000.0, confidence=0.95, seed=0, initial=25000, max_paths=400000
):
    """draw(n,rng) returns iid monetary losses; alpha spending covers planned looks."""
    if half_width <= 0 or not 0 < confidence < 1 or initial < 1 or max_paths < initial:
        raise ValueError("invalid precision/confidence/path budget")
    rng = np.random.default_rng(seed)
    losses = np.empty(0)
    n = initial
    stage = 1
    history = []
    while True:
        losses = np.r_[losses, np.asarray(draw(n - len(losses), rng), dtype=float)]
        if losses.shape != (n,) or not np.isfinite(losses).all():
            raise ValueError("invalid loss sample")
        ordered = np.sort(losses)
        alpha = (1 - confidence) / (2**stage)
        lower_rank = int(binom.ppf(alpha / 2, n, 0.99))
        upper_rank = int(binom.ppf(1 - alpha / 2, n, 0.99)) + 1
        low = ordered[lower_rank - 1] if lower_rank >= 1 else -np.inf
        high = ordered[upper_rank - 1] if upper_rank <= n else np.inf
        estimate = float(np.quantile(ordered, 0.99))
        history.append(
            dict(
                paths=n,
                estimate=estimate,
                low=float(low),
                high=float(high),
                look_alpha=alpha,
            )
        )
        if max(estimate - low, high - estimate) <= half_width:
            return {
                "converged": True,
                "estimate": estimate,
                "interval": (float(low), float(high)),
                "history": history,
            }
        if n == max_paths:
            return {
                "converged": False,
                "estimate": estimate,
                "interval": (float(low), float(high)),
                "history": history,
            }
        n = min(max_paths, n * 2)
        stage += 1
```

For reproduction, use `sigma=.1/2.326347874; draw=lambda n,rng:-1_000_000*rng.normal(0,sigma,n)` and call the function with seed 0; test against the analytic 100,000. Monte Carlo precision does not cover fitting uncertainty, stale risk factors or incorrect tails.

### Backtest, challenge and govern

For daily forecasts use an aligned one-day P&L convention (hypothetical fixed positions versus actual trading effects are separate checks), compare loss>forecast, and examine both exception frequency and clustering. Under a correct independent 99% model, 250 days have 2.5 expected exceptions; use exact binomial/unconditional coverage tests and transition/duration independence tests, with caution about very few tail observations. The traditional 250-day traffic-light interpretation is green 0–4 (continue monitoring), yellow 5–9 (investigate drivers, targeted validation/escalation and risk controls), red>=10 (presume a material problem, escalate/restrict and remediate). These are the cited Basel-style backtest bands, not a claim that one generic operational policy is today's entire capital rule. [BIS application guidance](https://www.bis.org/committees/bcbs/basel-framework/standard/mar/99/inforce/2019-12-15/published/2019-12-15).

Review rolling 250-day and longer/subperiod/slice results, logging model versions and regime shifts; overlapping windows are dependent and a green zone is not proof the tail beyond VaR is safe. Stress historical/hypothetical jumps, volatility/skew/correlation and missing-data shocks; compare historical simulation, parametric and heavy-tail challengers. Validate prices/corporate actions, calendars, stale/missing feeds, units and loss signs. Require independent change review, versioned assumptions, reproducible seeds/data and ongoing exception/latency/drift monitoring. Expected shortfall and stress loss complement a quantile that says nothing about severity beyond its threshold.

Borrow fees, recall closeouts, margin funding, forced liquidation/slippage and liquidity costs belong in an expanded short loss, e.g. $VR+fees+funding+closeout\_cost$. Unbounded positive R means unbounded short loss support. These frictions do not alter the mathematical VaR above unless explicitly included in L; operational limits require their own scenarios and controls.
