## Question

Value iteration and policy iteration are the two classical dynamic-programming methods for solving a Markov decision process whose transition model is known. In this exercise the MDP is a small grid world, Frozen Lake: an agent walks on ice towards a goal and must avoid holes, and on slippery ice a move can go sideways. You compute the optimal state values and an optimal policy with both methods.

The environment

The default map is a 4x4 grid. Rows are listed top to bottom.

S F F F
F H F H
F F F H
H F F G
S: start (safe). F: frozen surface (safe). H: hole, a terminal state. G: goal, a terminal state.
States are numbered row by row, so the start is state 0 and the goal of the 4x4 map is state 15.

```text
Actions: 0 = left, 1 = down, 2 = right, 3 = up. A move into the border leaves the agent where it is.
```

Reward: +1 when a move enters G, 0 otherwise (the reward_schedule default (1.0, 0.0, 0.0)).
With is_slippery=True the agent moves in the intended direction with probability success_rate, and in each of the two perpendicular directions with probability (1 - success_rate) / 2. With is_slippery=False the intended move always happens.
G and H are absorbing: every action keeps the agent there with reward 0.

The class FrozenLakeEnv (standalone, no Gym needed) is given in full under "Environment code" at the end. Use env.nS, env.nA and the transition table env.P, where env.P[s][a] is a list of (probability, next_state, reward, done) tuples. Do not change the class.

### What to implement

value_iteration(env, gamma=0.95, tol=1e-8, max_iterations=10000) -&gt; (V, policy)
policy_iteration(env, gamma=0.95, tol=1e-8, max_iterations=1000) -&gt; (V, policy)

Arguments: env is a FrozenLakeEnv; gamma is the discount factor; tol is the convergence threshold on the largest value change in one sweep; max_iterations caps the number of sweeps (value iteration) or improvement rounds (policy iteration).

Both functions return V, a float NumPy array of length env.nS with the optimal value of each state, and policy, an integer NumPy array of length env.nS with the optimal action of each state.

### Rules

1. The value of a state is the expected discounted sum of rewards, Q(s, a) = sum over (p, s', r, done) in env.P[s][a] of p * (r + gamma * V[s']), and the optimal value satisfies V[s] = max over a of Q(s, a). Terminal states have value 0.
2. value_iteration starts from V = 0, sweeps over all states updating V[s] to max_a Q(s, a), and stops when the largest change in a sweep is below tol. The policy is greedy with respect to the final V.
3. policy_iteration starts from the policy that always plays action 0, evaluates the current policy until the largest change in a sweep is below tol, then improves it greedily, and stops when no action changes.
4. The returned policy is greedy: in every state its action has a Q(s, a) within 1e-6 of the best one under the returned V. When two actions are exactly tied, as down and right are at the start of the deterministic 4x4 map, return the smaller index.
5. Both methods must give the same V (to within 1e-4) on the same environment and gamma; for the gamma and tol ranges in the constraints this is achievable, because each result is within about tol / (1 - gamma) of the true optimum.
6. Do not call env.step or env.reset: the model is known, so no sampling is needed.

import numpy as np
import random
from typing import Optional, Tuple, List, Dict

class FrozenLakeEnv:

A lightweight re-implementation of FrozenLake-v1 supporting:
• map_name or custom desc
• is_slippery
• success_rate (probability of following intended action)
• reward_schedule (tuple: (goal_reward, hole_reward, step_penalty))

States are numbered row-major from 0..(nrow*ncol-1).
Actions: 0=LEFT, 1=DOWN, 2=RIGHT, 3=UP.
"""

LEFT, DOWN, RIGHT, UP = range(4)

def __init__(
self,
desc: Optional[List[str]] = None,
map_name: str = "4x4",
is_slippery: bool = True,
success_rate: float = 1.0 / 3.0,
reward_schedule: Tuple[float, float, float] = (1.0, 0.0, 0.0),
):
# Map templates
MAPS = {
"4x4": [
"SFFF",
"FHFH",
"FFFH",
"HFFG",
],
"8x8": [
"SFFFFFFF",
"FFFFFFFF",
"FFFHFFFF",
"FFFFFHFF",
"FFFHFFFF",
"FHHFFFHF",
"FHFFHFHF",
"FFFHFFFG",
],
}
if desc is None:
desc = MAPS[map_name]
self.desc = np.asarray(desc, dtype="c")
self.nrow, self.ncol = self.desc.shape

self.is_slippery = is_slippery
self.success_rate = success_rate
self.reward_schedule = reward_schedule

self.nS = self.nrow * self.ncol
self.nA = 4
self.P = self._build_transition_model()
self.state = None
self.last_action = None

# ---------------------------------------------------------------
# Transition model
# ---------------------------------------------------------------
def _build_transition_model(self) -&gt; Dict[int, Dict[int, List[Tuple[float, int, float, bool]]]]:
P = {s: {a: [] for a in range(self.nA)} for s in range(self.nS)}
for r in range(self.nrow):
for c in range(self.ncol):
s = self.to_state(r, c)
for a in range(self.nA):
P[s][a] = self._calculate_transitions(r, c, a)
return P

def _calculate_transitions(self, r: int, c: int, a: int):
transitions = []
letter = self.desc[r, c].decode("utf-8")
if letter in "GH":  # terminal states
transitions.append((1.0, self.to_state(r, c), 0.0, True))
return transitions

def move(row, col, act):
if act == self.LEFT:
col = max(col - 1, 0)
elif act == self.DOWN:
row = min(row + 1, self.nrow - 1)
elif act == self.RIGHT:
col = min(col + 1, self.ncol - 1)
elif act == self.UP:
row = max(row - 1, 0)
return row, col

possible_actions = [a]
probs = [1.0]
if self.is_slippery:
# random left/right with some probability
left = (a - 1) % 4
right = (a + 1) % 4
intended = a
possible_actions = [intended, left, right]
probs = [self.success_rate, (1 - self.success_rate) / 2, (1 - self.success_rate) / 2]

for act, p in zip(possible_actions, probs):
newr, newc = move(r, c, act)
newstate = self.to_state(newr, newc)
newletter = self.desc[newr, newc].decode("utf-8")
done = newletter in "GH"
if newletter == "G":
reward = self.reward_schedule[0]
elif newletter == "H":
reward = self.reward_schedule[1]
else:
reward = self.reward_schedule[2]
transitions.append((p, newstate, reward, done))
return transitions

# ---------------------------------------------------------------
# Step/reset API (Gym-like)
# ---------------------------------------------------------------
def reset(self, seed: Optional[int] = None) -&gt; Tuple[int, dict]:
if seed is not None:
random.seed(seed)
np.random.seed(seed)
start_pos = np.argwhere(self.desc == b"S")[0]
self.state = self.to_state(start_pos[0], start_pos[1])
return self.state, {}

def step(self, action: int) -&gt; Tuple[int, float, bool, bool, dict]:
assert 0 &lt;= action &lt; self.nA
transitions = self.P[self.state][action]
probs = [p for p, _, _, _ in transitions]
i = np.random.choice(len(transitions), p=probs)
p, next_state, reward, done = transitions[i]
self.state = next_state
self.last_action = action
return next_state, reward, done, False, {}

# ---------------------------------------------------------------
# Utilities
# ---------------------------------------------------------------
def to_state(self, r: int, c: int) -&gt; int:
return r * self.ncol + c

def to_pos(self, s: int) -&gt; Tuple[int, int]:
return divmod(s, self.ncol)

def render(self):
desc = self.desc.copy().astype(str)
r, c = self.to_pos(self.state)
desc[r, c] = "A"
print("

## Worked solution

### Bellman backups over the supplied transition table

Use the known model, never `step/reset`. For a value vector `[nS]`, compute Q `[nS,nA]` by summing each transition's probability times reward plus discounted next value. Both algorithms keep absorbing terminal values zero because their self-loops have zero reward and start from zero. Value iteration applies the optimality backup; policy iteration repeatedly evaluates its chosen action and then chooses a greedy action. NumPy argmax returns the smaller index for exact ties.

The environment code in the prompt has lost indentation and includes a broken render string in its transcription; this solution consumes an environment with the stated `nS,nA,P` contract and does not change its semantics. Tests build the stated deterministic/slippery transition table as an explicitly labeled fixture, without claiming the malformed pasted class executes unchanged.

```python
import numpy as np


def _q_values(env, V, gamma):
    return np.array(
        [
            [
                sum(p * (r + gamma * V[sp]) for p, sp, r, done in env.P[s][a])
                for a in range(env.nA)
            ]
            for s in range(env.nS)
        ]
    )


def value_iteration(env, gamma=0.95, tol=1e-8, max_iterations=10000):
    V = np.zeros(env.nS, dtype=float)
    for _ in range(max_iterations):
        new = _q_values(env, V, gamma).max(axis=1)
        change = np.max(np.abs(new - V))
        V = new
        if change < tol:
            break
    else:
        raise RuntimeError("value iteration did not converge within cap")
    return V, _q_values(env, V, gamma).argmax(axis=1).astype(int)


def policy_iteration(env, gamma=0.95, tol=1e-8, max_iterations=1000):
    V, policy = np.zeros(env.nS), np.zeros(env.nS, dtype=int)
    for _ in range(max_iterations):
        # Discounted Bellman evaluation is a contraction; no sampling required.
        while True:
            q = _q_values(env, V, gamma)
            new = q[np.arange(env.nS), policy]
            delta = np.max(np.abs(new - V))
            V = new
            if delta < tol:
                break
        greedy = _q_values(env, V, gamma).argmax(axis=1).astype(int)
        if np.array_equal(greedy, policy):
            return V, greedy
        policy = greedy
    raise RuntimeError("policy iteration did not converge within cap")
```

A full backup costs $O(nS\,nA\,b)$ for b outcomes/action. Since gamma<1, the Bellman operator contracts sup-norm errors by gamma; a final sweep difference below tol bounds value error by approximately tol/(1-gamma). An exhausted iteration cap raises rather than returning an unlabelled unconverged result. Policy evaluation has its own convergent sweep loop; `max_iterations` caps improvement rounds as requested.

For deterministic ice the goal reward arrives on the sixth move, so $V[0]=.95^5=.7737809375$ and down (1) wins its exact tie with right (2). With slippery success rate .8, the fixture gives approximately .5312; holes and goal have value zero. Tests compare both methods, check every returned action's Q gap and use a no-reachable-goal fixture. Floating near-ties need only meet the stated 1e-6 greedy tolerance; if an evaluator demands a numerical tie policy, define its tolerance explicitly rather than silently changing argmax.
