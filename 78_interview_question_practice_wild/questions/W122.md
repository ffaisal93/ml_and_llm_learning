## Worked solution

1. Explain convolution, pooling and residual CNN blocks. Convolution reuses local filters across space; residual blocks make it easier to learn changes to a carried representation.
2. Specify channels, kernel, stride and padding, then calculate output height and width.
3. Apply learned local filters, nonlinearities and optional normalization; use pooling or strided operations to reduce resolution.
4. Add a shortcut only when shapes match, or use a projection. Explain the resulting receptive field and information loss.
5. Compare ReLU, GELU and gated activations. Activation choices alter gradient flow and representation, but must be compared under a fair parameter and compute budget.
6. ReLU returns max(0,x), with zero gradient on negative inputs under the usual convention.
7. GELU smoothly weights inputs by a Gaussian-CDF-based gate; SiLU uses x*sigmoid(x).
8. Gated FFNs use one learned branch to gate another, often with an extra projection. Count those extra weights when comparing models.
9. Why are residual connections and the feed-forward network both needed? Attention moves information between positions; the feed-forward network transforms the features at each position. Residual additions preserve an easy path for useful existing information.
10. An attention sublayer creates context-dependent mixtures of token values.
11. A position-wise nonlinear MLP expands the feature dimension, applies an activation or gate, and projects back. Its weights are shared across positions, not across all layers by default.
12. Add each sublayer's result to its input. Without nonlinearities, stacked affine feed-forward layers collapse into one affine map; attention's own input-dependent mixing remains nonlinear.

### Small example / sanity check

A 3-by-3 convolution with stride 1 and padding 1 preserves spatial size, while changing channel count through the filter bank.

### Common trap

Adding residual tensors with incompatible channel or spatial dimensions.
