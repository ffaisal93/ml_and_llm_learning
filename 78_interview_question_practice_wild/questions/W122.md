## Worked solution

### Solution outline

#### Explain convolution, pooling and residual CNN blocks.

Convolution reuses local filters across space; residual blocks make it easier to learn changes to a carried representation.

1. Specify channels, kernel, stride and padding, then calculate output height and width.
2. Apply learned local filters, nonlinearities and optional normalization; use pooling or strided operations to reduce resolution.
3. Add a shortcut only when shapes match, or use a projection. Explain the resulting receptive field and information loss.

#### Compare ReLU, GELU and gated activations.

Activation choices alter gradient flow and representation, but must be compared under a fair parameter and compute budget.

1. ReLU returns max(0,x), with zero gradient on negative inputs under the usual convention.
2. GELU smoothly weights inputs by a Gaussian-CDF-based gate; SiLU uses x*sigmoid(x).
3. Gated FFNs use one learned branch to gate another, often with an extra projection. Count those extra weights when comparing models.

#### Why are residual connections and the feed-forward network both needed?

Attention moves information between positions; the feed-forward network transforms the features at each position. Residual additions preserve an easy path for useful existing information.

1. An attention sublayer creates context-dependent mixtures of token values.
2. A position-wise nonlinear MLP expands the feature dimension, applies an activation or gate, and projects back. Its weights are shared across positions, not across all layers by default.
3. Add each sublayer's result to its input. Without nonlinearities, stacked affine feed-forward layers collapse into one affine map; attention's own input-dependent mixing remains nonlinear.

### Understand why the approach works

#### Connect the model, objective and evaluation split

A model class states what relationships can be represented; the objective states which errors training penalizes; the split estimates where those relationships generalize. These are separate choices. For binary logistic regression,

$$
z_i=x_i^\top w+b,\qquad p_i=\sigma(z_i),\qquad
L=\frac1N\sum_i\left[\log(1+e^{z_i})-y_i z_i\right]+\lambda R(w).
$$

Compute the softplus term stably from logits. The derivative of the unregularized per-example loss with respect to its score is $p_i-y_i$. A decision threshold changes actions but does not refit the probability model.

Inspect a simple baseline and training/validation curves before diagnosing high bias or variance. Low training error and poor validation performance may indicate overfitting, entity leakage, an inappropriate split or a genuine distribution change. The remedies differ: regularization does not repair a broken future-information boundary.

Fit scaling, imputation and encoders within training folds. For repeated users, grouped validation can be necessary; for forecasting, preserve the direction of time. Include class imbalance, calibration and subgroup errors rather than reporting only one accuracy number. A model can improve ranking while becoming worse as a probability estimate, and a statistically better estimate can still produce worse decisions at an unsuitable operating threshold.

### Check your reasoning on related cases

**Compare ReLU, GELU and gated activations.** A three-matrix gated FFN with hidden width m has about 3dm weights, versus 2dm for an ordinary two-matrix FFN.

What is a dead ReLU? A unit stuck in a region where its gradient is zero for the observed training inputs.

**Why are residual connections and the feed-forward network both needed?** With d=8 and hidden width 32, an ordinary two-matrix FFN has 8*32+32*8=512 weights before biases. A three-matrix gated FFN has a different count.

Why does a residual branch need scale management at large depth? Repeated additions can grow activation variance.
