## Question

Problem: Implement Two Distributed Matrix Multiplication Strategies (DP and FSDP) Using a Communication Simulator

Implement distributed matrix multiplication C = A @ B across world_size simulated ranks, once as Data Parallel (DP) and once as Fully Sharded Data Parallel (FSDP), using only a provided Communicator to exchange data between ranks.

Provided
Communicator(world_size) with one collective, all_gather(rank, data) -&gt; list: every rank contributes data and receives the list of all ranks' contributions, ordered by rank. It is barrier-synchronized, so every rank must call it the same number of times in the same order.
run(fn, A, B, world_size): starts one thread per rank, calls fn(A, B, rank, world_size, comm) on each, and returns rank 0's result.

### Requirements

1. dp_mat_mul(A, B, rank, world_size, comm) — the input A is sharded by rows across ranks and the parameters B are replicated on every rank. Compute this rank's rows of C, then gather the outputs so every rank returns the full C.
2. fsdp_mat_mul(A, B, rank, world_size, comm) — the parameters B are sharded across ranks (each rank owns only one shard, for example a block of columns). Temporarily gather the shards to reconstruct B, multiply this rank's row-shard of A, then gather the outputs so every rank returns the full C.
3. Both results must match single-machine A @ B (checked with np.allclose).
4. State which dimension you shard for A, B and C, and where each communication step happens (input distribution, parameter gather, output gather).
5. Avoid deadlocks: all ranks issue the same collectives in the same order.
Input
A: NumPy array of shape (m, k); B: NumPy array of shape (k, n).
rank in [0, world_size), world_size &gt;= 1, and a shared Communicator.
Output

The full matrix C of shape (m, n) on every rank.

Constraints and edge cases

```text
world_size = 1 must reduce to plain A @ B for both strategies.
```

m (and, for FSDP, the sharded dimension of B) need not be divisible by world_size; uneven shards must still give the correct result.

### Examples

A is 4x3, B is 3x5, world_size = 2: run(dp_mat_mul, A, B, 2) equals A @ B.
A is 8x8, B is 8x8, world_size = 4: run(fsdp_mat_mul, A, B, 4) equals A @ B.
A is 7x5, B is 5x6, world_size = 3 (uneven shards): both strategies equal A @ B.

## Worked solution

### Match ownership and collective order

For DP, rank r owns a contiguous row slice of A and replicated B, computes its C rows, then all-gathers C along rows. For this FSDP simulation, rank r owns B's contiguous output-column slice, all-gathers those slices along columns to materialize B temporarily, computes its A rows and all-gathers C rows. Uneven deterministic bounds distribute the first remainder rows/columns one extra each, including empty shards. Every rank makes exactly one DP gather or two FSDP gathers in the same order.

```python
import numpy as np


def bounds(length, rank, world_size):
    q, r = divmod(length, world_size)
    start = rank * q + min(rank, r)
    return start, start + q + (rank < r)


def dp_mat_mul(A, B, rank, world_size, comm):
    start, end = bounds(A.shape[0], rank, world_size)
    local_C = A[start:end] @ B
    return np.concatenate(comm.all_gather(rank, local_C), axis=0)


def fsdp_mat_mul(A, B, rank, world_size, comm):
    lo, hi = bounds(B.shape[1], rank, world_size)
    local_B = B[:, lo:hi].copy()
    # B is a full input only in this simulator's function signature; the
    # distributed computation uses the local shard and the gathered parameters.
    full_B = np.concatenate(comm.all_gather(rank, local_B), axis=1)
    start, end = bounds(A.shape[0], rank, world_size)
    local_C = A[start:end] @ full_B
    return np.concatenate(comm.all_gather(rank, local_C), axis=0)


# Chosen standalone communication fixture; use the provided comm in the exercise.
class Communicator:
    def __init__(self, world_size):
        import threading

        self.world_size = world_size
        self.barrier = threading.Barrier(world_size, timeout=10)
        self.slots = [None] * world_size
        self.calls = [0] * world_size

    def all_gather(self, rank, data):
        from copy import deepcopy

        self.calls[rank] += 1
        self.slots[rank] = deepcopy(data)
        self.barrier.wait()
        result = deepcopy(self.slots)
        self.barrier.wait()
        if rank == 0:
            self.slots = [None] * self.world_size
        self.barrier.wait()
        return result


def run_all(fn, A, B, world_size):
    from concurrent.futures import ThreadPoolExecutor

    comm = Communicator(world_size)

    def worker(rank):
        try:
            return fn(A, B, rank, world_size, comm)
        except BaseException:
            comm.barrier.abort()
            raise

    with ThreadPoolExecutor(max_workers=world_size) as pool:
        results = list(pool.map(worker, range(world_size)))
    return results, comm.calls


if __name__ == "__main__":
    rng = np.random.default_rng(3)
    for m, k, n, p in [
        (4, 3, 5, 2),
        (8, 8, 8, 4),
        (7, 5, 6, 3),
        (2, 3, 1, 5),
        (3, 2, 4, 1),
    ]:
        A = rng.normal(size=(m, k))
        B = rng.normal(size=(k, n))
        for fn, count in [(dp_mat_mul, 1), (fsdp_mat_mul, 2)]:
            outputs, calls = run_all(fn, A, B, p)
            assert all(np.allclose(C, A @ B) for C in outputs) and calls == [count] * p
    print(
        "W035: every rank matches A@B; rectangular/uneven/empty shards and collective counts passed"
    )
```

### Communication and memory accounting

The simulator passes full A/B to each callback, so selecting the local shard is an **input-distribution simulation**; it does not make the full input cease to exist in that process. Real input distribution would send only A rows and B column shards before these functions. The FSDP local matmul explicitly uses gathered B rather than cheating by multiplying the original global B. Both functions return the full C on every rank as requested.

For A:(7,5), B:(5,6), p=3, A row sizes are3/2/2 and B column sizes2/2/2; concatenation restores original order. With p greater than m/n, empty arrays keep correct two-dimensional shapes and still participate. The standalone fixture is barrier-synchronized, copies values and aborts on worker exceptions to expose rather than hang on a failed rank. Every-rank equality is tested for all supplied shapes, p=1 and empty shards.

Ignoring storage of the simulator's full inputs, DP holds B plus local A/C and gathered C; FSDP keeps a persistent B shard but peaks at a full temporary B plus gather buffers, so this single-layer operation alone does not deliver p-fold peak memory savings. Real FSDP gathers layer units and releases/reshards them and also manages gradients/optimizer states; this exercise implements only forward communication. Output shards concatenate; summing them would be a different matrix partition.
