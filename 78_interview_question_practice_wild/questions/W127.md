## Question

Oral ML-fundamentals quiz that runs at the front of nearly every MLE / Monetization / Commerce phone screen. Topics rotate but the deep-dive targets are stable: dropout mechanics, overfitting mitigation, normalization choices, and standard loss functions.

### Requirements

Verbal (no code) quiz at the start of MLE coding rounds, typically 15-30 minutes. Recurring questions across reports:

Dropout: explain the mechanism. How is the dropout rate applied? What is the inference-time correction (scaling by 1 - p)? Why does it work as regularization?
Overfitting: list mitigation strategies. Narrow to deep learning specifically — what works there that does not apply to classical models?
Normalization: differentiate Batch Norm vs. Layer Norm. How are statistics computed in training vs. inference?
Loss functions: derive binary cross-entropy from first principles. Why use KL divergence? What are its advantages over MSE for classification?
Classification metrics: what does AUC ROC measure? When does it mislead? How is it different from PR-AUC?
Transformer specifics: scaling attention by $\sqrt{d_k}$, role of the FFN in the attention block, KV cache, RoPE, Flash Attention.
Inference acceleration: walk through how multi-head attention is served and how to speed up LLM inference — KV-cache reuse, paged / continuous batching (vLLM-style), quantization, and where the latency vs. throughput trade-off lives.
RL post-training: where does RL fit in LLM post-training? Name the algorithm family (PPO / DPO / GRPO) and where each is preferred.
Multimodal LLM training: how would you set up a multimodal embedding pipeline for caption-to-video search? What metric trades off recall vs. latency?
Classical models: why is XGBoost less prone to overfit than a single decision tree? Cover learning rate, subsampling, regularization on tree depth.
Notes
The dropout question often drills into inverted-dropout: at train time scale activations by 1/(1-p) so that no inference-time scaling is needed.
For overfitting in deep learning, the expected list is: dropout, weight decay, early stopping, data augmentation, label smoothing, stochastic depth, ensembling, larger / more diverse data.
Batch Norm normalizes per-feature across the batch; Layer Norm normalizes per-sample across features. Transformer blocks use Layer Norm because batch statistics on variable-length sequences are unreliable.
The attention-scaling intuition: dot products grow with $d_k$, pushing softmax into saturated regions; dividing by $\sqrt{d_k}$ keeps gradients in a workable range.
KL divergence equals cross-entropy minus the (constant w.r.t. parameters) entropy of the target distribution — useful when matching distributions rather than one-hot labels.
Common failure mode: candidates explain dropout but cannot articulate the inference-time scaling rule. Interviewers reach for that follow-up consistently.

## Worked solution

### Dropout and overfitting

With conventional dropout, training uses $mh$ for $m\sim\mathrm{Bernoulli}(1-p)$ and inference uses $(1-p)h$. With **inverted** dropout, training uses $mh/(1-p)$ and inference uses h unchanged. Both preserve the activation expectation under their stated convention, though a nonlinear network's expected output is not exactly a scaled deterministic network. At p=.5 a retained activation 4 becomes 8 during inverted-dropout training. Masks discourage coadaptation and inject training noise; set evaluation mode for ordinary deterministic inference.

For deep learning use appropriate weight decay, early stopping, label-preserving augmentation, more/diverse data, label smoothing, dropout, stochastic depth and ensembling, tuned against clean validation. Penalties/early stopping/data collection also help classical models; activation dropout/stochastic depth need a neural structure. Diagnose training failure and data leakage before adding regularizers.

### Normalization and loss

BatchNorm computes channel-wise batch/spatial means/variances during training and normally uses running estimates at inference, with learned gamma/beta. LayerNorm uses each token/sample's feature statistics at both times and learns per-feature gamma/beta; it does not need running means. Tiny batches and distribution mismatch can hurt BatchNorm.

For independent Bernoulli labels, likelihood is $\prod_i p_i^{y_i}(1-p_i)^{1-y_i}$; minus its log gives BCE. Its logit derivative is $p-y$. For target distribution q, $D_{KL}(q\|p)=\sum q\log(q/p)=H(q,p)-H(q)$, so minimizing KL and cross-entropy is equivalent when q is fixed. It naturally matches soft teacher/label distributions and penalizes confidently assigning tiny mass to required outcomes. MSE on probabilities is a valid Brier scoring rule but yields sigmoid gradient $(p-y)p(1-p)$, which may become small when confidently wrong; MSE on raw logits is a different, generally unsuitable probability objective.

### Metrics and Transformer mechanics

ROC-AUC is $P(s(X^+)>s(X^-))$ with half credit for ties. It can look strong despite poor precision at rare prevalence or an unusable operating region. PR-AUC focuses positive retrieval and has a prevalence-dependent baseline; inspect operating cost/calibration too.

Attention scores have variance roughly $d_k$ under independent standardized coordinates, hence divide by $\sqrt{d_k}$. The FFN nonlinearly transforms each position; attention exchanges information across positions. RoPE rotates Q/K pairs to encode relative displacement; cached decoding must preserve positions. Flash-style attention tiles exact attention to reduce memory IO rather than approximating the softmax. Serving projects/splits heads, computes masked softmax value mixtures, concatenates and projects; cache K/V, batch active requests continuously and allocate cache pages to reduce fragmentation. Quantization saves bytes only with measured compatible kernels/quality. Larger batches improve aggregate utilization while queueing and long prefills can worsen TTFT/inter-token latency.

### Post-training, multimodal retrieval and trees

PPO uses sampled on-policy rollouts, a learned/baseline value estimate and clipped policy updates, often with a reference-policy KL penalty; it is useful when sequential policy interaction and explicit reward justify its cost. DPO fits preference pairs offline via a reference-relative logistic objective without an online RL rollout loop; prefer it when reliable static comparisons are available. GRPO uses groups of sampled answers and group-relative reward advantages instead of a separately trained value model; useful for verifiable outcomes such as math/code when group sampling is affordable. These methods optimize different data/reward setups and can exploit weak reward proxies.

For caption-to-video search, use a text encoder and a temporally pooled frame/video encoder projected to a shared normalized embedding space, trained on matched pairs with a contrastive loss and audited negatives. Hold out video/source families, measure Recall@k/mAP plus p95 end-to-end query latency and index memory. Vary ANN search effort/rerank depth to trace the recall-latency frontier; frame-only embeddings can miss temporal action order.

XGBoost is not immune to overfit. Compared with a deep single tree, shallow regularized additive trees, shrinkage, row/column subsampling and early stopping can control variance; too many/deep trees still memorize. L1/L2 leaf penalties and depth/min-child constraints regulate capacity. Compare on the same validation design rather than claiming boosting itself guarantees generalization.
