## Question

Implement a Two-Hidden-Layer MLP with Backpropagation in NumPy

Build a small fully connected neural network for regression from scratch, using only NumPy. It maps a 10-number input to one predicted number through two ReLU hidden layers. You write the forward pass, the mean squared error loss, the backward pass that returns every gradient, and a gradient descent step. No deep learning library is allowed.

### What to implement

A class MLP with:

__init__(self, input_dim=10, h1=64, h2=32, output_dim=1, seed=0): given in the starter. It stores the parameters in self.params, a dict with "W1" (input_dim, h1), "b1" (h1,), "W2" (h1, h2), "b2" (h2,), "W3" (h2, output_dim) and "b3" (output_dim,). Weights are drawn as rng.standard_normal(shape) * 0.01 with rng = np.random.default_rng(seed), in the order W1, W2, W3; biases start at zero.
forward(self, x) -&gt; np.ndarray: x has shape (B, input_dim); return the predictions, shape (B, output_dim).
loss(self, x, y) -&gt; float: the mean squared error between forward(x) and y (shape (B, output_dim)).
backward(self, x, y) -&gt; dict: the gradient of loss(x, y) with respect to every parameter, as a dict with the same six keys and shapes as self.params. It must not change the parameters.
step(self, grads, lr) -&gt; None: gradient descent, replacing every parameter p with p - lr * grads[name].

### Rules

1. The network is z1 = x W1 + b1, a1 = ReLU(z1), z2 = a1 W2 + b2, a2 = ReLU(z2), y_pred = a2 W3 + b3. The output layer has no activation.
2. ReLU(z) = max(z, 0). Its derivative is 1 where z &gt; 0 and 0 where z &lt;= 0 (so 0 at exactly 0).
3. The loss is mean((y_pred - y) ** 2) over all B * output_dim entries.
4. forward, loss and backward do not modify x, y or self.params.

### Examples

Both examples use a tiny network, MLP(input_dim=2, h1=2, h2=2, output_dim=1), with these parameters:

```python
W1 = [[1, -1], [2, 1]]
b1 = [0, 0.5]
W2 = [[1, 0], [-1, 1]]
b2 = [0, -1]
W3 = [[2], [1]]
b3 = [0.5]
```

Example 1: x = [[1, 2], [1, -1]], y = [[7], [1.5]].

forward(x) gives [[8], [0.5]]. For the first row, z1 = [5, 1.5] and z2 = [3.5, 0.5], so the output is 2 * 3.5 + 0.5 + 0.5 = 8. The second row has z1 = [-1, -1.5], so both hidden layers are off and the output is just b3.
loss(x, y) is 1.0: the errors are +1 and -1.
backward(x, y) gives W3 = [[3.5], [0.5]], b3 = [0], W2 = [[10, 5], [3, 1.5]], b2 = [2, 1], W1 = [[2, -1], [4, -2]], b1 = [2, -1]. Only the first row contributes to the hidden-layer gradients, and the two output errors cancel in b3.
After step(grads, 0.1), W1 is [[0.8, -0.9], [1.6, 1.2]].

Example 2: change b2 to [1, 0] and use x = [[1, -0.5]], y = [[1.5]].

```text
z1 = [0, -1] and z2 = [1, 0], so forward(x) gives [[2.5]] and the loss is 1.0.
```

backward gives b3 = [2], W3 = [[2], [0]], b2 = [4, 0], and zeros for W2, W1 and b1. The units with a pre-activation of exactly 0 pass no gradient (rule 2).

### Constraints

$1 \le  B \le  1000; all dimensions are between 1 and 128$

Inputs are float arrays. Use vectorised NumPy (matrix products), not Python loops over samples.

## Worked solution

### Solution outline

#### Write a two-hidden-layer MLP and derive backpropagation.

Cache local intermediate values, then apply the chain rule in the reverse order of the forward computation.

1. Use Z1=XW1+b1, A1=ReLU(Z1), Z2=A1W2+b2, A2=ReLU(Z2), Yhat=A2W3+b3.
2. For mean squared error over all N*C outputs, dY=2*(Yhat-Y)/(N*C). Compute dW3=A2ᵀ*dY and db3=sum(dY), then propagate through W3 and the ReLU masks.
3. Repeat for the earlier layers. Keep parameter updates separate from gradient calculation and check a small network numerically.

#### Why does zero initialization fail in a hidden layer?

Identical hidden units can receive identical gradients and remain redundant instead of learning different features.

1. Trace the forward activations of two units with equal incoming weights and biases.
2. Show that their backward gradients are equal under symmetric outgoing connections, so gradient descent preserves symmetry.
3. Use an initialization that breaks symmetry with a scale appropriate to activation and fan-in; zero biases can still be reasonable.

### Understand why the approach works

#### Walk backward through the exact scalar objective

Use row-major examples and explicitly name every activation:

$$
Z_1=XW_1+b_1,\ A_1=\operatorname{ReLU}(Z_1),\quad
Z_2=A_1W_2+b_2,\ A_2=\operatorname{ReLU}(Z_2),\quad
\hat Y=A_2W_3+b_3.
$$

For $N$ examples and $C$ target coordinates, define $L=\|\hat Y-Y\|_F^2/(NC)$. The output derivative is therefore

$$
G_3=\frac{2}{NC}(\hat Y-Y),\qquad
\nabla_{W_3}L=A_2^\top G_3,\quad
\nabla_{b_3}L=\sum_iG_{3,i,:}.
$$

Propagate through the matrix and activation in reverse order:

$$
G_2=(G_3W_3^\top)\odot\mathbf1[Z_2>0],\qquad
\nabla_{W_2}L=A_1^\top G_2,
$$

then repeat for layer one. The ReLU mask belongs to the **preactivation** of the corresponding layer. Bias derivatives sum across reused batch positions, and no additional mean should be introduced after the $1/(NC)$ already in $G_3$.

For $X$ shaped $(4,3)$ and $W_1$ shaped $(3,5)$, $Z_1$ is $(4,5)$, $\nabla W_1$ is $(3,5)$ and $\nabla X$ is $(4,3)$. Check these shapes before compacting expressions.

Compute all gradients before updating weights, and compare each parameter tensor with a central-difference reference on a tiny non-boundary example. Shape agreement alone misses wrong transpose/reduction choices. A constant or symmetric initialization can also prevent useful hidden-unit differentiation; a correct backward pass does not guarantee an effective training configuration.

### Readable reference implementation

Read the explanation first, then trace one small input through these functions. This is the same implementation used by the local checks; its stated simplifications still apply.

```python
import math
from collections import deque
from dataclasses import dataclass
import numpy as np


def mlp_loss_and_gradients(x, y, params):
    """Three affine layers, two ReLUs; MSE averaged over all target elements."""
    w1, b1, w2, b2, w3, b3 = params
    z1 = x @ w1 + b1
    a1 = np.maximum(z1, 0)
    z2 = a1 @ w2 + b2
    a2 = np.maximum(z2, 0)
    prediction = a2 @ w3 + b3
    residual = prediction - y
    loss = float(np.mean(residual ** 2))
    g3 = 2 * residual / residual.size
    dw3, db3 = a2.T @ g3, g3.sum(axis=0)
    g2 = (g3 @ w3.T) * (z2 > 0)
    dw2, db2 = a1.T @ g2, g2.sum(axis=0)
    g1 = (g2 @ w2.T) * (z1 > 0)
    dw1, db1 = x.T @ g1, g1.sum(axis=0)
    return loss, [dw1, db1, dw2, db2, dw3, db3]
```

### Work a small example

For a dense layer X:(4,3), W:(3,2), dY:(4,2), dW has shape (3,2) and dX has shape (4,3).

### Edge cases and common mistakes

Dividing by batch size twice, or updating a weight before using its original value in an earlier gradient.

### Check your reasoning on related cases

**Why does zero initialization fail in a hidden layer?** A layer of 100 identically initialized units can behave like copies of one unit rather than 100 distinct features.

Why can both LoRA factors not start at zero? Their product gradients both vanish at that point.
