## Question

Implement a Two-Hidden-Layer MLP with Backpropagation in NumPy

Build a small fully connected neural network for regression from scratch, using only NumPy. It maps a 10-number input to one predicted number through two ReLU hidden layers. You write the forward pass, the mean squared error loss, the backward pass that returns every gradient, and a gradient descent step. No deep learning library is allowed.

### What to implement

A class MLP with:

__init__(self, input_dim=10, h1=64, h2=32, output_dim=1, seed=0): given in the starter. It stores the parameters in self.params, a dict with "W1" (input_dim, h1), "b1" (h1,), "W2" (h1, h2), "b2" (h2,), "W3" (h2, output_dim) and "b3" (output_dim,). Weights are drawn as rng.standard_normal(shape) * 0.01 with rng = np.random.default_rng(seed), in the order W1, W2, W3; biases start at zero.
forward(self, x) -&gt; np.ndarray: x has shape (B, input_dim); return the predictions, shape (B, output_dim).
loss(self, x, y) -&gt; float: the mean squared error between forward(x) and y (shape (B, output_dim)).
backward(self, x, y) -&gt; dict: the gradient of loss(x, y) with respect to every parameter, as a dict with the same six keys and shapes as self.params. It must not change the parameters.
step(self, grads, lr) -&gt; None: gradient descent, replacing every parameter p with p - lr * grads[name].

### Rules

1. The network is z1 = x W1 + b1, a1 = ReLU(z1), z2 = a1 W2 + b2, a2 = ReLU(z2), y_pred = a2 W3 + b3. The output layer has no activation.
2. ReLU(z) = max(z, 0). Its derivative is 1 where z &gt; 0 and 0 where z &lt;= 0 (so 0 at exactly 0).
3. The loss is mean((y_pred - y) ** 2) over all B * output_dim entries.
4. forward, loss and backward do not modify x, y or self.params.

### Examples

Both examples use a tiny network, MLP(input_dim=2, h1=2, h2=2, output_dim=1), with these parameters:

```python
W1 = [[1, -1], [2, 1]]
b1 = [0, 0.5]
W2 = [[1, 0], [-1, 1]]
b2 = [0, -1]
W3 = [[2], [1]]
b3 = [0.5]
```

Example 1: x = [[1, 2], [1, -1]], y = [[7], [1.5]].

forward(x) gives [[8], [0.5]]. For the first row, z1 = [5, 1.5] and z2 = [3.5, 0.5], so the output is 2 * 3.5 + 0.5 + 0.5 = 8. The second row has z1 = [-1, -1.5], so both hidden layers are off and the output is just b3.
loss(x, y) is 1.0: the errors are +1 and -1.
backward(x, y) gives W3 = [[3.5], [0.5]], b3 = [0], W2 = [[10, 5], [3, 1.5]], b2 = [2, 1], W1 = [[2, -1], [4, -2]], b1 = [2, -1]. Only the first row contributes to the hidden-layer gradients, and the two output errors cancel in b3.
After step(grads, 0.1), W1 is [[0.8, -0.9], [1.6, 1.2]].

Example 2: change b2 to [1, 0] and use x = [[1, -0.5]], y = [[1.5]].

```text
z1 = [0, -1] and z2 = [1, 0], so forward(x) gives [[2.5]] and the loss is 1.0.
```

backward gives b3 = [2], W3 = [[2], [0]], b2 = [4, 0], and zeros for W2, W1 and b1. The units with a pre-activation of exactly 0 pass no gradient (rule 2).

### Constraints

$1 \le  B \le  1000; all dimensions are between 1 and 128$

Inputs are float arrays. Use vectorised NumPy (matrix products), not Python loops over samples.

## Worked solution

### Write the forward equations before differentiating

The two hidden layers use ReLU, and the output is linear:

$$Z_1=XW_1+b_1,\quad A_1=\max(Z_1,0),$$
$$Z_2=A_1W_2+b_2,\quad A_2=\max(Z_2,0),\quad \widehat Y=A_2W_3+b_3.$$

If $Y$ has $M=B\times\text{output_dim}$ entries, then $L=\|\widehat Y-Y\|_F^2/M$ and the starting output gradient is $G_3=2(\widehat Y-Y)/M$. Dividing only by batch size is wrong when output dimension exceeds one.

### Exact NumPy class

```python
import numpy as np


class MLP:
    def __init__(self, input_dim=10, h1=64, h2=32, output_dim=1, seed=0):
        rng = np.random.default_rng(seed)
        self.params = {
            "W1": rng.standard_normal((input_dim, h1)) * 0.01,
            "b1": np.zeros(h1),
            "W2": rng.standard_normal((h1, h2)) * 0.01,
            "b2": np.zeros(h2),
            "W3": rng.standard_normal((h2, output_dim)) * 0.01,
            "b3": np.zeros(output_dim),
        }

    def _forward(self, x):
        p = self.params
        z1 = x @ p["W1"] + p["b1"]
        a1 = np.maximum(z1, 0)
        z2 = a1 @ p["W2"] + p["b2"]
        a2 = np.maximum(z2, 0)
        return a2 @ p["W3"] + p["b3"], (z1, a1, z2, a2)

    def forward(self, x):
        return self._forward(x)[0]

    def loss(self, x, y):
        prediction = self.forward(x)
        if prediction.shape != y.shape or y.size == 0:
            raise ValueError("Targets must match nonempty predictions")
        return float(np.mean((prediction - y) ** 2))

    def backward(self, x, y):
        p = self.params
        pred, (z1, a1, z2, a2) = self._forward(x)
        if y.shape != pred.shape or y.size == 0:
            raise ValueError("Targets must match nonempty predictions")
        d3 = 2 * (pred - y) / y.size
        dz2 = (d3 @ p["W3"].T) * (z2 > 0)
        dz1 = (dz2 @ p["W2"].T) * (z1 > 0)
        return {
            "W3": a2.T @ d3,
            "b3": d3.sum(axis=0),
            "W2": a1.T @ dz2,
            "b2": dz2.sum(axis=0),
            "W1": x.T @ dz1,
            "b1": dz1.sum(axis=0),
        }

    def step(self, grads, lr):
        for name in self.params:
            self.params[name] = self.params[name] - lr * grads[name]
```

### Read the backward pass in reverse order

For any affine layer $Z=AW+b$, gradients are $dW=A^\top dZ$, $db=\sum_{\text{batch}}dZ$, and $dA=dZW^\top$. ReLU multiplies the incoming gradient by the Boolean mask `z > 0`, including a zero derivative at exactly zero. `backward` creates gradients without changing parameters; only `step` updates them.

For the supplied first example, predictions are `[8,0.5]`, errors are `[1,-1]`, and the mean squared loss is one. The two output errors cancel in `b3`, while only the first example contributes through the active hidden units. The resulting first-layer gradient is `[[2,-1],[4,-2]]`, giving `[[0.8,-0.9],[1.6,1.2]]` after the stated update. For example two, the zero preactivations block the hidden gradients exactly as required.

Check every parameter with central differences away from ReLU kinks:

$$\frac{\partial L}{\partial p_j}\approx\frac{L(p_j+\epsilon)-L(p_j-\epsilon)}{2\epsilon}.$$

Use floating-point copies and restore each perturbed value. Also compare arrays before/after `forward`, `loss` and `backward` to check non-mutation. A multi-output test catches the missing output-dimension factor.

### Equivalent PyTorch training implementation

```python
import torch
from torch import nn


class TorchMLP(nn.Module):
    def __init__(self, input_dim=10, h1=64, h2=32, output_dim=1):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Linear(input_dim, h1),
            nn.ReLU(),
            nn.Linear(h1, h2),
            nn.ReLU(),
            nn.Linear(h2, output_dim),
        )

    def forward(self, x):
        return self.layers(x)


model = TorchMLP()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
x = torch.randn(8, 10)
y = torch.randn(8, 1)
optimizer.zero_grad(set_to_none=True)
loss = nn.functional.mse_loss(model(x), y, reduction="mean")
loss.backward()
optimizer.step()
```

This version is for learning/autograd comparison; it is not the NumPy-only submission. To compare exact gradients, copy each NumPy weight transposed into its `nn.Linear.weight`, copy biases, use double precision and the same inputs. PyTorch's default initialization is different, so merely matching seeds does not make the two models identical.
