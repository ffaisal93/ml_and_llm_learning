## Question

A toy compiler translates a program made of assignment statements. Given the program text, compute how long its instructions take to run and how much temporary memory they need at peak, under the cost model below.

### What to implement

extract_time_and_mem_cost(program)

program: a string with one statement per line. Blank lines are ignored.
Returns a tuple (time, mem) of two integers.
Program format

Each statement has the form lhs = rhs.

lhs is a variable name (letters, digits, underscore; it does not start with a digit).
rhs is a sequence of operands separated by binary operators from + - * /, with no parentheses. An operand is a variable name or a non-negative integer constant. Spaces around tokens are optional.
Every lhs is assigned exactly once, and a statement only reads names that are either input variables (never assigned in the program) or assigned on an earlier line.

### Rules

Time cost of a statement is the sum of:

```text
1. 1 for the assignment itself.
2. 1 for each variable operand read (every occurrence counts).
3. 0 for each integer constant.
4. 1 for each + or -, and 5 for each * or /.
```

The total time is the sum over all statements.

Memory cost counts only temporaries, which are the variables assigned in the program (input variables never count).
5. A temporary becomes live when its statement finishes.
6. It stops being live right after the last statement that reads it, so it is already free when that statement's own result becomes live.
7. A temporary that is never read stays live until the end of the program.
8. mem is the largest number of live temporaries at any moment between statements.

### Examples

Example 1:

```python
res1 = var1 + var2
res2 = var3 - var4
res3 = res2 + var5
res = res1 + res3
```

Every statement costs 1 (assignment) + 2 (reads) + 1 (operator) = 4, so time = 16. After each statement the live temporaries are {res1}, {res1, res2}, {res1, res3} (res2 was read for the last time) and {res}, so mem = 2. Result: (16, 2).

Example 2:

```python
res1 = 10 * var2
res2 = var3 * 100 - var4
res3 = res1 / 2
res = res2 + res3
```

The statements cost 1+1+5 = 7, 1+2+5+1 = 9, 1+1+5 = 7 and 1+2+1 = 4, so time = 27. The live sets are {res1}, {res1, res2}, {res2, res3} and {res}, so mem = 2. Result: (27, 2).

Example 3:

```python
a = x + y
b = x - y
c = x * y
r = a + b
```

Costs are 4, 4, 8 and 4, so time = 20. The live sets are {a}, {a, b}, {a, b, c} and {c, r}, so mem = 3. Result: (20, 3).

### Constraints

At most 10^5 statements, each with at most 100 operands.
Names are at most 20 characters long.

## Worked solution

### Separate instruction accounting from temporary liveness

The grammar is guaranteed valid and single-assignment. Tokenize names, integer constants and operators; do not evaluate arithmetic or apply language precedence, because the supplied time model simply counts occurrences. Each statement adds one assignment, each variable occurrence adds one, `+/-` adds one and `*/` adds five. Reading the same name twice costs two reads.

A first pass records every temporary's last read statement and stores each statement's read names. In the second pass, remove temporaries whose last read is this statement, then add this statement's lhs and update peak. That order implements the explicit rule that operands die before the result becomes live. A temporary never read has no last-read removal and remains live to the end. Input names never enter the live set.

```python
import re


def extract_time_and_mem_cost(program):
    tokens = re.compile(r"[A-Za-z_][A-Za-z_0-9]*|[0-9]+|[+*/-]")
    rows, last_read, total = [], {}, 0
    for line in program.splitlines():
        if not line.strip():
            continue
        lhs, rhs = map(str.strip, line.split("=", 1))
        ts = tokens.findall(rhs)
        reads = [t for t in ts if t[0].isalpha() or t[0] == "_"]
        total += (
            1
            + len(reads)
            + sum(5 if t in "*/" else 1 for t in ts if t in ("+", "-", "*", "/"))
        )
        i = len(rows)
        for name in reads:
            last_read[name] = i
        rows.append((lhs, reads))
    live, peak = set(), 0
    for i, (lhs, reads) in enumerate(rows):
        for name in reads:
            if last_read[name] == i:
                live.discard(name)
        live.add(lhs)
        peak = max(peak, len(live))
    return total, peak
```

For Example 1, the live sets are `{res1}`, `{res1,res2}`, `{res1,res3}`, `{res}` and time=16, mem=2. For `a=x+x; b=a+a`, time=4+4=8 (each read counts), while a is released before b becomes live, so peak=1. The tests cover all three examples, repeated operands, unused outputs, constants-only statements and blank lines. Time and storage are linear in total input tokens; sets keep liveness bookkeeping average O(1) per name. This parser assumes the stated valid grammar; rejecting malformed expressions is a separate requirement, not a capability silently claimed here.
