## Question

A toy compiler translates a program made of assignment statements. Given the program text, compute how long its instructions take to run and how much temporary memory they need at peak, under the cost model below.

### What to implement

extract_time_and_mem_cost(program)

program: a string with one statement per line. Blank lines are ignored.
Returns a tuple (time, mem) of two integers.
Program format

Each statement has the form lhs = rhs.

lhs is a variable name (letters, digits, underscore; it does not start with a digit).
rhs is a sequence of operands separated by binary operators from + - * /, with no parentheses. An operand is a variable name or a non-negative integer constant. Spaces around tokens are optional.
Every lhs is assigned exactly once, and a statement only reads names that are either input variables (never assigned in the program) or assigned on an earlier line.

### Rules

Time cost of a statement is the sum of:

```text
1. 1 for the assignment itself.
2. 1 for each variable operand read (every occurrence counts).
3. 0 for each integer constant.
4. 1 for each + or -, and 5 for each * or /.
```

The total time is the sum over all statements.

Memory cost counts only temporaries, which are the variables assigned in the program (input variables never count).
5. A temporary becomes live when its statement finishes.
6. It stops being live right after the last statement that reads it, so it is already free when that statement's own result becomes live.
7. A temporary that is never read stays live until the end of the program.
8. mem is the largest number of live temporaries at any moment between statements.

### Examples

Example 1:

```python
res1 = var1 + var2
res2 = var3 - var4
res3 = res2 + var5
res = res1 + res3
```

Every statement costs 1 (assignment) + 2 (reads) + 1 (operator) = 4, so time = 16. After each statement the live temporaries are {res1}, {res1, res2}, {res1, res3} (res2 was read for the last time) and {res}, so mem = 2. Result: (16, 2).

Example 2:

```python
res1 = 10 * var2
res2 = var3 * 100 - var4
res3 = res1 / 2
res = res2 + res3
```

The statements cost 1+1+5 = 7, 1+2+5+1 = 9, 1+1+5 = 7 and 1+2+1 = 4, so time = 27. The live sets are {res1}, {res1, res2}, {res2, res3} and {res}, so mem = 2. Result: (27, 2).

Example 3:

```python
a = x + y
b = x - y
c = x * y
r = a + b
```

Costs are 4, 4, 8 and 4, so time = 20. The live sets are {a}, {a, b}, {a, b, c} and {c, r}, so mem = 3. Result: (20, 3).

### Constraints

At most 10^5 statements, each with at most 100 operands.
Names are at most 20 characters long.

## Worked solution

### Solution outline

1. Tokenize each rhs into identifiers, integer constants and permitted operators; do not evaluate the expression. Charge one assignment, one per variable occurrence, one per +/- and five per */; constants cost zero reads.
2. In a first pass, collect assigned names and the index of the last statement that reads each assigned temporary. Input-only names never count as temporaries.
3. In a second pass, after reading a statement remove every temporary whose last use is this statement, then add the lhs as live and update the peak between-statement count. A never-read lhs stays live to program end under this exercise’s rule.
4. Both passes are linear in tokens plus assigned variables. Keep last-use/free sets per statement so simulation does not rescan all live variables.

### Readable reference implementation

Read the explanation first, then trace one small input through these functions. This is the same implementation used by the local checks; its stated simplifications still apply.

```python
from collections import defaultdict
from functools import lru_cache
import math
import re
import numpy as np


def compiler_cost(program):
    """Linear token scan under the exercise's cost/liveness model."""
    statements=[]
    for line in program.splitlines():
        if not line.strip(): continue
        lhs,rhs=line.split('=',1)
        tokens=re.findall(r'[A-Za-z_]\w*|\d+|[+*/-]',rhs)
        statements.append((lhs.strip(),tokens))
    assigned={lhs for lhs,_ in statements}
    last_use={}
    total=0
    frees=defaultdict(set)
    for index,(_,tokens) in enumerate(statements):
        total+=1
        for token in tokens:
            if token in '+-':total+=1
            elif token in '*/':total+=5
            elif not token.isdigit():
                total+=1
                if token in assigned:last_use[token]=index
    for name,index in last_use.items():frees[index].add(name)
    live=set();peak=0
    for index,(lhs,_) in enumerate(statements):
        live.difference_update(frees[index])
        live.add(lhs)
        peak=max(peak,len(live))
    return total,peak
```

### Work a small example

The first example totals 16 time units and peak 2. In a=x+y; b=x-y; c=x*y; r=a+b, c is never read and stays live, giving time 20 and peak 3.

### Edge cases and common mistakes

Using arithmetic precedence to change instruction cost or freeing the newly assigned lhs before recording its lifetime.
