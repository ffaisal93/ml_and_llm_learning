## Question

Build a sampler for a labelled dataset that is stored in one bucket of examples per class. A draw must return a class label together with one example of that class, and every class must be equally likely to be the one returned, however many examples its bucket holds. This is the sampler you would use to build class-balanced training batches.

### What to implement

stratified_sample(training, rng=None) -&gt; tuple[str, object]

training: a dict that maps a class label (str) to the list of examples of that class, for example {"cat": [...], "dog": [...], "fox": [...]}.
rng: an optional random.Random instance. Use it for every random choice, so a seeded generator makes the draw repeatable. When it is None, use the module-level random.
Return (class_label, example).

### Rules

1. The probability that the returned label is a given class is the same for every class that has at least one example (1/K for K such classes), whatever the bucket sizes.
2. Given the class, every example in its bucket is equally likely.
3. A class whose bucket is empty is never returned and does not count towards K.
4. If no class has any example (including an empty dict), raise ValueError.
5. Do not modify training.

### Examples

```text
1. {"cat": [1, 2, 3, 4], "dog": ["d"]}: the label is "cat" with probability 1/2 and "dog" with probability 1/2. If it is "cat", each of 1, 2, 3, 4 has probability 1/4; if it is "dog", the example is "d". Drawing uniformly over all five examples would instead return "cat" 80% of the time, which is not what is wanted here.
2. {"a": [], "b": [7], "c": []} always returns ("b", 7).
3. {"a": [], "b": []} raises ValueError.
```

### Constraints

Up to 10^3 classes and 10^6 examples per class; each draw takes O(K) time and O(K) extra space, where K is the number of classes.

## Worked solution

### Sample in two stages

Choose uniformly among **nonempty class labels**, then uniformly within that selected bucket. Choosing one example uniformly from all buckets would weight a class by its bucket size and violate the question.

```python
import random


def stratified_sample(training, rng=None):
    generator = random if rng is None else rng
    labels = [label for label, examples in training.items() if examples]
    if not labels:
        raise ValueError("No nonempty class is available")
    label = generator.choice(labels)
    example = generator.choice(training[label])
    return label, example
```

If K classes are nonempty and class c contains $n_c$ examples,

$$P(C=c)=1/K,\qquad P(E=e\mid C=c)=1/n_c,$$

so an individual example in that class is selected with probability $1/(Kn_c)$. Examples need not be equally likely across different classes; equal class probability is the intended behavior.

For four cats and one dog, each class has probability one half. Each specific cat has probability one eighth and the dog has probability one half. Empty buckets are excluded before either draw. A sole nonempty bucket always supplies its label; the selected example is still uniform within it.

### Check repeatability and input preservation

```python
first = random.Random(7)
second = random.Random(7)
data = {"cat": [1, 2, 3, 4], "dog": ["d"], "empty": []}
assert [stratified_sample(data, first) for _ in range(20)] == [
    stratified_sample(data, second) for _ in range(20)
]
assert stratified_sample({"a": [], "b": [7]}, random.Random(1)) == ("b", 7)
try:
    stratified_sample({"a": []})
    raise AssertionError("Expected ValueError")
except ValueError:
    pass
```

Both random choices use the supplied generator, and the function never changes a list or dictionary. It returns the selected object itself rather than an expensive deep copy. Building the list costs $O(K_{\mathrm{all}})$ time/space in the number of dictionary classes; each choice is constant time for Python lists. For many draws from fixed buckets, cache the nonempty labels once, but refresh that cache if buckets change. This sampler draws with replacement; balanced sampling does not imply every batch has exactly equal class counts.
