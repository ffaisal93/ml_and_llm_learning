## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Build a sampler for a labelled dataset that is stored in one bucket of examples per class. A draw must return a class label together with one example of that class, and every class must be equally likely to be the one returned, however many examples its bucket holds. This is the sampler you would use to build class-balanced training batches.

What to implement

stratified_sample(training, rng=None) -&gt; tuple[str, object]

training: a dict that maps a class label (str) to the list of examples of that class, for example {&quot;cat&quot;: [...], &quot;dog&quot;: [...], &quot;fox&quot;: [...]}.
rng: an optional random.Random instance. Use it for every random choice, so a seeded generator makes the draw repeatable. When it is None, use the module-level random.
Return (class_label, example).
Rules
1.
The probability that the returned label is a given class is the same for every class that has at least one example (1/K for K such classes), whatever the bucket sizes.
2.
Given the class, every example in its bucket is equally likely.
3.
A class whose bucket is empty is never returned and does not count towards K.
4.
If no class has any example (including an empty dict), raise ValueError.
5.
Do not modify training.
Examples
1.
{&quot;cat&quot;: [1, 2, 3, 4], &quot;dog&quot;: [&quot;d&quot;]}: the label is &quot;cat&quot; with probability 1/2 and &quot;dog&quot; with probability 1/2. If it is &quot;cat&quot;, each of 1, 2, 3, 4 has probability 1/4; if it is &quot;dog&quot;, the example is &quot;d&quot;. Drawing uniformly over all five examples would instead return &quot;cat&quot; 80% of the time, which is not what is wanted here.
2.
{&quot;a&quot;: [], &quot;b&quot;: [7], &quot;c&quot;: []} always returns (&quot;b&quot;, 7).
3.
{&quot;a&quot;: [], &quot;b&quot;: []} raises ValueError.
Constraints
Up to 10^3 classes and 10^6 examples per class; each draw takes O(K) time and O(K) extra space, where K is the number of classes.</pre>

## Worked solution

1. Create stratified samples from class buckets. Sampling rules must specify desired class proportions, replacement and rounding behavior.
2. Compute class quotas from target proportions and requested size using a deterministic remainder-allocation rule.
3. Sample within buckets using a seeded generator, respecting available counts or explicitly allowing replacement.
4. Preserve or record inclusion probabilities if the sample will be used for population estimation.

### Small example / sanity check

For 10 examples at proportions [0.55,0.45], quotas cannot both be exact; a stated tie/rounding rule must allocate the final unit.

### Common trap

Assuming an intentionally balanced sample has the original population prevalence.
