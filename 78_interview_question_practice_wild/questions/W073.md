## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Fill in the TODOs of a tiny PyTorch skeleton so a feed-forward (no recurrence, no attention) model trains for next-token prediction conditioned only on the current token.

1.
DataLoader — wrap SyntheticDataset(num_samples, seq_len, vocab_size) with DataLoader(dataset, batch_size=32, shuffle=True).
2.
Model — Embedding(vocab_size, hidden_dim) → Linear(hidden_dim, hidden_dim) → ReLU → Linear(hidden_dim, vocab_size).
3.
forward(x) — return logits of shape (batch, seq_len, vocab_size).
4.
Input/target prep — given sequences (batch, seq_len), set inputs = sequences[:, :-1], targets = sequences[:, 1:]; flatten so cross-entropy sees (batch·(seq_len-1), vocab_size) and (batch·(seq_len-1),).
5.
Training loop — forward, cross-entropy, backward, optimizer step (Adam is fine).

Hidden tests check that loss strictly decreases on a fixed seed and that the input/target shift is correct.</pre>

## Worked solution

1. Why is a next-token model trained with shifted targets? At position t, the model sees tokens through t and predicts token t+1. The target shift makes the training task match autoregressive generation.
2. Given tokens [x0,x1,x2,x3], use inputs [x0,x1,x2] and targets [x1,x2,x3], unless the library performs this shift internally.
3. Apply a causal mask to prevent access to later input positions. Use cross-entropy over vocabulary logits without an extra softmax first.
4. For instruction tuning, mask unwanted target positions after aligning the shift. Divide by the count of supervised targets, not padded sequence length.
5. Debug a miniature GPT that fails to learn. Localize the first broken invariant rather than changing many hyperparameters at once.
6. Check shifted labels, causal masking, tensor axes, vocabulary bounds and padding/loss masks on a tiny batch.
7. Check train/eval mode, gradient presence, optimizer steps and parameter changes. Overfit a tiny dataset with dropout disabled as a diagnostic.
8. Compare against a simple trusted baseline; then test generation and caching separately. Record one controlled change and its effect at a time.

### Small example / sanity check

If a prompt ends at input position 3 and the first answer is token 4, the prediction at position 3 is the first supervised answer target.

### Common trap

Shifting twice because both a data collator and the model's loss already shift labels, or supervising the wrong prompt boundary.
