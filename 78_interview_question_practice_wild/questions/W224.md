## Worked solution

### Keep the target fixed while varying model width

The runnable experiment below generates one Gaussian training/test fixture per seed, fixes a signal supported on the first ten coordinates and adds independent noise. It varies p across 80 training examples, including p=n. Keeping the true w fixed avoids silently changing task difficulty when adding features. The SVD solution is the exact least-squares/minimum-norm fit; using PyTorch optimization instead would require convergence checks and can implicitly regularize away the spike.

```python
import numpy as np
import torch
import json
from pathlib import Path
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

def double_descent(output_dir, seeds=30, sample_wise=False):
    """Nested Gaussian fixture; exact minimum-norm fits, ridge comparison."""
    output_dir = Path(output_dir); output_dir.mkdir(parents=True, exist_ok=True)
    torch.set_num_threads(1)
    fixed, maximum, m, sigma = 80, 200, 2000, 0.5
    axis = [10, 20, 40, 60, 70, 75, 78, 79, 80, 81, 82, 85, 90, 100, 120, 160, 200]
    # Fixed truth on the first 10 coordinates: adding pure-noise features does
    # not silently change the target or renormalize the true signal.
    records = []
    for seed in range(seeds):
        g = torch.Generator().manual_seed(seed)
        d = fixed if sample_wise else maximum
        X = torch.randn((maximum, d), generator=g, dtype=torch.float64)
        Xt = torch.randn((m, d), generator=g, dtype=torch.float64)
        w = torch.zeros(d, dtype=torch.float64); w[:10] = 1 / np.sqrt(10)
        y = X @ w + sigma * torch.randn(maximum, generator=g, dtype=torch.float64)
        yt = Xt @ w + sigma * torch.randn(m, generator=g, dtype=torch.float64)
        for a in axis:
            n, p = (a, fixed) if sample_wise else (fixed, a)
            design, test = X[:n, :p], Xt[:, :p]
            # SVD solves both regimes and picks the minimum-Euclidean-norm fit.
            U, s, Vh = torch.linalg.svd(design, full_matrices=False)
            coeff = U.T @ y[:n]
            inv = torch.where(s > torch.finfo(s.dtype).eps * max(n, p) * s[0], 1 / s, 0.)
            beta = Vh.T @ (inv * coeff)
            # Objective mean squared error + lam * ||w||^2.
            lam = 0.02
            ridge = Vh.T @ ((s / (s * s + n * lam)) * coeff)
            records.append(dict(seed=seed, axis=a, train=float(((design @ beta-y[:n])**2).mean()),
                                test=float(((test @ beta-yt)**2).mean()),
                                ridge=float(((test @ ridge-yt)**2).mean())))
    summary = []
    for a in axis:
        row = [r for r in records if r['axis'] == a]
        summary.append({'axis': a, **{k: float(np.median([r[k] for r in row])) for k in ('train','test','ridge')},
                        'test_q25': float(np.quantile([r['test'] for r in row], .25)),
                        'test_q75': float(np.quantile([r['test'] for r in row], .75))})
    name = 'sample_wise' if sample_wise else 'parameter_wise'
    (output_dir / (name+'.json')).write_text(json.dumps({'records': records, 'summary': summary}, indent=2))
    fig, ax = plt.subplots(figsize=(8, 4.5))
    for k in ('train','test','ridge'):
        ax.plot(axis, [r[k] for r in summary], marker='.', label=k)
    ax.fill_between(axis, [r['test_q25'] for r in summary], [r['test_q75'] for r in summary], alpha=.15)
    ax.axvline(fixed, color='gray', linestyle='--', label='n=p')
    ax.set(xlabel='training samples n (p=80)' if sample_wise else 'features p (n=80)',
           ylabel='MSE (median across seeds)',
           title='Sample-wise double descent' if sample_wise else 'Parameter-wise double descent')
    ax.set_yscale('symlog', linthresh=.1)
    ax.set_ylim(bottom=0)
    ax.legend(); fig.tight_layout(); fig.savefig(output_dir / (name+'.png'), dpi=160); plt.close(fig)
    return summary
```

Run `double_descent("outputs_201_250", seeds=30)`. The batch artifacts record every seed's train/test MSE and plot medians with the test interquartile band; medians are explicit because near-threshold means can be unstable. Test samples are independent of training but shared across p within a seed. Across the 30 seeded runs, median test MSE was .286 at p=10, .491 at p=40, 38.915 at p=80 and 1.003 at p=200; median training MSE at p=80 was below $4\times10^{-29}$. See [the plot](../assets/review_201_250_parameter_wise.png) and [raw results](../assets/review_201_250_parameter_wise.json).

For p<n, the residual degrees of freedom shrink and training error falls. Near p=n, tiny singular values amplify label noise through factors 1/s, causing high variance and a test-error spike. For p>n, the minimum-norm interpolator spreads the fit across additional directions; training error remains essentially zero, but test error can descend as noise amplification falls. This second descent is a property of the data/model/implicit bias, not a guarantee for every signal and feature construction.

Ridge replaces 1/s by $s/(s^2+n\lambda)$ for the mean-MSE objective and suppresses small singular directions. The plot includes lambda=.02 as an illustrative fixed setting, not a test-tuned optimum. Select lambda using validation in an actual modeling exercise. Early stopping, more data, less noise or better features also help, at the cost of bias, compute or collection effort. Do not claim a smooth deterministic curve from one seed or force a spike by changing the target as p changes.
