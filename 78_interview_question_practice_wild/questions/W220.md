## Question

Analyze how ordinary least-squares slopes combine across two disjoint samples, then reuse a fitted model to select and add one new regressor. The goal is to distinguish what can be inferred from fitted slopes alone and to avoid repeatedly fitting the full expanded model.

Given
Sample 1 contains X1 and Y1 with M observations; sample 2 contains X2 and Y2 with N observations. In parts 1 through 3, each X and Y is a single column and both within-sample predictor sums of squares are positive.
In parts 4 and 5, X1 is an N by k full-column-rank matrix, X2 is an N by (f-k) matrix, e is the residual from regressing Y on X1, and X1 = QR is an available thin QR factorization.
Treat M and N as known in part 3, and also state what can be guessed if only the two slopes are known.
Questions
1. Fit without intercepts on both samples and their concatenation. Given the two sample slopes beta1 and beta2, derive the combined slope beta and give its exact possible range, including beta1 = beta2.
2. Repeat with an intercept in every regression. Given only the two within-sample slopes, determine the possible pooled slope. Assume the attainable set has no gaps.
3. Return to regressions without intercepts and assume all (x, y) pairs are i.i.d. from one zero-mean bivariate Gaussian distribution. Give a reasonable estimate of beta using beta1, beta2, M, and N, and state the equal-size or unknown-size approximation.
4. Compute which column of X2 produces the largest reduction in residual sum of squares when added to X1. Derive the reduction formula and give the cost of scanning all candidates using the existing QR factorization.
5. For the selected column, derive the new coefficient and the update to the k existing coefficients without a full refit.
Efficiency target

Do not fit f-k separate augmented models or refit the full design from scratch, which can cost O(N f^2). The candidate scan should use matrix projections in O(N k (f-k)) time, followed by an O(k^2) triangular solve for the coefficient update.

### Constraints

M, N &gt;= 2; 1 &lt;= k &lt; f &lt;= N.
Ignore a candidate column whose component orthogonal to X1 has zero norm, because it adds no identifiable direction.

## Worked solution

### Combine slopes using sufficient statistics

Write $S_j=\sum x_i^2>0$ and $T_j=\sum x_i y_i$ within sample $j$. Without intercept, $\beta_j=T_j/S_j$, hence

$$\beta=\frac{S_1\beta_1+S_2\beta_2}{S_1+S_2}.$$

If the slopes differ, the exact attainable set is the **open** interval between them: positive finite $S_1,S_2$ prevent either endpoint. Either endpoint is an infimum/supremum. If both slopes equal $b$, the pooled slope is exactly $b$. For example, slopes 1 and 3 with $S_1=3,S_2=1$ pool to 1.5; the arithmetic mean is unjustified without equal predictor energy.

With intercepts, let $C_j=\sum(x-\bar x_j)^2$ and $w=MN/(M+N)$. The pooled centered slope is

$$\beta=\frac{C_1\beta_1+C_2\beta_2+w(\bar x_1-\bar x_2)(\bar y_1-\bar y_2)}{C_1+C_2+w(\bar x_1-\bar x_2)^2}.$$

The means are not determined by within-sample slopes. Choose nonzero predictor-mean separation and vary the response-mean separation: any real pooled slope is attainable, including when $\beta_1=\beta_2$. This is the between-group/Simpson effect, not a convex average restriction.

For i.i.d. zero-mean bivariate Gaussian pairs, predictor energies typically scale with sample size, so use $(M\beta_1+N\beta_2)/(M+N)$ as a reasonable approximation, not an identity. Equal or unknown sizes suggest $(\beta_1+\beta_2)/2$; two slopes alone reveal neither sample sizes nor actual energies.

### Add a regressor with residual projections

For each candidate $z$, use $u=(I-QQ^T)z$ and current residual $e=(I-QQ^T)y$. Adding $z$ reduces RSS by $(u^Te)^2/(u^Tu)$ and gives new coefficient $\alpha=u^Te/(u^Tu)$. Ignore $u=0$. Choose the largest reduction, not the largest raw correlation: candidate scale and collinearity matter. With $c=Q^Tz$, the old coefficient update is $\beta_{old,new}=\beta_{old}-R^{-1}c\alpha$.

Compute $C=Q^TX_2$, $Z=X_2-QC$, then all scores in $O(Nk(f-k))$ time plus $O(N(f-k))$ norms/correlations; a triangular solve costs $O(k^2)$ after selection. The NumPy implementation uses explicit back substitution in $O(k^2)$ and accepts the existing `(Q,R)` through the optional `qr` argument, avoiding recomputation of the factorization. Stream candidate blocks if the $N\times(f-k)$ residual matrix is too large. Numerical rank tolerance prevents nearly dependent directions from appearing spuriously useful.

```python
import numpy as np


def triangular_solve(R, b):
    result = np.empty_like(b, dtype=float)
    for i in range(len(b) - 1, -1, -1):
        result[i] = (b[i] - R[i, i + 1 :] @ result[i + 1 :]) / R[i, i]
    return result


def add_best_regressor(X1, X2, y, qr=None):
    """X1 [N,k], X2 [N,c], y [N]; returns index, new coefficients, RSS drop."""
    Q, R = qr if qr is not None else np.linalg.qr(X1, mode="reduced")
    beta = triangular_solve(R, Q.T @ y)
    e = y - X1 @ beta
    C = Q.T @ X2
    Z = X2 - Q @ C
    denom = np.einsum("ij,ij->j", Z, Z)
    scale = np.einsum("ij,ij->j", X2, X2)
    valid = denom > np.finfo(float).eps * 100 * scale
    if not valid.any():
        return None, beta, 0.0
    numer = Z.T @ e
    drop = np.full(X2.shape[1], -np.inf)
    drop[valid] = numer[valid] ** 2 / denom[valid]
    j = int(np.argmax(drop))
    alpha = numer[j] / denom[j]
    updated = beta - triangular_solve(R, C[:, j]) * alpha
    return j, np.r_[updated, alpha], float(drop[j])
```

Validation compares the chosen RSS reduction and every returned coefficient with independent full augmented least-squares fits on a seeded fixture. For an orthogonal candidate with $u^Tu=4$ and $u^Te=6$, the new coefficient is 1.5 and RSS drops by 9. A tiny denominator needs a relative rank check, not blind division.
