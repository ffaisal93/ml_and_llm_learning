## Question

Follow-up: Implement a Gaussian Mixture Model (GMM) Trained With EM

Building on K-Means, implement a k-component Gaussian Mixture Model (GMM) and fit it using the EM algorithm.

### Requirements

Given X (n x d) and k, implement EM and return:

mixture weights pi (length k, sums to 1)
means mu (k x d)
covariances Sigma (k x d x d; choose full or diagonal but be consistent)
responsibilities gamma (n x k)
Initialization
initialize mu from K-Means centroids
initialize pi uniformly or proportional to cluster sizes
initialize Sigma as identity or using within-cluster variance
Iteration & Convergence
E-step: compute responsibilities gamma[i,j] = p(z=j|x_i)
M-step: update pi, mu, Sigma using gamma
stop when log-likelihood improvement &lt; tol or max_iters reached
Numerical Stability
use log-sum-exp when computing responsibilities / likelihoods
add small eps to covariance to prevent singular matrices

### Constraints

1 &lt;= n &lt;= 1e4
1 &lt;= d &lt;= 50
1 &lt;= k &lt;= 50
Example

### Input

```python
X=[[0.0],[0.1],[10.0],[10.1]]
k=2
max_iters=50
tol=1e-4
```

### Output

pi sums to 1; mu has 2 means near 0 and 10; gamma rows sum to 1

## Worked solution

### Solution outline

EM alternates estimating soft cluster membership and fitting weighted Gaussian components.

1. In the E step, compute log component densities plus log mixture weights and normalize with log-sum-exp.
2. In the M step, update component weights, weighted means and covariances from responsibilities.
3. Regularize covariance matrices, handle nearly empty components and stop using likelihood changes plus a maximum iteration cap.

### Understand why the approach works

#### Choose the geometry before the update rule

An algorithm's center update follows its objective. Squared Euclidean clustering uses means:

$$
J_2=\sum_i\|x_i-\mu_{c_i}\|_2^2.
$$

For fixed assignments, differentiating with respect to a center sets it to its members' arithmetic mean. Manhattan distance instead uses coordinatewise medians:

$$
J_1=\sum_i\|x_i-m_{c_i}\|_1.
$$

For points $0,2,10$, the squared-error center is $4$, while the absolute-distance center is $2$. Swapping these updates silently solves a different problem.

Alternating nearest-center assignment and an exact fixed-cluster update cannot increase the chosen objective, but it need not reach a global optimum. State initialization, empty-cluster handling, deterministic ties and a stopping rule. Recompute assignments for returned centers after the last update.

For retrieval, state normalization, similarity and relevance labels. Cosine and raw dot product rank differently when embedding norms vary. Index approximation must be evaluated using recall and downstream quality, not latency alone. Negative examples can actually be valid alternative matches; audit this before interpreting a lower contrastive loss as better semantics. Evaluate cluster/retrieval stability across seeds and important slices rather than trusting a visually attractive plot.

### Work a small example

A point between two overlapping components can have responsibilities [0.4,0.6] instead of one hard assignment.

### Edge cases and common mistakes

Allowing a covariance to collapse to zero around one point, making likelihood singular.
