## Question

Follow-up: Implement a Gaussian Mixture Model (GMM) Trained With EM

Building on K-Means, implement a k-component Gaussian Mixture Model (GMM) and fit it using the EM algorithm.

### Requirements

Given X (n x d) and k, implement EM and return:

mixture weights pi (length k, sums to 1)
means mu (k x d)
covariances Sigma (k x d x d; choose full or diagonal but be consistent)
responsibilities gamma (n x k)
Initialization
initialize mu from K-Means centroids
initialize pi uniformly or proportional to cluster sizes
initialize Sigma as identity or using within-cluster variance
Iteration & Convergence
E-step: compute responsibilities gamma[i,j] = p(z=j|x_i)
M-step: update pi, mu, Sigma using gamma
stop when log-likelihood improvement &lt; tol or max_iters reached
Numerical Stability
use log-sum-exp when computing responsibilities / likelihoods
add small eps to covariance to prevent singular matrices

### Constraints

1 &lt;= n &lt;= 1e4
1 &lt;= d &lt;= 50
1 &lt;= k &lt;= 50
Example

### Input

```python
X=[[0.0],[0.1],[10.0],[10.1]]
k=2
max_iters=50
tol=1e-4
```

### Output

pi sums to 1; mu has 2 means near 0 and 10; gamma rows sum to 1

## Worked solution

### EM for a diagonal-covariance Gaussian mixture

Choose diagonal covariances consistently; return them as k×d×d diagonal matrices to match the requested shape. The model is $p(x_i)=\sum_j\pi_j\mathcal N(x_i;\mu_j,\operatorname{diag}(v_j))$. The E-step computes log-joints and log-sum-exp-normalized responsibilities. With $N_j=\sum_i\gamma_{ij}$, the M-step uses $\pi_j=N_j/n$, $\mu_j=\sum_i\gamma_{ij}x_i/N_j$ and $v_j=\sum_i\gamma_{ij}(x_i-\mu_j)^2/N_j+\epsilon$. Initialize means with an explicit K-means phase, not independent random Gaussians.

```python
import numpy as np


def fit_gmm(X,k,max_iters=100,tol=1e-4,eps=1e-6,seed=0):
    X=np.asarray(X,dtype=np.float64)
    if X.ndim!=2 or not len(X) or not 1<=k<=len(X) or max_iters<1 or tol<0 or eps<=0:
        raise ValueError('invalid data/configuration')
    if not np.isfinite(X).all():raise ValueError('finite input required')
    n,d=X.shape;rng=np.random.default_rng(seed)
    mu=X[rng.choice(n,k,replace=False)].copy()
    # K-means initialization; ties go to the first centroid, empties stay fixed.
    for _ in range(30):
        distances=np.stack([np.sum((X-center)**2,axis=1) for center in mu],axis=1)
        labels=distances.argmin(1);updated=mu.copy()
        for j in range(k):
            if np.any(labels==j):updated[j]=X[labels==j].mean(0)
        if np.array_equal(mu,updated):break
        mu=updated
    # Diagonal covariances, returned later as full d*d diagonal matrices.
    var=np.tile(np.maximum(X.var(0),eps),(k,1))
    pi=np.full(k,1/k)
    def e_step():
        log_joint=np.empty((n,k))
        for j in range(k):
            log_joint[:,j]=np.log(pi[j])-.5*(d*np.log(2*np.pi)+np.log(var[j]).sum()+((X-mu[j])**2/var[j]).sum(1))
        maximum=log_joint.max(1,keepdims=True)
        log_norm=maximum+np.log(np.exp(log_joint-maximum).sum(1,keepdims=True))
        return np.exp(log_joint-log_norm),float(log_norm.sum())
    gamma,ll=e_step();history=[ll]
    for _ in range(max_iters):
        nk=gamma.sum(0)
        for j in range(k):
            if nk[j]<1e-12:
                # Documented recovery; this restart can lower likelihood.
                mu[j]=X[rng.integers(n)];var[j]=np.maximum(X.var(0),eps)
                nk[j]=1e-12
            else:
                mu[j]=gamma[:,j]@X/nk[j]
                var[j]=(gamma[:,j,None]*(X-mu[j])**2).sum(0)/nk[j]+eps
        pi=nk/nk.sum()
        gamma,new_ll=e_step();history.append(new_ll)
        improvement=new_ll-ll;ll=new_ll
        if 0<=improvement<tol:break
    Sigma=np.array([np.diag(v) for v in var])
    return pi,mu,Sigma,gamma,history

X=np.array([[0.],[.1],[10.],[10.1]])
pi,mu,Sigma,gamma,history=fit_gmm(X,2,max_iters=50)
assert np.allclose(np.sort(mu[:,0]),[.05,10.05],atol=.01)
assert np.isclose(pi.sum(),1) and np.allclose(gamma.sum(1),1)
assert np.all(Sigma[:,0,0]>0) and np.isfinite(history).all()
assert np.min(np.diff(history))>-1e-5
pi,mu,Sigma,gamma,_=fit_gmm([[2.,2.]],1)
assert np.allclose(mu,[[2,2]]) and np.isfinite(Sigma).all() and gamma.tolist()==[[1.]]
print('W130: separated means, normalized responsibilities, regularization and singleton passed')
```

### Explain convergence and behavior checks

The supplied example converges to component means .05 and 10.05 (order immaterial), weights .5/.5 and normalized near-hard responsibilities. A singleton remains finite with positive diagonal regularization. Recompute the E-step after every M-step, so returned responsibilities correspond to returned parameters; log likelihood is the sum of per-row log normalizers, not the log of a sum across rows.

Unregularized exact EM increases likelihood, but added covariance ridge and nearly-empty component resets can break strict monotonicity. The code stops only for a nonnegative improvement below tol or the iteration cap and returns likelihood history for inspection. A reset is documented instead of dividing by zero; production code should report resets and compare multiple seeded starts. The separated-data check independently verifies nondecreasing likelihood within tolerance. Diagonal covariance cannot model rotated correlations; full covariance needs Cholesky solves/log determinants and O(kd²) covariance storage. Here E/M cost O(nkd), storage O(nk+kd), appropriate for the stated n,d,k, while small-component collapse still needs scientific inspection.
