## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Compute Softmax Entropy with Constant Extra Space

Given a sequence of logits, compute the entropy of its softmax distribution without constructing the probability vector. The implementation must remain stable when logits have very different magnitudes and must scan the input in fixed-size blocks.

What to implement

Implement compute_entropy_blockwise(logits: List[float], block_size: int) -&gt; float.

logits is a read-only sequence of numeric logits that supports len(logits) and integer indexing logits[i]. It may be lazy: it does not support slicing or iteration, and it is never copied into memory by the caller.
block_size is the maximum number of consecutive input positions processed by each inner scan. The result must not depend on its value.
Return the softmax entropy in nats.
Rules
1.
Use only O(1) auxiliary memory: the peak memory allocated during a call must not grow with len(logits). Do not materialize a softmax vector, a list of weights, or a block copy.
2.
Use a numerically stable calculation. Inputs may include negative infinity, which contributes zero probability, but at least one logit must be finite.
3.
Raise ValueError when logits is empty, block_size &lt;= 0, a value is NaN or positive infinity, or every value is negative infinity.
4.
Do not mutate logits.
Examples
compute_entropy_blockwise([0.0, 0.0], 1)
# 0.6931471805599453

The two outcomes have equal probability, so the result is ln(2).

compute_entropy_blockwise([1000.0, 999.0], 8)
# approximately 0.5822031088882179

Subtracting the maximum logit keeps this case finite without changing the probabilities.

Constraints
1 &lt;= len(logits) &lt;= 1_000_000
1 &lt;= block_size
Each entry is a finite real number or negative infinity.
The result is accepted within standard floating-point tolerance.</pre>

## Worked solution

1. Compute softmax entropy with constant auxiliary memory. Entropy can be calculated from normalization statistics without materializing the probability vector.
2. Scan by integer indexing to validate logits and find the finite maximum m; reject NaN, positive infinity, empty input and all-negative-infinity input.
3. Scan again in bounded inner blocks, accumulating Z=sum(exp(x-m)) and S=sum(exp(x-m)*(x-m)); negative infinity contributes zero.
4. Return log(Z)-S/Z. The shifted form avoids subtracting two huge nearly equal unshifted numbers. Keep only scalar accumulators.

### Small example / sanity check

For [0,0], Z=2 and S=0, so entropy is log(2). For one finite logit and the rest negative infinity, entropy is zero.

### Common trap

Using slices or copying each block, which breaks the read-only lazy-sequence and O(1)-memory requirements.
