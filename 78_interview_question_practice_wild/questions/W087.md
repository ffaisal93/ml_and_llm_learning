## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Data Science coding task (leaf dataset, 3 classes). The original assignment is a Jupyter-notebook workflow: load train.csv (feature columns feature_0..feature_2, integer label with 3 classes), split into train/validation, implement KNN from scratch (no built-in KNN trainer), report validation accuracy, predict on test.csv, write predictions.csv preserving row order, then tune K (optionally with cross-validation).

This gradable version isolates the core algorithm — KNN classification from scratch:

Function
knn_predict(train_features, train_labels, test_features, k) -&gt; list[label]
train_features: list of numeric feature vectors.
train_labels: integer class labels aligned with train_features.
test_features: feature vectors to classify.
k: number of neighbours.

Use Euclidean distance. Return the majority label among the k nearest training points for each test row. Tie-breaking: on a voting tie, return the smallest class id.

Example
train_features = [[0,0,0],[1,1,1],[2,2,2]]
train_labels   = [0, 1, 2]
test_features  = [[1,1,1]],  k = 1
-&gt; [1]
Notes
Do not use a built-in KNN implementation.
Euclidean distance; smallest-class-id tie-break.</pre>

## Worked solution

1. Implement k-nearest-neighbor classification. Store the training examples; for a query, predict from the labels of the nearest k examples under a chosen distance.
2. Fit feature transformations on training data only and apply the same transformation to queries.
3. Compute query-to-training squared distances, choose k neighbors, and count their labels or use defined distance weights.
4. Specify tie-breaking and k bounds. For many queries use batching or a search index; the brute-force baseline costs O(ND) per query before selection overhead.

### Small example / sanity check

Neighbors with labels [A,A,B] predict A for k=3. With k=2 and labels [A,B], a deterministic tie rule is required.

### Common trap

Comparing unscaled features with incompatible units or including the test point as its own training neighbor.
