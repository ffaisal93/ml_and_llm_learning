## Worked solution

### Overfitting, imbalance and regularization

A linear model can overfit with too many weak/correlated features or too little data; deep networks additionally learn flexible representations and can memorize labels. Compare train/validation learning curves under correct group/time boundaries before blaming capacity. For squared loss, expected error is noise + bias² + variance under a fresh independent label; this decomposition does not transfer unchanged to classification 0-1 loss. More capacity/weaker regularization often reduces bias and raises variance; more independent data often reduces estimation variance, with no universal monotonic guarantee. Imbalance is different: a 99% negative dataset gives 99% accuracy to an always-negative model, so inspect class recall, PR-AUC and cost-sensitive thresholds.

L1 adds $\lambda\|w\|_1$ and can create sparse coefficients; L2 adds $\lambda\|w\|^2/2$ and shrinks continuously. Inverted dropout multiplies activations by $m/(1-p)$, $m\sim\mathrm{Bernoulli}(1-p)$, and disables masks at inference. Early stopping selects an epoch using validation; augmentation encodes justified label-preserving transformations after splitting; label smoothing softens targets. Weight decay is parameter shrinkage, with AdamW decoupling it from adaptive gradient moments. Classical linear models can use penalties, early stopping and valid augmentation too; activation dropout and stochastic depth act on neural architectures specifically.

### Normalize the correct axes

BatchNorm normalizes each channel using batch (and for images spatial) statistics during training and usually running estimates at inference; learned gamma/beta are per channel. Tiny/nonrepresentative batches and train/eval mismatch can fail. LayerNorm normalizes features within each sample/token using current statistics in both modes, with learned per-feature gamma/beta and no running averages. Variable-length sequence batches motivate LayerNorm but do not remove the need to mask padding elsewhere.

### Objectives and updates

For binary y, negative Bernoulli log likelihood is $-[y\log p+(1-y)\log(1-p)]$; multiclass cross-entropy is $-\log\operatorname{softmax}(z)_y$. Use logits-based stable functions. MSE estimates the conditional mean; MAE targets the median. SGD follows the gradient; momentum smooths directions; Adam divides a bias-corrected first moment by the square root of its second moment; AdamW applies separate decay. Learning rate, schedule and gradient scale often matter more than naming an optimizer.

### Transformer in one precise pass

For $X:(B,T,D)$, $Q=XW_Q$, $K=XW_K$, $V=XW_V$. Each head uses $\operatorname{softmax}(QK^T/\sqrt{d_h}+M)V$ over keys, then concatenate and project. The $\sqrt{d_h}$ divisor controls initial dot-product variance. Add residuals around attention and position-wise nonlinear FFN sublayers, with pre- or post-LayerNorm stated. Positional embeddings or RoPE encode order. Unpositioned unrestricted self-attention is **permutation equivariant**, rather than invariant as the question's informal note says: permute input tokens and outputs permute. Causal masking prevents future leakage; KV caching reuses past key/value projections during decoding.
