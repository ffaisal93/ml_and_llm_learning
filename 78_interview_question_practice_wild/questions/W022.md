## Worked solution

1. Choose a quantization approach and validate its cost. Quantization stores or computes numbers with fewer bits, trading representational precision for memory and possibly speed.
2. Specify which tensors are quantized: weights, activations or KV cache, and at what granularity and scale representation.
3. Estimate actual bytes including scales and metadata. Benchmark kernels on the target hardware; smaller storage does not automatically mean faster execution.
4. Evaluate representative tasks, long contexts and sensitive slices against a baseline. Keep a rollback path if quality regresses.
5. What makes attention quadratic, and what does FlashAttention change? Dense attention compares every query with every key. FlashAttention computes the same attention operation with a different memory-access schedule.
6. At sequence length T, the logical score matrix has T² entries per head; forming QKᵀ and multiplying by V cost O(T²*d_h).
7. A naive implementation materializes scores and probabilities in high-bandwidth memory, creating heavy memory traffic.
8. Tiled exact attention maintains rowwise normalization statistics and avoids storing the full matrix in that memory. Arithmetic remains quadratic for full attention; practical memory use and throughput improve.
9. Compare data, tensor and pipeline parallel training. They partition different parts of the training work and create different communication patterns.
10. Data parallelism replicates the model across workers processing different batches, then synchronizes gradients.
11. Tensor parallelism splits individual matrix operations and usually requires frequent high-bandwidth communication within layers.
12. Pipeline parallelism assigns groups of layers to stages and streams microbatches through them; balance stages and account for pipeline bubbles. Combine approaches only after estimating memory and network costs.

### Small example / sanity check

A nominal 4-bit weight tensor uses one quarter the raw weight bytes of a 16-bit tensor, before scales, packing and unquantized tensors.

### Common trap

Claiming a fourfold end-to-end memory or latency improvement from raw weight bits alone.
