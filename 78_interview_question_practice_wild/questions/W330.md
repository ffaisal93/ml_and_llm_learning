## Question

Given:

events(event_id, block_id, user_id, event_type, platform)

Write a SQL query to count events per event_type and return the event_type(s) with the highest event count (return all ties).

Output: event_type, event_count

Scale assumption: events up to 1e8 rows.

Example

Input: events: visit_page x3, edit_text x2

Output: visit_page 3

## Worked solution

### Aggregate once and return every maximum tie

```sql
WITH totals AS (
 SELECT event_type,COUNT(*) AS event_count FROM events GROUP BY event_type
)
SELECT event_type,event_count FROM totals
WHERE event_count=(SELECT MAX(event_count) FROM totals);
```

`COUNT(*)` counts rows, including duplicate event facts if the source has them; dedup by event_id first only if the question's event table contains retried duplicates rather than canonical events. GROUP BY produces a NULL event_type group as well; choose to reject/label missing types upstream if that is not meaningful. MAX over an empty aggregate returns NULL and no rows are returned. For visit_page×3 and edit_text×2, output is visit_page, 3; equal totals return both. Tests cover the example, ties, null type and empty input. A scan/parallel hash aggregation is O(events); a small maintained type-count table suits frequent reads but needs idempotent insert/delete corrections and reconciliation at 1e8 rows.
