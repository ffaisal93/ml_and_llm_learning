## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Given:

events(event_id, block_id, user_id, event_type, platform)

Write a SQL query to count events per event_type and return the event_type(s) with the highest event count (return all ties).

Output: event_type, event_count

Scale assumption: events up to 1e8 rows.

Example

Input: events: visit_page x3, edit_text x2

Output: visit_page 3</pre>

## Worked solution

1. Aggregate rows by event_type under the specified event-count contract.
2. Compare each aggregate to the maximum so all ties are preserved, and define whether null event_type is a valid category.
3. At scale, time partitioning helps windowed queries, while exact all-history totals need an index/rollup maintenance strategy and replay-safe ingestion.

### Reference query

```sql
WITH counts AS (
 SELECT event_type,COUNT(*) AS event_count FROM events GROUP BY event_type
)
SELECT event_type,event_count FROM counts
WHERE event_count=(SELECT MAX(event_count) FROM counts)
ORDER BY event_type;
```

### Small example / sanity check

Counts visit_page=3 and edit_text=2 return visit_page,3. If both are 3, return both.

### Common trap

Using LIMIT 1 for an all-ties requirement.
