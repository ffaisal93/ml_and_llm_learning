## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">You may not use any third-party libraries.

Given a grayscale image image, an odd kernel size K, and a standard deviation sigma, implement a 2D Gaussian filter. For an offset (dx, dy) from the kernel center, the Gaussian weight is:

weight(dx, dy) = exp(-(dx^2 + dy^2) / (2 * sigma^2))

For every pixel, compute the weighted average over its K x K window. For boundaries use edge replication: if a coordinate goes out of bounds, clamp it to the nearest valid coordinate. Print the filtered matrix with 6 decimal places.

Input Format
H W K sigma
row_0
row_1
...
row_{H-1}
Output Format

Print H rows, each containing W decimal values.

Constraints
1 &lt;= H, W &lt;= 100
K is odd, 1 &lt;= K &lt;= 15
0 &lt; sigma &lt;= 10
0 &lt;= image[i][j] &lt;= 255
Example

Input:

2 2 1 1
1 2
3 4

Output:

1.000000 2.000000
3.000000 4.000000</pre>

## Worked solution

1. Implement a Gaussian image filter with explicit boundary handling. A Gaussian filter replaces a pixel with a distance-weighted neighborhood average.
2. Choose sigma, kernel radius and a boundary policy such as reflection or zero padding.
3. Construct and normalize a one-dimensional Gaussian kernel, then apply it along rows and columns for a separable 2D filter.
4. Preserve channel independence unless requested otherwise and use a suitable floating accumulator.

### Small example / sanity check

A normalized kernel leaves an interior constant image unchanged; zero padding may darken borders under a different boundary contract.

### Common trap

Comparing two implementations with different padding rules and attributing the difference to arithmetic.
