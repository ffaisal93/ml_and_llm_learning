## Question

You may not use any third-party libraries.

Given a grayscale image image, an odd kernel size K, and a standard deviation sigma, implement a 2D Gaussian filter. For an offset (dx, dy) from the kernel center, the Gaussian weight is:

$$\text{weight}(dx, dy) = \exp\!\left(-\frac{dx^{2} + dy^{2}}{2\sigma^{2}}\right)$$

For every pixel, compute the weighted average over its K x K window. For boundaries use edge replication: if a coordinate goes out of bounds, clamp it to the nearest valid coordinate. Print the filtered matrix with 6 decimal places.

## Worked solution

### A separable filter with the exact boundary rule

The 2D weight factors into exp(-dx²/(2σ²))·exp(-dy²/(2σ²)). For a square truncated kernel, its normalizer is the product of the two 1D sums, so a horizontal weighted average followed by a vertical one equals the requested normalized 2D filter. Edge replication is applied in each direction. Keep floating-point intermediate values and round only when printing; rounding the first pass changes the answer.

```python
"""No third-party dependencies; exact replicated-edge Gaussian filter."""

import math
import sys


def gaussian_filter(image, k, sigma):
    if (
        not isinstance(k, int)
        or k < 1
        or k % 2 == 0
        or not math.isfinite(sigma)
        or sigma <= 0
    ):
        raise ValueError("positive odd K and finite positive sigma required")
    h = len(image)
    w = len(image[0]) if h else 0
    if h == 0 or w == 0 or any(len(row) != w for row in image):
        raise ValueError("nonempty rectangular image required")
    radius = k // 2

    # Equivalent separable kernel; avoids underflow in sigma*sigma for tiny sigma.
    def weight(d):
        scaled = abs(d) / sigma
        return 0.0 if scaled > 40 else math.exp(-0.5 * scaled * scaled)

    weights = [weight(d) for d in range(-radius, radius + 1)]
    norm = sum(weights)
    weights = [v / norm for v in weights]
    temp = [
        [
            sum(
                weights[j] * image[y][min(w - 1, max(0, x + j - radius))]
                for j in range(k)
            )
            for x in range(w)
        ]
        for y in range(h)
    ]
    return [
        [
            sum(
                weights[j] * temp[min(h - 1, max(0, y + j - radius))][x]
                for j in range(k)
            )
            for x in range(w)
        ]
        for y in range(h)
    ]


def solution():
    tokens = sys.stdin.read().split()
    if len(tokens) < 4:
        raise ValueError("expected H W K sigma and pixels")
    h, w, k = map(int, tokens[:3])
    sigma = float(tokens[3])
    if h < 1 or w < 1 or len(tokens) != 4 + h * w:
        raise ValueError("pixel count mismatch")
    values = list(map(float, tokens[4:]))
    image = [values[y * w : (y + 1) * w] for y in range(h)]
    for row in gaussian_filter(image, k, sigma):
        print(" ".join(f"{v:.6f}" for v in row))


if __name__ == "__main__":
    solution()
```

`solution()` parses H,W,K,sigma and exactly H×W values, then prints six decimals per output. It uses only standard-library math/sys; no NumPy or image library. Kernel center weight is always one, so normalization stays positive even for a tiny sigma whose noncentral weights underflow to zero. K=1 gives the identity, matching the supplied 2×2 example. The implementation returns a new nested list and leaves input unchanged.

### Worked edge example and cost

For a one-row image [0,100], K=3, sigma=1, let a=exp(-1/2). At the left pixel, the horizontal clamped neighborhood is [0,0,100], giving 100a/(1+2a)≈27.406862. At the right it is [0,100,100], giving about 72.593138. The vertical pass repeats the same single row and changes neither value. Zero padding would darken this row and violate the contract. A constant image remains constant even at borders because every normalized weighted sum contains that same value.

Kernel construction takes O(K), the two passes take O(HWK), and intermediate/output storage is O(HW+K). A direct O(HWK²) implementation also fits H,W≤100 and K≤15, but separability is simple and faster. The linked tests compare against a direct 2D reference on nonsquare images, K=1, single pixels, constant fields, clamped borders and tiny sigma, and check exact six-decimal CLI output. Floating-point results are compared within tolerance; textual rounding is tested separately.
