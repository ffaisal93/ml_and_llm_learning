## Question

You may not use any third-party libraries.

Given an array x of n real numbers, implement the softmax function:

$$\operatorname{softmax}(x_i) = \frac{\exp(x_i)}{\sum_{j=0}^{n-1}\exp(x_j)}$$

To avoid overflow, use the equivalent form:

$$\operatorname{softmax}(x_i) = \frac{\exp(x_i - \max(x))}{\sum_j \exp(x_j - \max(x))}$$

Print every softmax value rounded to 6 decimal places.

### Input Format

n
x_0 x_1 ... x_{n-1}
Output Format

Print one line containing n decimal values.

### Constraints

1 &lt;= n &lt;= 1000
-1000 &lt;= x_i &lt;= 1000
Example

### Input

```text
3
1 2 3
```

### Output

```text
0.090031 0.244728 0.665241
```

## Worked solution

### Why subtracting the maximum is safe

A common shift cancels between numerator and denominator:

$$\frac{e^{x_i-m}}{\sum_j e^{x_j-m}}
=\frac{e^{x_i}}{\sum_j e^{x_j}}.$$

Choose $m=\max_jx_j$. Every exponent is now nonpositive, so no exponential overflows; at least one term equals one, so the denominator is positive. Very negative terms may underflow to zero, which is harmless at the requested precision.

### Exact standard-library solution

```python
import math
import sys

def softmax(values):
    if not values:
        raise ValueError('At least one value is required')
    maximum = max(values)
    exponentials = [math.exp(value - maximum) for value in values]
    total = math.fsum(exponentials)
    return [value / total for value in exponentials]

if __name__ == '__main__':
    tokens = sys.stdin.read().split()
    n = int(tokens[0])
    values = list(map(float, tokens[1:]))
    if len(values) != n or n < 1:
        raise ValueError('Input count does not match n')
    print(' '.join(f'{probability:.6f}' for probability in softmax(values)))
```

For `[1,2,3]`, shifted scores are `[-2,-1,0]`, exponentials are approximately `[0.135335,0.367879,1]`, and the normalized output is `0.090031 0.244728 0.665241`. Equal inputs produce equal probabilities; one input produces one. `[1000,1000]` works without attempting `exp(1000)`. Adding a constant to every input leaves the result unchanged. The algorithm is $O(n)$ time and $O(n)$ space. Round only when printing; independently rounded values need not sum to exactly one.

### PyTorch implementation for study

The submission above obeys the no-third-party-libraries rule. For training code, operate along the class dimension and preserve autograd:

```python
import torch

def softmax_torch(logits, dim=-1):
    shifted = logits - logits.amax(dim=dim, keepdim=True)
    exponentials = shifted.exp()
    return exponentials / exponentials.sum(dim=dim, keepdim=True)

logits = torch.tensor([[1., 2., 3.]], requires_grad=True)
probabilities = softmax_torch(logits)
torch.testing.assert_close(probabilities, torch.softmax(logits, dim=-1))
(-probabilities[0, 2].log()).backward()
assert torch.isfinite(logits.grad).all()
```

For cross-entropy training, pass raw logits to `torch.nn.functional.cross_entropy`; do not manually softmax first. The loss computes a stable log-softmax internally.
