## Question

You may not use any third-party libraries.

Given an array x of n real numbers, implement the softmax function:

softmax(x_i) = exp(x_i) / sum(exp(x_j)), j = 0..n-1

To avoid overflow, use the equivalent form:

softmax(x_i) = exp(x_i - max(x)) / sum(exp(x_j - max(x)))

Print every softmax value rounded to 6 decimal places.

### Input Format

n
x_0 x_1 ... x_{n-1}
Output Format

Print one line containing n decimal values.

### Constraints

1 &lt;= n &lt;= 1000
-1000 &lt;= x_i &lt;= 1000
Example

### Input

```text
3
1 2 3
```

### Output

```text
0.090031 0.244728 0.665241
```

## Worked solution

### Solution outline

#### Implement stable softmax and log-softmax.

A common logit shift leaves the probability distribution unchanged, so subtract a maximum before exponentiation.

1. Convert finite logits to a floating array and choose the class axis explicitly.
2. Set z=x-max(x), then softmax=exp(z)/sum(exp(z)). Compute log-softmax directly as z-log(sum(exp(z))).
3. Test shift invariance, normalization and very large logits. Define a separate policy for negative-infinity masks rather than silently accepting an all-masked row.

#### Derive the softmax cross-entropy gradient.

The fused gradient is predicted probability minus target probability.

1. Write L=-sum(y_j*logp_j), with targets summing to one.
2. Differentiate logp_j=z_j-logsumexp(z), yielding dL/dz_i=p_i-y_i.
3. Apply the chosen batch or mask reduction afterward and preserve zero gradients for excluded examples.

### Understand why the approach works

#### Derive a local rule, then apply the chain rule

Treat a layer as a function with a declared input and output shape. Write the scalar loss and its reduction first: a sum, mean over rows and mean over all elements produce different gradient scales. For an affine layer $Y=XW+b$ with upstream gradient $G=\partial L/\partial Y$,

$$
\frac{\partial L}{\partial X}=GW^\top,\qquad
\frac{\partial L}{\partial W}=X^\top G,\qquad
\frac{\partial L}{\partial b}=\sum_i G_{i,:}.
$$

The bias sum is over all leading positions where the same bias was reused. Do not average again if $G$ already contains the mean-loss factor. For example, with one row $x=[2,3]$ and scalar upstream derivative $4$, the weight derivative is $[8,12]$.

Cache the forward values needed by the derivative; compute all gradients before updating parameters. Updating $W$ midway would make the earlier-layer derivative use a different function from the one evaluated forward.

Check a scalar objective using central differences:

$$
\frac{\partial L}{\partial\theta_j}\approx
\frac{L(\theta+h e_j)-L(\theta-h e_j)}{2h}.
$$

Use float64 and several sensible $h$ values. An arbitrarily tiny $h$ loses the difference to rounding, while a large one measures curvature rather than a local derivative. Avoid ReLU's kink at zero during this check, and test inputs, weights and biases separately.

### Readable reference implementation

Read the explanation first, then trace one small input through these functions. This is the same implementation used by the local checks; its stated simplifications still apply.

```python
import math
from collections import deque
from dataclasses import dataclass
import numpy as np


def log_softmax(x, axis=-1):
    x = np.asarray(x, dtype=np.float64)
    if x.size == 0 or not np.isfinite(x).all():
        raise ValueError("expected non-empty finite logits")
    z = x - np.max(x, axis=axis, keepdims=True)
    return z - np.log(np.exp(z).sum(axis=axis, keepdims=True))


def softmax(x, axis=-1):
    return np.exp(log_softmax(x, axis=axis))
```

Logits [1000,1001] give the same probabilities as [0,1], approximately [0.269,0.731].

### Edge cases and common mistakes

Computing log(softmax) when tiny probabilities may underflow to zero.
