## Worked solution

1. Explain PCA from centered data to reconstruction. PCA finds orthogonal directions that capture the greatest variance under squared reconstruction error.
2. Fit a training-data mean and center X; use SVD X=U*S*Vᵀ.
3. Project onto the first k right singular vectors and reconstruct with the same mean and directions.
4. Choose k using validation needs or explained variance; scale features first only when that matches the intended geometry.
5. Scale dimensionality reduction to large or sparse data. Choose a factorization that fits the data's size and storage structure rather than forming a dense covariance matrix automatically.
6. Use randomized/truncated SVD when only a small number of leading components is needed.
7. Use incremental PCA for bounded-memory dense batches, with its approximation and batch effects understood.
8. For sparse count matrices, truncated SVD can avoid densification from centering; explain that this changes the centered-PCA problem.
9. Interpret clustering completeness and homogeneity. External clustering metrics compare assignments with labels but reward different behaviors.
10. Homogeneity asks whether each predicted cluster contains one label; completeness asks whether all members of a label stay in one cluster.
11. Inspect both, plus a combined measure or task-specific evaluation, under the same data and label conventions.
12. Remember that the reference labels may not represent the only useful clustering structure.

### Small example / sanity check

If almost all variation lies along a diagonal line in 2D, one principal component can reconstruct points approximately on that line.

### Common trap

Fitting PCA on all train and test data before evaluating a model.
