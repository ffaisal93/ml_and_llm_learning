## Question

KMeans PCA and Completeness Score

Implement a function using Sklearn's KMeans and PCA to process data and calculate completeness score and v-measure. The requirements are:

Provide a pandas DataFrame with feature columns.
Use PCA to reduce dimensions to a specified number of n_components.
Use KMeans to cluster the data into a specified number of clusters.
Calculate and return completeness_score and v_measure_score.

### Input

pandas DataFrame
Number of PCA n_components
Number of KMeans clusters

### Output

completeness_score
v_measure_score

Test case:

Sample Input:

```python
df = pd.DataFrame({'feature1': [1, 2, 3, 4], 'feature2': [5, 6, 7, 8]})
n_components = 2
clusters = 2
```

Sample Output:

Completeness Score: 0.85
V-Measure: 0.9

Data Scale:

DataFrame can be at most 1,000 x 50.
Assume all data is valid.

Example

### Input

pd.DataFrame({'featA': [10, 20, 10, 15]}), 1, 2

## Worked solution

### A necessary input is missing

Completeness and v-measure compare predicted clusters against **reference labels**. The given feature-only DataFrame, component count and cluster count cannot determine either score. Comparing clusters to themselves would always give 1 and is not a solution. Add a separate `y_true` argument (or an explicitly named label column excluded from PCA). The sample scores .85/.9 cannot be reproduced from the supplied information.

```python
import numpy as np
import pandas as pd
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
from sklearn.metrics import completeness_score,v_measure_score


def pca_cluster_scores(df,n_components,clusters,y_true=None,seed=0):
    if y_true is None:
        raise ValueError('reference labels y_true are required for external clustering scores')
    if len(y_true)!=len(df):raise ValueError('one reference label per row required')
    if not 1<=n_components<=min(df.shape) or not 1<=clusters<=len(df):
        raise ValueError('invalid component/cluster count')
    # PCA centers but does not standardize: raw feature units are the stated choice.
    reduced=PCA(n_components=n_components,svd_solver='full').fit_transform(df.to_numpy(dtype=float))
    predicted=KMeans(n_clusters=clusters,n_init=10,random_state=seed).fit_predict(reduced)
    return completeness_score(y_true,predicted),v_measure_score(y_true,predicted)

df=pd.DataFrame({'feature1':[1,2,3,4],'feature2':[5,6,7,8]})
try:pca_cluster_scores(df,2,2)
except ValueError:pass
else:raise AssertionError('missing labels were silently invented')
assert np.allclose(pca_cluster_scores(df,2,2,[0,0,1,1]),[1.,1.])
assert completeness_score([0,0,1,1],[0,0,0,0])==1.
assert v_measure_score([0,0,1,1],[0,0,0,0])==0.
print('W135: missing-label rejection and labelled demonstration scores (1,1) passed')
```

### Compute only justified scores

PCA centers the numeric features and projects onto n_components directions; the choice here preserves raw units rather than silently standardizing. If units differ, decide whether training-fitted StandardScaler matches the desired geometry. KMeans uses a fixed seed and ten initializations. In the chosen **demonstration** labels `[0,0,1,1]` for the four-row feature sample yield completeness=1, v-measure=1; these are not the unspecified original labels.

For true class C and cluster K, homogeneity is $h=1-H(C\mid K)/H(C)$ and completeness $c=1-H(K\mid C)/H(K)$, with library conventions for zero entropy. V-measure is $2hc/(h+c)$ (default beta=1). All points in one cluster have completeness 1 but homogeneity/v-measure 0 when several true classes exist, as independently checked. Scores are invariant to cluster-id permutation. External labels must not be used to pick PCA/cluster count and then presented as an unbiased held-out evaluation.
