## Question

K-means is the standard algorithm for splitting points into K groups by distance. Implement it from scratch for a given set of starting centers, so that the result is deterministic.

### What to implement

kmeans(points, centroids, max_iters=100)

points: a list of n tuples of numbers, all of the same dimension d.
centroids: a list of k initial centers, each a tuple of d numbers.
max_iters: the maximum number of rounds, at least 1.
Return (centroids, labels): the final centers as k lists of d floats, and labels, a list of n integers where labels[i] is the cluster index of points[i].

### Rules

Repeat at most max_iters times:
1. Assignment: give each point the index of the centroid with the smallest squared Euclidean distance. If several centroids are equally close, use the lowest index.
2. If the labels equal the labels of the previous round, stop. The first round never stops here.
3. Update: set each centroid to the mean of the points assigned to it. A centroid with no points keeps its current value.

The returned labels are those of the last assignment, and the returned centroids are the values after the last update. Do not modify points or centroids.

### Examples

1. kmeans([(0, 0), (0, 1), (10, 10), (10, 11)], [(0, 0), (10, 10)]) returns ([[0.0, 0.5], [10.0, 10.5]], [0, 0, 1, 1]): two clear groups; the centers move to the group means.
2. kmeans([(0,), (1,), (2,), (3,), (10,)], [(0,), (1,)], 1) returns ([[0.0], [4.0]], [0, 1, 1, 1, 1]): after one round the labels come from the starting centers and the centers have been updated once.
3. kmeans([(0,), (4,)], [(2,), (2,)]) returns ([[2.0], [2.0]], [0, 0]): both centers are equally close, so index 0 wins and the empty cluster keeps its center.

### Constraints

1 &lt;= k &lt;= n &lt;= 1000, 1 &lt;= d &lt;= 10.
Coordinates are integers or floats of moderate size.

## Worked solution

### Preserve this problem's iteration contract

Use the **provided** centers, with no random initialization. Assignment ties choose the first index via Python's `min`. Stop only when labels repeat; empty centers stay fixed. Crucially, do not reassign after the final update: with an iteration cap, returned centers and labels describe different halves of that final round by explicit specification.

```python
def kmeans(points,centroids,max_iters=100):
    if not points or not centroids or max_iters<1:raise ValueError('invalid input')
    d=len(points[0]); k=len(centroids)
    if not d or k>len(points) or any(len(p)!=d for p in points+centroids):
        raise ValueError('incompatible dimensions')
    centers=[list(map(float,c)) for c in centroids]
    previous=None
    for _ in range(max_iters):
        labels=[min(range(k),key=lambda j:sum((a-b)**2 for a,b in zip(p,centers[j]))) for p in points]
        if labels==previous:break
        sums=[[0.]*d for _ in range(k)];counts=[0]*k
        for p,label in zip(points,labels):
            counts[label]+=1
            for j,value in enumerate(p):sums[label][j]+=value
        for j in range(k):
            if counts[j]:centers[j]=[v/counts[j] for v in sums[j]]
        previous=labels
    return centers,labels

points=[(0,0),(0,1),(10,10),(10,11)]; initial=[(0,0),(10,10)]
assert kmeans(points,initial)==([[0.,.5],[10.,10.5]],[0,0,1,1])
assert initial==[(0,0),(10,10)] and points[0]==(0,0)
assert kmeans([(0,),(1,),(2,),(3,),(10,)],[(0,),(1,)],1)==([[0.],[4.]],[0,1,1,1,1])
assert kmeans([(0,),(4,)],[(2,),(2,)])==([[2.],[2.]],[0,0])
print('W131: supplied centers, one-iteration labels, ties, empty cluster and nonmutation passed')
```

### Trace and justify

For `[0,1,2,3,10]` with centers `[0,1]` and one round, assignment is `[0,1,1,1,1]`; means become `[0,4]`. Reassigning against `[0,4]` would give a different answer and violate this question, even though some other K-means APIs require it. The duplicate-center case `[2,2]` assigns both points to cluster 0 and preserves the empty center 1.

The mean minimizes the sum of squared distances for fixed members: differentiating with respect to a center gives $2\sum_i(\mu-x_i)=0$. Assignment and update do not increase that objective, but a local solution depends on starting centers. Labels repeating means the same groups produce the same means, so the early stop is sound. Complexity is O(iterations·n·k·d) time and O(n+kd) auxiliary storage. Checks cover every example, exact cap semantics, tie/empty behavior and no input mutation.
