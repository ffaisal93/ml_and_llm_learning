### Mechanism

Logistic regression models a binary probability with a linear score followed by a sigmoid:

$$z=w^\top x+b,\qquad P(y=1\mid x)=\sigma(z)=\frac1{1+e^{-z}}.$$

The name refers to the linear **log odds**, $\log(p/(1-p))=w^\top x+b$. Probabilities are nonlinear in the features, but a fixed probability threshold produces a linear decision boundary in the chosen feature space. Add interactions or nonlinear features when the original relationship needs them.

Train by minimizing mean negative log likelihood, usually with regularization:

$$L=-\frac1n\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)]+\frac\lambda2\|w\|_2^2.$$

The data-loss gradients are $X^\top(p-y)/n$ and $\operatorname{mean}(p-y)$ for weights and bias. The regularization term adds $\lambda w$ if the bias is not penalized. Optimize with gradient-based methods; no closed-form normal equation gives the logistic solution.

### Small example and implementation

If $z=\log3$, then $p=0.75$. Raising feature $x_j$ by one changes the log odds by $w_j$, or multiplies the odds by $e^{w_j}$, holding other features fixed. This is an association conditional on the model, not automatically a causal effect.

```python
import torch
from torch import nn

model = nn.Linear(3, 1)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
x = torch.tensor([[0., 0., 1.], [1., 1., 0.]])
y = torch.tensor([0., 1.])
for _ in range(100):
    optimizer.zero_grad(set_to_none=True)
    logits = model(x).squeeze(-1)
    loss = nn.functional.binary_cross_entropy_with_logits(logits, y)
    loss.backward()
    optimizer.step()
with torch.no_grad():
    probabilities = model(x).squeeze(-1).sigmoid()
```

Use raw logits in the stable training loss. Fit imputers, encoders and scalers only on training data; evaluate on held-out data with log loss/calibration and precision/recall at the intended threshold. The default 0.5 threshold is not mandatory when error costs or prevalence differ.

Logistic regression is a useful interpretable baseline for churn, spam, medical-risk research or credit default when the target is binary and the feature relationship is adequately represented. It is fast and data-efficient, but omitted nonlinearities, correlated predictors, class imbalance and distribution shift can limit it.
