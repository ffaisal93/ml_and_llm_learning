## Question

A grayscale image can be cut into small square tiles, and tiles that look alike can be grouped together. Grouping tiles is a common first step for texture analysis and image compression. Write a NumPy-only function that cuts an image into patches, groups the patches with K-means, and returns the group of every patch. The typical case is a 255 × 255 image, 15 × 15 patches and K = 10, which gives a 17 × 17 grid of 289 patches.

### What to implement

cluster_patches(image: np.ndarray, p: int, K: int, n_iters: int) -&gt; np.ndarray

image: a 2-D array of shape (H, W), dtype uint8 or any float dtype.
p: the side length of each square patch.
K: the number of clusters.
n_iters: the number of K-means iterations to run.
Returns: an integer array of shape (H // p, W // p). Entry [i, j] is the cluster index, in 0..K-1, of the patch at grid row i and grid column j.

### Rules

1. Patches. Patch (i, j) covers rows i*p to i*p + p - 1 and columns j*p to j*p + p - 1. Patches do not overlap.
2. Patch order and vectors. Number the patches row by row, so patch (i, j) has index i * (W // p) + j. Flatten each patch row by row into a vector of length p * p.
3. Arithmetic. Convert the vectors to float64 before any arithmetic, so uint8 values cannot overflow or truncate.
4. Initialization. The starting centroids are the vectors of patches 0, 1, ..., K-1, in that order.
5. One iteration. First assign every patch to the centroid with the smallest squared Euclidean distance. If several centroids are equally close, pick the lowest centroid index. Distances are float64 values, and "equally close" means exactly equal. The tests never depend on two distances that differ only by rounding. Then replace each centroid with the mean of the patches assigned to it. A centroid with no patches keeps its previous value.
6. Output. Run exactly n_iters iterations and return the assignments made in the last one. Stopping early once the assignments stop changing is allowed, because the result is then the same.
7. Invalid input. Raise ValueError when any of these holds:
image is not 2-D, or p &lt; 1;
H or W is not a multiple of p;
K is below 1 or above the number of patches;
n_iters &lt; 1.
8. Efficiency. Use NumPy only, with no scikit-learn. Vectorize the work across patches and clusters rather than looping over them in Python; a loop over iterations is fine. The largest inputs allowed by the constraints should finish within a few seconds.

### Examples

Example 1:

```text
image = [[0, 0, 9, 9],
[0, 0, 9, 9],
[1, 1, 8, 8],
[1, 1, 8, 8]]      (uint8), p = 2, K = 2, n_iters = 3
output = [[0, 1],
[0, 1]]
```

Explanation: the patches are all-0, all-9, all-1 and all-8. The centroids start as patch 0 (all 0) and patch 1 (all 9). The all-1 patch is closer to 0 and the all-8 patch is closer to 9, and later iterations do not change that.

Example 2:

```text
image = [[0, 0, 4, 4],
[0, 0, 4, 4],
[2, 2, 4, 4],
[2, 2, 4, 4]]
p = 2, K = 2, n_iters = 1
output = [[0, 1],
[0, 1]]
```

```text
Explanation: the all-2 patch is at squared distance 4 * 2² = 16 from both starting centroids (all 0 and all 4). The tie goes to the lower index, cluster 0.
```

Example 3:

```text
image = [[5, 5, 5, 5],
[5, 5, 5, 5],
[7, 7, 0, 0],
[7, 7, 0, 0]]
p = 2, K = 2, n_iters = 2
output = [[1, 1],
[1, 0]]
```

```text
Explanation: both starting centroids are all 5, so iteration 1 sends every patch to cluster 0 by the tie rule. Centroid 0 becomes the mean, all 4.25, and the empty centroid 1 stays all 5. In iteration 2 the two all-5 patches and the all-7 patch are closer to centroid 1, and the all-0 patch stays with centroid 0. With n_iters = 1 the output would be [[0, 0], [0, 0]].
```

### Constraints

1 &lt;= H, W &lt;= 1024, and both are multiples of p.
1 &lt;= K &lt;= N, where N = (H // p) * (W // p) is the number of patches.
N * K &lt;= 2 * 10^6, so an (N, K) array of float64 values fits comfortably in memory.
1 &lt;= n_iters &lt;= 100.
Pixel values are finite.

## Worked solution

### Solution outline

#### Cluster image patches rather than full images.

Each patch is an observation whose representation and position must be defined explicitly.

1. Extract non-overlapping or overlapping patches under a stated boundary policy.
2. Flatten raw intensities or compute normalized descriptors, fit clustering on training patches and retain the index-to-image-position map.
3. Reconstruct or visualize cluster assignments to inspect what the representation actually grouped.

#### Implement k-means with convergence and empty clusters.

Alternate assigning points to their closest centers and moving each center to the mean of its assigned points.

1. Initialize k distinct data indices under an explicit random seed, requiring 1<=k<=N.
2. Compute squared distances, assign closest centers and recompute non-empty means. For an empty cluster, retain its center or explicitly reseed it.
3. Stop on a center-shift tolerance or iteration cap, then recompute labels for the returned centers. Compare objective values, not center ordering, across implementations.

### Understand why the approach works

#### Choose the geometry before the update rule

An algorithm's center update follows its objective. Squared Euclidean clustering uses means:

$$
J_2=\sum_i\|x_i-\mu_{c_i}\|_2^2.
$$

For fixed assignments, differentiating with respect to a center sets it to its members' arithmetic mean. Manhattan distance instead uses coordinatewise medians:

$$
J_1=\sum_i\|x_i-m_{c_i}\|_1.
$$

For points $0,2,10$, the squared-error center is $4$, while the absolute-distance center is $2$. Swapping these updates silently solves a different problem.

Alternating nearest-center assignment and an exact fixed-cluster update cannot increase the chosen objective, but it need not reach a global optimum. State initialization, empty-cluster handling, deterministic ties and a stopping rule. Recompute assignments for returned centers after the last update.

For retrieval, state normalization, similarity and relevance labels. Cosine and raw dot product rank differently when embedding norms vary. Index approximation must be evaluated using recall and downstream quality, not latency alone. Negative examples can actually be valid alternative matches; audit this before interpreting a lower contrastive loss as better semantics. Evaluate cluster/retrieval stability across seeds and important slices rather than trusting a visually attractive plot.

### Readable reference implementation

Read the explanation first, then trace one small input through these functions. This is the same implementation used by the local checks; its stated simplifications still apply.

```python
import math
from collections import deque
from dataclasses import dataclass
import numpy as np


def kmeans(x, k, seed=0, max_iter=100, tol=1e-6):
    x = np.asarray(x, dtype=np.float64)
    if x.ndim != 2 or not 1 <= k <= len(x) or max_iter < 1 or tol < 0:
        raise ValueError("invalid data or k-means configuration")
    if not np.isfinite(x).all():
        raise ValueError("data must be finite")
    rng = np.random.default_rng(seed)
    centers = x[rng.choice(len(x), size=k, replace=False)].copy()
    for _ in range(max_iter):
        distances = ((x[:, None, :] - centers[None, :, :]) ** 2).sum(axis=-1)
        labels = distances.argmin(axis=1)
        updated = centers.copy()
        for j in range(k):
            members = x[labels == j]
            if len(members):
                updated[j] = members.mean(axis=0)
        shift = np.linalg.norm(updated - centers)
        centers = updated
        if shift <= tol:
            break
    distances = ((x[:, None, :] - centers[None, :, :]) ** 2).sum(axis=-1)
    labels = distances.argmin(axis=1)
    return centers, labels
```
