## Question

Crossword Puzzle Solver
Description

You are given a partly filled crossword grid and a list of allowed words. Fill every empty cell with a letter so that each across and down entry of the grid spells a word from the list. Return one completed grid, or None when no legal fill exists.

### What to implement

```python
def solve_crossword(board: List[List[str]], dictionary: List[str]) -> Optional[List[List[str]]]:
    ...
```

board: an m x n grid; each cell is '#' (a blocked cell), '.' (an empty cell) or an uppercase letter 'A'–'Z' (a pre-filled cell).
dictionary: the allowed uppercase words; it may contain duplicates and words of any length.
Returns a new m x n grid with every '.' replaced by a letter, or None if no such grid satisfies the rules.

### Rules

1. A slot is a maximal run of 2 or more consecutive non-'#' cells in one row (read left to right) or one column (read top to bottom).
2. In the returned grid, the letters of every slot spell a word from dictionary. This includes slots that were already full in the input.
3. Blocked cells stay '#' and pre-filled letters stay unchanged; only '.' cells receive letters.
4. A run of length 1 is not a slot and is never checked against the dictionary, so one-letter dictionary words never matter.
5. A cell that lies in no slot (both its row run and its column run have length 1) is isolated. An isolated pre-filled letter is kept as is. An isolated '.' can never be filled, so the board has no solution and the result is None.
6. A word may be used in any number of slots.
7. When several completed grids are legal, return any one of them.
8. Do not modify board or dictionary.

board = [['#', '.', '.', '#'],

['#', '.', '.', '#']]

Explanation: the down slot in column 1 crosses the middle row at its second letter, which is H for both 4-letter words. No 3-letter word in this list has H in the middle.

### Constraints

1 &lt;= m, n &lt;= 8
0 &lt;= len(dictionary) &lt;= 2000; each word has 1 to 8 uppercase letters.
The search may take exponential time in the worst case, so pruning matters. Boards at the maximum size (8 x 8 with 2000 words, many of them near-misses) must finish within a few seconds: choose the most constrained slot first (fewest words that still fit), and abandon a branch as soon as any slot has no candidate left.
Follow-up 1: a dictionary of one million words

How would you index the dictionary so that finding the words that fit a partly filled slot stays fast?

Follow-up 2: return every solution

How would you change the solver to return all legal completed grids instead of one?

Follow-up 3: each word used at most once

What changes if every dictionary word may fill at most one slot?

Follow-up 4: interactive solving

How would you support a user who types letters one at a time and wants to know at once whether the grid can still be completed?

## Worked solution

### Search slots with indexed domains and immediate pruning

Extract maximal horizontal/vertical runs of length at least two and map cells to their owning slots/positions. An isolated `.` makes the board impossible; an isolated prefilled letter stays unchanged. Deduplicate dictionary words, index by length, and represent each `(length,position,letter)` posting as a Python integer bitset. A slot's candidate domain is the intersection of its length mask and all fixed-letter masks. This validates already-full slots too.

At every recursion choose the unassigned slot with the smallest remaining domain (MRV). Try a word, fill only originally empty cells, intersect every crossing unassigned slot's domain and reject immediately if one becomes empty. Restore only cells changed by this attempt when backtracking. Assigned crossing slots cannot conflict because previous assignments already constrained this slot's domain. Words are reusable, as required; no used-word set is present.

```python
from collections import defaultdict

def solve_crossword(board, dictionary):
    grid = [row[:] for row in board]
    m, n = len(grid), len(grid[0])
    slots = []
    for dr, dc in ((0, 1), (1, 0)):
        for r in range(m):
            for c in range(n):
                if grid[r][c] == '#':
                    continue
                pr, pc = r - dr, c - dc
                if 0 <= pr < m and 0 <= pc < n and grid[pr][pc] != '#':
                    continue
                cells, rr, cc = [], r, c
                while 0 <= rr < m and 0 <= cc < n and grid[rr][cc] != '#':
                    cells.append((rr, cc)); rr += dr; cc += dc
                if len(cells) >= 2:
                    slots.append(cells)
    owners = defaultdict(list)
    for s, cells in enumerate(slots):
        for pos, cell in enumerate(cells):
            owners[cell].append((s, pos))
    if any(grid[r][c] == '.' and (r, c) not in owners for r in range(m) for c in range(n)):
        return None
    words = defaultdict(list)
    for word in sorted(set(dictionary)):
        words[len(word)].append(word)
    masks = {}
    for length, ws in words.items():
        for j, w in enumerate(ws):
            for pos, char in enumerate(w):
                key = length, pos, char
                masks[key] = masks.get(key, 0) | (1 << j)
    domains = []
    for cells in slots:
        length = len(cells)
        mask = (1 << len(words[length])) - 1
        for pos, (r, c) in enumerate(cells):
            if grid[r][c] != '.':
                mask &= masks.get((length, pos, grid[r][c]), 0)
        domains.append(mask)
    def search(ds, remaining):
        if not remaining:
            return [row[:] for row in grid]
        s = min(remaining, key=lambda j: bin(ds[j]).count('1'))
        mask = ds[s]
        if not mask:
            return None
        cells, rest = slots[s], remaining - {s}
        while mask:
            bit = mask & -mask; mask -= bit
            word = words[len(cells)][bit.bit_length() - 1]
            new_ds, changed, valid = ds[:], [], True
            for (r, c), char in zip(cells, word):
                if grid[r][c] == '.':
                    changed.append((r, c)); grid[r][c] = char
                for other, pos in owners[(r, c)]:
                    if other in rest:
                        new_ds[other] &= masks.get((len(slots[other]), pos, char), 0)
                        if not new_ds[other]:
                            valid = False
            if valid:
                result = search(new_ds, rest)
                if result is not None:
                    return result
            for r, c in changed:
                grid[r][c] = '.'
        return None
    return search(domains, set(range(len(slots))))
```

Example 1 chooses THAT for the length-four row, with IS/AT across and IHA/SAT down. Removing IHA makes the crossing constraints impossible. `[['Z','#','.','.']]` with AB keeps Z and fills AB; replacing Z with `.` returns None. Tests check these, immutable input, fully filled invalid slots, duplicate words, reusable words and a seeded 8×8 near-miss dictionary fixture. Search remains exponential; MRV and forward checking improve pruning but cannot guarantee a few seconds on every adversarial NP-hard instance. The tested performance fixture is evidence about that fixture, not a universal bound.

For a million words, retain length/position/letter postings as compressed bitmaps or use a trie for prefix-heavy queries; intersection avoids scanning every word at every node. Enumerating all solutions changes early return to yielding deep copies and continuing search, with output potentially exponential. At-most-once word usage needs a shared word ID: remove the chosen word from all other compatible domains, restore on backtrack, and consider matching-based all-different pruning. Interactive solving maintains an immutable base plus user-letter constraints, propagates affected domains, and runs a cancellable completion search tied to the edit revision; an obsolete search cannot overwrite the latest UI state. Empty domains prove impossible immediately, but nonempty local domains alone do not prove global completable.
