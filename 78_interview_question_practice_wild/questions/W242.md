## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Crossword Puzzle Solver
Description

You are given a partly filled crossword grid and a list of allowed words. Fill every empty cell with a letter so that each across and down entry of the grid spells a word from the list. Return one completed grid, or None when no legal fill exists.

What to implement
def solve_crossword(board: List[List[str]], dictionary: List[str]) -&gt; Optional[List[List[str]]]:
board: an m x n grid; each cell is &#x27;#&#x27; (a blocked cell), &#x27;.&#x27; (an empty cell) or an uppercase letter &#x27;A&#x27;–&#x27;Z&#x27; (a pre-filled cell).
dictionary: the allowed uppercase words; it may contain duplicates and words of any length.
Returns a new m x n grid with every &#x27;.&#x27; replaced by a letter, or None if no such grid satisfies the rules.
Rules
1.
A slot is a maximal run of 2 or more consecutive non-&#x27;#&#x27; cells in one row (read left to right) or one column (read top to bottom).
2.
In the returned grid, the letters of every slot spell a word from dictionary. This includes slots that were already full in the input.
3.
Blocked cells stay &#x27;#&#x27; and pre-filled letters stay unchanged; only &#x27;.&#x27; cells receive letters.
4.
A run of length 1 is not a slot and is never checked against the dictionary, so one-letter dictionary words never matter.
5.
A cell that lies in no slot (both its row run and its column run have length 1) is isolated. An isolated pre-filled letter is kept as is. An isolated &#x27;.&#x27; can never be filled, so the board has no solution and the result is None.
6.
A word may be used in any number of slots.
7.
When several completed grids are legal, return any one of them.
8.
Do not modify board or dictionary.
Examples

Example 1:

board = [[&#x27;#&#x27;, &#x27;.&#x27;, &#x27;.&#x27;, &#x27;#&#x27;],
[&#x27;.&#x27;, &#x27;.&#x27;, &#x27;.&#x27;, &#x27;.&#x27;],
[&#x27;#&#x27;, &#x27;.&#x27;, &#x27;.&#x27;, &#x27;#&#x27;]]
dictionary = [&quot;THIS&quot;, &quot;THAT&quot;, &quot;IS&quot;, &quot;AT&quot;, &quot;HAT&quot;,
&quot;CAT&quot;, &quot;IHA&quot;, &quot;SAT&quot;]
output = [[&#x27;#&#x27;, &#x27;I&#x27;, &#x27;S&#x27;, &#x27;#&#x27;],
[&#x27;T&#x27;, &#x27;H&#x27;, &#x27;A&#x27;, &#x27;T&#x27;],
[&#x27;#&#x27;, &#x27;A&#x27;, &#x27;T&#x27;, &#x27;#&#x27;]]

Explanation: the slots are IS, THAT and AT across, and IHA and SAT down. THIS cannot be the middle row, because no 3-letter word has I in the middle. Column 0 holds a single open cell, so it is a run of length 1 and is not a slot.

Example 2:

board = the board of Example 1
dictionary = [&quot;THIS&quot;, &quot;THAT&quot;, &quot;IS&quot;, &quot;AT&quot;, &quot;HAT&quot;,
&quot;CAT&quot;, &quot;SAT&quot;]
output = None

Explanation: the down slot in column 1 crosses the middle row at its second letter, which is H for both 4-letter words. No 3-letter word in this list has H in the middle.

Example 3:

board = [[&#x27;Z&#x27;, &#x27;#&#x27;, &#x27;.&#x27;, &#x27;.&#x27;]]
dictionary = [&quot;AB&quot;]
output = [[&#x27;Z&#x27;, &#x27;#&#x27;, &#x27;A&#x27;, &#x27;B&#x27;]]

Explanation: the only slot is the last two cells. Z is an isolated pre-filled letter and stays. With board = [[&#x27;.&#x27;, &#x27;#&#x27;, &#x27;.&#x27;, &#x27;.&#x27;]] the first cell would be an isolated empty cell, and the output would be None.

Constraints
1 &lt;= m, n &lt;= 8
0 &lt;= len(dictionary) &lt;= 2000; each word has 1 to 8 uppercase letters.
The search may take exponential time in the worst case, so pruning matters. Boards at the maximum size (8 x 8 with 2000 words, many of them near-misses) must finish within a few seconds: choose the most constrained slot first (fewest words that still fit), and abandon a branch as soon as any slot has no candidate left.
Follow-up 1: a dictionary of one million words

How would you index the dictionary so that finding the words that fit a partly filled slot stays fast?

Follow-up 2: return every solution

How would you change the solver to return all legal completed grids instead of one?

Follow-up 3: each word used at most once

What changes if every dictionary word may fill at most one slot?

Follow-up 4: interactive solving

How would you support a user who types letters one at a time and wants to know at once whether the grid can still be completed?</pre>

## Worked solution

1. Enumerate maximal horizontal/vertical non-block runs of length at least two. Validate every already-filled slot against a dictionary set, and reject an isolated empty cell immediately.
2. Index dictionary words by length, retaining a deterministic candidate order if desired. Candidate words must agree with prefilled and crossing letters; words may be reused, so do not remove a word globally after choosing it.
3. Backtrack using the unfilled slot with the fewest compatible candidates. Write a candidate’s newly filled cells, propagate/check crossing constraints, recurse, and restore only cells that this branch changed.
4. Return a copy of a completed legal grid or None. Worst-case search is exponential in slots/candidates; indexing, forward checking and minimum-remaining-values pruning improve typical behavior without guaranteeing polynomial time.

### Small example / sanity check

A length-one run is not a checked word. A prefilled isolated letter is valid, but an isolated dot cannot be supplied by any slot and makes the input unsatisfiable.

### Common trap

Forbidding repeated dictionary use or undoing a crossing letter that was filled by another still-active slot.
