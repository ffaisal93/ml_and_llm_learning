## Question

Crossword Puzzle Solver
Description

You are given a partly filled crossword grid and a list of allowed words. Fill every empty cell with a letter so that each across and down entry of the grid spells a word from the list. Return one completed grid, or None when no legal fill exists.

### What to implement

```python
def solve_crossword(board: List[List[str]], dictionary: List[str]) -> Optional[List[List[str]]]:
    ...
```

board: an m x n grid; each cell is '#' (a blocked cell), '.' (an empty cell) or an uppercase letter 'A'–'Z' (a pre-filled cell).
dictionary: the allowed uppercase words; it may contain duplicates and words of any length.
Returns a new m x n grid with every '.' replaced by a letter, or None if no such grid satisfies the rules.

### Rules

1. A slot is a maximal run of 2 or more consecutive non-'#' cells in one row (read left to right) or one column (read top to bottom).
2. In the returned grid, the letters of every slot spell a word from dictionary. This includes slots that were already full in the input.
3. Blocked cells stay '#' and pre-filled letters stay unchanged; only '.' cells receive letters.
4. A run of length 1 is not a slot and is never checked against the dictionary, so one-letter dictionary words never matter.
5. A cell that lies in no slot (both its row run and its column run have length 1) is isolated. An isolated pre-filled letter is kept as is. An isolated '.' can never be filled, so the board has no solution and the result is None.
6. A word may be used in any number of slots.
7. When several completed grids are legal, return any one of them.
8. Do not modify board or dictionary.

### Constraints

1 &lt;= m, n &lt;= 8
0 &lt;= len(dictionary) &lt;= 2000; each word has 1 to 8 uppercase letters.
The search may take exponential time in the worst case, so pruning matters. Boards at the maximum size (8 x 8 with 2000 words, many of them near-misses) must finish within a few seconds: choose the most constrained slot first (fewest words that still fit), and abandon a branch as soon as any slot has no candidate left.

## Worked solution

### Solution outline

1. Enumerate maximal horizontal/vertical non-block runs of length at least two. Validate every already-filled slot against a dictionary set, and reject an isolated empty cell immediately.
2. Index dictionary words by length, retaining a deterministic candidate order if desired. Candidate words must agree with prefilled and crossing letters; words may be reused, so do not remove a word globally after choosing it.
3. Backtrack using the unfilled slot with the fewest compatible candidates. Write a candidate’s newly filled cells, propagate/check crossing constraints, recurse, and restore only cells that this branch changed.
4. Return a copy of a completed legal grid or None. Worst-case search is exponential in slots/candidates; indexing, forward checking and minimum-remaining-values pruning improve typical behavior without guaranteeing polynomial time.

### Readable reference implementation

Read the explanation first, then trace one small input through these functions. This is the same implementation used by the local checks; its stated simplifications still apply.

```python
from collections import Counter


def solve_crossword(board, dictionary):
    """Return one legal copied grid; slots are maximal runs of length >= 2."""
    if not board:
        return []
    rows, cols = len(board), len(board[0])
    if any(len(row) != cols for row in board):
        raise ValueError("board must be rectangular")
    grid = [list(row) for row in board]
    slots = []
    for row in range(rows):
        col = 0
        while col < cols:
            start = col
            while col < cols and grid[row][col] != "#":
                col += 1
            if col - start >= 2:
                slots.append([(row, c) for c in range(start, col)])
            col += 1
    for col in range(cols):
        row = 0
        while row < rows:
            start = row
            while row < rows and grid[row][col] != "#":
                row += 1
            if row - start >= 2:
                slots.append([(r, col) for r in range(start, row)])
            row += 1
    covered = {cell for slot in slots for cell in slot}
    if any(grid[r][c] == "." and (r, c) not in covered
           for r in range(rows) for c in range(cols)):
        return None
    words = {}
    for word in set(dictionary):
        words.setdefault(len(word), []).append(word)
    for candidates in words.values():
        candidates.sort()

    def search():
        chosen = None
        for slot in slots:
            candidates = [
                word for word in words.get(len(slot), [])
                if all(grid[r][c] in (".", char)
                       for (r, c), char in zip(slot, word))
            ]
            if not candidates:
                return None
            if any(grid[r][c] == "." for r, c in slot):
                if chosen is None or len(candidates) < len(chosen[1]):
                    chosen = (slot, candidates)
        if chosen is None:
            return [row[:] for row in grid]
        slot, candidates = chosen
        for word in candidates:
            changed = []
            for (r, c), char in zip(slot, word):
                if grid[r][c] == ".":
                    changed.append((r, c))
                    grid[r][c] = char
            answer = search()
            if answer is not None:
                return answer
            for r, c in changed:
                grid[r][c] = "."
        return None

    return search()
```

A length-one run is not a checked word. A prefilled isolated letter is valid, but an isolated dot cannot be supplied by any slot and makes the input unsatisfiable.
