## Question

Given:

blocks(workspace_id, block_id, parent_id, block_type)
events(event_id, block_id, user_id, event_type, platform)

where events.block_id = blocks.block_id.

```text
Definition: a block is "never edited" if its block_id has never appeared in any edit-type event (if the exact edit event type is known, filter by it, e.g. event_type = 'edit_text').
```

Write a SQL query to compute the percentage of blocks that have never been edited.

Output: never_edited_percentage (a number between 0 and 100).

Note: A block can have many events.

Example

Input: blocks: 4 blocks; edit events hit 1 block

Output: 75.0

## Worked solution

### Use anti-existence, not a join-expanded denominator

Choose the declared edit type `edit_text`. This query returns NULL for an empty block population (undefined percentage); wrap COALESCE(...,0) only if product explicitly defines it as zero.

```sql
SELECT 100.0*SUM(CASE WHEN NOT EXISTS (
 SELECT 1 FROM events e WHERE e.block_id=b.block_id AND e.event_type='edit_text'
) THEN 1 ELSE 0 END)/NULLIF(COUNT(*),0) AS never_edited_percentage
FROM blocks b;
```

NOT EXISTS contributes one boolean per block regardless of how many events it has, so repeated edits cannot inflate either denominator or numerator. For four blocks with edits on one, output is 75.0, even if that block has a thousand edit events. Non-edit views do not disqualify a block, and NULL event.block_id does not match any real block. Tests cover those cases and empty input.

The supplied events schema lacks workspace_id, so the query necessarily assumes block_id globally identifies a block, as its stated join says. If IDs repeat across workspaces, the data contract is insufficient: add workspace_id to events and correlate on both columns rather than mixing unrelated blocks. Index `(block_id,event_type)` or a partial index on block_id where type='edit_text'; the engine can implement an efficient anti-join. An approximate distinct edit count divided by blocks is not an exact substitute when duplicate events, missing blocks or multiple workspaces exist.
