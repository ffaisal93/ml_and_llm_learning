## Question

Expected Value of Reciprocal of Trials Until First Six

Given a fair six-sided die, it is rolled n times until the number 6 appears for the first time. Calculate the expected value of 1/n.

Example

### Input

```python
1
```

## Worked solution

### Use the geometric distribution, then sum the reciprocal

Let N be the positive integer index of the first six. Independence of fair die rolls gives

$$P(N=n)=\left(\frac56\right)^{n-1}\frac16,\qquad n=1,2,\ldots.$$

For general success probability p∈(0,1), put q=1−p. Then

$$E\left[\frac1N\right]=\sum_{n\ge1}\frac{p q^{n-1}}n
=\frac pq\sum_{n\ge1}\frac{q^n}n
=-\frac{p\log p}{1-p}.$$

The series identity follows by integrating Σ[k≥0]t^k=1/(1−t) from 0 to q∈(0,1), giving Σq^n/n=−log(1−q). All summands are nonnegative, which justifies interchange by monotone convergence, or uniform convergence on [0,q]. For p=1/6 the requested answer is

$$\boxed{E[1/N]=\frac{\log6}{5}\approx0.3583518938}.$$

It is **not** 1/E[N]=1/6: expectation does not commute with reciprocals. Jensen's inequality for the convex function 1/x gives E[1/N]≥1/E[N], and 0.35835≥0.16667 is a useful check. Also E[1/N]≤1 since N≥1. At p=1, N=1 and the answer is one, agreeing with the formula's limit; p=0 gives no finite first-success time and is outside this geometric support contract.

The stray example input `1` does not define an input-dependent program and is unnecessary for this mathematical question. The linked numeric test sums p q^(n−1)/n to a large finite cutoff and bounds the tail by q^M/(M+1), validating the closed form. A Monte Carlo check rolls until six, averages **1/N for each trial**, and should approach the boxed value; taking the reciprocal of average N instead estimates the wrong quantity.
