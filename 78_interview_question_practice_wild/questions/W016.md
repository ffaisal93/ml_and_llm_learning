## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Supervised fine-tuning of a language model on short examples wastes compute if every example is padded to the full context length. Sample packing fixes this: several examples are concatenated into one fixed-length training sequence, and a loss mask makes sure the model is trained only on answer tokens. Implement the packing step.

What to implement

pack(examples, seq_len, sep, pad_id) -&gt; list[PackedSample]

examples: a list of (prompt_tokens, answer_tokens) pairs, each a list of non-negative integer token ids.
seq_len: the exact length of every packed sample.
sep: the separator (end-of-sequence) token id.
pad_id: the token id used to fill unused space.

PackedSample is a dataclass with three lists of length seq_len: input_ids, loss_mask and position_ids.

Rules
1.
Layout of one example. An example occupies len(prompt) + len(answer) + 1 positions: the prompt tokens, then the answer tokens, then one sep token. The separator is placed after every example, including the last one in a sample, and it counts toward seq_len.
2.
Loss mask. It is 0 on prompt positions and 1 on answer positions and on the sep position, so the model also learns to emit the separator.
3.
Position ids. They restart at 0 at the first token of every example and increase by 1 along the example, so positions do not continue across examples that share a sample.
4.
Placement. Process the examples from longest to shortest layout (examples of equal layout length keep their input order). Put each one into the first existing sample that has enough room left, or into a new sample if none has. Examples inside a sample appear in the order they were placed, and samples are returned in the order they were created.
5.
Padding. After the last example, fill the rest of the sample with pad_id in input_ids and with 0 in both loss_mask and position_ids.
6.
Oversize examples. An example whose layout is longer than seq_len cannot fit anywhere and is skipped. If no example fits, the result is an empty list.
Examples
1.
seq_len = 8, sep = 99, pad_id = 0, examples = [([5, 6], [7]), ([8], [9, 10]), ([11], [12])] returns two samples. The layouts have lengths 4, 4 and 3, so the first two fill sample 0 exactly and the third starts sample 1.
sample 0: input_ids = [5, 6, 7, 99, 8, 9, 10, 99], loss_mask = [0, 0, 1, 1, 0, 1, 1, 1], position_ids = [0, 1, 2, 3, 0, 1, 2, 3]
sample 1: input_ids = [11, 12, 99, 0, 0, 0, 0, 0], loss_mask = [0, 1, 1, 0, 0, 0, 0, 0], position_ids = [0, 1, 2, 0, 0, 0, 0, 0]
2.
seq_len = 6, sep = 99, pad_id = 0, examples = [([1], [2]), ([3, 4], [5, 6, 7])] returns two samples. The second example has layout length 6, is placed first, and fills sample 0; the first example (length 3) goes into sample 1.
3.
seq_len = 4, sep = 99, pad_id = 0, examples = [([1, 2], [3, 4, 5]), ([6], [7])] returns one sample input_ids = [6, 7, 99, 0]. The first example needs 6 positions and is skipped.
Constraints
0 &lt;= len(examples) &lt;= 2000
1 &lt;= seq_len &lt;= 4096
Token ids are non-negative integers; prompts and answers may be empty.</pre>

## Worked solution

1. Pack SFT examples without corrupting targets. Packing reduces padding, but positions, attention visibility and target selection are three separate concerns.
2. For the practice contract, lay out prompt+answer+separator; mark prompt positions 0 and answer/separator positions 1.
3. Sort layouts longest first with stable ties. Place each into the first sample with enough capacity; skip oversize examples and pad the rest. Restart position ids per example.
4. During training, shift the target loss mask consistently with next-token labels. If examples must be independent, also use segment-aware attention or separate sequences.

### Small example / sanity check

Prompt [5,6], answer [7], separator 99 gives ids [5,6,7,99], mask [0,0,1,1] and positions [0,1,2,3].

### Common trap

Assuming a loss mask or reset position ids prevent one packed example from attending to another.
