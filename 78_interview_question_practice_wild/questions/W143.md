## Question

Implement a Basic Tokenizer and Train a Simple Language Model

Build a small end-to-end language-model pipeline: tokenize text, encode tokens to ids, decode ids back to text, and train a next-token model whose loss decreases.

Implement the class SimpleTokenizer and the function train_bigram using NumPy only (no deep-learning framework).

### Requirements

1. tokenize(text) — split text into word tokens on whitespace. A string returns List[str]; a list of strings returns List[List[str]]. Runs of whitespace collapse, and the result is deterministic.
2. build_vocab(texts) — from a list of strings, build vocab (token -&gt; id) and inv_vocab (id -&gt; token). Id 0 is reserved for the unknown token "&lt;unk&gt;"; the other tokens get ids in order of first appearance. Return vocab.
3. word_to_token(text) (encoding) — map a string to a list of ids, or a list of strings to a list of id lists. A token that is not in the vocabulary maps to the &lt;unk&gt; id.
4. token_to_word(ids) (decoding) — map a list of ids to a space-joined string, or a list of id lists to a list of strings. An unknown id decodes to &lt;unk&gt;.
5. train_bigram(token_ids, vocab_size, epochs=200, lr=0.5, seed=0) — train a bigram next-token model: a vocab_size x vocab_size weight matrix W (initialized from a normal distribution with standard deviation 0.01 and the given seed) whose row x holds the logits of the token that follows x. Each epoch computes the mean cross-entropy over all (current, next) pairs and takes one plain SGD step on its gradient. Return (W, losses), where losses holds the loss of each epoch.
Input / Output
Texts are Python strings; ids are non-negative integers.
train_bigram takes the id sequence of a training text and returns the trained matrix and the per-epoch losses.

### Constraints

Decoding the encoding of in-vocabulary text returns the whitespace-normalized text.
Training must reduce the loss: losses[-1] &lt; losses[0].
Example
tok = SimpleTokenizer()
tok.tokenize("the  cat   sat")       -&gt;  ["the", "cat", "sat"]
tok.tokenize(["a b", "c"])           -&gt;  [["a", "b"], ["c"]]
tok.build_vocab(["the cat sat on the mat", "the dog sat on the log"])
-&gt;  {"&lt;unk&gt;": 0, "the": 1, "cat": 2, "sat": 3,
"on": 4, "mat": 5, "dog": 6, "log": 7}
tok.word_to_token("the cat elephant") -&gt;  [1, 2, 0]
tok.token_to_word([1, 2, 3])         -&gt;  "the cat sat"

ids = tok.word_to_token("the cat sat on the mat the dog sat on the log")
W, losses = train_bigram(ids, 8)     # losses[0] ~ 2.08, losses[-1] ~ 0.59

## Worked solution

### Implement the requested whitespace tokenizer and bigram model

No BPE and no attention are needed. Whitespace tokenization collapses runs; vocabulary id zero is reserved, even if `<unk>` appears in training text. Build ids in first-appearance order. Decoding normalizes whitespace because token boundaries do not preserve the original spaces.

For pairs $x=ids[:-1]$ and $y=ids[1:]$, row W[x] is the next-token logit vector. Loss is mean negative log-softmax at y, and each occurrence contributes $(p-onehot(y))/n$ to its row. Repeated source-token ids require `np.add.at`; fancy-index `grad[x] += g` can lose repeated-index contributions.

```python
import numpy as np


class SimpleTokenizer:
    def __init__(self):
        self.vocab={'<unk>':0};self.inv_vocab={0:'<unk>'}

    def tokenize(self,text):
        if isinstance(text,str):return text.split()
        return [self.tokenize(item) for item in text]

    def build_vocab(self,texts):
        self.vocab={'<unk>':0}
        for text in texts:
            for token in self.tokenize(text):
                if token not in self.vocab:self.vocab[token]=len(self.vocab)
        self.inv_vocab={i:t for t,i in self.vocab.items()}
        return self.vocab

    def word_to_token(self,text):
        if isinstance(text,str):return [self.vocab.get(t,0) for t in self.tokenize(text)]
        return [self.word_to_token(t) for t in text]

    def token_to_word(self,ids):
        # [] is the empty single sequence; [[],[]] is a batch of two empties.
        if ids and isinstance(ids[0],(list,tuple)):
            return [self.token_to_word(row) for row in ids]
        return ' '.join(self.inv_vocab.get(int(i),'<unk>') for i in ids)


def train_bigram(token_ids,vocab_size,epochs=200,lr=.5,seed=0):
    ids=np.asarray(token_ids)
    if ids.ndim!=1 or len(ids)<2 or not np.issubdtype(ids.dtype,np.integer):
        raise ValueError('at least two integer ids required')
    if vocab_size<1 or np.any(ids<0) or np.any(ids>=vocab_size) or epochs<1 or lr<=0:
        raise ValueError('invalid training configuration')
    rng=np.random.default_rng(seed)
    W=rng.normal(0,.01,(vocab_size,vocab_size));losses=[]
    x,y=ids[:-1],ids[1:];n=len(x)
    for _ in range(epochs):
        logits=W[x];shifted=logits-logits.max(1,keepdims=True)
        logp=shifted-np.log(np.exp(shifted).sum(1,keepdims=True))
        losses.append(float(-logp[np.arange(n),y].mean()))
        g=np.exp(logp);g[np.arange(n),y]-=1;g/=n
        grad=np.zeros_like(W)
        np.add.at(grad,x,g)  # repeated current-token ids must accumulate!
        W-=lr*grad
    return W,losses

tok=SimpleTokenizer()
assert tok.tokenize('the  cat   sat')==['the','cat','sat']
assert tok.tokenize(['a b','c'])==[['a','b'],['c']]
assert tok.build_vocab(['the cat sat on the mat','the dog sat on the log'])=={'<unk>':0,'the':1,'cat':2,'sat':3,'on':4,'mat':5,'dog':6,'log':7}
assert tok.word_to_token('the cat elephant')==[1,2,0]
assert tok.token_to_word([1,2,3])=='the cat sat'
assert tok.token_to_word([[],[999]])==['','<unk>']
assert tok.token_to_word(tok.word_to_token(' the  cat\nsat '))=='the cat sat'
ids=tok.word_to_token('the cat sat on the mat the dog sat on the log')
W,losses=train_bigram(ids,8)
assert losses[-1]<losses[0] and np.isfinite(W).all()
# Independently verify a single SGD update with repeated x=1 and conflicting targets.
W0=np.random.default_rng(3).normal(0,.01,(3,3));p=np.exp(W0[1]-max(W0[1]));p/=p.sum()
expected=W0.copy();expected[1]-=.5*(p-np.array([0,.5,.5]))
W1,_=train_bigram([1,1,2],3,epochs=1,seed=3)
assert np.allclose(W1,expected)
print(f'W143: roundtrips and exact SGD update passed; losses {losses[0]:.6f} -> {losses[-1]:.6f}')
```

### Read the measured output

The example builds exactly the requested vocabulary and checks roundtrip/unknown behavior. The executable prints actual initial/final losses rather than assuming the informal ≈.59 endpoint. The empirical optimum cannot give zero loss when a token has multiple possible next tokens: “the” precedes cat/mat/dog/log. It still learns a lower cross-entropy than its near-uniform initial ≈log(8). A separate exact one-step oracle checks accumulation for repeated current token 1 with conflicting next labels 1 and 2.

Only the current token conditions this bigram model; it cannot distinguish histories ending in the same word. No causal mask is required because W is indexed solely by x. Reject length<2 because there are no supervised pairs. For n pairs and vocabulary V, each epoch costs O(nV+V²) with this dense reference, storing V² weights; large-vocabulary training needs sparse touched-row updates and batching. The exercise's full-batch SGD update and provided initialization remain unchanged.
