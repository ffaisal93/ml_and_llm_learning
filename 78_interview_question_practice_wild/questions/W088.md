## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Given two tensors of shape [B, N, 100] and [B, M, 100], compute the Euclidean distance between them so the output is a tensor of shape [B, N, M].

For every batch b, output out[b][i][j] is the Euclidean distance between the vector A[b][i] and the vector B[b][j] (each of length D = 100).

Example
Input: A = [[[1]*100]*3]*2, B = [[[2]*100]*4]*2

Here A is a batch of 2, each holding 3 vectors of one hundred 1s; B is a batch of 2, each holding 4 vectors of one hundred 2s. Every pairwise distance equals sqrt(100 * (2-1)^2) = 10, so the output has shape [2, 3, 4] and every entry is 10.0.</pre>

## Worked solution

1. Compute pairwise Euclidean distances between two tensor batches. Make the desired pairwise shape explicit before using broadcasting.
2. For X:(N,D), Y:(M,D), the result is (N,M). A direct reference uses X[:,None,:]-Y[None,:,:].
3. A lower-memory algebraic version computes squared distances as norm(X)²+norm(Y)²-2X@Yᵀ, clamping tiny negative roundoff to zero.
4. Take square roots only if actual distances are needed. Block the computation when N*M is too large; no formula removes the output-size cost.

### Small example / sanity check

The distance between [0,0] and [3,4] is 5; the squared distance is 25.

### Common trap

Returning elementwise distances between matching rows when the question asks for every pair.
