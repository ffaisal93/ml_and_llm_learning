## Question

Given two tensors of shape [B, N, 100] and [B, M, 100], compute the Euclidean distance between them so the output is a tensor of shape [B, N, M].

For every batch b, output out[b][i][j] is the Euclidean distance between the vector A[b][i] and the vector B[b][j] (each of length D = 100).

Example

```text
Input: A = [[[1]*100]*3]*2, B = [[[2]*100]*4]*2
```

Here A is a batch of 2, each holding 3 vectors of one hundred 1s; B is a batch of 2, each holding 4 vectors of one hundred 2s. Every pairwise distance equals $\sqrt{100 \times (2-1)^{2}} = 10$, so the output has shape [2, 3, 4] and every entry is 10.0.

## Worked solution

### Add axes to create every within-batch pair

Let A have shape `(B,N,D)` and C have shape `(B,M,D)`. The desired entry is

$$d_{bij}=\sqrt{\sum_{r=1}^{D}(A_{bir}-C_{bjr})^2}.$$

Insert a singleton candidate axis in A and a singleton query axis in C. Broadcasting then forms `(B,N,M,D)` differences; reduce only the final feature axis. Never flatten the batch dimension, which would create cross-batch pairs.

```python
import numpy as np

def distances_numpy(a, c):
    a = np.asarray(a, dtype=float)
    c = np.asarray(c, dtype=float)
    if a.ndim != 3 or c.ndim != 3 or a.shape[0] != c.shape[0] or a.shape[2] != c.shape[2]:
        raise ValueError('Need (B,N,D) and (B,M,D) arrays')
    difference = a[:, :, None, :] - c[:, None, :, :]
    return np.sqrt(np.sum(difference ** 2, axis=-1))
```

The prompt's vectors differ by one in each of 100 coordinates, so squared distance is 100, distance is ten, and every element of the `(2,3,4)` result is ten.

### PyTorch and memory-efficient forms

```python
import torch

def distances_torch(a, c):
    return (a[:, :, None, :] - c[:, None, :, :]).square().sum(dim=-1).sqrt()

# The library operation avoids spelling out a giant difference tensor:
result = torch.cdist(a, c, p=2)  # a and c must be floating tensors

# Alternatively use ||a-c||² = ||a||² + ||c||² - 2 a·c:
squared = (a.square().sum(-1, keepdim=True)
           + c.square().sum(-1)[:, None, :]
           - 2 * torch.bmm(a, c.transpose(1, 2)))
result_from_products = squared.clamp_min(0).sqrt()
```

Direct broadcasting costs $O(BNMD)$ work and temporary memory; the matrix-product form retains an $O(BNM)$ result plus inputs and multiplication workspace. Clamp small negative round-off before square root. The product identity can lose relative accuracy for nearly identical large vectors; direct differences or a carefully selected distance kernel may be preferable. Chunk over N or M when the result/workspace is too large.

Autograd works for floating tensors, but Euclidean distance is nondifferentiable at coincident points; a literal square-root expression can produce problematic gradients at zero. Use squared distances if that suits the loss, or a tested library kernel/explicit smoothing rule if gradients at coincidence matter. Smoothing changes the exact mathematical distance, so distinguish it from the requested forward result.
