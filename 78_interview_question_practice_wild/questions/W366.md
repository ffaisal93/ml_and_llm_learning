### Two concrete, explicitly conditional interpretations

For an **aircraft position**, if input is timestamped latitude/longitude/altitude and observer latitude/longitude/altitude, convert both geodetic positions to a consistent Earth-fixed Cartesian frame, subtract and rotate into local east/north/up. With relative vector(E, N, U), range=sqrt(E²+N²+U²), azimuth=atan2(E, N) and elevation=atan2(U, sqrt(E²+N²)). Earth ellipsoid/datum, altitude reference, units and synchronized times matter. A single image bearing cannot establish aircraft range/3D position without extra information; a stale exact GPS point does not locate a moving aircraft now.

For a **celestial direction** given right ascension alpha and declination delta in a named reference frame/epoch, the unit vector is `(cos(delta)cos(alpha), cos(delta)sin(alpha), sin(delta))`. Mapping it to an observer's altitude/azimuth additionally requires observation time, Earth orientation and observer location; mapping to pixels additionally requires projection, field of view and camera calibration. A tangent/gnomonic chart has a limited visible hemisphere and becomes singular90degrees from its center; no single flat projection preserves every spherical property.

A tiny runnable direction conversion for this chosen celestial-only contract is:

```python
import math


def radec_unit_vector(ra_degrees, dec_degrees):
    if not -90 <= dec_degrees <= 90:
        raise ValueError("declination outside sphere")
    a, d = map(math.radians, (ra_degrees, dec_degrees))
    return (math.cos(d) * math.cos(a), math.cos(d) * math.sin(a), math.sin(d))


assert all(abs(a - b) < 1e-12 for a, b in zip(radec_unit_vector(0, 0), (1, 0, 0)))
assert all(abs(a - b) < 1e-12 for a, b in zip(radec_unit_vector(90, 0), (0, 1, 0)))
assert abs(radec_unit_vector(0, 90)[2] - 1) < 1e-12
```

This O(1) function converts a direction only; it neither tracks aircraft nor implements a complete sky-navigation map.
