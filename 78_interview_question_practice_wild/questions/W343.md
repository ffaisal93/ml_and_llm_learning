## Question

Given transactions(transaction_id, user_id, vendor_id, transaction_time, transaction_dollars, transaction_type, refund_transaction_id) (transaction_type PURCHASE/REFUND; a REFUND's refund_transaction_id points to the original PURCHASE) and vendors(vendor_id, city, state_province, country).

Write a SQL query to: consider only PURCHASE transactions; filter to the last 2 years; aggregate transaction_dollars by vendor_id; return the top 3 vendors by total dollars charged.

Output columns

vendor_id, total_dollars_charged

Sample tests
1. Example output rows like 3107 | 603.18, 3997 | 600.00, 3140 | 569.00.
2. No PURCHASE in the last 2 years =&gt; empty result.
3. Ties in totals =&gt; still return 3 rows (order by total desc, optionally break ties by vendor_id asc).
4. REFUND rows exist =&gt; ignore them (count only PURCHASE).
5. transaction_dollars has 0/NULL =&gt; SUM behaves per engine defaults (NULL ignored, 0 included).

## Worked solution

### This variant explicitly ignores refunds

Use only PURCHASE rows, sum transaction_dollars and return exactly three vendors ordered by total descending then ID. It differs from the net-refund variants W341/W342; the existence of refund_transaction_id does not change the instruction to ignore all REFUND rows.

```sql
SELECT vendor_id,SUM(transaction_dollars) AS total_dollars_charged
FROM transactions
WHERE transaction_type='PURCHASE'
 AND transaction_time>=CURRENT_DATE-INTERVAL '2 years'
 AND transaction_time<CURRENT_DATE+INTERVAL '1 day'
GROUP BY vendor_id ORDER BY total_dollars_charged DESC NULLS LAST,vendor_id LIMIT 3;
```

A vendor with purchases 100 and 150 plus refund 200 still has total 250 here, not 50. NULL dollars are ignored by SUM and zero is included; an all-NULL purchase group has NULL total, ordered last explicitly. No purchases in range gives no rows. The half-open date range includes today and excludes future-dated events; use CURRENT_TIMESTAMP if the as-of instant is required. The vendors table is not needed for these two output columns. Tests exercise all five listed cases with a fixed as-of date, including ties limited to three, NULL/zero and refunds. The sample figures are examples without source rows, so no fabricated derivation of those exact totals is offered.
