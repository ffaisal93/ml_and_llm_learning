## Question

A rapid-fire ML-knowledge oral for research/MLE roles, usually after a 30-minute project deep-dive. Give crisp, correct one-paragraph answers to:

Describe self-attention. Why is the attention score divided by $\sqrt{d_k}$?
Describe LoRA and its benefits. Why does LoRA reduce GPU memory consumption?
Difference between Adam and SGD.
ViT vs CNN — pros/cons, and what influences the ViT patch size.
Difference between MSE loss and cross-entropy loss.

Usually closes with a trivial coding task (e.g. count word occurrences over a stream — a dict/Counter suffices).

## Worked solution

### Self-attention

From token states X form Q=XWq,K=XWk,V=XWv, compute $\operatorname{softmax}_{keys}(QK^T/\sqrt{d_k}+M)V$ and mix heads. Queries match keys and copy weighted values; a causal mask blocks future keys. Independent zero-mean unit-variance query/key coordinates give dot-product variance d_k, so division by sqrt(d_k) controls scale/saturation. Softmax max subtraction separately prevents overflow. Unlike an RNN hidden-state recurrence, teacher-forced attention evaluates positions in parallel; autoregressive generation still depends on previously generated tokens.

### LoRA and GPU memory

Freeze W and learn $\Delta W=(\alpha/r)BA$, with r(d_in+d_out) entries instead of d_in·d_out trainable weights. This saves gradient/Adam-state memory and per-task checkpoints, while the frozen base and activations remain necessary; 4-bit base storage is an additional QLoRA choice. Initialize only one factor zero to permit gradients, validate target tasks and merge-compatible adapters for inference if useful. It may underfit compared with full tuning and does not guarantee a fixed whole-GPU memory factor.

### Adam versus SGD

SGD subtracts eta times the minibatch gradient; momentum smooths a velocity across steps. Adam tracks exponential first/second gradient moments, bias-corrects them and divides the first by the square root of the second plus epsilon, adapting per-coordinate scales. It often handles noisy/sparse signals conveniently but stores two moment tensors and needs learning-rate/decay tuning. SGD can use less memory and generalize well after scheduling; neither universally wins. AdamW decouples weight shrinkage from adaptive moments.

### ViT versus CNN and patch size

A CNN shares local kernels, building locality/translation equivariance and often good data efficiency. A ViT embeds image patches and attends globally, offering flexible long-range relationships but weaker built-in locality and data/compute demands. For H×W images and patch side p, token count is about HW/p²; halving p makes4× tokens and about16× dense attention interactions. Small patches preserve detail useful for small objects but cost more; large patches are cheaper and may erase fine structure. Choose by resolution, objects, data/pretraining, positional scheme, memory/latency and validation, not a universal patch size.

### MSE versus cross-entropy

Squared error targets a conditional mean and corresponds to Gaussian observation noise for regression. Cross-entropy is negative log likelihood for categorical/Bernoulli outcomes and acts on normalized class probabilities, preferably computed from logits. For sigmoid BCE the logit gradient is p-y, whereas MSE on probability includes an extra p(1-p) factor that can shrink updates when confidently wrong. MSE/Brier loss is still a valid probability scoring rule; it is a different objective. Compare calibration and task cost, not just raw loss magnitudes across incompatible scales.

### A stream word-count implementation

```python
from collections import Counter

def count_words(records):
    counts=Counter()
    for record in records:
        counts.update(record.lower().split())
    return dict(counts)

assert count_words(iter(['The cat','the dog cat']))=={'the':2,'cat':2,'dog':1}
assert count_words(iter([]))=={}
```

This explicitly chooses lowercase whitespace words, keeping punctuation attached; replace that policy if the interviewer specifies a different tokenizer. It scans once, storing O(distinct words) counts rather than the full stream.
