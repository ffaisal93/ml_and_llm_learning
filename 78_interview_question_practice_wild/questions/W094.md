## Worked solution

### 1. Noiseless baseline

Each of the other $N-1$ nodes sends its measurement once to node one. Node one adds its own exact value and divides by N. This uses $N-1$ messages; fully connected topology does not require every node to talk to every other node. N=1 needs no communication.

### 2. Average repeated noisy observations

Independent Gaussian noise remains Gaussian under averaging:

$$\bar Y\sim\mathcal N(X_i,\sigma^2/k).$$

Thus $P(|\bar Y-X_i|\le\tau)=2\Phi(\tau\sqrt{k}/\sigma)-1$. For $0<\alpha<1$ and positive sigma,

$$k_{\min}=\left\lceil\left(\frac{z_{1-\alpha/2}\sigma}{\tau}\right)^2\right\rceil.$$

At least one transmission is required to observe an unknown value; with zero noise one suffices. At $\tau=10^{-4}$, k scales as $10^8z^2\sigma^2$. For sigma 0.1 and 95% confidence this is roughly 3.84 million transmissions per remote node. Halving tolerance quadruples the work.

If the goal is only the global mean rather than each individual measurement, independent per-node estimation errors partly average out: using k transmissions per remote node gives aggregate variance $(N-1)\sigma^2/(N^2k)$. Do not impose every-node accuracy if the product only needs a mean-accuracy guarantee; conversely, individual confidence does not automatically give simultaneous confidence for all nodes.

### 3. Quantize and decode bits

For bit zero, an error is noise above 0.5; for bit one, an error is noise at most -0.5. Both have probability

$$p_{\mathrm{bit}}=\Phi(-0.5/\sigma).$$

Truncation to 32 fractional bits has absolute error below $2^{-32}\approx2.33\times10^{-10}$ for $0\le X_i<1$. The stated representation cannot encode exactly one, so saturate one to $1-2^{-32}$ or define a special endpoint convention; the same bound then holds with $\le$.

If every bit is correct, quantization error is far below $10^{-4}$. A union bound gives

$$P(\text{any bit wrong})\le\min(1,32\,p_{\mathrm{bit}}).$$

To make this at most alpha, a sufficient condition is

$$\sigma\le\frac{0.5}{z_{1-\alpha/32}}.$$

For alpha 0.01 this is approximately sigma at most 0.146. It is a conservative sufficient condition because an incorrect very low-order bit need not exceed the numerical tolerance. To guarantee all 32-bit words across $N-1$ senders, allocate failure probability over $32(N-1)$ bits instead.

### Explain the communication gain and its limits

Analog estimation distinguishes values only $10^{-4}$ apart by averaging tiny differences. Binary signaling distinguishes two levels one unit apart and regenerates a clean symbol after thresholding. The numerical precision comes from position in the word rather than estimating every voltage to 32-bit accuracy. However, a flipped high-order bit causes a large error, so the scheme works only when symbol error is sufficiently small. Coding, checksums and retransmission address higher-noise channels at extra bandwidth/latency cost. The comparison assumes equal per-symbol channel resources; a “real-valued message” is not an infinite-precision free packet in a physical system. Digital encoding also requires agreed framing, quantization and error handling.
