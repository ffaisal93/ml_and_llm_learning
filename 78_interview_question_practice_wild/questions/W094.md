## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Distributed Averaging Under Noisy Communication

You are given a fully connected network of N nodes. Node i holds a real-valued measurement Xi. A designated aggregator node (node 1) must compute the average value:

μ = (1 / N) · Σ Xi (sum over i = 1 … N)

Communication between nodes may be noisy.

Part 1 — Noiseless Baseline

Assume communication is perfect: when a node sends a value, the receiver gets it exactly.

1.
Describe a simple protocol that allows node 1 to compute μ exactly.
2.
State the total number of messages required as a function of N.
Part 2 — Noisy Communication and Statistical Estimation

Now assume communication is corrupted by additive Gaussian noise.

When node i sends a real value v, the receiver observes:

Y = v + ε

where ε is independent noise distributed as:

ε ~ Normal(0, σ²)

Node 1 wants to estimate the value Xi held by node i.

Node i sends Xi exactly k times, producing observations:

Y₁, Y₂, …, Yₖ

with Yₜ = Xi + εₜ

Node 1 estimates Xi using the sample mean:

Ȳ = (1 / k) · Σ Yₜ

Answer the following:

1.Derive the distribution of Ȳ (its mean and variance).

2.Given an absolute error tolerance τ &gt; 0 and confidence level 1 − α, derive the minimum k such that:

P(|Ȳ − Xi| ≤ τ) ≥ 1 − α

Express k in terms of τ, σ, and the standard normal quantile z_{1−α/2}.

3.Evaluate how k scales when τ = 10⁻⁴ and σ is fixed. Explain why repeated analog transmission becomes impractical at this tolerance.

Part 3 — Reducing Communication via Bit Encoding

To reduce communication cost, assume now that Xi ∈ [0, 1].

Instead of sending Xi as a real number, node i encodes it using a 32-bit fixed-point representation:

Xi ≈ b₁·2⁻¹ + b₂·2⁻² + … + b₃₂·2⁻³²

where each bⱼ ∈ {0, 1}

Each bit is sent once over the same noisy channel:

Transmit bit b as voltage b (0 or 1)
Receiver observes V = b + ε
Decode b̂ = 1 if V &gt; 0.5, otherwise b̂ = 0

Answer the following:

1.Derive the bit error probability p_bit = P(b̂ ≠ b) as a function of σ.

2.If all bits are decoded correctly, bound the maximum numerical error in reconstructing Xi and compare it to τ = 10⁻⁴.

3.Use a union bound to estimate the probability that at least one of the 32 bits is incorrect.

4.Under what conditions on σ can the 32-bit scheme achieve error ≤ τ with high probability using only 32 transmissions?

5.Explain intuitively why bit-based transmission tolerates more noise per symbol than analog transmission and how this enables a large reduction in total messages.

Engineering Discussion

Discuss the trade-offs between analog averaging and bit-based encoding in real distributed systems, considering bandwidth, latency, noise levels, and implementation complexity.</pre>

## Worked solution

1. Without noise, send each non-aggregator value to node 1: N-1 messages and mean (X1+sum_received)/N. For k independent analog transmissions of Xi, the sample mean is Normal(Xi,sigma²/k).
2. The two-sided confidence requirement gives k>=ceil((z_(1-alpha/2)*sigma/tau)²). Halving tau quadruples k; tau=10^-4 creates order 10^8 transmissions per fixed-scale value before the confidence constant.
3. For a bit sent as voltage 0 or 1 and decoded at 0.5, crossover probability is q=Phi(-1/(2*sigma)). With fixed-point estimate sum_j b_hat_j*2^-j, its conditional expectation is q*(1-2^-32)+(1-2q)*x_quantized, so one noisy bit per position is generally biased.
4. Its conditional noise variance is q*(1-q)*sum_j 4^-j=q*(1-q)*(1-4^-32)/3; add quantization error separately. Repeat/protect bits with an explicit coding strategy, especially high-significance bits, rather than claiming bit encoding eliminates noise.

### Small example / sanity check

At sigma=1, tau=10^-4 and 95% confidence, k is about ceil(1.96²*10^8)=384160000. Digital transmission helps only if its bit-error and reconstruction effects are controlled.

### Common trap

Confusing unbiased analog averaging with a one-shot digital estimator, or treating all bit errors as equally costly.
