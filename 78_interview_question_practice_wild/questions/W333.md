## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Write SQL statements to implement select, select limit, and select where. Given an example data table where each row contains columns with different data types (such as ID and Name), implement complete SQL code that can perform these operations and design some test cases to verify the correctness of the code. Note: You may need to implement all logic from scratch if the programming language used does not have boilerplate code.

Example
CREATE TABLE students (id INT, name VARCHAR(255), age INT);
INSERT INTO students VALUES
(1, &#x27;Alice&#x27;, 22),
(2, &#x27;Bob&#x27;, 25),
(3, &#x27;Charlie&#x27;, 30);
SELECT * FROM students; SELECT * FROM students LIMIT 2; SELECT * FROM students WHERE age &gt; 24;</pre>

## Worked solution

1. Define the example schema and insert the three rows before querying. SELECT projects columns, WHERE filters rows and LIMIT bounds the returned row count.
2. Use ORDER BY for deterministic limited results; without it SQL does not promise which two rows LIMIT returns.
3. If asked to implement relational operations in a general-purpose language instead of SQL, use independent projection, predicate-filter and limit functions over typed rows; do not claim the exercise requires a full SQL parser.

### Reference query

```sql
SELECT id,name,age FROM students ORDER BY id;
SELECT id,name,age FROM students ORDER BY id LIMIT 2;
SELECT id,name,age FROM students WHERE age>24 ORDER BY id;
```

### Small example / sanity check

The final query returns Bob (25) and Charlie (30); the limited ordered query returns Alice and Bob.

### Common trap

Treating implicit row storage order as guaranteed SELECT order.
