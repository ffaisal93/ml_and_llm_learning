## Question

Implement a Vision Transformer (ViT) from Scratch

Implement the forward pass of a Vision Transformer image classifier using only NumPy. The model cuts an image into square patches, turns every patch into a token, adds one extra classification token (CLS) and a learned position embedding, runs the tokens through a stack of pre-norm transformer encoder blocks, and predicts the class from the final CLS token. The weights are given; you write the computation.

### What to implement

```python
import numpy as np
```

```text
def softmax(x, axis=-1): ...
    def layer_norm(x, gamma, beta, eps=1e-5): ...
    def gelu(x): ...
    def patch_embed(images, w, b, patch_size): ...
    def multi_head_attention(x, w_qkv, b_qkv, w_out, b_out, num_heads): ...
    def encoder_block(x, p, num_heads): ...
    def vit_forward(images, params, patch_size, num_heads): ...
```

Do not use any deep-learning library or ready-made attention or transformer layer; only NumPy. B is the batch size, N the number of patches, D the embedding size.

### Rules

1. softmax(x, axis): subtract the maximum along axis before exponentiating, so large inputs do not overflow.
2. layer_norm(x, gamma, beta, eps): normalize over the last axis: (x - mean) / sqrt(var + eps) * gamma + beta, with the biased variance (divide by the count).
3. `gelu(x)`: the tanh form $0.5\,x\,\big(1 + \tanh(\sqrt{2/\pi}\,(x + 0.044715\,x^{3}))\big)$.
4. patch_embed(images, w, b, patch_size): images has shape (B, C, H, W) with H and W divisible by P = patch_size. Patches are taken row by row (left to right, then top to bottom), and the pixels of one patch are flattened in (C, P, P) order into a vector of length C*P*P. The result is flat @ w + b with w of shape (C*P*P, D), shape (B, N, D), N = (H/P) * (W/P).
5. multi_head_attention(x, ...): x has shape (B, N, D). Compute qkv = x @ w_qkv + b_qkv with w_qkv of shape (D, 3D). Columns [0, D) are the queries, [D, 2D) the keys, [2D, 3D) the values. Head h uses columns [h*d, (h+1)*d) of each, where d = D / num_heads. Per head, the attention weights are softmax(Q K^T / sqrt(d)) over the keys (no mask), and the head output is the weights times V. Concatenate the heads in order and return concat @ w_out + b_out, shape (B, N, D).
6. encoder_block(x, p, num_heads) is pre-norm with residual connections: x = x + attention(layer_norm(x)), then x = x + mlp(layer_norm(x)), where mlp(h) = gelu(h @ fc1_w + fc1_b) @ fc2_w + fc2_b. The dictionary p has the keys ln1_g, ln1_b, qkv_w, qkv_b, proj_w, proj_b, ln2_g, ln2_b, fc1_w, fc1_b, fc2_w, fc2_b.
7. vit_forward(images, params, patch_size, num_heads): embed the patches with params["patch_w"], params["patch_b"]; put the CLS vector params["cls"] (shape (D,)) in front of the tokens as token 0; add params["pos"] (shape (N+1, D)); apply the blocks in params["blocks"] (a list of dictionaries as in rule 6); apply layer_norm with params["ln_g"], params["ln_b"]; and return the logits of token 0: token0 @ params["head_w"] + params["head_b"], shape (B, num_classes).

### Examples

Example 1: images of shape (2, 3, 16, 16), patch_size = 4, D = 8, 10 classes. patch_embed returns shape (2, 16, 8), the sequence has 17 tokens after the CLS token is added, and vit_forward returns shape (2, 10).

Example 2: layer_norm(np.array([1.0, 2.0, 3.0]), 1.0, 0.0, eps=0.0) returns [-1.2247, 0.0, 1.2247]. The mean is 2 and the biased variance is 2/3.

Example 3: images = [[[[1, 2], [3, 4]]]] (one image, one channel, 2 x 2 pixels), patch_size = 1, w = [[2.0]], b = [1.0] returns [[[3.0], [5.0], [7.0], [9.0]]]. Each pixel is a patch and is mapped to 2 * pixel + 1, in row-major order.

### Constraints

1 &lt;= B &lt;= 8; images up to 224 x 224; 1 &lt;= C &lt;= 3.
D is divisible by num_heads; D &lt;= 768; up to 12 blocks.
The inputs and the parameters are not modified.

## Worked solution

### Follow the shape changes

This exercise asks for a forward computation with supplied weights, not training. Keep the required NumPy implementation separate from a library model. Start with images `(B,C,H,W)`, rearrange them into `(B,N,C*P*P)` patches, project to `(B,N,D)`, prepend CLS and add positions. Each pre-norm block preserves `(B,N+1,D)`. Only token zero goes into the final classifier.

The subtle part is patch order: grid row, grid column, channel, patch row, patch column. A plain reshape without transposing can mix pixels from different patches. The other common error is combining Q/K/V heads in the wrong order. Split the three contiguous Q/K/V column ranges first, then split each into heads.

### NumPy forward pass

[Download the complete numerical implementations](../exact_numeric_51_100.py).

```python
"""Exact NumPy contracts for W072, W076 and W079."""
import numpy as np

def softmax(x, axis=-1):
    shifted = x - np.max(x, axis=axis, keepdims=True)
    exps = np.exp(shifted)
    return exps / exps.sum(axis=axis, keepdims=True)

def layer_norm(x, gamma, beta, eps=1e-5):
    centered = x - x.mean(axis=-1, keepdims=True)
    variance = (centered**2).mean(axis=-1, keepdims=True)
    return centered / np.sqrt(variance + eps) * gamma + beta

def gelu(x):
    return .5*x*(1+np.tanh(np.sqrt(2/np.pi)*(x+.044715*x**3)))

def patch_embed(images, w, b, patch_size):
    B,C,H,W = images.shape
    P = patch_size
    if P<=0 or H%P or W%P:
        raise ValueError('Patch size must divide both image dimensions')
    # B,C,patch-row,pixel-row,patch-col,pixel-col
    patches = images.reshape(B,C,H//P,P,W//P,P)
    patches = patches.transpose(0,2,4,1,3,5)  # B,grid-H,grid-W,C,P,P
    flat = patches.reshape(B,(H//P)*(W//P),C*P*P)
    return flat @ w + b

def multi_head_attention(x, w_qkv, b_qkv, w_out, b_out, num_heads):
    B,N,D = x.shape
    if num_heads<=0 or D%num_heads:
        raise ValueError('Heads must divide embedding dimension')
    h,d = num_heads,D//num_heads
    qkv = x @ w_qkv + b_qkv
    q,k,v = [part.reshape(B,N,h,d).transpose(0,2,1,3)
             for part in np.split(qkv,3,axis=-1)]
    weights = softmax((q @ k.swapaxes(-1,-2))/np.sqrt(d),axis=-1)
    combined = (weights @ v).transpose(0,2,1,3).reshape(B,N,D)
    return combined @ w_out + b_out

def encoder_block(x, p, num_heads):
    h = layer_norm(x,p['ln1_g'],p['ln1_b'])
    x = x + multi_head_attention(h,p['qkv_w'],p['qkv_b'],
                                 p['proj_w'],p['proj_b'],num_heads)
    h = layer_norm(x,p['ln2_g'],p['ln2_b'])
    return x + gelu(h @ p['fc1_w']+p['fc1_b']) @ p['fc2_w']+p['fc2_b']

def vit_forward(images, params, patch_size, num_heads):
    tokens = patch_embed(images,params['patch_w'],params['patch_b'],patch_size)
    B,N,D = tokens.shape
    cls = np.broadcast_to(params['cls'],(B,1,D))
    x = np.concatenate([cls,tokens],axis=1)+params['pos']
    for block in params['blocks']:
        x = encoder_block(x,block,num_heads)
    x = layer_norm(x,params['ln_g'],params['ln_b'])
    return x[:,0] @ params['head_w']+params['head_b']


```

For head dimension $d=D/h$, each head computes

$$A=\operatorname{softmax}(QK^\top/\sqrt d),\qquad O=AV.$$

The key axis is the final axis of the score matrix; there is no causal mask for this image encoder. Layer normalization uses the population variance across features, and both residual additions use the unnormalized residual input. Final normalization applies to all tokens before selecting CLS.

### Check values, not just output shape

For the one-channel 2×2 example and patch size one, `patch_embed` produces `[3,5,7,9]` with the given weight/bias. For a larger patch, compare one flattened patch directly against `images[b,:,row:row+P,col:col+P].reshape(-1)`. Check layer normalization of `[1,2,3]` against `[-sqrt(1.5),0,sqrt(1.5)]` when epsilon is zero.

Validate attention against a slow per-head reference and confirm that a zero attention/MLP branch leaves its residual unchanged. Save copies of input/parameter arrays and compare them afterward to check the no-mutation rule. The companion tests exercise those cases and a complete small classifier. The normal computation costs roughly $O(BN^2D+BND^2)$ per block and stores attention of size $O(BhN^2)$, so patch size strongly affects memory.

A PyTorch equivalent for study is shown below; it is **not** the answer to the NumPy-only constraint. Convert NumPy linear weights with `.T` because `nn.Linear` stores `(out,in)` weights. PyTorch's `gelu(..., approximate="tanh")` and `LayerNorm(eps=1e-5)` match the specified formulas.

```python
import torch
from torch import nn
class StudyViT(nn.Module):
    def __init__(self, channels, image_size, patch_size, dimension,
                 heads, hidden, layers, classes):
        super().__init__()
        self.patch = nn.Conv2d(channels, dimension, patch_size, patch_size)
        count = (image_size // patch_size) ** 2
        self.cls = nn.Parameter(torch.zeros(1, 1, dimension))
        self.pos = nn.Parameter(torch.zeros(1, count + 1, dimension))
        self.blocks = nn.ModuleList([
            nn.TransformerEncoderLayer(dimension, heads, hidden, dropout=0.,
                activation=lambda x: torch.nn.functional.gelu(x, approximate='tanh'),
                batch_first=True, norm_first=True) for _ in range(layers)])
        self.norm = nn.LayerNorm(dimension)
        self.head = nn.Linear(dimension, classes)
    def forward(self, images):
        tokens = self.patch(images).flatten(2).transpose(1, 2)
        x = torch.cat([self.cls.expand(len(images), -1, -1), tokens], dim=1) + self.pos
        for block in self.blocks:
            x = block(x)
        return self.head(self.norm(x)[:, 0])
```
