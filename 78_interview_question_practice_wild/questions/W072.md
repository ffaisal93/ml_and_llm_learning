## Question

Implement a Vision Transformer (ViT) from Scratch

Implement the forward pass of a Vision Transformer image classifier using only NumPy. The model cuts an image into square patches, turns every patch into a token, adds one extra classification token (CLS) and a learned position embedding, runs the tokens through a stack of pre-norm transformer encoder blocks, and predicts the class from the final CLS token. The weights are given; you write the computation.

### What to implement

```python
import numpy as np
```

```text
def softmax(x, axis=-1): ...
    def layer_norm(x, gamma, beta, eps=1e-5): ...
    def gelu(x): ...
    def patch_embed(images, w, b, patch_size): ...
    def multi_head_attention(x, w_qkv, b_qkv, w_out, b_out, num_heads): ...
    def encoder_block(x, p, num_heads): ...
    def vit_forward(images, params, patch_size, num_heads): ...
```

Do not use any deep-learning library or ready-made attention or transformer layer; only NumPy. B is the batch size, N the number of patches, D the embedding size.

### Rules

1. softmax(x, axis): subtract the maximum along axis before exponentiating, so large inputs do not overflow.
2. layer_norm(x, gamma, beta, eps): normalize over the last axis: (x - mean) / sqrt(var + eps) * gamma + beta, with the biased variance (divide by the count).
3. gelu(x): the tanh form 0.5 * x * (1 + tanh(sqrt(2 / pi) * (x + 0.044715 * x^3))).
4. patch_embed(images, w, b, patch_size): images has shape (B, C, H, W) with H and W divisible by P = patch_size. Patches are taken row by row (left to right, then top to bottom), and the pixels of one patch are flattened in (C, P, P) order into a vector of length C*P*P. The result is flat @ w + b with w of shape (C*P*P, D), shape (B, N, D), N = (H/P) * (W/P).
5. multi_head_attention(x, ...): x has shape (B, N, D). Compute qkv = x @ w_qkv + b_qkv with w_qkv of shape (D, 3D). Columns [0, D) are the queries, [D, 2D) the keys, [2D, 3D) the values. Head h uses columns [h*d, (h+1)*d) of each, where d = D / num_heads. Per head, the attention weights are softmax(Q K^T / sqrt(d)) over the keys (no mask), and the head output is the weights times V. Concatenate the heads in order and return concat @ w_out + b_out, shape (B, N, D).
6. encoder_block(x, p, num_heads) is pre-norm with residual connections: x = x + attention(layer_norm(x)), then x = x + mlp(layer_norm(x)), where mlp(h) = gelu(h @ fc1_w + fc1_b) @ fc2_w + fc2_b. The dictionary p has the keys ln1_g, ln1_b, qkv_w, qkv_b, proj_w, proj_b, ln2_g, ln2_b, fc1_w, fc1_b, fc2_w, fc2_b.
7. vit_forward(images, params, patch_size, num_heads): embed the patches with params["patch_w"], params["patch_b"]; put the CLS vector params["cls"] (shape (D,)) in front of the tokens as token 0; add params["pos"] (shape (N+1, D)); apply the blocks in params["blocks"] (a list of dictionaries as in rule 6); apply layer_norm with params["ln_g"], params["ln_b"]; and return the logits of token 0: token0 @ params["head_w"] + params["head_b"], shape (B, num_classes).

### Examples

Example 1: images of shape (2, 3, 16, 16), patch_size = 4, D = 8, 10 classes. patch_embed returns shape (2, 16, 8), the sequence has 17 tokens after the CLS token is added, and vit_forward returns shape (2, 10).

Example 2: layer_norm(np.array([1.0, 2.0, 3.0]), 1.0, 0.0, eps=0.0) returns [-1.2247, 0.0, 1.2247]. The mean is 2 and the biased variance is 2/3.

Example 3: images = [[[[1, 2], [3, 4]]]] (one image, one channel, 2 x 2 pixels), patch_size = 1, w = [[2.0]], b = [1.0] returns [[[3.0], [5.0], [7.0], [9.0]]]. Each pixel is a patch and is mapped to 2 * pixel + 1, in row-major order.

### Constraints

1 &lt;= B &lt;= 8; images up to 224 x 224; 1 &lt;= C &lt;= 3.
D is divisible by num_heads; D &lt;= 768; up to 12 blocks.
The inputs and the parameters are not modified.

## Worked solution

### Solution outline

A ViT turns image patches into a sequence processed by Transformer blocks.

1. Split an image into non-overlapping patches, requiring compatible image dimensions or an explicit padding policy.
2. Flatten each patch, project it into the model dimension and add position information and any classification token.
3. Run normalization, attention and FFN blocks, then use the specified pooling/head. Trace every reshape to preserve patch order.

### Understand why the approach works

#### Build the computation before optimizing it

Start by saying which axis represents examples, positions, heads and features. With batch size $B$, query length $T_q$, key length $T_k$ and head width $d_k$, a head receives $Q\in\mathbb R^{B\times T_q\times d_k}$ and $K\in\mathbb R^{B\times T_k\times d_k}$. Values may have a different final width $d_v$. The essential operation is

$$
S=\frac{QK^\top}{\sqrt{d_k}}+M,\qquad
P_{ij}=\frac{\exp(S_{ij}-m_i)}{\sum_j\exp(S_{ij}-m_i)},\qquad O=PV.
$$

Here the transpose affects the final two axes, $m_i=\max_j S_{ij}$ is a row maximum, and $M$ contains zero for allowed positions and $-\infty$ for forbidden ones. Each query produces one distribution **over keys**, so summing the wrong axis changes the operation even when the output shape looks plausible.

For a tiny check, give a query access to exactly one key. Its output must equal that key's value, regardless of the score. Then change a forbidden future token: earlier causal outputs must remain unchanged. These checks expose mistakes that a random shape test misses.

Explain the limitation of the simple implementation. Explicitly materializing $P$ uses $O(T_qT_k)$ score storage per head. A reference implementation is useful for correctness; a tiled kernel can avoid that materialization while preserving the mathematical attention operation. Generation additionally needs correct target shifts, positions and cache state, not just a working matrix multiplication.

### Work a small example

A 32-by-32 RGB image with 8-by-8 patches gives 16 patch tokens of 192 input features each, before projection.

### Edge cases and common mistakes

Mixing channels and patch positions during reshape or silently discarding image borders.
