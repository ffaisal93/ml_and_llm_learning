## Question

A GPU cluster scheduler receives tasks as a stream. Each task occupies one GPU node for a time range. Build a tracker that records the busy time of every node as tasks arrive and, on request, reports when a node was idle inside a time window.

### What to implement

```text
class GPUIdleIntervalTracker:
def add_task(self, start: int, end: int, node_id: str) -> None: ...
def get_idle_intervals(
self, node_id: str, window_start: int, window_end: int
```

) -&gt; list[tuple[int, int]]: ...
add_task(start, end, node_id): record a task that occupies node node_id during [start, end). Times are integers.
get_idle_intervals(node_id, window_start, window_end): return the idle intervals of that node inside [window_start, window_end), sorted by start time.

### Rules

1. All intervals are half-open: [start, end) contains start but not end.
2. The busy time of a node is the union of its tasks. Tasks that overlap or touch form one busy stretch: [1, 3) and [3, 5) give [1, 5), [1, 4) and [2, 6) give [1, 6), while [1, 3) and [4, 6) stay separate. Tasks may arrive in any order.
3. An idle interval is a maximal stretch of the window that is not busy. Idle intervals are clipped to the window and returned in increasing order.
4. A node that has never received a task is idle for the whole window. An empty window (window_start == window_end) returns [].
5. add_task raises ValueError if start &gt;= end; get_idle_intervals raises ValueError if window_start &gt; window_end. A call that raises changes nothing.
6. Nodes are independent: a task on one node never affects another.

### Examples

Example 1:

```python
tracker = GPUIdleIntervalTracker()
```

tracker.add_task(10, 20, "node-A")
tracker.add_task(30, 40, "node-A")
tracker.add_task(18, 35, "node-A")
tracker.get_idle_intervals("node-A", 0, 50)   # [(0, 10), (40, 50)]

Explanation: the third task overlaps both earlier ones, so the busy time becomes [(10, 40)].

### Constraints

Up to 10^5 calls in total; times fit in 64-bit integers.
Let k be the number of busy intervals on the node, m the number of intervals an insertion merges and r the number of busy intervals that overlap a query window.
add_task should find its position in O(log k) and examine only the m intervals it merges. With a Python list, replacing the merged run shifts the intervals after it whenever the run's length changes and the run is not at the end of the list, so a list-based add_task is O(k) in the worst case; Follow-up 2 asks how to remove that cost.
get_idle_intervals should take O(log k + r) time.

## Worked solution

### Solution outline

1. Keep each node’s busy intervals sorted and disjoint. Validate start<end before mutation; insert a task by finding neighbors and merging every overlapping or touching interval.
2. For a query validate window_start<=window_end. Return [] for an empty window, and the full window for an unknown node.
3. Scan busy intervals intersecting the window with a cursor initially at window_start. Emit [cursor,busy_start) when nonempty, advance cursor to max(cursor,busy_end), clip to window_end and emit the remaining tail.
4. A simple sorted-list implementation has $O(m)$ worst-case insertion/query for m intervals on the node; a balanced interval structure can improve search, with output-size costs unavoidable. Nodes have independent state.

### Readable reference implementation

Read the explanation first, then trace one small input through these functions. This is the same implementation used by the local checks; its stated simplifications still apply.

```python
from collections import defaultdict
from functools import lru_cache
import math
import re
import numpy as np


def merge_intervals(intervals):
    result=[]
    for start,end in sorted(intervals):
        if start>=end:raise ValueError('interval must be nonempty')
        if result and start<=result[-1][1]:result[-1]=(result[-1][0],max(end,result[-1][1]))
        else:result.append((start,end))
    return result


class GPUIdleIntervalTracker:
    def __init__(self): self.busy=defaultdict(list)
    def add_task(self,start,end,node_id):
        if start>=end:raise ValueError('invalid task')
        self.busy[node_id]=merge_intervals(self.busy[node_id]+[(start,end)])
    def get_idle_intervals(self,node_id,window_start,window_end):
        if window_start>window_end:raise ValueError('invalid window')
        cursor=window_start;out=[]
        for start,end in self.busy.get(node_id,[]):
            if end<=cursor:continue
            if start>=window_end:break
            if start>cursor:out.append((cursor,min(start,window_end)))
            cursor=max(cursor,min(end,window_end))
        if cursor<window_end:out.append((cursor,window_end))
        return out
```
