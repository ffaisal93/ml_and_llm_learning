## Question

Given Query, Key, and Value tensors, implement the forward pass of Grouped Query Attention (GQA) without masks.

Tensor shapes:

Q: [B, Hq, Tq, D]
K: [B, Hkv, Tk, D]
V: [B, Hkv, Tk, D]

Where:

B is the batch size.
Hq is the number of query heads.
Hkv is the number of key/value heads.
Hq is divisible by Hkv.
Every Hq / Hkv query heads share one key/value head. For query head h, the corresponding key/value head is:

```python
kv_head = h // (Hq / Hkv)
```

For every batch, query head, and query position, compute:

```python
scores_j = dot(Q[b][h][t], K[b][kv_head][j]) / sqrt(D)
weights  = softmax(scores)
```

output[b][h][t] = sum_j weights_j * V[b][kv_head][j]

### Constraints

1 &lt;= B &lt;= 4
1 &lt;= Hkv &lt;= Hq &lt;= 32
Hq % Hkv == 0
1 &lt;= Tq, Tk &lt;= 256
1 &lt;= D &lt;= 128

Return the output tensor shaped [B, Hq, Tq, D].

## Worked solution

### Solution outline

#### Implement grouped-query attention without losing the head mapping.

Several query heads share one key/value head, reducing stored K and V while retaining multiple query patterns.

1. Require Hq divisible by Hkv and let group_size=Hq/Hkv.
2. For query head h, use KV head h//group_size. Apply scaled attention independently for each query head.
3. For a simple reference implementation, repeat each KV head group_size times along the head axis; optimized kernels avoid materializing the repetitions.

#### Backpropagate through shared KV heads in GQA.

When several query heads use one KV head, their gradient contributions must accumulate into the shared tensors.

1. Compute each query head's attention derivatives using its mapped KV head.
2. Sum all dK and dV contributions assigned to each shared head before propagating through the KV projections.
3. Compare the result with an explicit repeated-head reference whose repeat operation's backward sums repeated entries.

### Understand why the approach works

#### Derive the shared-head mapping

Let $H_q$ query heads share $H_{\rm KV}$ key/value heads, with $g=H_q/H_{\rm KV}$ an integer. For query head $h$, the contiguous grouping contract is

$$
k(h)=\left\lfloor\frac hg\right\rfloor,\qquad
O_h=\operatorname{softmax}\!\left(\frac{Q_hK_{k(h)}^\top}{\sqrt d}\right)V_{k(h)}.
$$

For eight query heads and two KV heads, heads $0,1,2,3$ use KV head zero and heads $4,5,6,7$ use KV head one. Mapping by $h\bmod H_{\rm KV}$ alternates heads and implements a different convention.

A clear reference loops over batch and query head, using the mapped KV head. Repeating KV tensors along the head axis can verify the result independently, but materializing repeats loses part of the memory advantage. The output still has $H_q$ heads; sharing keys does not average away query outputs.

The ideal cache storage ratio relative to otherwise equivalent ordinary MHA is $H_{\rm KV}/H_q$. With 32 query heads and eight KV heads, raw cached K/V elements drop fourfold. Query attention still computes a distribution for every query head, so do not claim all attention arithmetic also drops by four.

During backward, all query heads sharing a KV tensor contribute derivatives to it. Those contributions **sum**; retaining only the final head or averaging without an objective-based factor changes training. Test the mapping using KV values that differ unmistakably between groups.

### Readable reference implementation

Read the explanation first, then trace one small input through these functions. This is the same implementation used by the local checks; its stated simplifications still apply.

```python
import math
from collections import deque
from dataclasses import dataclass
import numpy as np


def attention_qkv(q, k, v, mask=None):
    """Single-head attention. True mask entries mean allowed. Empty rows rejected."""
    q, k, v = [np.asarray(a, dtype=np.float64) for a in (q, k, v)]
    if any(a.ndim != 2 for a in (q, k, v)):
        raise ValueError("q,k,v must be matrices")
    if q.shape[1] != k.shape[1] or k.shape[0] != v.shape[0]:
        raise ValueError("incompatible attention shapes")
    if q.shape[1] == 0 or k.shape[0] == 0:
        raise ValueError("empty head dimension or key sequence")
    if not all(np.isfinite(a).all() for a in (q, k, v)):
        raise ValueError("inputs must be finite")
    scores = q @ k.T / math.sqrt(q.shape[1])
    if mask is not None:
        mask = np.asarray(mask, dtype=bool)
        if mask.shape != scores.shape or not mask.any(axis=-1).all():
            raise ValueError("invalid mask or all-masked row")
        scores = np.where(mask, scores, -np.inf)
    z = scores - scores.max(axis=-1, keepdims=True)
    weights = np.exp(z)
    weights /= weights.sum(axis=-1, keepdims=True)
    return weights @ v


def grouped_query_attention(q, k, v):
    """Reference loops preserve the contiguous head mapping without repeating KV."""
    q, k, v = [np.asarray(a, dtype=np.float64) for a in (q, k, v)]
    if any(a.ndim != 4 for a in (q, k, v)):
        raise ValueError("expected (B,H,T,D) tensors")
    b, hq, tq, d = q.shape
    if k.shape != v.shape or k.shape[0] != b or k.shape[-1] != d:
        raise ValueError("incompatible KV tensors")
    hkv = k.shape[1]
    if hkv < 1 or hq < 1 or hq % hkv:
        raise ValueError("Hq must be divisible by positive Hkv")
    out = np.empty_like(q)
    group = hq // hkv
    for batch in range(b):
        for h in range(hq):
            kh = h // group
            out[batch, h] = attention_qkv(q[batch, h], k[batch, kh], v[batch, kh])
    return out
```
