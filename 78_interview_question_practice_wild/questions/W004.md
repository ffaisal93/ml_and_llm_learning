## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Given Query, Key, and Value tensors, implement the forward pass of Grouped Query Attention (GQA) without masks.

Tensor shapes:

Q: [B, Hq, Tq, D]
K: [B, Hkv, Tk, D]
V: [B, Hkv, Tk, D]

Where:

B is the batch size.
Hq is the number of query heads.
Hkv is the number of key/value heads.
Hq is divisible by Hkv.
Every Hq / Hkv query heads share one key/value head. For query head h, the corresponding key/value head is:
kv_head = h // (Hq / Hkv)

For every batch, query head, and query position, compute:

scores_j = dot(Q[b][h][t], K[b][kv_head][j]) / sqrt(D)
weights  = softmax(scores)
output[b][h][t] = sum_j weights_j * V[b][kv_head][j]
Constraints
1 &lt;= B &lt;= 4
1 &lt;= Hkv &lt;= Hq &lt;= 32
Hq % Hkv == 0
1 &lt;= Tq, Tk &lt;= 256
1 &lt;= D &lt;= 128

Return the output tensor shaped [B, Hq, Tq, D].</pre>

## Worked solution

1. Implement grouped-query attention without losing the head mapping. Several query heads share one key/value head, reducing stored K and V while retaining multiple query patterns.
2. Require Hq divisible by Hkv and let group_size=Hq/Hkv.
3. For query head h, use KV head h//group_size. Apply scaled attention independently for each query head.
4. For a simple reference implementation, repeat each KV head group_size times along the head axis; optimized kernels avoid materializing the repetitions.
5. Backpropagate through shared KV heads in GQA. When several query heads use one KV head, their gradient contributions must accumulate into the shared tensors.
6. Compute each query head's attention derivatives using its mapped KV head.
7. Sum all dK and dV contributions assigned to each shared head before propagating through the KV projections.
8. Compare the result with an explicit repeated-head reference whose repeat operation's backward sums repeated entries.

### Small example / sanity check

With Hq=8 and Hkv=2, query heads 0–3 use KV head 0; heads 4–7 use head 1.

### Common trap

Using h%Hkv, which produces alternating KV heads and a different grouping.
