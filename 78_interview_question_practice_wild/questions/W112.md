## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">This problem has five parts on a small neural network classifier built from first principles: its probability layer, its loss, its training procedure, and how to verify its gradients.

Task

Implement a two-layer neural network classifier from scratch in NumPy, with a numerically stable softmax, a cross-entropy loss, and a hand-derived backward pass. Use NumPy only: no PyTorch, no autograd. Work in float64.

Part 1 — Numerically stable softmax

Implement softmax(z, axis=-1), returning probabilities along axis that sum to 1. It must accept a 1-D array or an array of any shape, and must return finite values for every finite input — for example [1000, 1001, 1002] and [-1000, -1000].

Then answer:

1.
Why does the direct formula softmax(z)ᵢ = exp(zᵢ) / Σⱼ exp(zⱼ) fail in floating point? Give the input range where np.exp overflows in float64 and in float32, and describe the failure for very negative inputs.
2.
Prove that softmax(z − c) = softmax(z) for any constant c.
3.
Explain why choosing c = max(z) removes overflow and division by zero, and which form of underflow it does not remove.
Part 2 — Log-softmax

Implement log_softmax(z, axis=-1), returning log-probabilities that stay finite even where a probability underflows to 0 — for example log_softmax([0, -1000]) must equal [0, -1000]. Explain why np.log(softmax(z)) is not an acceptable implementation, and state the log-sum-exp identity your implementation uses.

Part 3 — Cross-entropy loss

Implement cross_entropy(logits, y): the mean over the batch of −log p(yᵢ | logitsᵢ), for logits of shape (n, k) and integer labels y of shape (n,). Raise ValueError if logits is not 2-D, if y does not hold one label per row, if the batch is empty, or if a label lies outside [0, k). The loss must be finite for extreme logits, e.g. cross_entropy([[0, 1000]], [0]) == 1000.

Part 4 — Two-layer network

Implement TwoLayerNet(n_in, n_hidden, n_out, seed=0) computing Linear → ReLU → Linear, with parameters W1 (n_in, n_hidden), b1 (n_hidden,), W2 (n_hidden, n_out), b2 (n_out,) drawn from np.random.default_rng(seed). Provide:

forward(X) → (logits, cache).
loss_and_grads(X, y) → (loss, grads), where grads[name] has the shape of params[name]. Derive the backward pass by hand.
step(grads, lr) — one gradient-descent update, in place.
predict(X) — the class index per row.
fit(X, y, lr=0.5, epochs=500) — full-batch gradient descent, returning the loss per epoch.

Then answer:

1.
Derive the gradient of the loss with respect to the logits for softmax followed by cross-entropy, and show it equals (softmax(logits) − onehot(y)) / n.
2.
Write the gradients for W2, b2, W1 and b1, including how the ReLU enters.
3.
Which initialisation do you use for W1, and why? What goes wrong if every weight starts at zero?
Part 5 — Verifying the backward pass

Describe how you would verify loss_and_grads numerically: the finite-difference formula, the step size, and the relative error you would accept in float64.</pre>

## Worked solution

1. Write a two-hidden-layer MLP and derive backpropagation. Cache local intermediate values, then apply the chain rule in the reverse order of the forward computation.
2. Use Z1=XW1+b1, A1=ReLU(Z1), Z2=A1W2+b2, A2=ReLU(Z2), Yhat=A2W3+b3.
3. For mean squared error over all N*C outputs, dY=2*(Yhat-Y)/(N*C). Compute dW3=A2ᵀ*dY and db3=sum(dY), then propagate through W3 and the ReLU masks.
4. Repeat for the earlier layers. Keep parameter updates separate from gradient calculation and check a small network numerically.
5. Why does zero initialization fail in a hidden layer? Identical hidden units can receive identical gradients and remain redundant instead of learning different features.
6. Trace the forward activations of two units with equal incoming weights and biases.
7. Show that their backward gradients are equal under symmetric outgoing connections, so gradient descent preserves symmetry.
8. Use an initialization that breaks symmetry with a scale appropriate to activation and fan-in; zero biases can still be reasonable.

### Small example / sanity check

For a dense layer X:(4,3), W:(3,2), dY:(4,2), dW has shape (3,2) and dX has shape (4,3).

### Common trap

Dividing by batch size twice, or updating a weight before using its original value in an earlier gradient.
