## Question

This problem has five parts on a small neural network classifier built from first principles: its probability layer, its loss, its training procedure, and how to verify its gradients.

Task

Implement a two-layer neural network classifier from scratch in NumPy, with a numerically stable softmax, a cross-entropy loss, and a hand-derived backward pass. Use NumPy only: no PyTorch, no autograd. Work in float64.

Part 1 — Numerically stable softmax

Implement softmax(z, axis=-1), returning probabilities along axis that sum to 1. It must accept a 1-D array or an array of any shape, and must return finite values for every finite input — for example [1000, 1001, 1002] and [-1000, -1000].

Then answer:
1. Why does the direct formula softmax(z)ᵢ = exp(zᵢ) / Σⱼ exp(zⱼ) fail in floating point? Give the input range where np.exp overflows in float64 and in float32, and describe the failure for very negative inputs.
2. Prove that softmax(z − c) = softmax(z) for any constant c.
3. Explain why choosing c = max(z) removes overflow and division by zero, and which form of underflow it does not remove.
Part 2 — Log-softmax

Implement log_softmax(z, axis=-1), returning log-probabilities that stay finite even where a probability underflows to 0 — for example log_softmax([0, -1000]) must equal [0, -1000]. Explain why np.log(softmax(z)) is not an acceptable implementation, and state the log-sum-exp identity your implementation uses.

Part 3 — Cross-entropy loss

Implement cross_entropy(logits, y): the mean over the batch of −log p(yᵢ | logitsᵢ), for logits of shape (n, k) and integer labels y of shape (n,). Raise ValueError if logits is not 2-D, if y does not hold one label per row, if the batch is empty, or if a label lies outside [0, k). The loss must be finite for extreme logits, e.g. cross_entropy([[0, 1000]], [0]) == 1000.

Part 4 — Two-layer network

Implement TwoLayerNet(n_in, n_hidden, n_out, seed=0) computing Linear → ReLU → Linear, with parameters W1 (n_in, n_hidden), b1 (n_hidden,), W2 (n_hidden, n_out), b2 (n_out,) drawn from np.random.default_rng(seed). Provide:

forward(X) → (logits, cache).
loss_and_grads(X, y) → (loss, grads), where grads[name] has the shape of params[name]. Derive the backward pass by hand.
step(grads, lr) — one gradient-descent update, in place.
predict(X) — the class index per row.
fit(X, y, lr=0.5, epochs=500) — full-batch gradient descent, returning the loss per epoch.

Then answer:
1. Derive the gradient of the loss with respect to the logits for softmax followed by cross-entropy, and show it equals (softmax(logits) − onehot(y)) / n.
2. Write the gradients for W2, b2, W1 and b1, including how the ReLU enters.
3. Which initialisation do you use for W1, and why? What goes wrong if every weight starts at zero?
Part 5 — Verifying the backward pass

Describe how you would verify loss_and_grads numerically: the finite-difference formula, the step size, and the relative error you would accept in float64.

## Worked solution

### Stable probabilities and the floating-point boundary

Direct exponentiation overflows above roughly 709.78 in float64 or 88.72 in float32. Very negative inputs can all underflow, causing 0/0. Since $e^{z_i-c}/\sum_j e^{z_j-c}=e^{z_i}/\sum_j e^{z_j}$, subtract the maximum: all exponent arguments are nonpositive and at least one equals zero. The denominator is at least one. Tiny probabilities may still underflow individually; that is why log-softmax must use

$$\log p_i=(z_i-m)-\log\sum_j e^{z_j-m},\qquad m=\max_j z_j,$$

rather than `log(softmax(z))`. Thus `[0,-1000]` has finite log-probabilities `[0,-1000]` even though its second probability rounds to zero. Empty softmax reduction axes have no probability distribution and are outside the input contract. For finite values at opposite extremes of float64, a true log-probability can be less than the most negative representable number; no float64 implementation can promise finite *exact* log-probabilities in that case. The probability routine below still yields finite probabilities for finite nonempty inputs, including subtraction overflow to negative infinity.

### Derive the exact two-layer classifier

For $Z=XW_1+b_1$, $H=\max(Z,0)$ and logits $A=HW_2+b_2$, the per-example loss is $-A_{iy_i}+\log\sum_c e^{A_{ic}}$. Differentiating gives

$$G=\partial L/\partial A=(P-\operatorname{onehot}(y))/n.$$

Therefore $\nabla W_2=H^TG$, $\nabla b_2=\sum_iG_i$, $D=(GW_2^T)\odot1[Z>0]$, $\nabla W_1=X^TD$ and $\nabla b_1=\sum_iD_i$. For $X:(n,d)$ and $h$ hidden units, these have shapes $(h,k),(k,),(d,h),(h,)$. ReLU's derivative at zero is chosen to be zero. Gradients use original weights and all are computed before any update.

He initialization gives $\operatorname{Var}(W_1)=2/d$, approximately compensating for ReLU zeroing half a symmetric activation distribution. Biases are zero. Every hidden weight starting at zero fails to break symmetry; with all weights zero and this ReLU convention the hidden gradients vanish.

```python
import numpy as np


def softmax(z, axis=-1):
    z = np.asarray(z, dtype=np.float64)
    with np.errstate(over="ignore", under="ignore"):
        shifted = z - np.max(z, axis=axis, keepdims=True)
        e = np.exp(shifted)
    return e / e.sum(axis=axis, keepdims=True)


def log_softmax(z, axis=-1):
    z = np.asarray(z, dtype=np.float64)
    with np.errstate(over="ignore", under="ignore"):
        shifted = z - np.max(z, axis=axis, keepdims=True)
        return shifted - np.log(np.exp(shifted).sum(axis=axis, keepdims=True))


def validate(logits, y):
    logits = np.asarray(logits, dtype=np.float64)
    y = np.asarray(y)
    if logits.ndim != 2 or logits.shape[0] == 0 or logits.shape[1] == 0:
        raise ValueError("nonempty 2-D logits required")
    if y.shape != (len(logits),) or not np.issubdtype(y.dtype, np.integer):
        raise ValueError("one integer label per row required")
    if np.any(y < 0) or np.any(y >= logits.shape[1]):
        raise ValueError("label outside class range")
    return logits, y


def cross_entropy(logits, y):
    logits, y = validate(logits, y)
    return float(-log_softmax(logits)[np.arange(len(y)), y].mean())


class TwoLayerNet:
    def __init__(self, n_in, n_hidden, n_out, seed=0):
        rng = np.random.default_rng(seed)
        self.params = {
            "W1": rng.normal(size=(n_in, n_hidden)) * np.sqrt(2/n_in),
            "b1": np.zeros(n_hidden, dtype=np.float64),
            "W2": rng.normal(size=(n_hidden, n_out)) / np.sqrt(n_hidden),
            "b2": np.zeros(n_out, dtype=np.float64),
        }

    def forward(self, X):
        X = np.asarray(X, dtype=np.float64)
        p = self.params
        z1 = X @ p["W1"] + p["b1"]
        h = np.maximum(z1, 0)
        return h @ p["W2"] + p["b2"], (X, z1, h)

    def loss_and_grads(self, X, y):
        logits, (X, z1, h) = self.forward(X)
        loss = cross_entropy(logits, y)
        y = np.asarray(y)
        g = softmax(logits)
        g[np.arange(len(y)), y] -= 1
        g /= len(y)
        hidden_grad = (g @ self.params["W2"].T) * (z1 > 0)
        grads = {"W2": h.T @ g, "b2": g.sum(axis=0),
                 "W1": X.T @ hidden_grad, "b1": hidden_grad.sum(axis=0)}
        return loss, grads

    def step(self, grads, lr):
        for name, value in self.params.items():
            value -= lr * grads[name]

    def predict(self, X):
        return self.forward(X)[0].argmax(axis=1)

    def fit(self, X, y, lr=0.5, epochs=500):
        losses = []
        for _ in range(epochs):
            loss, grads = self.loss_and_grads(X, y)
            losses.append(loss)
            self.step(grads, lr)
        return losses


def check():
    assert np.allclose(softmax([1000,1001,1002]), [.09003057,.24472847,.66524096])
    assert np.allclose(softmax([-1000,-1000]), [.5,.5])
    assert np.allclose(log_softmax([0,-1000]), [0,-1000])
    assert cross_entropy([[0,1000]], [0]) == 1000
    assert np.allclose(softmax(np.ones((2,3,4)),axis=1).sum(axis=1), 1)
    for a,b in [([],[]), ([[1,2]],[-1]), ([[1,2]],[2]), ([[1,2]],[.5]), ([[1,2]],[]), ([1,2],[0])]:
        try: cross_entropy(a,b)
        except ValueError: pass
        else: raise AssertionError("invalid input accepted")
    rng = np.random.default_rng(42)
    X, y = rng.normal(size=(4,3)), np.array([0,1,0,1])
    net = TwoLayerNet(3,4,2,seed=9)
    _, grads = net.loss_and_grads(X,y)
    eps, worst = 1e-6, 0.
    for name,p in net.params.items():
        numeric = np.empty_like(p)
        for index in np.ndindex(p.shape):
            old = p[index]
            p[index] = old + eps; plus = cross_entropy(net.forward(X)[0],y)
            p[index] = old - eps; minus = cross_entropy(net.forward(X)[0],y)
            p[index] = old
            numeric[index] = (plus-minus)/(2*eps)
        error = np.linalg.norm(numeric-grads[name]) / max(1e-12, np.linalg.norm(numeric)+np.linalg.norm(grads[name]))
        worst = max(worst,error)
        assert error < 1e-6, (name,error)
    X = np.array([[-1.,-1.],[-1.,1.],[1.,-1.],[1.,1.]])
    y = np.array([0,1,1,0])
    net = TwoLayerNet(2,16,2,seed=0)
    losses = net.fit(X,y)
    assert losses[-1] < .03 and np.array_equal(net.predict(X),y)
    print(f"W112: gradient relative error {worst:.2g}; XOR loss {losses[-1]:.4f}; predictions {net.predict(X)}")

if __name__ == "__main__":
    check()
```

### Verify behavior rather than only shapes

The runnable checks cover arbitrary-axis normalization, extreme logits, all requested cross-entropy errors, a central-difference comparison of every parameter, and learning XOR to the exact labels `[0,1,1,0]`. With $\epsilon=10^{-6}$, compute $(L(	heta+\epsilon e_j)-L(	heta-\epsilon e_j))/(2\epsilon)$ and require tensor relative error $\|g-g_{num}\|/(\|g\|+\|g_{num}\|)<10^{-6}$ in float64. Avoid ReLU boundaries, try several step sizes if disagreement appears, and use an absolute tolerance for near-zero gradients. A gradient test alone does not prove learning, hence the separate XOR check. Run `python3 ../review_w112_implementation.py`.
