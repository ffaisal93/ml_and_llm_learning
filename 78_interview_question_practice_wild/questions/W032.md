## Worked solution

### Tie the fundamentals to a measured workload

Amdahl's law is $S=1/[(1-p)+p/s]$ when fraction p is accelerated by s. If p=.9 and s=10, total speedup=5.26, capped at10 even with infinitely fast accelerated work. Include communication/launch/new overhead instead of counting only the fast kernel.

Registers are smallest, per-thread low-latency state; shared memory is programmer-managed per-block SRAM; caches are hardware-managed; global device memory is usually backed by HBM, which is large/high-bandwidth but much slower than on-chip reuse. HBM and “global” are physical-memory and address-space terms, not two guaranteed separate capacities. Too many registers/shared bytes can reduce active blocks; occupancy is active warps relative to hardware capacity, helping hide latency but not proving maximum throughput. Threads/block, blocks/SM, register limits and warp sizes are architecture-specific; query target-device properties rather than inventing one universal maximum.

### Matmul, tensor shapes and execution

A:(M,K) times B:(K,N) gives C:(M,N), roughly2MKN FLOPs. Tile A/B through shared memory/registers so loaded values contribute to many multiply-adds; contiguous/coalesced layouts, aligned matrix-unit tiles and reduced global intermediates raise arithmetic intensity. CPU BLAS uses cache blocking/vector cores and avoids GPU launch/transfer overhead, often useful for small/irregular work; GPUs exploit many tiles/lanes and matrix units for large batches. Include host/device copies and synchronize when timing.

For an MLP X:(B,T,D), nn.Linear(D,F) stores W:(F,D) and bias(F,), producing X@W.T+b:(B,T,F). A nonlinear activation then a map F→D restores width. Bias broadcasts over B/T; a mistaken transpose may only fail when D≠F. Q/K/V attention exchanges token information through softmax(QKᵀ/sqrt(d))V, whereas RNN state depends recursively on the preceding step. Multi-head splitting needs a token/head transpose before concatenation.

### Distributed execution and software compilation

Tensor parallelism shards operators and needs frequent intra-layer collectives, favoring fast links. Pipeline parallelism shards layers and streams microbatches with boundary transfers/bubbles. Their communication is not interchangeable. Data-parallel replicas raise aggregate throughput when independent requests/batches exist; they do not reduce one replica's model size.

In C++, a virtual member dispatches through the runtime object's dynamic type, enabling overrides through base pointers/references; use a virtual destructor when deleting derived objects through a base. `inline` permits repeated identical definitions across translation units and is not a promise that a compiler substitutes code at each call. Inheritance expresses an is-a interface relation; composition can keep model/backend dependencies simpler. Devirtualization/inlining are compiler decisions and excessive abstraction can complicate hot-path optimization.

JAX emphasizes functional array programs, explicit PRNG keys and transformations such as jit/grad/vmap with compiled execution. PyTorch supports eager autograd and compiled graph paths; both can generate optimized kernels, and dynamic shapes/control flow/unsupported operations affect capture and recompilation. A frontend model may export an ONNX/computation graph for runtime optimization, shape/type inference, fusion, kernel selection, layout/precision transforms and target code generation; export is not always necessary, and custom operators require runtime support. Validate exported/compiled numerical parity and target tasks.

### Benchmark what the user experiences

State model/version, hardware, precision, batch/concurrency, prompt/output lengths, warmup, cache state, software and load pattern. Measure completed requests/s and output tokens/s alongside TTFT, inter-token latency, end-to-end p50/p95/p99, failures and memory. CUDA work is asynchronous, so use synchronized events/appropriate barriers and separate compilation/warmup from steady state. A large batch can improve throughput while worsening queue delay; compare quality and tail latency at matched workloads instead of quoting one isolated tokens/s number.
