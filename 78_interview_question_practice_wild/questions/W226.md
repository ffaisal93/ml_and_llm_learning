## Question

Problem: Implement a Multi-Armed Bandit Policy

You have K arms; choosing an arm yields a stochastic reward. Implement a bandit policy to maximize cumulative reward over T interactions.

### Input

Line 1: three integers K T seed

K : number of arms (2 ≤ K ≤ 50)
T : number of rounds (1 ≤ T ≤ 200000)
seed : RNG seed used to generate rewards

Line 2: K floats p[0..K-1] (0 ≤ p[i] ≤ 1), Bernoulli success probabilities (reward is 0/1).

Environment

Initialize RNG with seed.

At round t (1-indexed), if you pick arm a, you get reward 1 with probability p[a], else 0.

Task

Implement UCB1:

Pull each arm at least once.
For t thereafter, pick arm a maximizing:
$$\text{score}(a) = \hat{\mu}_a + \sqrt{\frac{2\ln t}{n_a}}$$

where $\hat{\mu}_a$ is the empirical mean reward and $n_a$ is the number of pulls for arm $a$.

### Output

Print one integer: the total reward over T rounds.

### Constraints

Must run efficiently up to T=200000.
Standard library only.
Sample Tests

See the 5 sample cases in the Chinese version.

Example

### Input

```text
3 10 42
0.1 0.5 0.9
```

## Worked solution

### UCB1 with reproducible environment randomness

Maintain each arm's pull count and reward sum. Pull arms 0, 1,... until either all are tried or T is exhausted. At round t thereafter, choose the largest empirical mean plus the specified exploration bonus; ties use the smallest arm index because Python's max keeps the first encountered maximum. Use one local seeded RNG for rewards only. The input probabilities simulate the environment; the policy never reads them when selecting an arm.

```python
import sys
import math
import random


def ucb1(K, T, seed, probabilities):
    if len(probabilities) != K or K < 1 or T < 0:
        raise ValueError("invalid dimensions")
    rng = random.Random(seed)
    counts, sums = [0] * K, [0] * K
    total = 0
    for t in range(1, T + 1):
        if t <= K:
            arm = t - 1
        else:
            log_term = 2.0 * math.log(t)
            arm = max(
                range(K),
                key=lambda a: sums[a] / counts[a] + math.sqrt(log_term / counts[a]),
            )
        reward = int(rng.random() < probabilities[arm])
        counts[arm] += 1
        sums[arm] += reward
        total += reward
    return total


def bandit_main():
    K, T, seed = map(int, sys.stdin.readline().split())
    print(ucb1(K, T, seed, list(map(float, sys.stdin.readline().split()))))
```

Call `bandit_main()` for the stdin/stdout contract. Time is $O(TK)$ (at most ten million score evaluations), space $O(K)$. The logarithm is computed once per round. For T<K only T arms can be tried, which is the only feasible interpretation of “pull each arm at least once.” Tests include all-zero/all-one rewards, T<K, deterministic seed replay and a reference action trace. The Chinese sample outputs are absent, and RNG algorithms differ across languages, so no unknown sample output is asserted. With this explicitly chosen Python `random.Random` contract, the example is reproducible by running the code; UCB1 maximizes long-run reward through exploration and need not pull the best arm on every short run.
