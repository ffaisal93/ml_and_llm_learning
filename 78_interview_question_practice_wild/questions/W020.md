## Worked solution

1. Explain LoRA and calculate its trainable parameter count. LoRA represents a weight update as the product of two thin matrices while leaving the original weight frozen.
2. For W shaped (d_out,d_in), use delta_W=(alpha/r)*B@A with A:(r,d_in) and B:(d_out,r).
3. Train A and B, usually initializing one factor to zero so the initial update is zero without making both gradients permanently zero.
4. The trainable count is r*(d_in+d_out), versus d_in*d_out for the full matrix. Include all targeted matrices when estimating the whole model.

### Small example / sanity check

A 4096-by-4096 matrix with r=8 has 65536 adapter parameters instead of 16777216 full parameters, excluding biases.

### Common trap

Saying the rank r alone is the parameter count, or that frozen base weights remove forward activation-memory costs.
