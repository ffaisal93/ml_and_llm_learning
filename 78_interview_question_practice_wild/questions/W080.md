## Question

Task: Debug an NLP Classifier Training Pipeline (BERT + Linear)

You are given a training codebase skeleton for text classification (you may choose a PyTorch or TensorFlow implementation). The high-level components include:

Dataset
DataLoader
Customized Model   (Transformer/BERT + a few Linear layers)
Trainer            (similar to HuggingFace Transformers)
Evaluation
AUC metric

The code contains multiple bugs that prevent training/evaluation from running correctly or produce incorrect metrics. Your task is to debug and fix the pipeline within a limited time.

Issues you are expected to identify and fix (cover at least these areas)

1. Dataset / label parsing

The dataset parses label as a string.
Training expects labels in a numeric form usable by the loss function (e.g., int / tensor).

2. One-hot encoding bug

A one-hot encoding snippet is provided and can replace the current label logic.
However, the provided one-hot implementation has a dimension/shape mismatch that must be fixed.

3. Incorrect use of model output (last_hidden_state)

The model uses a BERT/Transformer output for classification.
The current usage of last_hidden_state is incorrect, leading to wrong shapes or an invalid classifier head input. Fix it (e.g., choose an appropriate pooling strategy or token representation).

4. Loss bug: applying Softmax before CrossEntropy

The implementation applies softmax before cross entropy loss.
Fix it to follow the correct usage for the chosen framework.

5. AUC metric input/parameter bug

The AUC computation has incorrect inputs and/or key parameters, causing errors or wrong results.
Fix the AUC call so it matches the binary or multiclass setting.

6. Training detail checks

Verify dropout behavior (train vs eval mode).
Verify no incorrect requires_grad settings that freeze parameters unintentionally.
Deliverables
1. A corrected pipeline that trains without crashing and reports a valid AUC.
2. For each bug: the symptom, the root cause, and the fix.
3. A sanity check showing the fixed pipeline learns (for example, overfitting one small batch).

## Worked solution

### Diagnose shapes before changing the optimizer

The original buggy codebase is absent, so the implementation below is a reference pipeline with an injected BERT-compatible encoder, not a claim to patch unseen lines. It uses integer class targets, masked mean pooling and raw-logit cross-entropy. The offline toy encoder checks the plumbing; replace it with a pretrained BERT encoder for the actual task.

| Symptom | Cause | Fix |
|---|---|---|
| Loss rejects string labels | Dataset returns text labels | Parse a validated class ID and return `torch.long` |
| One-hot has wrong shape | Scatter/index axis does not match classes | If needed use `F.one_hot(labels, num_classes=C)` → `(B,C)`; ordinary class-index CE needs no one-hot |
| Head output is `(B,L,C)` | Linear head applied to every token | Pool hidden states `(B,L,H)` to `(B,H)` with a padding mask |
| Loss behaves oddly | Softmax applied before CE | Pass raw `(B,C)` logits to CE with `(B,)` targets |
| AUC is wrong/errors | Hard labels or wrong probability column | Binary: score for class one; multiclass: all class probabilities with explicit strategy |
| Eval changes randomly | Dropout still training | Use `model.eval()` and `no_grad()` |
| Encoder never learns | Unintended freezing/omitted optimizer parameters | Inspect `requires_grad`, optimizer groups and nonzero gradients |

### Corrected pipeline

[Download the runnable pipeline and tiny-batch check](../classifier_080.py).

```python
"""W080: runnable classifier pipeline, with an injected BERT-compatible encoder."""
from types import SimpleNamespace
import torch
from torch import nn
from torch.utils.data import Dataset,DataLoader

class TextDataset(Dataset):
    def __init__(self,rows,tokenizer,max_length=32):
        self.rows=rows; self.tokenizer=tokenizer; self.max_length=max_length
    def __len__(self): return len(self.rows)
    def __getitem__(self,index):
        text,label=self.rows[index]
        encoded=self.tokenizer(text,padding='max_length',truncation=True,
                               max_length=self.max_length,return_tensors='pt')
        item={key:value.squeeze(0) for key,value in encoded.items()}
        item['labels']=torch.tensor(int(label),dtype=torch.long)
        return item

class Classifier(nn.Module):
    def __init__(self,encoder,hidden_size,classes=2):
        super().__init__()
        self.encoder=encoder; self.dropout=nn.Dropout(.1)
        self.head=nn.Linear(hidden_size,classes)
    def forward(self,input_ids,attention_mask,**kwargs):
        hidden=self.encoder(input_ids=input_ids,attention_mask=attention_mask,**kwargs).last_hidden_state
        mask=attention_mask.unsqueeze(-1).to(hidden.dtype)
        pooled=(hidden*mask).sum(1)/mask.sum(1).clamp_min(1)
        return self.head(self.dropout(pooled))

def train_epoch(model,loader,optimizer):
    model.train(); total=0.; count=0
    device=next(model.parameters()).device
    for batch in loader:
        batch={k:v.to(device) for k,v in batch.items()}
        labels=batch.pop('labels')
        optimizer.zero_grad(set_to_none=True)
        logits=model(**batch)
        loss=nn.functional.cross_entropy(logits,labels)  # raw B,C logits, B long labels
        loss.backward(); optimizer.step()
        total+=loss.item()*len(labels); count+=len(labels)
    return total/count

@torch.no_grad()
def evaluate(model,loader):
    from sklearn.metrics import roc_auc_score
    model.eval(); labels=[]; probabilities=[]
    device=next(model.parameters()).device
    for batch in loader:
        batch={k:v.to(device) for k,v in batch.items()}
        y=batch.pop('labels')
        probabilities.append(model(**batch).softmax(-1).cpu())
        labels.append(y.cpu())
    y=torch.cat(labels).numpy(); p=torch.cat(probabilities).numpy()
    if len(set(y.tolist()))!=p.shape[1]:
        raise ValueError('AUC requires both classes, or all classes for this multiclass evaluation')
    auc=roc_auc_score(y,p[:,1]) if p.shape[1]==2 else roc_auc_score(
        y,p,multi_class='ovr',average='macro',labels=list(range(p.shape[1])))
    return float(auc)

class ToyTokenizer:
    def __call__(self,text,**kwargs):
        ids=torch.zeros(1,kwargs['max_length'],dtype=torch.long)
        ids[0,0]=1 if text=='positive' else 2
        mask=torch.zeros_like(ids); mask[0,0]=1
        return dict(input_ids=ids,attention_mask=mask)

class ToyEncoder(nn.Module):
    def __init__(self):
        super().__init__(); self.embeddings=nn.Embedding(3,8)
    def forward(self,input_ids,attention_mask):
        return SimpleNamespace(last_hidden_state=self.embeddings(input_ids))

if __name__=='__main__':
    torch.manual_seed(3); torch.set_num_threads(1)
    rows=[('positive','1'),('negative','0')]*8
    loader=DataLoader(TextDataset(rows,ToyTokenizer()),batch_size=16)
    model=Classifier(ToyEncoder(),8)
    assert all(p.requires_grad for p in model.parameters())
    optimizer=torch.optim.Adam(model.parameters(),lr=.03)
    before=train_epoch(model,loader,optimizer)
    for _ in range(79): after=train_epoch(model,loader,optimizer)
    auc=evaluate(model,loader)
    assert after<.01 and auc==1.
    print('Toy-batch loss',before,'->',after,'AUC',auc)

```

### Validate learning and metrics

First inspect one batch: IDs and masks are `(B,L)` integer tensors, labels are `(B,)` long tensors, and logits are `(B,C)` floating-point tensors. A padding token must not affect the pooled representation because its mask is zero. Compare one-hot output shape only if another task explicitly needs it.

Overfit one fixed, balanced tiny batch. The executable demonstration uses a toy embedding encoder and checks loss below 0.01 and AUC one; it does not establish BERT generalization. In the real skeleton, repeat the test with the actual tokenizer/encoder and inspect gradients in both encoder and head. If loss cannot fall, check target mapping, shuffled labels, truncation, optimizer updates and train/eval mode before hyperparameter tuning.

For binary AUC, collect continuous class-one probabilities across the entire evaluation set. For multiclass AUC, supply all class probabilities, an explicit one-vs-rest macro strategy and the matching label order. Do not average per-batch AUCs: a batch may contain one class and AUC is then undefined. A full evaluation set lacking required classes should report that limitation, not replace AUC with zero. Restore training mode by calling the next training epoch's `model.train()`.
