## Question

You are given a tabular dataset for predicting heart disease. Features include age, weight, height, and other numeric/categorical columns; the label target is a 0/1 disease indicator. You may use Python with pandas for data manipulation and seaborn/matplotlib for visualization.

Tasks
Data cleaning: check missing values, outliers, duplicates; implement a reasonable missing-value strategy.

```text
EDA: label distribution (ratio of target = 0/1); distributions of key features (e.g. age/weight/height) across labels; feature correlations (e.g. a correlation heatmap) highlighting features strongly associated with the target.
```

Feature engineering (bonus): derive features such as BMI = weight / height^2; encode categoricals (e.g. one-hot).
Modeling and evaluation: train/test split; a baseline model (logistic regression / random forest / gradient boosting); evaluate with appropriate metrics (accuracy, precision/recall, ROC-AUC) and justify the choice.
Interpretation: identify 2-3 most important features and support with plots or statistics.

### Constraints

Rows ~1e4 (fits in memory); 10-50 features. Produce a runnable script/notebook within ~1 hour.

## Worked solution

### State the missing data contract first

No patient dataset is attached, so actual disease prevalence, most important features and clinical performance cannot be reported. The following complete script accepts a CSV with `target`, `age`, `weight` in kg, `height` in an explicitly chosen unit, and additional numeric or categorical predictors. Its default fixture is synthetic and deliberately contains missing weights and three duplicate rows. It is a demonstration of the workflow, not a clinical result. Map real column names/units, exclude post-outcome information, and choose patient/time splits before applying it to real data.

```python
"""Usage: python3 w102.py data.csv --height-unit cm --out results
No input file: runs a clearly synthetic demonstration, not clinical evidence.
Requires numpy pandas scikit-learn matplotlib seaborn.
"""

import argparse
from pathlib import Path
import numpy as np
import pandas as pd
import matplotlib

matplotlib.use("Agg")
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.dummy import DummyClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import (
    accuracy_score,
    precision_score,
    recall_score,
    roc_auc_score,
    average_precision_score,
    confusion_matrix,
)
from sklearn.inspection import permutation_importance


def fixture(n=600, seed=42):
    rng = np.random.default_rng(seed)
    df = pd.DataFrame(
        {
            "age": rng.uniform(25, 85, n),
            "weight": rng.normal(80, 14, n),
            "height": rng.normal(170, 10, n),
            "smoker": rng.choice(["yes", "no"], n),
        }
    )
    z = (df.age - 55) / 14 + (df.weight - 80) / 30 + (df.smoker == "yes") * 0.6
    df["target"] = rng.binomial(1, 1 / (1 + np.exp(-z)))
    df.loc[::17, "weight"] = np.nan
    return pd.concat([df, df.iloc[:3]], ignore_index=True)


def run(df, height_unit, out):
    out = Path(out)
    out.mkdir(parents=True, exist_ok=True)
    if "target" not in df or df.target.isna().any() or not df.target.isin([0, 1]).all():
        raise ValueError("target must contain only nonmissing 0/1 labels")
    if not {"age", "weight", "height"} <= set(df.columns):
        raise ValueError("age, weight (kg), height are required; map names first")
    print("missing counts before cleaning:\n", df.isna().sum().to_string())
    print("exact duplicate rows:", df.duplicated().sum())
    # Actual patient IDs, timestamps and post-outcome columns must be removed or used
    # to define an appropriate grouped/temporal split BEFORE calling this function.
    df = df.drop_duplicates().copy()
    for col in ["age", "weight", "height"]:
        df[col] = pd.to_numeric(df[col], errors="coerce")
    hm = df.height / (100 if height_unit == "cm" else 1)
    # These are declared broad plausibility rules, not automatic statistical clipping.
    bad = ~df.age.between(0, 120) | ~df.weight.between(2, 500) | ~hm.between(0.4, 2.6)
    print("rows flagged by broad plausibility checks:", int(bad.sum()))
    df.loc[~df.age.between(0, 120), "age"] = np.nan
    df.loc[~df.weight.between(2, 500), "weight"] = np.nan
    hm = hm.where(hm.between(0.4, 2.6))
    df["height"] = hm  # Explicit meters from this point onward.
    df["BMI"] = df.weight / hm**2
    y = df.pop("target").astype(int)
    Xtr, Xte, ytr, yte = train_test_split(
        df, y, test_size=0.25, random_state=42, stratify=y
    )
    print(
        "training label ratios:\n",
        ytr.value_counts(normalize=True).sort_index().to_string(),
    )
    eda = Xtr.assign(target=ytr)
    sns.countplot(data=eda, x="target")
    plt.savefig(out / "labels.png")
    plt.close()
    for col in ["age", "weight", "height", "BMI"]:
        sns.histplot(
            data=eda,
            x=col,
            hue="target",
            stat="density",
            common_norm=False,
            element="step",
        )
        plt.savefig(out / f"{col}.png")
        plt.close()
    corr = eda.select_dtypes(include="number").corr()
    sns.heatmap(corr, cmap="coolwarm", center=0)
    plt.tight_layout()
    plt.savefig(out / "correlations.png")
    plt.close()
    print(
        "training target correlations (association, not causality):\n",
        corr.target.drop("target").sort_values(key=abs, ascending=False).to_string(),
    )
    num = Xtr.select_dtypes(include="number").columns.tolist()
    cat = [c for c in Xtr if c not in num]
    prep = ColumnTransformer(
        [
            (
                "num",
                Pipeline(
                    [
                        (
                            "impute",
                            SimpleImputer(strategy="median", add_indicator=True),
                        ),
                        ("scale", StandardScaler()),
                    ]
                ),
                num,
            ),
            (
                "cat",
                Pipeline(
                    [
                        ("impute", SimpleImputer(strategy="most_frequent")),
                        ("encode", OneHotEncoder(handle_unknown="ignore")),
                    ]
                ),
                cat,
            ),
        ]
    )
    model = Pipeline([("prep", prep), ("model", LogisticRegression(max_iter=2000))])
    model.fit(Xtr, ytr)
    dummy = DummyClassifier(strategy="prior").fit(Xtr, ytr)
    for name, m in [("prior baseline", dummy), ("logistic", model)]:
        prob = m.predict_proba(Xte)[:, 1]
        pred = prob >= 0.5
        print(
            name,
            dict(
                accuracy=accuracy_score(yte, pred),
                precision=precision_score(yte, pred, zero_division=0),
                recall=recall_score(yte, pred, zero_division=0),
                roc_auc=roc_auc_score(yte, prob),
                pr_auc=average_precision_score(yte, prob),
            ),
        )
        print(
            "confusion matrix [true rows, predicted columns]:\n",
            confusion_matrix(yte, pred),
        )
    imp = permutation_importance(
        model, Xte, yte, scoring="roc_auc", n_repeats=10, random_state=42
    )
    importance = pd.DataFrame(
        {
            "feature": Xte.columns,
            "auc_drop": imp.importances_mean,
            "std": imp.importances_std,
        }
    ).sort_values("auc_drop", ascending=False)
    print(
        "top 3 features by held-out permutation:\n",
        importance.head(3).to_string(index=False),
    )
    importance.head(10).set_index("feature").auc_drop.sort_values().plot.barh(
        xerr=importance.head(10).sort_values("auc_drop")["std"]
    )
    plt.xlabel("ROC-AUC decrease after permutation")
    plt.tight_layout()
    plt.savefig(out / "importance.png")
    plt.close()
    assert np.isfinite(model.predict_proba(Xte)).all()
    assert len(Xtr) + len(Xte) == len(df)
    return model, importance


if __name__ == "__main__":
    p = argparse.ArgumentParser()
    p.add_argument("csv", nargs="?")
    p.add_argument("--height-unit", choices=["cm", "m"], required=True)
    p.add_argument("--out", default="w102_results")
    a = p.parse_args()
    print(
        "ACTUAL CSV"
        if a.csv
        else "SYNTHETIC DEMONSTRATION: no patient dataset supplied"
    )
    run(pd.read_csv(a.csv) if a.csv else fixture(), a.height_unit, a.out)
```

### Read the outputs and make the decision

Run `python3 ../review_w102_implementation.py --height-unit cm --out /tmp/w102-demo`, or supply the real CSV as the first argument. The demonstration removes exactly three repeated rows, reports missingness, produces label, age, weight, height, BMI, correlation and permutation-importance plots, and prints baseline/model metrics and the top three feature names with variation across permutations. A 200 cm person weighing 80 kg has BMI 20; treating 200 as meters would be a serious unit error. Missing BMI remains missing until training-only imputation.

Plausibility rules only flag broad invalid values. Inspect statistical outliers using training quantiles/boxplots and source records; a rare but real disease case should not be discarded merely for being extreme. Exact duplicate removal is appropriate only if duplicates represent repeated ingestion; repeated legitimate visits require a patient key and grouped splitting. Numeric medians, categorical modes, scaling and one-hot vocabularies are fitted inside the training pipeline; unseen categories are supported. Entirely missing columns should be investigated and explicitly removed or configured with a supported keep-empty imputer before real training.

Report precision and recall at the stated .5 demonstration threshold, ROC-AUC for ranking and PR-AUC against prevalence under imbalance; accuracy alone can reward always predicting the majority class. Select a clinical operating threshold and any hyperparameters on training/validation data using the intended false-negative/false-positive costs; keep final test results for one final evaluation. Confidence intervals and patient-level resampling belong in a deployment assessment.

The top-three conclusion must come from the printed actual-data table and plots. Permutation importance estimates a held-out predictive association, with correlated features able to share or mask importance; correlations are univariate and neither proves causation. Do not claim that the demonstration's generated risk factors are discovered medical evidence. Any choices prompted by examining the test importance need a new untouched validation/test boundary.
