## Question

Interview Question: Classify a Float Into One of Two Arrays

You are given two arrays of floating-point numbers, A and B, and a single float value x.

Your task is to determine which array x most likely belongs to, assuming A and B come from different (unknown) distributions.

### Requirements

1. Explain how you would determine whether x belongs to A or B.
2. You may use statistical methods, distance-based methods, or supervised learning.
3. Clearly describe:
What features or information you use
Which algorithm you choose
How you would train it
How to evaluate correctness
Example

```python
A = [1.1, 1.2, 0.9, 1.3]
```

```python
B = [4.5, 4.8, 5.0, 4.6]
```

```text
x = 1.05 → should belong to A
```

Follow-up Questions
1. How does your approach change if the two arrays overlap heavily?
2. How would you handle noisy or high-variance data?
3. If you cannot retrain a model, what fixed rule would you design?

## Worked solution

### Treat membership as probabilistic classification

The sole feature is the scalar value x; A and B supply labels. Their distributions and deployment class priors are unknown, so the generating array cannot be identified with certainty for every future value. A transparent initial assumption is a Gaussian density per class with equal priors. Estimate $\mu_A,\sigma_A^2,\mu_B,\sigma_B^2$ from training values, floor tiny variances, and compare

$$s_c(x)=\log\pi_c-\tfrac12\log\sigma_c^2-\frac{(x-\mu_c)^2}{2\sigma_c^2}.$$

Normalize scores with log-sum-exp to get an assumption-dependent posterior. With enough samples, inspect histograms and compare 1-D k-NN/KDE to handle multimodal or skewed distributions; choose k/bandwidth using validation, not the query x. Array size reflects the sampling procedure and is not automatically the deployment prior.

For the supplied arrays, means are 1.125 and 4.725; population variances used as Gaussian maximum-likelihood estimates are .021875 and .036875. At x=1.05 the two scores excluding the shared constant are approximately 1.783 and -181.48 under equal priors, decisively selecting A under this model. A nearest-mean fixed rule also selects A, with boundary $(1.125+4.725)/2=2.925$ and lower-index tie policy. This fixed rule assumes comparable spreads/equal costs/priors; it is not universal distribution inference.

### Train, evaluate and handle ambiguity

For larger samples, stratify held-out values (group/time split if correlated), fit on training only and compare class-wise precision/recall, balanced accuracy, log loss and calibration to a prior baseline. With four observations/class, leave-one-out gives only a noisy diagnostic, not proof of correctness; collect more independent data. Bootstrap at independent-source units to assess stability.

Heavy overlap creates irreducible classification error using x alone. Return posterior/score and optionally abstain when both classes are plausible; collect another feature if a decision matters. High variance need not mean contamination: fit the spread rather than merely picking the closest raw point. For genuine outliers consider robust median/MAD scores, a heavy-tailed density or larger validated k, while preserving meaningful tails. If retraining is impossible, freeze a documented midpoint/nearest-median rule, tie/abstention policy and monitoring boundary; a static rule cannot adapt to changing distributions. Cost-sensitive decisions compare expected errors rather than always thresholding at .5.
