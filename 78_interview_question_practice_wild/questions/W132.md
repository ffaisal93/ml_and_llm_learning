## Question

Problem: Implement K-Means Clustering With a Convergence Check

Given a dataset X as a 2D array (with n samples and d features) and an integer k, implement K-Means from scratch and return the final centroids and the cluster assignment for each point. Your implementation must include a convergence criterion.

### Requirements

Initialization: use the provided init_centroids if given; otherwise randomly pick k samples as initial centroids.
Repeat until convergence or max_iters:
Assignment step: assign each sample to the nearest centroid (Euclidean distance).
Update step: recompute each centroid as the mean of samples assigned to it.

```text
Convergence: stop when the maximum centroid movement is <= tol.
```

Edge case: if a cluster receives no points in an iteration, keep its centroid unchanged.
After the loop, return the labels of the final assignment against the final centroids.
Input
X: float array of shape n x d

```text
k: integer, 1 <= k <= n
```

max_iters: maximum iterations (default 100)
tol: tolerance (default 1e-4)
init_centroids (optional): float array of shape k x d
Output

Return a tuple:

centroids: float array k x d
labels: int array of length n, values in 0..k-1

### Constraints

1 &lt;= n &lt;= 1e4
1 &lt;= d &lt;= 100
1 &lt;= k &lt;= 100
max_iters &lt;= 300
Example

### Input

```python
X = [[0,0],[0,1],[1,0],[10,10],[10,11],[11,10]]
k = 2
init_centroids = [[0,0],[10,10]]
max_iters = 100
tol = 1e-6
```

### Output

```python
centroids = [[1/3, 1/3], [31/3, 31/3]]   (about [[0.3333, 0.3333], [10.3333, 10.3333]])
labels    = [0, 0, 0, 1, 1, 1]
```

The first three points form one cluster and the last three the other; with these initial centroids the labels are exactly as shown.

## Worked solution

### Stop on maximum per-center movement

Convert to float64, copy supplied centers or sample k distinct rows using a reproducible generator. Assign by squared distance, accumulate sums/counts, and preserve empty centers. The convergence statistic is $\max_j\|c_j^{new}-c_j^{old}\|_2$, rather than a global Frobenius norm. After the loop, perform the required final assignment against the returned centers.

```python
import numpy as np


def kmeans(X, k, max_iters=100, tol=1e-4, init_centroids=None, seed=0):
    X = np.asarray(X, dtype=np.float64)
    if (
        X.ndim != 2
        or not 1 <= k <= len(X)
        or max_iters < 1
        or tol < 0
        or not np.isfinite(X).all()
    ):
        raise ValueError("invalid data/configuration")
    if init_centroids is None:
        centers = X[np.random.default_rng(seed).choice(len(X), k, replace=False)].copy()
    else:
        centers = np.asarray(init_centroids, dtype=np.float64).copy()
    if centers.shape != (k, X.shape[1]) or not np.isfinite(centers).all():
        raise ValueError("invalid initial centers")

    def assign():
        # O(n*k) storage, avoiding an n*k*d temporary.
        distances = (
            (X * X).sum(1)[:, None]
            + (centers * centers).sum(1)[None, :]
            - 2 * X @ centers.T
        )
        return distances.argmin(1)

    for _ in range(max_iters):
        labels = assign()
        sums = np.zeros_like(centers)
        np.add.at(sums, labels, X)
        counts = np.bincount(labels, minlength=k)
        updated = centers.copy()
        active = counts > 0
        updated[active] = sums[active] / counts[active, None]
        movement = np.linalg.norm(updated - centers, axis=1).max()
        centers = updated
        if movement <= tol:
            break
    return centers, assign()


c, l = kmeans(
    [[0, 0], [0, 1], [1, 0], [10, 10], [10, 11], [11, 10]],
    2,
    init_centroids=[[0, 0], [10, 10]],
    tol=1e-6,
)
assert np.allclose(c, [[1 / 3, 1 / 3], [31 / 3, 31 / 3]]) and l.tolist() == [
    0,
    0,
    0,
    1,
    1,
    1,
]
c, l = kmeans([[0], [1], [2], [3], [10]], 2, init_centroids=[[0], [1]], max_iters=1)
assert np.allclose(c, [[0], [4]]) and l.tolist() == [0, 0, 0, 1, 1]
c, l = kmeans([[0], [4]], 2, init_centroids=[[2], [2]])
assert np.allclose(c, [[2], [2]]) and l.tolist() == [0, 0]
assert np.array_equal(
    kmeans([[0], [1], [9], [10]], 2, seed=3)[0],
    kmeans([[0], [1], [9], [10]], 2, seed=3)[0],
)
print(
    "W132: provided example, FINAL reassignment, empty clusters and seed determinism passed"
)
```

### Output and numerical scope

The supplied six points yield centers `[[1/3,1/3],[31/3,31/3]]` and `[0,0,0,1,1,1]`. The one-round check demonstrates that final reassignment is intentional here, unlike W131. Lowest-index ties follow NumPy argmin. Center updates minimize fixed-membership SSE, while cap/tolerance stopping need not give a global optimum. Check multiple initializations for a modeling task, but preserve supplied centers in this exercise.

Each round costs O(nkd) and O(nk+kd) auxiliary storage; the norm-product distance avoids the potentially large n×k×d temporary. With huge shared coordinate offsets subtract a common origin first or compute direct/chunked squared differences to reduce cancellation; the supplied moderate-coordinate examples are unambiguous. Check max_iters≥1, valid finite shapes and nonnegative tolerance. The executable checks cover final-center labels, initialization determinism and empty/tied centers.
