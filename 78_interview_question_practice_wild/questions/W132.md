## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Problem: Implement K-Means Clustering With a Convergence Check

Given a dataset X as a 2D array (with n samples and d features) and an integer k, implement K-Means from scratch and return the final centroids and the cluster assignment for each point. Your implementation must include a convergence criterion.

Requirements
Initialization: use the provided init_centroids if given; otherwise randomly pick k samples as initial centroids.
Repeat until convergence or max_iters:
Assignment step: assign each sample to the nearest centroid (Euclidean distance).
Update step: recompute each centroid as the mean of samples assigned to it.
Convergence: stop when the maximum centroid movement is &lt;= tol.
Edge case: if a cluster receives no points in an iteration, keep its centroid unchanged.
After the loop, return the labels of the final assignment against the final centroids.
Input
X: float array of shape n x d
k: integer, 1 &lt;= k &lt;= n
max_iters: maximum iterations (default 100)
tol: tolerance (default 1e-4)
init_centroids (optional): float array of shape k x d
Output

Return a tuple:

centroids: float array k x d
labels: int array of length n, values in 0..k-1
Constraints
1 &lt;= n &lt;= 1e4
1 &lt;= d &lt;= 100
1 &lt;= k &lt;= 100
max_iters &lt;= 300
Example

Input:

X = [[0,0],[0,1],[1,0],[10,10],[10,11],[11,10]]
k = 2
init_centroids = [[0,0],[10,10]]
max_iters = 100
tol = 1e-6

Output:

centroids = [[1/3, 1/3], [31/3, 31/3]]   (about [[0.3333, 0.3333], [10.3333, 10.3333]])
labels    = [0, 0, 0, 1, 1, 1]

The first three points form one cluster and the last three the other; with these initial centroids the labels are exactly as shown.</pre>

## Worked solution

1. Implement k-means with convergence and empty clusters. Alternate assigning points to their closest centers and moving each center to the mean of its assigned points.
2. Initialize k distinct data indices under an explicit random seed, requiring 1<=k<=N.
3. Compute squared distances, assign closest centers and recompute non-empty means. For an empty cluster, retain its center or explicitly reseed it.
4. Stop on a center-shift tolerance or iteration cap, then recompute labels for the returned centers. Compare objective values, not center ordering, across implementations.
5. Choose the number of k-means clusters. There is rarely one objectively correct k; the useful resolution depends on geometry and the downstream task.
6. Compare objective curves across k, using several initialization seeds.
7. Inspect cluster stability, silhouette behavior, sizes and representative examples, and standardize features if appropriate.
8. Validate usefulness for the real decision; do not choose a visually neat elbow without checking whether clusters are meaningful.

### Small example / sanity check

For [0,1,9,10] with k=2 and sensible initialization, centers converge to 0.5 and 9.5.

### Common trap

Taking the mean of an empty slice, stopping with labels from old centers, or assuming a local optimum is globally best.
