## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Expected Handshakes in 10x10 Grid Dice Rolls

Given a 10 × 10 grid where each cell represents a person. Each person rolls a dice and they shake hands with their neighbors if they roll the same number. What is the expected total number of handshakes?

Example

Input

10 10</pre>

## Worked solution

1. Count undirected orthogonal neighbor pairs, not per-person neighbor totals without correction.
2. A 10-by-10 grid has 10*9 horizontal and 10*9 vertical edges, totaling 180. Two independent fair six-sided dice match with probability sum_faces(1/6)²=1/6.
3. Let I_e indicate a handshake on edge e. By linearity, expected total is sum E[I_e]=180/6=30; indicators sharing a person need not be independent for this expectation.
4. For an m-by-n grid and a common face distribution p_j, the general expectation is [m*(n-1)+n*(m-1)]*sum_j p_j², assuming independent rolls between people.

### Small example / sanity check

For a 1-by-2 grid there is one neighbor pair, so the expectation is 1/6, a quick check against double counting.

### Common trap

Counting each edge once from both endpoints or requiring pairwise independence of all handshake indicators.
