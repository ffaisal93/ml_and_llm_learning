## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">In a k-means clustering problem, a dataset contains n data points, where the i data point is represented by the feature vector location[i]. The goal is to create k clusters, where the cluster centers (the cluster centroids) can be placed at any point in the feature space. The overall quality of the clustering is measured by the maximum distance between any data point and its nearest cluster center.

The best possible quality is achieved by optimally placing the cluster centers to minimize this maximum distance. Determine this maximum distance between any data point and its nearest cluster center.

Note: The distance between two feature points x and y is defined as |x - y|, where |x| denotes the absolute value of x.

Example

Input

location = [4, 1, 6, 7, 2]
k = 2

Output

2</pre>

## Worked solution

1. Implement k-means with convergence and empty clusters. Alternate assigning points to their closest centers and moving each center to the mean of its assigned points.
2. Initialize k distinct data indices under an explicit random seed, requiring 1<=k<=N.
3. Compute squared distances, assign closest centers and recompute non-empty means. For an empty cluster, retain its center or explicitly reseed it.
4. Stop on a center-shift tolerance or iteration cap, then recompute labels for the returned centers. Compare objective values, not center ordering, across implementations.
5. Choose the number of k-means clusters. There is rarely one objectively correct k; the useful resolution depends on geometry and the downstream task.
6. Compare objective curves across k, using several initialization seeds.
7. Inspect cluster stability, silhouette behavior, sizes and representative examples, and standardize features if appropriate.
8. Validate usefulness for the real decision; do not choose a visually neat elbow without checking whether clusters are meaningful.

### Small example / sanity check

For [0,1,9,10] with k=2 and sensible initialization, centers converge to 0.5 and 9.5.

### Common trap

Taking the mean of an empty slice, stopping with labels from old centers, or assuming a local optimum is globally best.
