## Question

One round in every MLE / AI/ML loop is a 45-60 minute domain interview: 10 min resume walkthrough, then rapid-fire ML fundamentals, often around the candidate's chosen track (LLM / NLP / CV / Recsys). Interviewers go deep on why each concept works, not just definitions.

### Requirements

The round is a Q&A oral exam plus light whiteboard derivations. Candidates pick a track when scheduling; the interviewer tailors questions to that track but always anchors on ML fundamentals.

Core ML fundamentals (across most loops): bias-variance trade-off; overfitting/underfitting remedies; logistic regression (loss, optimization, decision boundary); gradient descent variants (batch/mini-batch/SGD/momentum/Adam); cross-entropy vs MSE and why; L1 vs L2 (why L1 gives sparsity, geometric explanation); forward/backward propagation; Bayesian vs frequentist, perplexity; why Transformers beat RNNs (attention vs recurrent step, autoregressive decoding cost).

LLM / NLP track: fine-tuning methods (full / LoRA / adapters / prefix); inference (KV cache, top-p / top-k / nucleus, temperature); MoE; tokenization (BPE / WordPiece / SentencePiece); autoencoder vs VAE vs VQ-VAE; LLM for product features (retrieval vs prompting).

Recsys track: cold-start mitigations (give multiple options); two-tower retrieval vs ranking; online/offline + counterfactual eval; LSH/ANN at scale; human-in-the-loop calibration.

CV track: ViT vs CNN; vector DBs / product quantization; quantization + pruning for serving.

Project-dive sub-section (~15 min): walk through one project — problem framing, modeling choices, alternatives ruled out, results, limitations. Interviewer fishes for honesty about what didn't work (Googliness signal).

### Notes

Interviewer expects you to defend mechanism, not terminology ("L1 gives sparsity" is not enough — show why the L1 ball corners snap weights to 0).
Be ready to derive: softmax + cross-entropy gradient, attention forward pass, gradient flow through a residual block, on a whiteboard.
State the standard answer first, then the interesting modern variant — don't lead with niche papers.

## Worked solution

### Prepare an explanation you can derive

Use the resume portion to describe one real project: target/user problem, data split, baseline, your contribution, measured result and limitation. Do not replace evidence with architecture names. For each concept below, state the mechanism, one equation and the condition under which it can fail.

### Core fundamentals

Bias is systematic error of the average fitted model; variance is sensitivity to training data. High train/validation error suggests underfitting or optimization/data problems; a large gap suggests variance or distribution mismatch. Improve features/capacity for confirmed underfitting; regularize, gather representative data or simplify for confirmed variance. The squared-error decomposition includes bias squared, variance and irreducible conditional noise.

Logistic regression uses $p=\sigma(w^\top x+b)$ and binary negative log likelihood. Its fixed-threshold boundary is linear in the supplied features. For multiclass logits z, softmax and cross-entropy give

$$p_j=\frac{e^{z_j}}{\sum_k e^{z_k}},\qquad
L=-\log p_y,\qquad \frac{\partial L}{\partial z_j}=p_j-\mathbf1[j=y].$$

Cross-entropy corresponds to a categorical likelihood; MSE corresponds to a Gaussian conditional-mean model under standard assumptions, though it can also score probabilities as the Brier loss. Choose a loss for the target and statistical objective rather than declaring MSE universally invalid for classification.

Full-batch gradient descent uses all observations per step; SGD uses one and mini-batch methods trade throughput against gradient noise. Momentum smooths directions with an exponential gradient accumulator. Adam also rescales coordinates using bias-corrected first/second moments. Tune learning rate, batch size and decay; adaptive scaling does not prove better generalization.

L2 smoothly shrinks weights; L1's nonsmooth corner allows zeros. For the scalar objective $\tfrac12(w-z)^2+\lambda|w|$, the optimum is soft thresholding, $\operatorname{sign}(z)\max(|z|-\lambda,0)$. Geometrically, a loss contour often first touches an L1 ball at a coordinate-axis corner. Feature scaling and correlation affect which coefficient is selected.

For a layer $Z=XW+b$, backward propagation gives $dW=X^\top dZ$ and $dX=dZW^\top$. A residual $h=x+F(x)$ has Jacobian $I+J_F$; the identity path helps gradients but does not guarantee stable training. Bayesian inference updates a prior to a posterior over unknowns; frequentist inference treats parameters as fixed and studies the repeated-sampling behavior of estimators/tests. Perplexity is $\exp(\text{mean token NLL})$ with natural logs; compare only compatible tokenization/data.

### LLM/NLP track

Attention computes $\operatorname{softmax}(QK^\top/\sqrt{d_k})V$, with a causal mask for autoregressive training. Transformers parallelize token computations during training; RNN recurrence serializes positions. Dense attention has quadratic sequence interactions, and autoregressive generation still emits sequential tokens. KV caching avoids recomputing past keys/values but consumes memory proportional to cached sequence length.

Full fine-tuning updates all weights; LoRA learns a low-rank update $\Delta W=BA$; adapters add small trainable modules; prefix methods train extra conditioning vectors. They differ in trainable memory, optimizer state and deployment support. Temperature rescales logits; top-k retains a fixed count and top-p the smallest high-probability set exceeding a mass threshold, followed by renormalization.

MoE routes a token to selected experts, reducing active compute relative to activating every expert while retaining large total weights and communication costs. BPE merges frequent token pairs; WordPiece uses a vocabulary-building/subword scheme with different selection conventions; SentencePiece is a tokenizer toolkit supporting models such as unigram and BPE. Do not confuse a toolkit with one unique merge algorithm.

An autoencoder reconstructs from a deterministic latent. A VAE learns a probabilistic latent with reconstruction and KL terms; a VQ-VAE quantizes to discrete codebook entries and needs a codebook/commitment learning strategy. For a product needing current private facts, retrieval supplies authorized evidence; prompting alone cannot insert absent facts or guarantee factuality.

### Recommender and CV tracks

For cold-start recommendations, use content embeddings, onboarding preferences, contextual/popular candidates and controlled exploration. Two-tower retrieval cheaply finds a broad pool; a heavier ranker models detailed interactions. ANN/LSH trade exactness for speed; measure recall against exact neighbors. Offline ranking metrics cannot alone establish online value under exposure bias; log impressions and use experiments or defensible propensity-based estimates. Human reviews help calibrate relevance/quality rubrics when sampled and audited independently.

CNNs encode locality/translation structure through convolution; ViTs tokenize patches and learn global interactions, with different data/compute needs. Product quantization stores vectors as sub-codebook indices and approximates distance, saving memory at recall cost. Weight/activation quantization and pruning can reduce serving resources only if supported kernels exploit them; benchmark task quality and actual latency after conversion.

### Practice the project dive

Spend two minutes framing the task, five explaining the data/model decision, five on evidence and failure analysis, and the remainder on alternatives/limitations. Be ready to derive the gradients above and trace tensor shapes. “I did not test that; here is the experiment I would run” is a stronger answer than an invented metric.
