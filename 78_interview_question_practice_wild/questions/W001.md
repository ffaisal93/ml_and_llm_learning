## Worked solution

1. Why are Q, K and V separate projections? Attention is a learned lookup: a query says what to find, a key says what can be matched, and a value carries what to copy.
2. Write Q=XWq, K=XWk and V=XWv, with X shaped (B,T,d_model).
3. Compute scores QKᵀ, normalize each query's row over keys, then mix the value vectors.
4. Separate Q and K allow asymmetric relevance. Separate V lets the features used for matching differ from the features transmitted; the output projection mixes heads.
5. Why divide attention logits by the square root of the head dimension? It controls the initial scale of the dot products so softmax is less likely to become nearly one-hot before learning.
6. Assume independent, zero-mean, unit-variance query and key coordinates. Each product has variance one.
7. A sum of d_k such products has variance d_k and standard deviation sqrt(d_k).
8. Divide by sqrt(d_k), then subtract the row maximum before exponentiation. The divisor controls scale; max subtraction prevents overflow. These are different mechanisms.
9. Trace every shape in multi-head self-attention. Heads are parallel attention computations over smaller feature spaces; they do not each attend to a disjoint piece of the sequence.
10. Project X:(B,T,d) into Q,K,V:(B,T,H*d_h). Reshape and transpose to (B,H,T,d_h).
11. Multiply Q by K transposed on its last two axes to obtain (B,H,T,T). Softmax over the final key axis.
12. Multiply by V to obtain (B,H,T,d_h), transpose to (B,T,H,d_h), concatenate to (B,T,H*d_h), and apply Wo to return to (B,T,d).
13. Where does the causal mask go, and why? A decoder must predict using only tokens already available at that position. The mask prevents future-token information from entering the weighted sum.
14. For query position i, allow key positions j<=i, including the current input token.
15. Set forbidden scores to negative infinity before softmax; their exponentials become zero and the allowed probabilities are renormalized.
16. Combine causality with padding and any segment restrictions. Ensure each valid query has at least one allowed key or explicitly define zero output for an empty row.
17. Why do Transformers need positional information, and what does RoPE do? Without position information, ordinary self-attention cannot reliably distinguish token order. RoPE puts position-dependent rotations into queries and keys.
18. Split each head vector into coordinate pairs and rotate each pair by its position times a frequency.
19. Use rotated Q and K in the attention dot product. The relative rotation depends on the difference between their positions.
20. At cached decoding time, continue the absolute position offset from the prefix. Long-context extension still needs validation; relative structure alone does not guarantee extrapolation.
21. Compare pre-norm, post-norm, LayerNorm and RMSNorm. Normalization controls activation scale; its placement also changes how gradients travel through a deep residual stack.
22. Post-norm computes LN(x+F(x)); pre-norm computes x+F(LN(x)). Pre-norm leaves an explicit identity route through the residual addition.
23. LayerNorm subtracts each token's feature mean and divides by sqrt(feature variance+epsilon), then applies learned scale and usually bias.
24. RMSNorm divides by sqrt(mean(x²)+epsilon), usually with scale but no centering. Compare stability and quality empirically; neither architecture removes the need to tune training.
25. Why are residual connections and the feed-forward network both needed? Attention moves information between positions; the feed-forward network transforms the features at each position. Residual additions preserve an easy path for useful existing information.
26. An attention sublayer creates context-dependent mixtures of token values.
27. A position-wise nonlinear MLP expands the feature dimension, applies an activation or gate, and projects back. Its weights are shared across positions, not across all layers by default.
28. Add each sublayer's result to its input. Without nonlinearities, stacked affine feed-forward layers collapse into one affine map; attention's own input-dependent mixing remains nonlinear.
29. What makes attention quadratic, and what does FlashAttention change? Dense attention compares every query with every key. FlashAttention computes the same attention operation with a different memory-access schedule.
30. At sequence length T, the logical score matrix has T² entries per head; forming QKᵀ and multiplying by V cost O(T²*d_h).
31. A naive implementation materializes scores and probabilities in high-bandwidth memory, creating heavy memory traffic.
32. Tiled exact attention maintains rowwise normalization statistics and avoids storing the full matrix in that memory. Arithmetic remains quadratic for full attention; practical memory use and throughput improve.

### Apply the exact contract

Remaining oral points: self-attention pairwise work is O(T²d), with projection/FFN work O(Td²) depending on widths; an LSTM is O(T*(d*h+h²)) and sequential over T. Multi-head attention gives distinct routing/content subspaces, not disjoint token ranges. Sinusoidal positions avoid a finite learned lookup table but do not guarantee useful extrapolation; RoPE rotates Q/K to expose relative phase. Dot-product attention maps efficiently to matrix multiplication; additive attention scores through a learned nonlinear network and is not universally inferior. Softmax gives nonnegative row-normalized mixing weights, with a saturation tradeoff. Scaled attention is softmax(QKᵀ/sqrt(d_k)+M)V. The mask and residual/FFN explanations above cover the remaining repeated why-questions.

### Small example / sanity check

In “The dog chased the ball because it moved,” a pronoun's query may match an object's key while its value carries object attributes. The three vectors serve different jobs even though they start from the same token state.

### Common trap

Calling Q, K and V three different input sequences: self-attention projects the same input; cross-attention uses a different source for K and V.
