## Worked solution

### Data structures and execution models

1. A **linked list** stores values in nodes with next references (and prev for a doubly linked list). Index/search is O(n); insert/delete is O(1) only when the needed node/predecessor is already known. Arrays provide O(1) indexing and better locality, but interior insert/delete shifts O(n) values; dynamic-array append is amortized O(1). List reference overhead and poor cache locality can outweigh cheap splicing.
2. **Quicksort** selects a pivot, partitions smaller/equal/larger elements and recursively sorts the sides. Random pivots or median heuristics reduce bad patterns; expected comparisons are O(n log n), worst O(n²). Three-way partition handles duplicates well. Typical in-place variants are unstable; recursion uses expected O(log n) stack but naive worst O(n). Recursing on the smaller side bounds stack depth.
3. **Compiled versus interpreted** describes implementation stages, not immutable language categories. Compilation translates source/IR before or during execution; an interpreter executes a representation. Python commonly compiles to bytecode then interprets; JVM runtimes can interpret then JIT machine code. Startup, optimization, portability and tooling vary; “compiled is always faster” is not a theorem.

### Numerical mathematics

4. For f(x)=0, linearize 0≈f(x_k)+f'(x_k)(x_next−x_k), giving **Newton** x_next=x_k−f/f'. Near a simple root, sufficiently smooth f and a close start give quadratic convergence. For x²−2, starting at 1 gives 1.5 then 1.416667. Zero derivatives, cycles or poor starts can fail; damping/bracketing improves robustness.
5. A square **matrix is invertible** iff full rank, det≠0 and zero nullspace. Gauss–Jordan on [A|I] with pivoting gives [I|A^-1], or solve A x_j=e_j via one LU factorization, generally O(n³). For Ax=b, solve directly instead of explicitly inverting; near-singular matrices amplify floating-point error despite nonzero determinant. Rectangular matrices require least squares/pseudoinverse, a different object.
6. For f:R^n→R^m, **Jacobian** J_ij=∂f_i/∂x_j has shape m×n. If f(x,y)=(x²y,sin y), J=[[2xy,x²],[0,cos y]]. It maps small input changes to first-order output changes; differentiability is required for that local approximation.

### Probability and learning

7. From P(A∩B)=P(A|B)P(B)=P(B|A)P(A), **Bayes** gives P(A|B)=P(B|A)P(A)/P(B), for P(B)>0. It reverses conditioning, not simply exchanges the two conditionals.
8. **Inverse-transform sampling:** draw U uniform(0,1), return generalized inverse F^-1(U)=inf{x:F(x)≥U}. Then P(F^-1(U)≤x)=F(x), including discrete jumps. For Exp(λ), use −log(1−U)/λ with U∈[0,1) to avoid log0.
9. **Variance** is E[(X−μ)²]=E[X²]−2μE[X]+μ²=E[X²]−μ² when the second moment exists. It scales as Var(aX+b)=a²Var(X); standard deviation is its square root.
10. A soft-margin **SVM** minimizes ½||w||²+CΣmax(0,1−y_i(wᵀx_i+b)); it balances margin and violations. A valid positive-semidefinite kernel replaces feature-space inner products, enabling nonlinear boundaries without explicitly constructing that space. Kernel SVMs can scale poorly with sample count; feature scaling and C/kernel selection need validation.
11. **Curse of dimensionality:** covering a d-dimensional unit cube with side ε cells needs ε^-d cells. Sparse coverage and concentrated distances can harm nearest-neighbor/density methods; good representations, regularization and more relevant data help, while intrinsic dimension may be much lower than raw feature count.
12. **Backpropagation** applies the chain rule in reverse computational-graph order, accumulating contributions from every use of a variable. For z=wx+b and L=(z−y)²/2, ∂L/∂w=(z−y)x, ∂L/∂b=z−y, ∂L/∂x=(z−y)w. Compute gradients using forward-pass weights before optimizer updates; reverse-mode computes vector-Jacobian products efficiently for scalar losses, not a full Jacobian unnecessarily.
