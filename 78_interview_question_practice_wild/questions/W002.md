## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Implement the forward pass of one scaled dot-product self-attention head with NumPy. Each token looks at every token that is allowed, takes a weighted average of their value vectors, and the weights come from how well its query matches their keys.

What to implement
def attention(X: np.ndarray, Wq: np.ndarray, Wk: np.ndarray, Wv: np.ndarray,
mask: np.ndarray | None = None) -&gt; np.ndarray:
...
X has shape (n, d_model): one row per token.
Wq and Wk have shape (d_model, d_k), and Wv has shape (d_model, d_v).
mask is None or a boolean array of shape (n, n). mask[i, j] = True means token i may attend to token j.
Return an array of shape (n, d_v).
Rules
1.
Compute Q = X @ Wq, K = X @ Wk, V = X @ Wv.
2.
The scores are Q @ K.T / sqrt(d_k), shape (n, n).
3.
Where mask is False, the pair gets attention weight 0. Every row of mask has at least one True.
4.
Each row of weights is the softmax of that row of scores over the allowed positions, so the weights of a row sum to 1.
5.
The result is weights @ V. Do not round it.
6.
The softmax must not overflow for large scores.
Examples

Example 1

X  = [[1, 0], [0, 1]]    Wq = Wk = [[1, 0], [0, 1]]    Wv = [[1, 2], [3, 4]]
Output: [[1.6604769, 2.6604769], [2.3395231, 3.3395231]]

Here V = [[1, 2], [3, 4]]. The scores are [[1, 0], [0, 1]] / sqrt(2), so row 0 puts weight 0.6698 on token 0 and 0.3302 on token 1.

Example 2: a mask

Same inputs, mask = [[True, False], [True, True]]
Output: [[1, 2], [2.3395231, 3.3395231]]

Token 0 may only look at itself, so its output is V[0]. Token 1 may look at both tokens, so its row is unchanged.

Constraints
1 &lt;= n &lt;= 512, 1 &lt;= d_model, d_k, d_v &lt;= 256.
Inputs are finite float64 arrays.</pre>

## Worked solution

1. Implement stable scaled dot-product attention. Compute a normalized weighted average of values, with one probability distribution per query.
2. Project X into Q,K,V, then form QKᵀ/sqrt(d_k).
3. Replace forbidden scores with negative infinity. Subtract each row's maximum, exponentiate, and divide by the row sum.
4. Return probabilities @ V. Check mask shape and reject rows with no valid keys. See the executable attention implementation in the coding lab.

### Small example / sanity check

With only the diagonal allowed, output row i must equal value row i, regardless of the other scores.

### Common trap

Softmax over the query axis instead of the key axis, or allowing masked keys to retain probability.
