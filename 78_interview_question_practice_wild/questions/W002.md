## Question

Implement the forward pass of one scaled dot-product self-attention head with NumPy. Each token looks at every token that is allowed, takes a weighted average of their value vectors, and the weights come from how well its query matches their keys.

### What to implement

```python
def attention(X: np.ndarray, Wq: np.ndarray, Wk: np.ndarray, Wv: np.ndarray,
    mask: np.ndarray | None = None) -> np.ndarray:
    ...
```

X has shape (n, d_model): one row per token.
Wq and Wk have shape (d_model, d_k), and Wv has shape (d_model, d_v).
mask is None or a boolean array of shape (n, n). mask[i, j] = True means token i may attend to token j.
Return an array of shape (n, d_v).

### Rules

1. Compute Q = X @ Wq, K = X @ Wk, V = X @ Wv.
2. The scores are $QK^{\top}/\sqrt{d_k}$, shape $(n, n)$.
3. Where mask is False, the pair gets attention weight 0. Every row of mask has at least one True.
4. Each row of weights is the softmax of that row of scores over the allowed positions, so the weights of a row sum to 1.
5. The result is weights @ V. Do not round it.
6. The softmax must not overflow for large scores.

### Examples

Example 1

```python
X  = [[1, 0], [0, 1]]
Wq = Wk = [[1, 0], [0, 1]]
Wv = [[1, 2], [3, 4]]
```

Output: [[1.6604769, 2.6604769], [2.3395231, 3.3395231]]

Here V = [[1, 2], [3, 4]]. The scores are [[1, 0], [0, 1]] / sqrt(2), so row 0 puts weight 0.6698 on token 0 and 0.3302 on token 1.

Example 2: a mask

Same inputs, mask = [[True, False], [True, True]]
Output: [[1, 2], [2.3395231, 3.3395231]]

Token 0 may only look at itself, so its output is V[0]. Token 1 may look at both tokens, so its row is unchanged.

### Constraints

1 &lt;= n &lt;= 512, 1 &lt;= d_model, d_k, d_v &lt;= 256.
Inputs are finite float64 arrays.

## Worked solution

### Solution outline

Compute a normalized weighted average of values, with one probability distribution per query.

1. Project X into Q,K,V, then form $QK^\top/\sqrt{d_k}$.
2. Replace forbidden scores with negative infinity. Subtract each row's maximum, exponentiate, and divide by the row sum.
3. Return probabilities @ V. Check mask shape and reject rows with no valid keys. See the executable attention implementation in the coding lab.

### Understand why the approach works

#### Derivation and a complete small example

For one token matrix $X\in\mathbb R^{n\times d_{\rm model}}$, learn projections

$$
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V,
$$

with $W_Q,W_K\in\mathbb R^{d_{\rm model}\times d_k}$ and $W_V\in\mathbb R^{d_{\rm model}\times d_v}$. The output has shape $n\times d_v$. Row $i$ asks which keys help query $i$; therefore softmax normalizes **across columns**, not across queries.

Let $X=W_Q=W_K=I_2$ and $V=\begin{bmatrix}1&2\\3&4\end{bmatrix}$. The score matrix is $I_2/\sqrt2$. The first row's probabilities are

$$
p_{11}=\frac{e^{1/\sqrt2}}{e^{1/\sqrt2}+1}\approx0.669762,
\qquad p_{12}\approx0.330238.
$$

Its output is $0.669762[1,2]+0.330238[3,4]\approx[1.660477,2.660477]$. This explicitly shows that the output is a weighted value mixture, not the selected key or a vocabulary probability.

For a boolean allowed-mask, set forbidden scores to $-\infty$ **before** softmax. Subtract each valid row maximum before exponentiation; this prevents overflow without changing the distribution. An all-forbidden row needs a declared policy because subtracting $-\infty$ from $-\infty$ creates NaN. This exercise guarantees at least one allowed key, and the reference rejects a violated contract.

**Cost.** Pairwise attention uses $O(n^2(d_k+d_v))$ arithmetic and $O(n^2)$ score storage in this straightforward implementation, in addition to the linear projections. **Checks.** Identity-only masking returns $V$ exactly; changing a forbidden future input must not change an earlier causal output.

```python
import math
import numpy as np


def attention_qkv(q, k, v, mask=None):
    """Single-head attention. True mask entries mean allowed. Empty rows rejected."""
    q, k, v = [np.asarray(a, dtype=np.float64) for a in (q, k, v)]
    if any(a.ndim != 2 for a in (q, k, v)):
        raise ValueError("q,k,v must be matrices")
    if q.shape[1] != k.shape[1] or k.shape[0] != v.shape[0]:
        raise ValueError("incompatible attention shapes")
    if q.shape[1] == 0 or k.shape[0] == 0:
        raise ValueError("empty head dimension or key sequence")
    if not all(np.isfinite(a).all() for a in (q, k, v)):
        raise ValueError("inputs must be finite")
    scores = q @ k.T / math.sqrt(q.shape[1])
    if mask is not None:
        mask = np.asarray(mask, dtype=bool)
        if mask.shape != scores.shape or not mask.any(axis=-1).all():
            raise ValueError("invalid mask or all-masked row")
        scores = np.where(mask, scores, -np.inf)
    z = scores - scores.max(axis=-1, keepdims=True)
    weights = np.exp(z)
    weights /= weights.sum(axis=-1, keepdims=True)
    return weights @ v


def attention(x, wq, wk, wv, mask=None):
    x = np.asarray(x, dtype=np.float64)
    return attention_qkv(x @ wq, x @ wk, x @ wv, mask)


X = np.eye(2)
W = np.eye(2)
V = np.array([[1.0, 2.0], [3.0, 4.0]])
y = attention(X, W, W, V)
assert np.allclose(y, [[1.6604769, 2.6604769], [2.3395231, 3.3395231]])
assert np.allclose(attention(X, W, W, V, np.eye(2, dtype=bool)), V)
causal = np.tril(np.ones((2, 2), dtype=bool))
changed = X.copy()
changed[1] *= 100
assert np.allclose(
    attention(X, W, W, V, causal)[0], attention(changed, W, W, V, causal)[0]
)
assert np.isfinite(attention(np.eye(2) * 1000, W, W, V)).all()

print("W002: all exact-contract behavior checks passed")
```

### Optional PyTorch study counterpart

This is a separate tensor/autograd study. The required NumPy function above remains the exercise submission. X is (n,d_model), Wq/Wk are (d_model,d_k), Wv is (d_model,d_v), and the boolean mask is exactly (n,n) with True meaning allowed. Masking precedes row-max subtraction/softmax. No attention library or extra projection is used. Float64 matches the original numerical contract; differentiating a scalar function of the result produces gradients for X and all three projection matrices.

```python
import math
import torch


def attention_torch(X, Wq, Wk, Wv, mask=None):
    """W002: (n,dm) and projection weights -> (n,dv); True means allowed."""
    if X.ndim != 2 or any((W.ndim != 2 for W in (Wq, Wk, Wv))):
        raise ValueError("X and weights must be matrices")
    n, dm = X.shape
    if (
        n < 1
        or any((W.shape[0] != dm for W in (Wq, Wk, Wv)))
        or Wq.shape[1] != Wk.shape[1]
        or (min(Wq.shape[1], Wv.shape[1]) < 1)
    ):
        raise ValueError("incompatible projection shapes")
    q, k, v = (X @ Wq, X @ Wk, X @ Wv)
    scores = q @ k.T / math.sqrt(q.shape[1])
    if mask is not None:
        allowed = torch.as_tensor(mask, dtype=torch.bool, device=X.device)
        if allowed.shape != (n, n) or not bool(allowed.any(dim=-1).all()):
            raise ValueError("mask must be (n,n) with a key in every row")
        scores = scores.masked_fill(~allowed, -torch.inf)
    shifted = scores - scores.amax(dim=-1, keepdim=True)
    weights = shifted.exp()
    weights = weights / weights.sum(dim=-1, keepdim=True)
    return weights @ v
```
