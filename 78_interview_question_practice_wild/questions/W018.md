## Worked solution

1. Compare PPO, DPO and GRPO using their training requirements. Choose by available feedback, exploration needs and memory budget rather than treating the methods as interchangeable names.
2. PPO uses current-policy rollouts, advantages and a clipped probability-ratio objective; common RLHF setups add a reward model, critic and reference-policy regularization.
3. DPO trains on preferred/rejected pairs with a frozen reference and a logistic loss on differences of sequence log-probability ratios; no explicit reward model is required in that objective.
4. GRPO compares several sampled answers for a prompt using group-relative rewards, avoiding a learned value critic in its usual form. Reward and variant details still matter.
5. Explain a clipped PPO update in plain language. PPO rewards actions with positive estimated advantage while limiting the incentive for a large probability-ratio change within an update.
6. Form r=pi_new(action|state)/pi_old(action|state) from the rollout policy, with rollout quantities treated as fixed.
7. Maximize mean(min(r*A,clip(r,1-epsilon,1+epsilon)*A)). A common minimized total loss adds value error and KL regularization and subtracts an entropy bonus.
8. Estimate advantages from returns and a value baseline, then monitor policy KL, reward, value error and clipping fraction.
9. Calculate group-relative advantages and diagnose zero-variance rewards. GRPO-style normalization asks which sampled answers did better than their siblings for the same prompt.
10. Sample G responses, score each, and compute A_i=(r_i-mean(r))/(std(r)+epsilon) under the chosen convention.
11. Use these fixed advantages in the policy-ratio update, with any reference penalty and token reduction explicitly specified.
12. If every reward is equal, centered advantages are zero. Investigate sampling diversity, task difficulty and reward informativeness rather than dividing by zero.

### Apply the exact contract

For GSPO versus token-level GRPO/PPO, distinguish the sequence-level importance ratio and clipping convention from token-level ratios. One convention forms exp(mean_t(log pi_new-log pi_old)) per completion, then applies a sequence-level clipped objective. State the exact variant, token masks and reduction instead of substituting method names for a loss definition.

### Small example / sanity check

Use preference pairs with modest compute for a DPO baseline; programmatically checked math/code rewards are a natural setting for group-relative online training.

### Common trap

Saying DPO requires online rollouts at every step, or that critic-free training removes the need for a reliable reward signal.
