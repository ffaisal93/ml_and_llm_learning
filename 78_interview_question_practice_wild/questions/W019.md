## Worked solution

1. Distinguish pretraining, supervised fine-tuning and preference optimization. They change the training signal and data distribution, rather than automatically changing the model architecture.
2. Pretraining predicts tokens over broad text to learn general representations and continuation behavior.
3. SFT applies supervised likelihood to demonstrations, often masking prompt targets so answers receive the training signal.
4. Preference optimization changes relative response desirability using comparisons or rewards. Evaluate task performance, behavior and regressions separately after each stage.
5. Compare PPO, DPO and GRPO using their training requirements. Choose by available feedback, exploration needs and memory budget rather than treating the methods as interchangeable names.
6. PPO uses current-policy rollouts, advantages and a clipped probability-ratio objective; common RLHF setups add a reward model, critic and reference-policy regularization.
7. DPO trains on preferred/rejected pairs with a frozen reference and a logistic loss on differences of sequence log-probability ratios; no explicit reward model is required in that objective.
8. GRPO compares several sampled answers for a prompt using group-relative rewards, avoiding a learned value critic in its usual form. Reward and variant details still matter.
9. Write and interpret the DPO loss. DPO increases the preferred response's relative probability advantage over the rejected response, measured against a reference policy.
10. Let a=log pi_theta(y_w|x)-log pi_ref(y_w|x) and b=log pi_theta(y_l|x)-log pi_ref(y_l|x).
11. Minimize L=-log sigmoid(beta*(a-b)); use a stable log-sigmoid or softplus implementation.
12. Sum token log probabilities over each response, excluding prompt and padding targets under a consistent convention. Keep the reference frozen.
13. Explain a clipped PPO update in plain language. PPO rewards actions with positive estimated advantage while limiting the incentive for a large probability-ratio change within an update.
14. Form r=pi_new(action|state)/pi_old(action|state) from the rollout policy, with rollout quantities treated as fixed.
15. Maximize mean(min(r*A,clip(r,1-epsilon,1+epsilon)*A)). A common minimized total loss adds value error and KL regularization and subtracts an entropy bonus.
16. Estimate advantages from returns and a value baseline, then monitor policy KL, reward, value error and clipping fraction.
17. Calculate group-relative advantages and diagnose zero-variance rewards. GRPO-style normalization asks which sampled answers did better than their siblings for the same prompt.
18. Sample G responses, score each, and compute A_i=(r_i-mean(r))/(std(r)+epsilon) under the chosen convention.
19. Use these fixed advantages in the policy-ratio update, with any reference penalty and token reduction explicitly specified.
20. If every reward is equal, centered advantages are zero. Investigate sampling diversity, task difficulty and reward informativeness rather than dividing by zero.

### Small example / sanity check

A correct SFT response demonstrates one answer; a preference pair says one answer is preferred to another, without requiring either to be an ideal demonstration.

### Common trap

Claiming preference training guarantees truthfulness or that SFT itself retrieves fresh facts.
