## Question

Given n binary classification samples, true labels y_i ∈ {0,1}, and predicted probabilities p_i for the positive class, implement Binary Focal Loss.

For each sample:

If y_i = 1, then p_t = p_i, alpha_t = alpha.
If y_i = 0, then p_t = 1 - p_i, alpha_t = 1 - alpha.

The per-sample loss is:

```python
loss_i = - alpha_t * (1 - p_t)^gamma * log(p_t)
```

To avoid log(0), clip probabilities to [1e-15, 1 - 1e-15].

### Input Format

n gamma alpha reduction
y_1 y_2 ... y_n
p_1 p_2 ... p_n

Where reduction is one of mean, sum, or none:

mean outputs the average loss.
sum outputs the total loss.
none outputs every sample's loss.
Output Format
If reduction is mean or sum, print one float rounded to 6 decimal places.
If reduction is none, print n floats separated by spaces, each rounded to 6 decimal places.

### Constraints

1 &lt;= n &lt;= 100000
0 &lt;= gamma &lt;= 10
0 &lt;= alpha &lt;= 1
0 &lt;= p_i &lt;= 1
Example

### Input

```text
3 2.0 0.25 mean
1 0 1
0.9 0.1 0.2
```

## Worked solution

### Solution outline

#### Implement numerically stable binary focal loss.

Focal loss reduces the contribution of already-easy examples by multiplying binary cross-entropy by (1-p_true)^gamma.

1. Given a binary label y and logit z, compute stable BCE as logaddexp(0,z)-y*z.
2. Let log_p_true=-BCE and compute 1-p_true stably as -expm1(log_p_true).
3. Multiply BCE by that factor raised to gamma and by alpha for positives or 1-alpha for negatives, if alpha weighting is specified. State the reduction.

#### Differentiate binary focal loss conceptually.

Its gradient includes both cross-entropy's gradient and the derivative of the focusing weight.

1. Write L=(1-p_t)^gamma*(-logp_t), with any class weight explicit.
2. Apply the product rule: changing the logit changes the BCE term and the modulation term.
3. Use a stable differentiable implementation and compare gradients with finite differences rather than multiplying BCE gradients by a fixed-looking weight.

### Understand why the approach works

#### Derive a local rule, then apply the chain rule

Treat a layer as a function with a declared input and output shape. Write the scalar loss and its reduction first: a sum, mean over rows and mean over all elements produce different gradient scales. For an affine layer $Y=XW+b$ with upstream gradient $G=\partial L/\partial Y$,

$$
\frac{\partial L}{\partial X}=GW^\top,\qquad
\frac{\partial L}{\partial W}=X^\top G,\qquad
\frac{\partial L}{\partial b}=\sum_i G_{i,:}.
$$

The bias sum is over all leading positions where the same bias was reused. Do not average again if $G$ already contains the mean-loss factor. For example, with one row $x=[2,3]$ and scalar upstream derivative $4$, the weight derivative is $[8,12]$.

Cache the forward values needed by the derivative; compute all gradients before updating parameters. Updating $W$ midway would make the earlier-layer derivative use a different function from the one evaluated forward.

Check a scalar objective using central differences:

$$
\frac{\partial L}{\partial\theta_j}\approx
\frac{L(\theta+h e_j)-L(\theta-h e_j)}{2h}.
$$

Use float64 and several sensible $h$ values. An arbitrarily tiny $h$ loses the difference to rounding, while a large one measures curvature rather than a local derivative. Avoid ReLU's kink at zero during this check, and test inputs, weights and biases separately.

### Readable reference implementation

Read the explanation first, then trace one small input through these functions. This is the same implementation used by the local checks; its stated simplifications still apply.

```python
import math
from collections import deque
from dataclasses import dataclass
import numpy as np


def binary_focal_loss(logits, labels, gamma=2.0, alpha=None):
    z, y = np.asarray(logits, dtype=float), np.asarray(labels, dtype=float)
    if z.shape != y.shape or not z.size or not np.isin(y, [0, 1]).all() or gamma < 0:
        raise ValueError("invalid focal-loss inputs")
    if not np.isfinite(z).all() or (alpha is not None and not 0 <= alpha <= 1):
        raise ValueError("invalid logits or alpha")
    bce = np.logaddexp(0, z) - y * z
    modulation = (-np.expm1(-bce)) ** gamma
    weights = 1 if alpha is None else np.where(y == 1, alpha, 1 - alpha)
    return float(np.mean(weights * modulation * bce))
```

### Work a small example

At gamma=0, focal modulation is one, so the result reduces to ordinary BCE with the chosen alpha weighting.

### Edge cases and common mistakes

Applying focal loss twice to already-probability-transformed scores or confusing it with calibration improvement.
