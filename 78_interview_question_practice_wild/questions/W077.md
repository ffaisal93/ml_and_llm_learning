## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Given n binary classification samples, true labels y_i ∈ {0,1}, and predicted probabilities p_i for the positive class, implement Binary Focal Loss.

For each sample:

If y_i = 1, then p_t = p_i, alpha_t = alpha.
If y_i = 0, then p_t = 1 - p_i, alpha_t = 1 - alpha.

The per-sample loss is:

loss_i = - alpha_t * (1 - p_t)^gamma * log(p_t)

To avoid log(0), clip probabilities to [1e-15, 1 - 1e-15].

Input Format
n gamma alpha reduction
y_1 y_2 ... y_n
p_1 p_2 ... p_n

Where reduction is one of mean, sum, or none:

mean outputs the average loss.
sum outputs the total loss.
none outputs every sample&#x27;s loss.
Output Format
If reduction is mean or sum, print one float rounded to 6 decimal places.
If reduction is none, print n floats separated by spaces, each rounded to 6 decimal places.
Constraints
1 &lt;= n &lt;= 100000
0 &lt;= gamma &lt;= 10
0 &lt;= alpha &lt;= 1
0 &lt;= p_i &lt;= 1
Example

Input:

3 2.0 0.25 mean
1 0 1
0.9 0.1 0.2</pre>

## Worked solution

1. Implement numerically stable binary focal loss. Focal loss reduces the contribution of already-easy examples by multiplying binary cross-entropy by (1-p_true)^gamma.
2. Given a binary label y and logit z, compute stable BCE as logaddexp(0,z)-y*z.
3. Let log_p_true=-BCE and compute 1-p_true stably as -expm1(log_p_true).
4. Multiply BCE by that factor raised to gamma and by alpha for positives or 1-alpha for negatives, if alpha weighting is specified. State the reduction.
5. Differentiate binary focal loss conceptually. Its gradient includes both cross-entropy's gradient and the derivative of the focusing weight.
6. Write L=(1-p_t)^gamma*(-logp_t), with any class weight explicit.
7. Apply the product rule: changing the logit changes the BCE term and the modulation term.
8. Use a stable differentiable implementation and compare gradients with finite differences rather than multiplying BCE gradients by a fixed-looking weight.

### Small example / sanity check

At gamma=0, focal modulation is one, so the result reduces to ordinary BCE with the chosen alpha weighting.

### Common trap

Applying focal loss twice to already-probability-transformed scores or confusing it with calibration improvement.
