## Worked solution

### Solution outline

1. State sorting bounds precisely: comparison sorting needs Omega(n log n) comparisons in the worst case, while bounded-key non-comparison methods have different assumptions. Explain expected/worst behavior for the chosen algorithm.
2. For tail(n) on a seekable file, scan fixed-size byte blocks backward, count newlines and retain only enough suffix data to locate the last n lines; define terminal-newline behavior and decode bytes carefully.
3. For a non-seekable stream, keep a deque of at most n lines. This uses $O(size of retained lines)$ memory; a single line can itself be arbitrarily large.
4. Explain file descriptors, buffering, page cache and process/thread scheduling only as they affect the requested path. Benchmark filesystem and I/O behavior rather than attributing all latency to CPU complexity.

### Understand why the approach works

#### Explain the assumptions behind a familiar formula

A definition, implementation and asymptotic guarantee are related but different. A linked list can insert in constant time **given the needed node/predecessor**, but locating that node may take linear time. Randomized quicksort has expected $O(n\log n)$ comparisons, not a universal worst-case guarantee.

For numerical mathematics, write the function and the local approximation. Newton's method comes from setting the tangent-line estimate to zero:

$$
0\approx f(x_k)+f'(x_k)(x_{k+1}-x_k),\qquad
x_{k+1}=x_k-\frac{f(x_k)}{f'(x_k)}.
$$

A simple root and a sufficiently good starting point can give quadratic local convergence; small derivatives or a poor start can cause failure. A memorized update alone does not explain that behavior.

For probability limits, state moment and independence/dependence assumptions. The CLT concerns a normalized sample mean, not a claim that all raw data become normally distributed. For information quantities, state support and log base. A useful interview answer gives the definition, one small example, the computational or statistical consequence and one case where the usual shortcut is invalid.
