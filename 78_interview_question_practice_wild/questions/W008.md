## Question

Problem: Implement Masked Cross Entropy Loss with Label Smoothing

Given a batch of classification model outputs logits, ground-truth labels labels, a sample mask mask, and a label smoothing parameter epsilon, implement the cross entropy loss using NumPy/Python.

Definition

logits is a 2D array of shape (N, C), where:

N is the number of samples;
C is the number of classes.

labels[i] is the ground-truth class of sample i, satisfying 0 &lt;= labels[i] &lt; C.

mask[i] indicates whether sample i participates in the loss computation:

```text
mask[i] = 1: include this sample;
mask[i] = 0: ignore this sample.
```

epsilon is the label smoothing coefficient, satisfying 0 &lt;= epsilon &lt; 1.

For sample i, define the softmax probability as:

p[i][j] = exp(logits[i][j]) / sum_k exp(logits[i][k])

Use the following label smoothing rule to construct the target distribution:

target[i][j] = epsilon / C                  if j != labels[i]
target[i][labels[i]] = 1 - epsilon + epsilon / C

The per-sample loss is:

```text
loss[i] = - sum_j target[i][j] * log(p[i][j])
```

Return the masked mean loss:

sum_i mask[i] * loss[i] / sum_i mask[i]

If all mask[i] are 0, return 0.0.

Your implementation should be numerically stable and should avoid directly applying exp to very large logits.

### Input Format

N C
logits[0][0] logits[0][1] ... logits[0][C-1]


logits[N-1][0] ... logits[N-1][C-1]
labels[0] labels[1] ... labels[N-1]

### Constraints

N * C &lt;= 200000
-1000 &lt;= logits[i][j] &lt;= 1000
0 &lt;= labels[i] &lt; C

## Worked solution

### Solution outline

Smoothing mixes the true-label target with a uniform distribution; masking controls which examples contribute to the average.

1. Compute stable log probabilities by subtracting each row maximum before log-sum-exp.
2. For each row use loss=(1-epsilon)*(-logp_true)+epsilon*(-mean(logp)). This corresponds to target_true=1-epsilon+epsilon/C.
3. Average included rows only; return 0 when the mask selects none. Validate target ranges and use the executable implementation in the lab.

### Understand why the approach works

#### Derive a stable masked, smoothed objective

For logits $z_{ic}$, labels $y_i$ and smoothing coefficient $\varepsilon$, the stated target convention is

$$
q_{ic}=(1-\varepsilon)\mathbf1[c=y_i]+\frac{\varepsilon}{C}.
$$

The true class therefore receives $1-\varepsilon+\varepsilon/C$, not just $1-\varepsilon$. Compute stable log probabilities with $a_i=\max_c z_{ic}$:

$$
\log p_{ic}=z_{ic}-a_i-\log\sum_j e^{z_{ij}-a_i}.
$$

Expanding the cross-entropy avoids constructing every target vector:

$$
\ell_i=-(1-\varepsilon)\log p_{i,y_i}
-\frac{\varepsilon}{C}\sum_c\log p_{ic},\qquad
L=\frac{\sum_i m_i\ell_i}{\sum_i m_i}.
$$

The denominator counts included examples; dividing by the original batch size changes the loss when masking changes. If no example is selected, this exercise returns zero. For a selected row, the derivative with respect to its logit is $(p_{ic}-q_{ic})/\sum_i m_i$; masked rows contribute zero.

For uniform predictions on four classes, every $\log p=-\log4$ and the loss is $\log4\approx1.386294$ at any smoothing coefficient. This is a useful independent check. Also test logits around $1000$, a single active row and all rows masked. Avoid computing `log(softmax(...))` when probabilities can underflow; calculate log-softmax directly.

### Readable reference implementation

Read the explanation first, then trace one small input through these functions. This is the same implementation used by the local checks; its stated simplifications still apply.

```python
import math
from collections import deque
from dataclasses import dataclass
import numpy as np


def log_softmax(x, axis=-1):
    x = np.asarray(x, dtype=np.float64)
    if x.size == 0 or not np.isfinite(x).all():
        raise ValueError("expected non-empty finite logits")
    z = x - np.max(x, axis=axis, keepdims=True)
    return z - np.log(np.exp(z).sum(axis=axis, keepdims=True))


def masked_cross_entropy(logits, labels, mask, epsilon=0.0):
    logits = np.asarray(logits, dtype=np.float64)
    labels = np.asarray(labels)
    mask = np.asarray(mask)
    if logits.ndim != 2 or logits.shape[1] == 0:
        raise ValueError("logits must be (N,C), C > 0")
    n, c = logits.shape
    if labels.shape != (n,) or mask.shape != (n,):
        raise ValueError("labels and mask must have shape (N,)")
    if labels.dtype.kind not in "iu" or np.any((labels < 0) | (labels >= c)):
        raise ValueError("labels must be integer class indices")
    if not 0 <= epsilon < 1 or not np.isin(mask, [0, 1]).all():
        raise ValueError("invalid smoothing or binary mask")
    if not np.isfinite(logits).all():
        raise ValueError("logits must be finite")
    active = mask.astype(bool)
    if not active.any():
        return 0.0
    lp = log_softmax(logits[active])
    targets = labels[active]
    losses = -(1 - epsilon) * lp[np.arange(len(targets)), targets]
    losses -= epsilon * lp.mean(axis=-1)
    return float(losses.mean())
```

### Work a small example

For uniform predictions over 4 classes, the loss is log(4) for any smoothing coefficient because every class has the same log probability.

### Edge cases and common mistakes

Dividing by the original batch size after excluding examples, or using epsilon/(C-1), which is a different smoothing convention.
