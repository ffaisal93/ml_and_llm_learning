## Question

Implement top-k sampling for LLM decoding using NumPy.

Given the logits at a generation step, sample the next token id from the top-k tokens.

### Input

A float array logits of shape (V,) where V is the vocabulary size (unnormalized log-probabilities).
An integer k (1 &lt;= k &lt;= V).
Output
An integer token_id: the sampled token index drawn from the probability distribution restricted to the top-k tokens.

### Requirements

Use NumPy only (no PyTorch/TF).
Find the indices of the top k logits to form a set S.
Compute softmax probabilities only over S, then sample according to that distribution.
Ensure numerical stability (subtract max before exp).

### Constraints

V can be up to 100000.
Example
logits = [1.0, 2.0, 0.5, 4.0], k = 2
top-2 indices are {3,1}; apply softmax over these and sample; output is either 3 or 1.

Example Input:

4
1.0 2.0 0.5 4.0
2

Example Output:

1 or 3

## Worked solution

### Solution outline

Keep a fixed number of candidate tokens, renormalize their probabilities and sample among them.

1. Validate 1<=k<=vocabulary_size and temperature>0.
2. Select the k greatest logits, divide retained logits by temperature, and compute stable softmax only over them.
3. Sample a local candidate index and map it back to the original vocabulary index. Use an explicit random generator for reproducible experiments.

### Understand why the approach works

#### Define the candidate set before sampling

Sampling has three operations: choose retained tokens, normalize their scores, and draw a vocabulary id. With temperature $\tau>0$ and retained set $S$,

$$
P(i\mid i\in S)=\frac{\exp(z_i/\tau)}{\sum_{j\in S}\exp(z_j/\tau)}.
$$

Top-$k$ defines $S$ as the $k$ largest logits. Temperature changes the distribution within that fixed set but does not change its ordering for positive $\tau$. With logits $[1,2,0.5,4]$ and $k=2$, only original ids 1 and 3 may be returned. A local index zero in the two-element candidate array is not necessarily vocabulary id zero.

For top-$p$, first sort probabilities $p_{(1)}\ge\cdots\ge p_{(V)}$ and choose

$$
k^*=\min\left\{k:\sum_{j=1}^k p_{(j)}\ge p\right\}.
$$

Include the token that crosses the threshold, then renormalize. For $[0.6,0.25,0.15]$ and threshold $0.8$, retain the first two tokens, whose mass is $0.85$. Keeping only the first would fail the requested coverage.

A readable reference sorts in $O(V\log V)$; partial selection can improve top-$k$ selection cost but needs a deliberate equal-score rule. Use an explicit random generator to reproduce experiments. Test $k=1$, $k=V$, $p=1$, very small positive $p$ and tied logits. A fixed seed does not guarantee identical sequences after a change in floating-point reduction or the number/order of random draws.

### Readable reference implementation

Read the explanation first, then trace one small input through these functions. This is the same implementation used by the local checks; its stated simplifications still apply.

```python
import math
from collections import deque
from dataclasses import dataclass
import numpy as np


def log_softmax(x, axis=-1):
    x = np.asarray(x, dtype=np.float64)
    if x.size == 0 or not np.isfinite(x).all():
        raise ValueError("expected non-empty finite logits")
    z = x - np.max(x, axis=axis, keepdims=True)
    return z - np.log(np.exp(z).sum(axis=axis, keepdims=True))


def softmax(x, axis=-1):
    return np.exp(log_softmax(x, axis=axis))


def sample_top_k(logits, k, rng=None, temperature=1.0):
    x = np.asarray(logits, dtype=np.float64)
    if x.ndim != 1 or not 1 <= k <= len(x) or temperature <= 0:
        raise ValueError("invalid logits, k or temperature")
    if not np.isfinite(x).all():
        raise ValueError("logits must be finite")
    rng = np.random.default_rng() if rng is None else rng
    # Stable descending order makes equal-logit behavior explicit.
    ids = np.argsort(-x, kind="stable")[:k]
    p = softmax(x[ids] / temperature)
    return int(rng.choice(ids, p=p))
```
