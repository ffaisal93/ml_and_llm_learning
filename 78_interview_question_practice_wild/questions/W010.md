## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Implement top-k sampling for LLM decoding using NumPy.

Given the logits at a generation step, sample the next token id from the top-k tokens.

Input
A float array logits of shape (V,) where V is the vocabulary size (unnormalized log-probabilities).
An integer k (1 &lt;= k &lt;= V).
Output
An integer token_id: the sampled token index drawn from the probability distribution restricted to the top-k tokens.
Requirements
Use NumPy only (no PyTorch/TF).
Find the indices of the top k logits to form a set S.
Compute softmax probabilities only over S, then sample according to that distribution.
Ensure numerical stability (subtract max before exp).
Constraints
V can be up to 100000.
Example
logits = [1.0, 2.0, 0.5, 4.0], k = 2
top-2 indices are {3,1}; apply softmax over these and sample; output is either 3 or 1.

Example Input:

4
1.0 2.0 0.5 4.0
2

Example Output:

1 or 3</pre>

## Worked solution

1. Implement top-k sampling from logits. Keep a fixed number of candidate tokens, renormalize their probabilities and sample among them.
2. Validate 1<=k<=vocabulary_size and temperature>0.
3. Select the k greatest logits, divide retained logits by temperature, and compute stable softmax only over them.
4. Sample a local candidate index and map it back to the original vocabulary index. Use an explicit random generator for reproducible experiments.

### Small example / sanity check

For logits [1,2,0.5,4] and k=2, only token indices 1 and 3 can be returned.

### Common trap

Returning the index inside the small candidate array instead of the original token id.
