## Question

<pre class="question-text" style="white-space:pre-wrap;font-family:inherit;line-height:1.55">Implement one post-LayerNorm Transformer block: multi-head self-attention, a two-layer ReLU feed-forward network, two residual connections and two LayerNorms. Then write its backward pass by hand. It returns the gradient of the loss with respect to the input and to every parameter, without any automatic differentiation.

Setting

Matrices are plain Python lists of row lists, and one sequence is processed at a time (no batch axis). The editor provides helpers you may use unchanged: zeros, matmul, transpose, add, add_into, cols, set_cols, linear, linear_grad, softmax_rows and layernorm. A linear layer follows the nn.Linear convention y = x @ Wᵀ + b, so a map from D to F features is stored as an F x D matrix. layernorm(x, gamma, beta, eps) uses the biased variance (divide by D) and returns (y, xhat, inv_std).

Forward pass

For an input x of shape S x D, H heads of width hd = D / H:

Q, K, V = linear(x, W_Q), linear(x, W_K), linear(x, W_V)          S x D
for each head h (columns h*hd .. (h+1)*hd - 1 of Q, K, V):
P_h   = softmax_rows(Q_h K_hᵀ / sqrt(hd))                      S x S
ctx_h = P_h V_h                                                S x hd
ctx  = the heads&#x27; ctx_h concatenated column-wise                   S x D
attn = linear(ctx, W_O)
n1   = LayerNorm1(x + attn)
y    = LayerNorm2(n1 + linear(relu(linear(n1, ffn1_w, ffn1_b)), ffn2_w, ffn2_b))
Requirements
1.
softmax_rows_grad(P, g): given P = softmax_rows(z) and the upstream gradient g = dL/dP (both S x S), return dL/dz.
2.
layernorm_grad(g, xhat, inv, gamma): given the upstream gradient g = dL/dy and the xhat, inv_std returned by layernorm, return the tuple (dL/dx, dL/dgamma, dL/dbeta). The parameter gradients are summed over the rows.
3.
ManualTransformerBlock(embed_dim, num_heads, ff_hidden_dim, params, eps=1e-5), where params is a dict with keys W_Q, W_K, W_V, W_O (D x D), ffn1_w (F x D), ffn1_b (length F), ffn2_w (D x F), ffn2_b (length D), and norm1_gamma, norm1_beta, norm2_gamma, norm2_beta (length D):
forward(x) returns y (S x D) and caches whatever the backward pass needs.
backward(grad_output) takes dL/dy (S x D) for the most recent forward call and returns (dL/dx, grads), where grads has exactly the keys of params and each gradient has the shape of its parameter.
4.
backward must not call anything that differentiates for you; every gradient is derived by hand from the forward formulas.
Input
x: a list of S rows, each a list of D floats.
params: the weights described above; D is divisible by H.
grad_output: a list of S rows of D floats.
Output
forward: the block output, S x D.
backward: (dL/dx, grads) as described in requirement 3.
Examples

Example 1: the softmax backward on one row.

softmax_rows_grad([[0.5, 0.5]], [[1.0, 0.0]])  -&gt;  [[0.25, -0.25]]

Here P = softmax_rows([[0.0, 0.0]]) = [[0.5, 0.5]] and rowsum(g ⊙ P) = 0.5, so the entries are 0.5 · (1 − 0.5) = 0.25 and 0.5 · (0 − 0.5) = −0.25.

Example 2: a constant upstream gradient.

softmax_rows_grad([[0.5, 0.5]], [[1.0, 1.0]])  -&gt;  [[0.0, 0.0]]

A constant upstream gradient yields zero, because every row of P sums to 1.

Example 3: one forward pass. Take D = 2, H = 1, F = 2, every weight matrix the 2×2 identity, every bias and beta zero, every gamma one, and x = [[1.0, 3.0]].

forward([[1.0, 3.0]])  -&gt;  [[-0.9999978, 0.9999978]]   (rounded to 7 places)

With one token, P = [[1.0]], so attn = x and x + attn = [[2, 6]]. LayerNorm of a 2-vector [a, b] with a &lt; b gives about [-1, 1], so n1 ≈ [[-1, 1]]. The ReLU keeps [0, 1], the second residual gives about [[-1, 2]], and the second LayerNorm maps that back to about [-1, 1]. The values sit just inside ±1 because of eps.

Constraints
1 &lt;= S &lt;= 16, 1 &lt;= H &lt;= D &lt;= 64, 1 &lt;= F &lt;= 128.
Every returned gradient must agree with a central finite difference of the loss to within 1e-6.
Discussion
1.
Why is the attention score divided by sqrt(hd)?
2.
What happens to the gradients when the attention weights saturate and one key position dominates a row?
3.
How would you verify a manual backward pass against an automatic-differentiation framework?
4.
How would you extend the block to masked or causal attention?
5.
What would you optimise first for GPU performance?</pre>

## Worked solution

1. Derive a manual attention backward pass. Backpropagate through value mixing, rowwise softmax and the scaled score product.
2. For O=P@V and upstream G, compute dV=Pᵀ@G and dP=G@Vᵀ.
3. For each softmax row, dS=P*(dP-sum(dP*P)); zero forbidden-score gradients.
4. For S=QKᵀ/sqrt(d), use dQ=dS@K/sqrt(d) and dK=dSᵀ@Q/sqrt(d), then chain through projections.
5. Implement LayerNorm forward and backward. Each row is centered and rescaled independently across its features; the backward pass must include the effects of both statistics.
6. Compute mean, centered values, population variance and inv_std=1/sqrt(var+eps). Set xhat=centered*inv_std and out=gamma*xhat+beta.
7. For g=dout*gamma, use dx=inv_std*(g-mean(g)-xhat*mean(g*xhat)), with means over features.
8. Sum dout*xhat and dout over the batch for dgamma and dbeta. Verify with central finite differences in float64.
9. Derive a dense layer's input, weight and bias gradients. Each parameter receives the sum of contributions from every example that used it.
10. For Y=XW+b with X:(N,D), W:(D,C), let upstream G:(N,C).
11. Compute dX=G@Wᵀ, dW=Xᵀ@G and db=sum(G,axis=0).
12. Do not average again unless the scalar objective's reduction requires it; G may already include the mean factor.

### Apply the exact contract

Complete the block by chaining residual addition, normalization and FFN derivatives in reverse forward order. At every residual join, add the direct upstream gradient to the sublayer gradient. Validate every projection, bias, normalization scale and input gradient independently; attention-only gradients are not a full Transformer-block backward pass.

### Small example / sanity check

Every row of dS sums approximately to zero because softmax is invariant to adding a row constant.

### Common trap

Materializing an enormous softmax Jacobian or forgetting the scale in both Q and K gradients.
