## Question

Implement one post-LayerNorm Transformer block: multi-head self-attention, a two-layer ReLU feed-forward network, two residual connections and two LayerNorms. Then write its backward pass by hand. It returns the gradient of the loss with respect to the input and to every parameter, without any automatic differentiation.

Setting

Matrices are plain Python lists of row lists, and one sequence is processed at a time (no batch axis). The editor provides helpers you may use unchanged: zeros, matmul, transpose, add, add_into, cols, set_cols, linear, linear_grad, softmax_rows and layernorm. A linear layer follows the nn.Linear convention y = x @ Wᵀ + b, so a map from D to F features is stored as an F x D matrix. layernorm(x, gamma, beta, eps) uses the biased variance (divide by D) and returns (y, xhat, inv_std).

Forward pass

For an input x of shape S x D, H heads of width hd = D / H:

Q, K, V = linear(x, W_Q), linear(x, W_K), linear(x, W_V)          S x D
for each head h (columns h*hd .. (h+1)*hd - 1 of Q, K, V):

```text
P_h   = softmax_rows(Q_h K_hᵀ / sqrt(hd))                      S x S
ctx_h = P_h V_h                                                S x hd
ctx  = the heads' ctx_h concatenated column-wise                   S x D
attn = linear(ctx, W_O)
n1   = LayerNorm1(x + attn)
y    = LayerNorm2(n1 + linear(relu(linear(n1, ffn1_w, ffn1_b)), ffn2_w, ffn2_b))
```

### Requirements

1. softmax_rows_grad(P, g): given P = softmax_rows(z) and the upstream gradient g = dL/dP (both S x S), return dL/dz.
2. layernorm_grad(g, xhat, inv, gamma): given the upstream gradient g = dL/dy and the xhat, inv_std returned by layernorm, return the tuple (dL/dx, dL/dgamma, dL/dbeta). The parameter gradients are summed over the rows.
3. ManualTransformerBlock(embed_dim, num_heads, ff_hidden_dim, params, eps=1e-5), where params is a dict with keys W_Q, W_K, W_V, W_O (D x D), ffn1_w (F x D), ffn1_b (length F), ffn2_w (D x F), ffn2_b (length D), and norm1_gamma, norm1_beta, norm2_gamma, norm2_beta (length D):
forward(x) returns y (S x D) and caches whatever the backward pass needs.
backward(grad_output) takes dL/dy (S x D) for the most recent forward call and returns (dL/dx, grads), where grads has exactly the keys of params and each gradient has the shape of its parameter.
4. backward must not call anything that differentiates for you; every gradient is derived by hand from the forward formulas.
Input
x: a list of S rows, each a list of D floats.
params: the weights described above; D is divisible by H.
grad_output: a list of S rows of D floats.
Output
forward: the block output, S x D.
backward: (dL/dx, grads) as described in requirement 3.

### Examples

Example 1: the softmax backward on one row.

softmax_rows_grad([[0.5, 0.5]], [[1.0, 0.0]])  -&gt;  [[0.25, -0.25]]

Here P = softmax_rows([[0.0, 0.0]]) = [[0.5, 0.5]] and rowsum(g ⊙ P) = 0.5, so the entries are 0.5 · (1 − 0.5) = 0.25 and 0.5 · (0 − 0.5) = −0.25.

Example 2: a constant upstream gradient.

softmax_rows_grad([[0.5, 0.5]], [[1.0, 1.0]])  -&gt;  [[0.0, 0.0]]

A constant upstream gradient yields zero, because every row of P sums to 1.

Example 3: one forward pass. Take D = 2, H = 1, F = 2, every weight matrix the 2×2 identity, every bias and beta zero, every gamma one, and x = [[1.0, 3.0]].

forward([[1.0, 3.0]])  -&gt;  [[-0.9999978, 0.9999978]]   (rounded to 7 places)

With one token, P = [[1.0]], so attn = x and x + attn = [[2, 6]]. LayerNorm of a 2-vector [a, b] with a &lt; b gives about [-1, 1], so n1 ≈ [[-1, 1]]. The ReLU keeps [0, 1], the second residual gives about [[-1, 2]], and the second LayerNorm maps that back to about [-1, 1]. The values sit just inside ±1 because of eps.

### Constraints

1 &lt;= S &lt;= 16, 1 &lt;= H &lt;= D &lt;= 64, 1 &lt;= F &lt;= 128.
Every returned gradient must agree with a central finite difference of the loss to within 1e-6.

## Worked solution

### Solution outline

#### Derive a manual attention backward pass.

Backpropagate through value mixing, rowwise softmax and the scaled score product.

1. For O=P@V and upstream G, compute dV=Pᵀ@G and dP=G@Vᵀ.
2. For each softmax row, dS=P*(dP-sum(dP*P)); zero forbidden-score gradients.
3. For S=$QK^\top$/sqrt(d), use dQ=dS@K/sqrt(d) and dK=dSᵀ@Q/sqrt(d), then chain through projections.

#### Implement LayerNorm forward and backward.

Each row is centered and rescaled independently across its features; the backward pass must include the effects of both statistics.

1. Compute mean, centered values, population variance and inv_std=$1/\sqrt{v+\epsilon}$. Set xhat=centered*inv_std and out=gamma*xhat+beta.
2. For g=dout*gamma, use dx=inv_std*(g-mean(g)-xhat*mean(g*xhat)), with means over features.
3. Sum dout*xhat and dout over the batch for dgamma and dbeta. Verify with central finite differences in float64.

#### Derive a dense layer's input, weight and bias gradients.

Each parameter receives the sum of contributions from every example that used it.

1. For Y=XW+b with X:(N,D), W:(D,C), let upstream G:(N,C).
2. Compute dX=G@Wᵀ, dW=Xᵀ@G and db=sum(G,axis=0).
3. Do not average again unless the scalar objective's reduction requires it; G may already include the mean factor.

### Understand why the approach works

#### Derive the normalization and its gradient

For row $x_i\in\mathbb R^D$, compute population statistics across **features**, independently of the other rows:

$$
\mu_i=\frac1D\sum_jx_{ij},\quad
v_i=\frac1D\sum_j(x_{ij}-\mu_i)^2,\quad
s_i=(v_i+\epsilon)^{-1/2},\quad
\hat x_{ij}=(x_{ij}-\mu_i)s_i.
$$

Then $y_{ij}=\gamma_j\hat x_{ij}+\beta_j$. The epsilon goes inside the square root. Compute variance from centered deviations, not $E[x^2]-E[x]^2$: the latter subtracts two huge nearly equal numbers when inputs share a large offset.

Let $G_{ij}=\partial L/\partial y_{ij}$ and $U_{ij}=G_{ij}\gamma_j$. The chain rule has three paths: a direct input path, the row mean path and the row variance path. Combining them gives

$$
\frac{\partial L}{\partial x_{ij}}=
 s_i\left(U_{ij}-\overline U_i-
 \hat x_{ij}\,\overline{U_i\hat x_i}\right),
$$

where each overline averages across the $D$ features of that row. The parameter gradients sum over rows:

$$
\frac{\partial L}{\partial\gamma_j}=\sum_iG_{ij}\hat x_{ij},\qquad
\frac{\partial L}{\partial\beta_j}=\sum_iG_{ij}.
$$

For $[1,2,3,4]$, the mean is $2.5$ and variance $1.25$. With unit scale and zero bias, the result is approximately $[-1.3416,-0.4472,0.4472,1.3416]$. A constant row normalizes to zero, so its output equals the bias. Its input derivative is not universally zero: it depends on the upstream pattern and epsilon.

The forward cache stores normalized inputs, inverse standard deviations and scale. Do not mutate these before backward. Validate $x$, $\gamma$ and $\beta$ derivatives independently with float64 central differences; checking only output shape cannot catch omitted statistic paths. Both passes cost $O(ND)$.

### Apply this question’s exact contract

Complete the block by chaining residual addition, normalization and FFN derivatives in reverse forward order. At every residual join, add the direct upstream gradient to the sublayer gradient. Validate every projection, bias, normalization scale and input gradient independently; attention-only gradients are not a full Transformer-block backward pass.

### Work a small example

Every row of dS sums approximately to zero because softmax is invariant to adding a row constant.

### Edge cases and common mistakes

Materializing an enormous softmax Jacobian or forgetting the scale in both Q and K gradients.

### Check your reasoning on related cases

**Implement LayerNorm forward and backward.** A constant row has xhat=0, so its forward output equals beta; epsilon keeps the inverse standard deviation finite.

Why can constant upstream gradients give zero dx for gamma=1? A normalized row is invariant to a common input shift.

**Derive a dense layer's input, weight and bias gradients.** For one example x=[2,3] and scalar upstream 4, the weight gradient is [8,12].

How do extra leading dimensions work? Flatten independent positions or sum their contributions consistently.
