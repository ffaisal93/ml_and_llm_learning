## Question

Implement one post-LayerNorm Transformer block: multi-head self-attention, a two-layer ReLU feed-forward network, two residual connections and two LayerNorms. Then write its backward pass by hand. It returns the gradient of the loss with respect to the input and to every parameter, without any automatic differentiation.

Setting

Matrices are plain Python lists of row lists, and one sequence is processed at a time (no batch axis). The editor provides helpers you may use unchanged: zeros, matmul, transpose, add, add_into, cols, set_cols, linear, linear_grad, softmax_rows and layernorm. A linear layer follows the nn.Linear convention y = x @ Wᵀ + b, so a map from D to F features is stored as an F x D matrix. layernorm(x, gamma, beta, eps) uses the biased variance (divide by D) and returns (y, xhat, inv_std).

Forward pass

For an input x of shape S x D, H heads of width hd = D / H:

Q, K, V = linear(x, W_Q), linear(x, W_K), linear(x, W_V)          S x D
for each head h (columns h*hd .. (h+1)*hd - 1 of Q, K, V):

```text
P_h   = softmax_rows(Q_h K_hᵀ / sqrt(hd))                      S x S
ctx_h = P_h V_h                                                S x hd
ctx  = the heads' ctx_h concatenated column-wise                   S x D
attn = linear(ctx, W_O)
n1   = LayerNorm1(x + attn)
y    = LayerNorm2(n1 + linear(relu(linear(n1, ffn1_w, ffn1_b)), ffn2_w, ffn2_b))
```

### Requirements

1. softmax_rows_grad(P, g): given P = softmax_rows(z) and the upstream gradient g = dL/dP (both S x S), return dL/dz.
2. layernorm_grad(g, xhat, inv, gamma): given the upstream gradient g = dL/dy and the xhat, inv_std returned by layernorm, return the tuple (dL/dx, dL/dgamma, dL/dbeta). The parameter gradients are summed over the rows.
3. ManualTransformerBlock(embed_dim, num_heads, ff_hidden_dim, params, eps=1e-5), where params is a dict with keys W_Q, W_K, W_V, W_O (D x D), ffn1_w (F x D), ffn1_b (length F), ffn2_w (D x F), ffn2_b (length D), and norm1_gamma, norm1_beta, norm2_gamma, norm2_beta (length D):
forward(x) returns y (S x D) and caches whatever the backward pass needs.
backward(grad_output) takes dL/dy (S x D) for the most recent forward call and returns (dL/dx, grads), where grads has exactly the keys of params and each gradient has the shape of its parameter.
4. backward must not call anything that differentiates for you; every gradient is derived by hand from the forward formulas.
Input
x: a list of S rows, each a list of D floats.
params: the weights described above; D is divisible by H.
grad_output: a list of S rows of D floats.
Output
forward: the block output, S x D.
backward: (dL/dx, grads) as described in requirement 3.

### Examples

Example 1: the softmax backward on one row.

softmax_rows_grad([[0.5, 0.5]], [[1.0, 0.0]])  -&gt;  [[0.25, -0.25]]

Here P = softmax_rows([[0.0, 0.0]]) = [[0.5, 0.5]] and rowsum(g ⊙ P) = 0.5, so the entries are 0.5 · (1 − 0.5) = 0.25 and 0.5 · (0 − 0.5) = −0.25.

Example 2: a constant upstream gradient.

softmax_rows_grad([[0.5, 0.5]], [[1.0, 1.0]])  -&gt;  [[0.0, 0.0]]

A constant upstream gradient yields zero, because every row of P sums to 1.

Example 3: one forward pass. Take D = 2, H = 1, F = 2, every weight matrix the 2×2 identity, every bias and beta zero, every gamma one, and x = [[1.0, 3.0]].

forward([[1.0, 3.0]])  -&gt;  [[-0.9999978, 0.9999978]]   (rounded to 7 places)

With one token, P = [[1.0]], so attn = x and x + attn = [[2, 6]]. LayerNorm of a 2-vector [a, b] with a &lt; b gives about [-1, 1], so n1 ≈ [[-1, 1]]. The ReLU keeps [0, 1], the second residual gives about [[-1, 2]], and the second LayerNorm maps that back to about [-1, 1]. The values sit just inside ±1 because of eps.

### Constraints

1 &lt;= S &lt;= 16, 1 &lt;= H &lt;= D &lt;= 64, 1 &lt;= F &lt;= 128.
Every returned gradient must agree with a central finite difference of the loss to within 1e-6.
Discussion
1. Why is the attention score divided by sqrt(hd)?
2. What happens to the gradients when the attention weights saturate and one key position dominates a row?
3. How would you verify a manual backward pass against an automatic-differentiation framework?
4. How would you extend the block to masked or causal attention?
5. What would you optimise first for GPU performance?

## Worked solution

### Backpropagate the whole post-LayerNorm block

This implementation is plain Python lists and handwritten derivatives throughout. It includes the supplied-style helpers so it can run independently. Projection weights use **output×input** convention, hence for $Y=XW^T+b$, $dX=GW$, $dW=G^TX$ and $db=\sum_{rows}G$. The attention projections have no biases because params specifies none.

For softmax, $dS=P\odot(G-\sum_jG_jP_j)$ rowwise. For LayerNorm with $U=G\odot\gamma$, $dX=inv\,[U-\overline U-\hat X\overline{U\hat X}]$, $d\gamma=\sum G\hat X$ and $d\beta=\sum G$. These include both statistic paths and use biased row variance. Reverse the second norm, FFN and residual, then the first norm, output projection and multi-head attention. At each residual split, **add** the direct gradient to the branch gradient.

```python
"""Plain-list post-LN transformer; no array or differentiation libraries."""

import math


def zeros(rows, cols):
    return [[0.0] * cols for _ in range(rows)]


def transpose(a):
    return [list(row) for row in zip(*a)]


def matmul(a, b):
    bt = transpose(b)
    return [[sum(x * y for x, y in zip(row, col)) for col in bt] for row in a]


def add(a, b):
    return [[x + y for x, y in zip(r, s)] for r, s in zip(a, b)]


def scale(a, c):
    return [[c * x for x in row] for row in a]


def linear(x, w, b=None):
    y = matmul(x, transpose(w))
    return [
        [v + (b[j] if b is not None else 0.0) for j, v in enumerate(row)] for row in y
    ]


def linear_grad(x, w, g):
    return (
        matmul(g, w),
        matmul(transpose(g), x),
        [sum(row[j] for row in g) for j in range(len(g[0]))],
    )


def cols(x, start, end):
    return [row[start:end] for row in x]


def set_cols(x, start, part):
    for row, p in zip(x, part):
        row[start : start + len(p)] = p


def softmax_rows(z):
    out = []
    for row in z:
        m = max(row)
        e = [math.exp(v - m) for v in row]
        total = sum(e)
        out.append([v / total for v in e])
    return out


def softmax_rows_grad(P, g):
    result = []
    for p, grad in zip(P, g):
        dot = sum(a * b for a, b in zip(p, grad))
        result.append([a * (b - dot) for a, b in zip(p, grad)])
    return result


def layernorm(x, gamma, beta, eps):
    hats = []
    invs = []
    output = []
    d = len(gamma)
    for row in x:
        mean = sum(row) / d
        inv = 1 / math.sqrt(sum((v - mean) ** 2 for v in row) / d + eps)
        hat = [(v - mean) * inv for v in row]
        hats.append(hat)
        invs.append(inv)
        output.append([gamma[j] * v + beta[j] for j, v in enumerate(hat)])
    return output, hats, invs


def layernorm_grad(g, xhat, inv, gamma):
    d = len(gamma)
    dx = []
    dg = [0.0] * d
    db = [0.0] * d
    for row, hat, s in zip(g, xhat, inv):
        u = [v * a for v, a in zip(row, gamma)]
        mean = sum(u) / d
        mean_hat = sum(v * h for v, h in zip(u, hat)) / d
        dx.append([s * (v - mean - h * mean_hat) for v, h in zip(u, hat)])
        for j in range(d):
            dg[j] += row[j] * hat[j]
            db[j] += row[j]
    return dx, dg, db


class ManualTransformerBlock:
    def __init__(self, embed_dim, num_heads, ff_hidden_dim, params, eps=1e-5):
        if embed_dim % num_heads or num_heads < 1 or eps <= 0:
            raise ValueError("invalid head dimensions or epsilon")
        self.D, self.H, self.F = embed_dim, num_heads, ff_hidden_dim
        self.p, self.eps = params, eps
        self.cache = None

    def forward(self, x):
        p = self.p
        hd = self.D // self.H
        factor = 1 / math.sqrt(hd)
        # Caller must not mutate x or parameters before backward.
        q, k, v = [linear(x, p[name]) for name in ("W_Q", "W_K", "W_V")]
        context = zeros(len(x), self.D)
        heads = []
        for h in range(self.H):
            start = h * hd
            end = start + hd
            qh, kh, vh = [cols(a, start, end) for a in (q, k, v)]
            prob = softmax_rows(scale(matmul(qh, transpose(kh)), factor))
            set_cols(context, start, matmul(prob, vh))
            heads.append((qh, kh, vh, prob))
        attn = linear(context, p["W_O"])
        n1, hat1, inv1 = layernorm(
            add(x, attn), p["norm1_gamma"], p["norm1_beta"], self.eps
        )
        z = linear(n1, p["ffn1_w"], p["ffn1_b"])
        a = [[max(0.0, v) for v in row] for row in z]
        f = linear(a, p["ffn2_w"], p["ffn2_b"])
        y, hat2, inv2 = layernorm(
            add(n1, f), p["norm2_gamma"], p["norm2_beta"], self.eps
        )
        self.cache = (x, context, heads, n1, z, a, hat1, inv1, hat2, inv2)
        return y

    def backward(self, grad_output):
        if self.cache is None:
            raise RuntimeError("forward required")
        x, context, heads, n1, z, a, hat1, inv1, hat2, inv2 = self.cache
        p = self.p
        grads = {}
        hd = self.D // self.H
        factor = 1 / math.sqrt(hd)
        g, grads["norm2_gamma"], grads["norm2_beta"] = layernorm_grad(
            grad_output, hat2, inv2, p["norm2_gamma"]
        )
        ga, grads["ffn2_w"], grads["ffn2_b"] = linear_grad(a, p["ffn2_w"], g)
        gz = [[u * (v > 0.0) for u, v in zip(row, zrow)] for row, zrow in zip(ga, z)]
        gn, grads["ffn1_w"], grads["ffn1_b"] = linear_grad(n1, p["ffn1_w"], gz)
        gn = add(gn, g)  # The second residual's direct n1 path.
        gr, grads["norm1_gamma"], grads["norm1_beta"] = layernorm_grad(
            gn, hat1, inv1, p["norm1_gamma"]
        )
        gc, grads["W_O"], _ = linear_grad(context, p["W_O"], gr)
        gq, gk, gv = [zeros(len(x), self.D) for _ in range(3)]
        for h, (qh, kh, vh, prob) in enumerate(heads):
            gh = cols(gc, h * hd, (h + 1) * hd)
            gp = matmul(gh, transpose(vh))
            gs = softmax_rows_grad(prob, gp)
            set_cols(gq, h * hd, scale(matmul(gs, kh), factor))
            set_cols(gk, h * hd, scale(matmul(transpose(gs), qh), factor))
            set_cols(gv, h * hd, matmul(transpose(prob), gh))
        dx = [row[:] for row in gr]  # First residual's direct x path.
        for name, gproj in [("W_Q", gq), ("W_K", gk), ("W_V", gv)]:
            part, grads[name], _ = linear_grad(x, p[name], gproj)
            dx = add(dx, part)
        assert set(grads) == set(p)
        return dx, grads


def check():
    import random

    assert softmax_rows_grad([[0.5, 0.5]], [[1.0, 0.0]]) == [[0.25, -0.25]]
    assert softmax_rows_grad([[0.5, 0.5]], [[1.0, 1.0]]) == [[0.0, 0.0]]
    rng = random.Random(7)
    D, H, F = 4, 2, 3
    matrix = lambda a, b: [[rng.uniform(-0.4, 0.4) for _ in range(b)] for _ in range(a)]
    params = {name: matrix(D, D) for name in ["W_Q", "W_K", "W_V", "W_O"]}
    params.update(
        ffn1_w=matrix(F, D),
        ffn1_b=[0.2, -0.3, 0.4],
        ffn2_w=matrix(D, F),
        ffn2_b=[0.1] * D,
    )
    for n in [1, 2]:
        params[f"norm{n}_gamma"] = [rng.uniform(0.7, 1.3) for _ in range(D)]
        params[f"norm{n}_beta"] = [rng.uniform(-0.2, 0.2) for _ in range(D)]
    x = matrix(3, D)
    upstream = matrix(3, D)
    block = ManualTransformerBlock(D, H, F, params)
    block.forward(x)
    dx, grads = block.backward(upstream)

    def objective():
        y = block.forward(x)
        return sum(v * g for row, gr in zip(y, upstream) for v, g in zip(row, gr))

    eps = 1e-6
    worst = 0.0
    count = 0
    for name, values, analytic in [("input", x, dx)] + [
        (n, params[n], grads[n]) for n in params
    ]:
        is_matrix = isinstance(values[0], list)
        rows = values if is_matrix else [values]
        grows = analytic if is_matrix else [analytic]
        for row, grad in zip(rows, grows):
            for j in range(len(row)):
                old = row[j]
                row[j] = old + eps
                plus = objective()
                row[j] = old - eps
                minus = objective()
                row[j] = old
                err = abs((plus - minus) / (2 * eps) - grad[j])
                worst = max(worst, err)
                count += 1
                assert err < 1e-6, (name, j, err)
    # Stated one-token identity example.
    identity = [[1.0, 0.0], [0.0, 1.0]]
    p = {
        n: [r[:] for r in identity]
        for n in ["W_Q", "W_K", "W_V", "W_O", "ffn1_w", "ffn2_w"]
    }
    p.update(
        ffn1_b=[0.0, 0.0],
        ffn2_b=[0.0, 0.0],
        norm1_gamma=[1.0, 1.0],
        norm2_gamma=[1.0, 1.0],
        norm1_beta=[0.0, 0.0],
        norm2_beta=[0.0, 0.0],
    )
    y = ManualTransformerBlock(2, 1, 2, p).forward([[1.0, 3.0]])
    assert abs(y[0][0] + 0.9999978) < 1e-7
    print(
        f"W149: {count} central differences; worst absolute error {worst:.3g}; identity output {y}"
    )


if __name__ == "__main__":
    check()
```

### Attention derivatives and checks

For each head, context $C=PV$ gives $dV=P^TdC$ and $dP=dCV^T$. Softmax gives dS, then $dQ=dSK/\sqrt{hd}$ and $dK=dS^TQ/\sqrt{hd}$. Concatenate head gradients, differentiate each projection and sum all three x contributions plus the first residual's direct path. No automatic differentiation call occurs in backward. Cache belongs to the most recent forward; do not mutate x/params between forward/backward or expect concurrent forwards to share this single cache safely.

The executable verifies both supplied softmax examples, the one-token identity example (output `[-.9999977778,.9999977778]`) and central differences for **all 123 scalar input and parameter entries** of a 3-token, 2-head block. Worst absolute finite-difference error is approximately 3.1e-10 at epsilon 1e-6, below the required 1e-6. ReLU test preactivations avoid zero; at a kink the ordinary central derivative need not match the chosen zero subgradient. An independent autograd comparison can copy these exact tensors into float64 PyTorch linear/LayerNorm operations and compare the scalar `sum(output*upstream)` gradients, with dropout off and identical epsilon/variance conventions.

The score scale controls initial dot-product variance. Saturated P makes softmax derivatives small, particularly for losing keys, though dV can remain substantial. To add causal/padding masks, set forbidden scores to negative infinity **before** softmax and their dS to zero; ensure every query has at least one allowed key or define all-masked-row behavior. Forward/backward cost O(SD²+S²D+SDF), with O(HS²+SD+SF) activations. GPU optimization starts with batched matrix kernels, fused norm/activation and tiled attention rather than Python scalar loops; validate their gradients against this reference before optimizing further.

### Executable PyTorch counterpart for the autograd check

The primary implementation above is still plain Python with a manual backward pass. This independent study model follows the **same post-LayerNorm order**, has no attention-projection biases or dropout, and copies the exact output-by-input weight convention from `params`. Using a pre-norm ready-made block would compare a different function.

[Download the comparison model](../torch_comparisons_112_149.py) and [all-parameter comparison tests](../test_torch_comparisons_112_149.py).

```python
import math
import torch
from torch import nn
from torch.nn import functional as F


class TorchPostNormBlock(nn.Module):
    def __init__(self, embed_dim, num_heads, params, eps=1e-5):
        super().__init__()
        if num_heads < 1 or embed_dim % num_heads:
            raise ValueError("Head count must divide embed_dim")
        self.dimension = embed_dim
        self.heads = num_heads
        self.eps = eps
        # W149 already uses nn.Linear's output-by-input convention.
        self.params = nn.ParameterDict(
            {
                name: nn.Parameter(torch.tensor(value, dtype=torch.float64))
                for name, value in params.items()
            }
        )

    def forward(self, x):
        sequence, dimension = x.shape
        head_width = self.dimension // self.heads

        def split(weight):
            projected = F.linear(x, weight)
            return projected.reshape(sequence, self.heads, head_width).transpose(0, 1)

        p = self.params
        query = split(p["W_Q"])
        key = split(p["W_K"])
        value = split(p["W_V"])
        weights = (query @ key.transpose(-1, -2) / math.sqrt(head_width)).softmax(
            dim=-1
        )
        context = (weights @ value).transpose(0, 1).reshape(sequence, dimension)
        attention = F.linear(context, p["W_O"])
        norm1 = F.layer_norm(
            x + attention, (dimension,), p["norm1_gamma"], p["norm1_beta"], self.eps
        )
        hidden = F.relu(F.linear(norm1, p["ffn1_w"], p["ffn1_b"]))
        feedforward = F.linear(hidden, p["ffn2_w"], p["ffn2_b"])
        return F.layer_norm(
            norm1 + feedforward,
            (dimension,),
            p["norm2_gamma"],
            p["norm2_beta"],
            self.eps,
        )
```

For the same sequence `x`, parameter dictionary and upstream matrix, compute `output = model(x_tensor)` and differentiate `(output * upstream_tensor).sum()`. Compare `x_tensor.grad` with the manual input gradient and each `model.params[name].grad` with the matching handwritten parameter gradient. The executable test covers the full three-token, two-head fixture and checks forward values plus **every** input/parameter gradient. This is an actual autograd cross-check, alongside the finite-difference verification above; PyTorch is not called inside the submitted manual backward.
